RTK 概论

GNSS 与 RTK

GNSS

GNSS（Global Navigation Satellite System），即全球卫星导航系统，它并不是某一种具体算法，而是一类卫星导航系统的总称呼，包括：

  1. GPS：Global Positioning System（美国）
  2. BDS：北斗卫星导航系统（中国）
  3. Galileo：Galileo Navigation Satellite System（欧盟）
  4. GLONASS：GLObal NAvigation Satellite System（俄罗斯）

GNSS 卫星持续广播三类基本信息：

  1. 测距信息：供接收机测量信号传播时间和载波相位
  2. 导航电文：包含卫星轨道，卫星钟差等相关信息
  3. 时间基准：让接收机建立卫星信号的时间关系

接收机通过多个卫星的观测值，估计自身的位置、速度和接收机钟差

需要区分以下的几个概念：

  1. GNSS：卫星导航系统
  2. GNSS 接收机：接收和跟踪卫星信号的设备
  3. GNSS 观测值：接收机测得的伪距、载波相位、多普勒、C/N0 等
  4. GNSS 定位算法：根据观测值求位置、速度和其他位置参数的方法

普通单点定位

普通单点定位通常称为 SPP（Single Point Positioning），它只使用一台接收机自身的观测数据和卫星广播星历进行定位

其基本思想是：根据测得接收机到多颗卫星的距离，求解接收机的三维坐标

但是在实际测量条件下，接收机测得的 “距离” 并不严格等于接收机到卫星的几何距离，而是混入了卫星钟差、接收机钟差、卫星轨道误差、电离层延迟、对流层延迟、多路径、接收机测量噪声等误差

因此，普通的单点定位 SPP 通常难以达到厘米级定位精度

RTKLIB 中将单点定位作为一种独立定位模式，其同时还支持 DGNSS，Kinematic，Static，Moving-Baseline 和 PPP 等多种实时或后处理模式

RTK

RTK（Real-Time Kinematic）称为实时动态差分定位，它的核心不是基于普通单点定位结果做修正或优化，而是通过同时使用基准站和流动站的 GNSS 原始观测值，通过站间差分削弱共同误差，并利用高精度载波相位观测求解流动站位置

经典 RTK 通常使用一台基准站和一台流动站，通过载波相位观测值，构造站间差分或双差观测模型，估计并固定载波相位中的整周模糊度，实时输出流动站的高精度位置

因此可以认为，RTK 本质上是一套相对定位算法与数据处理方式

RTK 系统的三个基本对象

基准站

基准站也称为参考站，通常记为 Base Station 或 Reference Station，它是一台放置在已知坐标位置上的 GNSS 接收机

通常记录基准站真实坐标为：

rb\mathbf{r}_b rb​

其中，bbb 表示 base

基准站会持续接收卫星信号，并生成：

  • 伪距观测值
  • 载波相位观测值
  • 多普勒观测值
  • C/N0
  • 卫星跟踪状态

因为基准站的精确位置固定且已知，因此可以作为空间参考使用

流动站

流动站通常记作 Rover，它是坐标未知或随时间变化的接收机

通常记录流动站在 tkt_ktk​ 时刻的位置为：

ru(tk)\mathbf{r}_u(t_k) ru​(tk​)

其中，uuu 表示 user 或 rover receiver

RTK 算法的最终估计目标主要就是：

r^u(tk)\hat{\mathbb{r}}_u(t_k) r^u​(tk​)

其中，⋅^\hat{\cdot}⋅^ 表示对流动站位置的估计值

基线

从基准站指向流动站的向量称为基线向量：

b=ru−rb\mathbf{b} = \mathbf{r}_u - \mathbf{r}_b b=ru​−rb​

因此，只要基准站坐标 rb\mathbf{r}_brb​ 已知，且成功估计出基线向量 b\mathbf{b}b，就能够得到流动站坐标：

ru=rb+b\mathbf{r}_u = \mathbf{r}_b + \mathbf{b} ru​=rb​+b

基线向量的模长，即称为计算长度：

Lb=∥b∥L_b = \|\mathbf{b}\| Lb​=∥b∥

RTK 的很多误差抵消能力都与基线长度有关，流动站和基准站的距离越近，二者观测到的卫星轨道误差、大气误差通常就越相似，做差分后就越容易被抵消，对应的测量精度也就越高

RTK 精度来源

RTK 达到高精度（厘米级定位）主要依靠三个核心条件，三者缺一不可：

  1. 差分消除或削弱基准站和流动站的共同误差
  2. 使用高精度载波相位观测值
  3. 正确求解了载波相位的整周模糊度

仅使用伪距的局限

伪距通过测量卫星信号的传播时间来估计距离，其概念模型为：

Prs=ρrs+钟差项+大气延迟项+硬件偏差项+测量噪声P_r^s = \rho_r^s + \text{钟差项} + \text{大气延迟项} + \text{硬件偏差项} + \text{测量噪声} Prs​=ρrs​+钟差项+大气延迟项+硬件偏差项+测量噪声

其中，PrsP^s_rPrs​ 是接收机 rrr 对卫星 sss 的伪距观测值，ρrs\rho_r^sρrs​ 是卫星到接收机的真实几何距离

伪距的优点是不存在整周模糊度问题，但测量噪声和多路径影响较大，因此仅使用伪距一般难以稳定实现在厘米级定位

载波相位的精确性

卫星信号是在高频载波上进行传播的，接收机能够测量接收到的载波相位

将载波相位换算成距离后，其概念模型为：

Lrs=ρrs+钟差项+大气延迟项+λNrs+测量噪声L_r^s = \rho_r^s + \text{钟差项} + \text{大气延迟项} + \lambda N_r^s + \text{测量噪声} Lrs​=ρrs​+钟差项+大气延迟项+λNrs​+测量噪声

其中，LrsL_r^sLrs​ 是以距离为单位的载波相位观测值，ρrs\rho_r^sρrs​ 是卫星到接收机的真实几何距离，λ\lambdaλ 是载波波长，NrsN_r^sNrs​ 是整周模糊度

载波相位的测量精度远高于伪距，但它存在一个关键问题：接收机能够精确测量当前载波的小数相位，却无法记录从卫星到接收机之间一共包含了多少个完整的载波周期

未知的完整载波周期数就是整周模糊度：

Nrs∈ZN_r^s\in\mathbb{Z} Nrs​∈Z

差分的作用

假设基准站和流动站可以同时观测同一颗卫星，那么两台接收机观测值中包含的误差部分是相似的

相对两个接收机作差，可以消除卫星钟差，再对两颗卫星作差，则可以进一步消除接收机钟差

经典的双差载波相位模型可以写为：

∇ΔLubsj=∇Δρubsj+λ∇ΔNubsj+∇Δεubsj\nabla\Delta L_{ub}^{sj} = \nabla\Delta \rho_{ub}^{sj} + \lambda\nabla\Delta N_{ub}^{sj} + \nabla\Delta\varepsilon_{ub}^{sj} ∇ΔLubsj​=∇Δρubsj​+λ∇ΔNubsj​+∇Δεubsj​

其中，∇\nabla∇ 表示接收机单差，Δ\DeltaΔ 表示卫星单差，∇Δ\nabla\Delta∇Δ 表示双差，uuu 表示流动站，bbb 表示基准站，s,js,js,j 是选取的两颗观测卫星，∇ΔNubsj\nabla\Delta N_{ub}^{sj}∇ΔNubsj​ 表示双差整周模糊度，∇Δεubsj\nabla\Delta\varepsilon_{ub}^{sj}∇Δεubsj​ 表示双差后的剩余误差

在本节中，对于该公式只需要理解以下两点：

  1. 大量共同钟差和空间相关误差在差分过程中被消除或削弱
  2. 双差整周模糊度仍然会保留，且仍然保持整数性质

RTK 厘米级精度的关键

RTK 首先按会把双差整周模糊度作为实数未知量进行估计，得到：

N^∈Rn\hat{\mathbf N}\in\mathbb{R}^n N^∈Rn

这称为浮点模糊度估计

接着通过整数模糊度搜索，找到最可能的整数向量：

Nˇ∈Zn\check{\mathbf{N}}\in\mathbb{Z}^n Nˇ∈Zn

即固定后的整数模糊度

只有整数模糊度被正确固定，载波相位中原本未知的完整周期数才能被恢复，载波相位的高精度才能充分转化成位置精度

因此 RTK 的核心思想可以概括为：

差分误差削弱+高精度载波相位+整数模糊度固定\text{差分误差削弱} + \text{高精度载波相位} + \text{整数模糊度固定} 差分误差削弱+高精度载波相位+整数模糊度固定

所以不要天真的认为，找一个精确的基准站坐标，流动站就能够轻易达到厘米级的精确定位

RTK 解的种类

RTK 在进行结算时，通常会看到以下状态

Single - 单点解

只使用流动站自身的观测数据，没有利用基准站进行差分，通常主要依靠伪距进行求解

DGPS/DGNSS - 码差分解

使用基准站和流动站进行差分，但主要依靠伪距观测值，其精度一般优于单点定位，但没有充分利用载波相位的高精度

Float - 浮点解

已经使用载波相位差分模型，但整周模糊度仍然作为实数估计：

N^∈Rn\hat{\mathbf N}\in\mathbb{R}^n N^∈Rn

需要注意的是，得到浮点解并不意味着解算失败，而是表示相对定位模型已经成功建立，但当前数据还不足以可靠地确认整数模糊度

Fixed - 固定解

整数模糊度已经被固定为整数：

Nˇ∈Zn\check{\mathbf N}\in\mathbb{Z}^n Nˇ∈Zn

并且通过了算法设置的验证条件

固定解通常能够达到更高的精度，但需要注意的是，Fixed 仅表示算法接受了某组整数模糊度，但不代表该整数一定真实正确

如果多路径、周跳、随机模型或验证阈值设置不合理，就有可能发生错误固定

PPK

RTK 是一种实时解算与定位算法，与之对应的是 PPK（Post-Processed Kinematic），即事后动态差分定位

它先分别记录基准站和流动站原始数据，采集结束后再统一处理。

实时 RTK 与 PPK 的核心载波差分模型可以非常相似，主要差别在于：

  • 数据是实时到达还是事后读取
  • PPK 可以进行前向、后向或组合处理
  • 实时 RTK 只能利用当前及过去数据
  • PPK 能利用未来历元信息改善轨迹估计和周跳处理

因此我们说，RTK 更强调实时性，而 PPK 则更强调事后处理，两者都可以使用载波相位差分与整数模糊度固定
