(VLN)概论

Destiny2026-07-132026-10-02

导论

基础概念

具身智能

具身智能（Embodied AI）是指能够通过感知，推理和行动与物理世界交互的智能体，通过身体与环境的交互来学习和理解

不同于传统 AI，具身智能不仅仅是符号推理或数据模式的识别，更强调物理存在和与现实世界的交互

案例：智能机器人，自动驾驶汽车，虚拟智能体

VLN

VLN 是具身智能第一个子领域，目标是训练一个智能体，使其能够根据自然语言，融合视觉和语言信息进行决策，在 3D 环境中进行导航

输入：视觉感知和自然语言指令，例如：turn right，walk through the hallway

输出：路径点，离散动作，例如：go forward ''x" m, turn right “x” degree, stop，包括线速度和角速度，使得智能体到达目标位置

目前 VLN 的关键挑战：

  • 感知模糊性：视觉信息可能不完整或模糊
  • 语言模糊性：自然语言指令可能不精确，有歧义或包含隐含信息
  • 泛化能力：在未见过的环境中导航的能力
  • 长程规划：规划跨过多个房间或复杂路径的行动序列
  • 指令遵循：准确理解和执行指令的每个部分
  • 记忆与推理：记住已探索的区域和指令进度

基础概念

VLN 中的 V 指的是 Visual，即计算机视觉，其核心任务包括：

  • 图像识别
  • 目标检测
  • 语义分割

图像识别用于对视场（view）进行宏观归类，例如 “厨房”，“卧室”，提供全局语境，帮助智能体判断是否到达了指令中的目标区域

目标检测用于识别并定位场景中的物体实例，例如 “桌子”，“椅子”，“微波炉”，作为大部分指令执行的基础（比如指令 “去打开微波炉” 首先要求 Agent 能够检测到 “微波炉” 的存在）

语义分割用于识别场景的像素级布局，即对视场中的每一个像素进行语义分类（当前像素点是属于 “地板” 还是 “墙壁”），通过识别出所有属于 “地板” 的像素，从而确定可通行区域，实现有效的路径规划和避障

综上所述，VLN 中的视觉概念，是一个集成了分类，检测与分割能力，能够处理时序性，第一人称视角输入，并最终服务于语言接地的复杂感知系统，这个系统是 VLN 智能体的前端，它提供的场景理解质量，直接决定了后续语言理解和动作规划模块的性能上限

VLN 中的 L 指的是 Language，即自然语言处理，其核心任务包括：

  • 词嵌入
  • 序列模型构建
  • 注意力机制

词嵌入即 Word Embeddings，将离散的词语符号，映射为连续的、能表达语义的低维稠密向量，向量间的数学关系对应词语的逻辑关系，在 VLN 中，词嵌入作为语言理解的起点，为后续编码完整的，富含上下文的导航指令提供输入

循环神经网络通过循环传递的记忆单元（隐状态）来处理序列化信息，从而有效捕获上下文关联，按顺序读取指令中的词嵌入，将其逐步压缩为一个能带代表完整意图的指令向量

RNN 可以整合整个 Agent 过去的动作与观测序列 (a1,a2,…,at−1)(a_1,a_2,\dots,a_{t-1})(a1​,a2​,…,at−1​)，形成动态的状态认知，为当前决策提供依据

Transformer 模型可以动态计算输入信息的重要性权重，让模型集中处理最相关的部分，忽略无关噪音，以自注意力机制为核心，融合语言，视觉，历史等多模态信息，在 VLN 中，Transformer 模型可以精准建立语言指令中特定词语与视觉画面中特定像素区域之间的对应关系

VLN 架构 - 早期方法

Seq2Seq 模型

直接将语言指令和视觉图像序列映射到行动序列，大多采用 Encoder-Decoder 结构

  • Encoder：编码语言指令，其中 Language Encoder 通常使用 LSTM 或 GRU 编码指令，而 Vision Encoder 用于提取当前视角的特征，可以使用 CNN，ResNet 等
  • Decoder：根据编码后的指令和视觉观测生成行动，通常由另一个 LSTM 或 GRU 生成行动

结合注意力机制在 VLN 中的应用

  • 视觉注意力：有助于模型聚焦环境中的相关地标
    1. 根据指令或当前导航目标，动态地加权是视觉特征图的不同区域
    2. 通常在视觉特征提取后，通过一个注意力网络生成注意力权重
  • 语言注意力：有助于模型处理长指令和多步骤任务
    1. 在解码时，模型可以回顾指令的不同部分，以确保指令的完整遵循
    2. 在解码器中，通过一个注意力机制对语言编码器的输出进行加权
  • 跨模态注意力：促进更深层次的跨模态理解
    1. 允许视觉和语言模态之间相互影响，共同决定导航策略
    2. 视觉特征可以影响语言注意力，反之亦然

Seq2Seq 结合注意力机制，即得到早期经典的 CMA VLN 模型

Speqker-Follower 模型

模型包括一个指令解释（Follower）模块，将指令映射到动作序列，同时包含一个指令生成（Speaker）模块，将操作序列映射到指令，二者都使用标准的 Seq2Seq 架构实现，Speaker 学习为视觉路线提供文本指令，用于给出更高质量的指令，Follower 学习为文本指令提供视觉路线，用于给出更准确的导航路线预测

结合强化学习

VLN 本质上是一个序列决策问题，智能体需要根据指令和视觉观察（观察到周围的环境信息可以认为是环境的反馈），一步一步做出决策（即每一步该怎么走），直到完成任务，该过程可以很自然地被建模为马尔科夫决策过程（MDP），而强化学习正是解决这类问题的经典框架

在强化学习的视角下，我们的目标即：学习一个最优策略（Policy），让智能体直到在任何状态下该采取什么动作

VLN 中的奖励稀疏问题

如果只有当智能体到达目标时才获得奖励，这会导致学习效率低下，也导致了信誉分配问题（Credit Assignment Problem）：一条路径通常由几十个步骤组成，如果最终成功，我们很难判断，这几十步中哪些才是关键的正确决策，哪些是无效甚至错误的决策；如果最终失败，也很难判断是哪几步错误导致了失败，这种模糊的反馈信号让模型学习变得非常困难，这就是所谓的奖励稀疏问题

解决该问题的核心思想即重构奖励函数：

  • RCM 模型：同时设置外部奖励和内部奖励
    1. 外部奖励（Extrinsic Reward）：与任务目标相关的奖励，比如某一步之后，智能体是否距离终点更近
    2. 内部奖励（Intrinsic Reward）：与指令匹配度相关的奖励，比如，当智能体执行的动作与当前指令子句高度匹配时，就给予一个奖励，这实现了指令和视觉的跨模态对齐（cross-modal Grounding）
  • 引入三维地图信息，利用地图上关键地标作为显式约束

VLN 架构 - 高级方法

基于 Transformer 的 VLN 模型

把 Transformer 架构应用与 VLN，利用其强大的序列建模和注意力机制，处理长指令和长视觉序列，捕获复杂的跨模态交互

其中 Cross-Modal Encoder 可以认为是把 Transformer 架构嵌入到 Seq2Seq 中去工作

预训练策略

在引入 Transformer 以后，可以利用大规模多模态数据进行预训练，学习通用的视觉 - 语言表示（可以先以基本的 Image Text Pair，掩码语言建模等任务进行预训练），以提高模型在下游 VLN 任务上的性能和泛化能力

VLN-BERT

VLN-BERT 即 Vision and Language Navigation BERT，将 BERT 的预训练范式扩展到 VLN 邻域，以学习到强大的跨模态表示

CLIP-based VLN Approaches

这类模型利用 CLIP 学习到的通用的视觉 - 语言表示，把 CLIP 特征集成到 VLN 模型中，用于实现视觉 - 语言的对齐

分层导航

分层导航（Hierarchical Navigation）用于将复杂导航任务分解为多个层次的子任务，尤其适用于连续环境的导航

  • 高层（Waypoint Predictor）：规划粗粒度路径点（当前观测下可行进的路径点）
  • 底层（Navigator）：执行细粒度行动以达到最终目标，例如前进，转弯等动作

整体上可以提高模型的长程规划能力，降低任务的复杂性

Waypoint Predictor

该模块用于接收 RGBD（彩色+深度）全景输入，使用一个多层 Transformer 来建模空间关系，并预测智能体临近区域中路径点的位置，这些位置被认为在当前环境下，智能体可以安全、有效地移动到的候选路径点，例如门口的中心，走廊的拐角处，空旷区域的中心点等

低层执行器

根据当前中间目标和局部视觉预测，执行具体行动，Navigator 的主要工作是为每一个候选路径点打分，分数的高低代表这个点有多符合指令，这个过程通常由一个跨模态 Transformer 或类似的融合模块来完成，它能够同时处理视觉和语言信息，并推理它们之间的关系，从而执行细粒度行动以达到最终目标

相当于一个候选 + 采样的过程，上层模型先粗选出候选点，下层模型逐个评分，最终选择得分最高的候选

记忆机制

智能体需要记住自己已经探索过的区域、当前指令完成进度和历史行动，以避免重复探索，提高效率，以更好地遵循长指令，常见的记忆方法如下：

  • 循环记忆网络
  • 图像记忆
  • 地图记忆

循环记忆网络（Recurrent Memory Networks）使用 RNN 或 LSTM 来维护一个内部记忆状态，编码历史信息

图像记忆将探索过的环境构建成一系列图像组，并存储节点和边的特征，能够显式表示历史信息，便于检索和推理

地图记忆将探索过的环境构建成隐式 / 显式的地图，例如拓扑地图，Grid 地图等，并储存节点和边的特征，可以显式地表示历史信息，便于检索和推理，同时避免过量的历史信息（比如大量的历史帧图像）

图结构建模

VLN 中通常把环境建模为图结构，用节点表示位置或对象，边表示连接，能够更好地捕获环境的拓扑结构和空间关系，一张导航图的元素通常如下：

  • 节点：采样环境中的可导航点
  • 边：连接直接可到达的相邻节点
  • 节点特征：视觉特征，语义信息
  • 边特征：距离，相对方向（单向 or 可往返，允许通过次数）

在基于图结构的导航策略中，通过将环境动态构建为拓扑图，融合视觉、语言和图信息，在该图上进行全局路径规划与跨模态推理，从而实现对长指令和复杂空间结构的精确理解与执行

多智能体协作

多个智能体在共享环境中通过通信、协调来完成导航任务，例如 DiscussNav，通过模拟一个由多个大语言模型专家组成的讨论组，共同解读人类指令并协作引导机器人移动，从而解决了导航训练数据稀疏的问题

数据集和评估指标

VLN 数据集

VLN 领域的常见数据集如下：

  • R2R（Room2Room）：最早也是最广泛使用的 VLN 数据集之一，使用 Matterport3D 环境建模，包含 90 个不同场景的全景，约 21500 条路径，每条路径上有 3 条人工标注的指令
  • RxR（Room across Room）：R2R 的扩展，包含多种语言的指令，用于实现跨语言导航，多语言理解等任务
  • Touchdown：基于街景图像的 VLN 数据集，指令包含细粒度地表，使用 Google Street View 环境，包含导航路径和地标识别任务
  • CVDN（Cooperative Vision-and-Dialogue Navigation）：包含对话式导航
  • REVRIE（Realistic Virtual Environment for Embodied AI）：包含目标定位和导航
  • SOON（Semantic Object-Oriented Navigation）：专用于语义导航
  • ALFRED（Action Learning From Embodied Demonstrations）：包含复杂的多步骤任务

VLN 任务评估指标

成功率

成功率（Success Rate，SR）：智能体成功到达目标区域的路径百分比，所谓成功到达指的是智能体最终位置与目标位置的距离小于阈值，不考虑路径效率（即可以绕路，到达目标即可）

SR=成功完成的任务数量任务总数量\text{SR} = \frac{\text{成功完成的任务数量}}{\text{任务总数量}} SR=任务总数量成功完成的任务数量​

导航误差

导航误差（Navigation Error，NE）：智能体最终位置与目标位置之间的最短路径距离，NE 越小，说明导航越精确

NE=distance(Agent的最终停止位置,指令的目标位置)\text{NE} = \text{distance}(\text{Agent的最终停止位置},\text{指令的目标位置}) NE=distance(Agent的最终停止位置,指令的目标位置)

成功加权路径长度

成功加权路径长度（Success weighted by Path Length，SPL）：结合了成功率和路径效率的指标，在成功完成任务的基础上，对路径效率进行打分，智能体走的路径越接近理论上的最短路径，得分相应越高

单个任务的 SPL 计算公式为：

其中 SiS_iSi​ 表示任务 iii 是否成功，LiL_iLi​ 表示起点到终点的最短路径长度，PiP_iPi​ 表示智能体实际行走的路径长度，最终的 SPL 指标是所有任务得分的平均值

轨迹长度

轨迹长度（Trajectory Length，TL）：智能体在执行一次导航任务时，实际走过的总路程，即 SPL 公式中的 PiP_iPi​，现在通常不会单独作为一个核心的性能指标，因为我们一般不追求路径越短越好，而是希望路径尽可能和指令准确贴合

先知成功率

先知成功率（Oracle Success Rate，OS）：我们检查智能体走过的一条路径上，是否存在任何一个点，这个点与真实目标点的距离在成功半径之内（例如 3m），如果存在这样的点，那么这次任务的 OS 就判定为成功，如果整条路径上没有一个点曾进入过成功半径，那么 OS 就判定为失败

评估设置

在 VLN 领域，通常按照 Seen Environments 和 Unseen Environments 进行评估设置

  • Seen：用于训练（train）和验证（valid）的场景
  • Unseen：模型在训练中从未见过的场景，用于评估泛化能力（test）

对于测试环境 Test Environments 而言，通常都使用 Unseen Environments，即模型从未见过的环境，作为最终的、最权威的评测标准，为了保证公平，测试集的正确答案（路径）通常是不公开的，研究者需要把训练好的模型提交到官方的评测服务器上，由服务器计算并返回评测成绩

未来挑战

（1）泛化到未见环境

挑战：智能体在训练中未见过的环境中表现不佳

策略：领域适应，拟真数据，无监督 / 自监督学习

（2）鲁棒性与模糊性处理

挑战：指令模糊，感知噪声，环境动态变化

策略：不确定性建模，鲁棒性训练，主动学习

（3）长程规划与记忆

挑战：规划长距离路径，记住大量历史信息

策略：更好的记忆架构、分层规划、符号推理与神经网络结合

（4）人机交互与可解释性

挑战：如何让人类用户更好地理解和信任 VLN 智能体

策略：可解释 AI，交互式导航，自然语言反馈

（5）真实世界部署

挑战：模拟器与真实世界之间的域间隙，硬件限制，安全性问题

策略：真实世界数据收集，多模态大模型，物理仿真与现实世界桥接

（6）多模态融合 beyond VLN

挑战：除了视觉和语言模态，如何整合其他模态（IMU，GNSS，陀螺仪等）

策略：多传感器融合，更全面的具身感知

视觉语言导航（Vision-and-Language Navigation，VLN）是具身智能领域重要的研究方向，旨在让 AI 智能体能够理解自然语言指令，并利用视觉感知能力自主完成导航和交互任务，后续我们将系统介绍 VLN 的核心概念、关键技术与最新研究进展，从基础的视觉 - 语言导航模型，数据集与任务，到更高级的学习方法（如模仿学习，强化学习）和预训练模型

同时，我们也会聚焦 VLN 与前沿技术（如 LLM 和机器人）的结合，探讨其在无人机和地面机器人等现实世界的应用，为相关领域的研究和系统开发提供坚实的理论基础和方法指导
