BERT

通过阅读本文，您可以大致了解 BERT 的架构与设计思想，以及与之有关的两个核心预训练任务

整体设计思想

BERT（Bidirectional Encoder Representations from Transformers），即基于 Transformer 的双向编码表示模型

从架构上看，BERT 由输入表示层和多个 Transformer Encoder 所组成，其接收一段 Token 序列，输出每个位置的上下文化隐藏表示：

(x1,x2,…,xn)→(h1(L),h2(L),…,hn(L))(x_1,x_2,\dots,x_n)\to(h_1^{(L)},h_2^{(L)},\dots,h_n^{(L)}) (x1​,x2​,…,xn​)→(h1(L)​,h2(L)​,…,hn(L)​)

其中，xix_ixi​ 表示第 iii 个位置的输入向量，hi(L)h_i^{(L)}hi(L)​ 表示经过 LLL 层编码器后，该位置的最终隐藏表示

BERT 本身并不是一个固定的分类器、问答器或者生成器，而是一个通用文本表示主干模型

Transformer Encoder

BERT 架构的核心是多层 Transformer Encoder 的堆叠，它的作用是：根据完整的输入序列，为每个位置生成上下文化表示

在 BERT 中，每个位置都可以利用序列中的其他位置：

hi(L)=F(x1,…,xi,…,xn)h_i^{(L)} = F(x_1,\dots,x_i,\dots,x_n) hi(L)​=F(x1​,…,xi​,…,xn​)

因此，BERT 适合解决文本理解任务，例如分类、序列标注和抽取式问答任务

BERT 之所以没有采用 Transformer Decoder，主要是因为它的核心目标不是按照从左到右的顺序生成新序列，而是对已有的完整序列进行重新编码，因此不需要 Decoder 的因果掩码机制，仅使用 Encoder 即可

双向上下文建模

假设输入序列为：

x1,x2,…,xnx_1,x_2,\dots,x_n x1​,x2​,…,xn​

在计算位置 iii 的隐藏表示时，BERT 会同时利用 x1,…,xi−1x_1,\dots,x_{i-1}x1​,…,xi−1​ 和 xi+1,…,xnx_{i+1},\dots,x_nxi+1​,…,xn​，即：

hi=F(x<i,xi,x>i)h_i = F(x_{\lt i},x_i,x_{\gt i}) hi​=F(x<i​,xi​,x>i​)

这里的 “双向” 不是设置两个独立网络分别进行正向和反向处理，而是同一套 Encoder 在一次计算中允许每个位置同时和左右侧的上下文进行信息交互

因此，BERT 所谓的 “双向” 与双向 LSTM 的结构有所不同：

  • BiLSTM：正向 LSTM 和反向 LSTM 是两条独立的分支
  • BERT：通过非因自注意力直接联合建模完整上下文

BERT 预训练 vs. 自回归语言模型

自回归模型通常建模为：

p(xi∣x1,…,xi−1)p(x_i\mid x_1,\dots,x_{i-1}) p(xi​∣x1​,…,xi−1​)

预测当前位置时只能读取左侧信息，以避免提前看到待预测的内容

在预训练任务中，我们希望 BERT 能够学习到：

p(xi∣x<i,x>i)p(x_i\mid x_{\lt i},x_{\gt i}) p(xi​∣x<i​,x>i​)

即根据左右上下文恢复某个位置的信息

对于 BERT 而言，如果输入中直接保留 xix_ixi​，模型会直接看到答案，因此，BERT 在预训练时需要遮盖部分 Token，再让模型根据上下文恢复它们，这构成了后续掩码语言模型 MLM

预训练 - 微调范式

BERT 的训练分为两个阶段

预训练阶段

使用大规模无标注文本学习通用语言规律：

大规模文本→通用 BERT 参数\text{大规模文本}\to\text{通用 BERT 参数} 大规模文本→通用 BERT 参数

在预训练阶段，模型主要学习词语关系、上下文依赖和句子级信息

微调阶段

针对具体任务增加一个轻量任务头，并使用有标签数据联合训练：

预训练 BERT + 任务头→具体任务模型\text{预训练 BERT + 任务头}\to\text{具体任务模型} 预训练 BERT + 任务头→具体任务模型

例如，对于文本分类任务，则使用序列级表示；对于 Token 分类任务，则使用每个位置的隐藏表示；对于抽取式问答任务，则预测答案的起始位置

整体任务规划

在正式接触 BERT 之前，我们需要区分 BERT 本身的设计思想，预训练时的训练目标，以及常见的下游任务规划

BERT 本体的功能

BERT 主干网络本质上是一个双向序列编码器

给定输入 Token 序列：

X=(x1,x2,…,xn)X=(x_1,x_2,\ldots,x_n) X=(x1​,x2​,…,xn​)

BERT 经过多层 Transformer Encoder，输出：

H(L)=(h1(L),h2(L),…,hn(L))H^{(L)} = (h_1^{(L)},h_2^{(L)},\ldots,h_n^{(L)}) H(L)=(h1(L)​,h2(L)​,…,hn(L)​)

其中 hi(L)h_i^{(L)}hi(L)​ 是第 iii 个位置的上下文化隐藏表示，它融合了整个可见输入序列的信息

因此，BERT 模型本体完成的是从输入的 Token 序列到生成每个 Token 对应的上下文隐藏表示的过程，更准确地说，这是 BERT 的模型功能或表示学习能力，并不是 BERT 可以完成的一个具体任务

BERT 预训练目标

预训练任务是为了训练 BERT 参数而人为设计的学习目标

原始 BERT 主要使用两个预训练目标：MLM 和 NSP

MLM Task

将部分 Token 遮盖，让模型利用上下文恢复原 Token：

p(xi∣X∖M)p(x_i\mid X_{\setminus\mathcal M}) p(xi​∣X∖M​)

BERT 先得到被遮盖位置的隐藏表示：

hi(L)h_i^{(L)} hi(L)​

再通过 MLM 预测头得到词表概率：

p(xi∣X)=softmax⁡(WMLMhi(L)+b)p(x_i\mid X) = \operatorname{softmax} (W_{\mathrm{MLM}}h_i^{(L)}+b) p(xi​∣X)=softmax(WMLM​hi(L)​+b)

MLM 是训练 BERT 表示能力的方法，不是 BERT 主干网络本身

NSP Task

利用 [CLS][\mathrm{CLS}][CLS] 位置的隐藏表示，判断句子 BBB 是否真实接在句子 AAA 后面：

p(yNSP∣A,B)p(y_{\mathrm{NSP}}\mid A,B) p(yNSP​∣A,B)

它同样是预训练时附加的监督目标

下游任务

预训练结束后，MLM 和 NSP 预测头通常会被删除或替换，BERT 主干参数被保留下来

然后根据具体任务连接新的任务头

文本分类

hCLS(L)→分类头→y^h_{\mathrm{CLS}}^{(L)} \rightarrow \text{分类头} \rightarrow \hat y hCLS(L)​→分类头→y^​

Token 分类

hi(L)→Token 分类头→y^ih_i^{(L)} \rightarrow \text{Token 分类头} \rightarrow \hat y_i hi(L)​→Token 分类头→y^​i​

抽取式问答

hi(L)→起点/终点预测头h_i^{(L)} \rightarrow \text{起点/终点预测头} hi(L)​→起点/终点预测头

由此可知，同一个预训练的 BERT 主干，可以通过接入下游不同的任务头，进而完成下游多种不同任务

BERT 文本输入的组织方式

BERT 不能直接接收字符串，原始文本必须依次经过：

文本→Token 序列→Token ID 序列→批次输入张量\text{文本}\to\text{Token 序列}\to\text{Token ID 序列}\to\text{批次输入张量} 文本→Token 序列→Token ID 序列→批次输入张量

本节我们先讨论数据如何被组织，暂时不展开嵌入计算

WordPiece 分词

BERT 使用 WordPiece 将文本拆分为词或子词 Token，低频词可能被拆分为多个子词，例如：

playing→[play,##ing]\text{playing}\to[\text{play},\text{\#\#ing}] playing→[play,##ing]

需要区分词嵌入过程的几个概念，Token 为词表中的离散符号，Token ID 是该 Token 在词表中对应的整数编号，Token ID 经过 Embedding 向量嵌入后才变成向量

特殊 Token

BERT 使用以下特殊 Token：

  • [CLS]：放在序列首部，其对应的向量在经过多层注意力计算后，会融合整句话的信息，常用于序列级任务
  • [SEP]：标记一个序列的结束，或用于分隔两个序列
  • [MASK]：MLM 预训练时用于遮盖待预测的 Token
  • [PAD]：批量处理中用于补齐不同长度的序列
  • [UNK]：表示词表无法处理的未知 Token

其中，[MASK] 主要用于预训练，普通下游输入通常不会主动加入

序列输入

单序列输入

对于一个序列 AAA，组织形式为：

[CLS],A1,A2,…,Am,[SEP]\text{[CLS]},A_1,A_2,\dots,A_m,\text{[SEP]} [CLS],A1​,A2​,…,Am​,[SEP]

例如：

[CLS],I,love,machine,learning,[SEP]\text{[CLS]},\text{I},\text{love},\text{machine},\text{learning},\text{[SEP]} [CLS],I,love,machine,learning,[SEP]

特殊 Token 也会占据实际序列位置，并且拥有对应的 Token ID

序列对输入

对于两个序列 AAA 和 BBB：

[CLS],A,[SEP],B,[SEP]\text{[CLS]},A,\text{[SEP]},B,\text{[SEP]} [CLS],A,[SEP],B,[SEP]

这种组织方式用于句子关系判断、文本匹配和问答等任务，例如抽取式问答任务通常把输入组织为：

[CLS],question,[SEP],context,[SEP]\text{[CLS]},\text{question},\text{[SEP]},\text{context},\text{[SEP]} [CLS],question,[SEP],context,[SEP]

BERT 会把两段文本作为一个联合序列进行统一编码

输入编号

输入数据组织完成后，通常形成三组长度均为 NNN 的输入

Token ID

\text{input_ids} = [id_1,id_2,\dots,id_N]

表示序列中每个位置的 Token 在词表中的编号

Segment ID

单序列场景下，Segment ID 通常全部为 0；对于序列对场景，通常组织为：

[0,…,0,1,…,1][0,\dots,0,1,\dots,1] [0,…,0,1,…,1]

用于表明每个位置是属于序列 AAA 还是序列 BBB

Attention Mask

mi={1,真实 Token,0[PAD].m_i = \begin{cases} 1,&\text{真实 Token},\\0 & \text{[PAD]}. \end{cases} mi​={1,0​真实 Token,[PAD].​

它使得注意力机制能够忽略补齐位置，这里的 Attention Mask 指的是有效位置掩码，并不是 Transformer Decoder 中的因果掩码

同一批次中的序列必须具有相同长度，较短序列使用 [PAD][\mathrm{PAD}][PAD] 补齐，过长序列需要截断

最终输入张量通常为：

\text{input_ids}, \text{token_type_ids}, \text{attention_mask} \in\mathbb{R}^{B\times N}

其中 BBB 是批量大小，NNN 是统一后的序列长度

完整输入组织过程为：

文本→WordPiece Token→加入特殊 Token→生成三组 ID→补齐并组成批量\text{文本} \rightarrow \text{WordPiece Token} \rightarrow \text{加入特殊 Token} \rightarrow \text{生成三组 ID} \rightarrow \text{补齐并组成批量} 文本→WordPiece Token→加入特殊 Token→生成三组 ID→补齐并组成批量

BERT 的输入表示

经过上一节的文本组织后，BERT 得到长度为 NNN 的 Token ID 序列，输入表示层的任务，是要把每个离散位置转换为 dhd_hdh​ 维的连续向量，形成第一层 Encoder 的输入：

H(0)∈RN×dhH^{(0)}\in\mathbb{R}^{N\times d_h} H(0)∈RN×dh​

BERT 会给每个位置叠加三种嵌入：

Hi(0)=Etoken(xi)+Esegment(si)+Eposition(i)H_i^{(0)} = E_{\text{token}}(x_i) + E_{\text{segment}}(s_i) + E_{\text{position}}(i) Hi(0)​=Etoken​(xi​)+Esegment​(si​)+Eposition​(i)

三者分别描述：当前位置是什么 Token，属于哪一段文本，位于序列的什么位置

Token Embedding

设词表大小为 VVV，嵌入矩阵为：

WE∈RV×dhW_E\in\mathbb{R}^{V\times d_h} WE​∈RV×dh​

位置 iii 的 Token ID 为 xix_ixi​，通过查表得到：

eitok=WE[xi]∈Rdhe_i^{\text{tok}} = W_E[x_i]\in\mathbb{R}^{d_h} eitok​=WE​[xi​]∈Rdh​

这是该 Token 的基础语义向量，相同 Token ID 在输入层得到相同向量，进入 Encoder 以后，因为上下文不同，其隐藏表示才会不同

对词嵌入矩阵 WEW_EWE​ 的理解，可以认为第 xix_ixi​ 行就对应词表中第 xix_ixi​ 个 Token 的嵌入向量，因此可以用 WE[xi]W_E[x_i]WE​[xi​] 的形式取出

WEW_EWE​ 初始化可以随机给出，在训练过程中，会逐渐调整参数，形成符合语义的各个 Token 的词向量表示

Segment Embedding

对于句子对形式的输入：

[CLS],A,[SEP],B,[SEP]\text{[CLS]},A,\text{[SEP]},B,\text{[SEP]} [CLS],A,[SEP],B,[SEP]

每个位置还有 Segment ID：

si∈{0,1}s_i\in\{0,1\} si​∈{0,1}

BERT 使用可学习矩阵：

WS∈R2×dhW_S\in\mathbb{R}^{2\times d_h} WS​∈R2×dh​

完成 Segment ID 到对应 dhd_hdh​ 维向量的映射，即：

eiseg=WS[si]∈Rdhe_i^{\text{seg}} = W_S[s_i]\in\mathbb{R}^{d_h} eiseg​=WS​[si​]∈Rdh​

序列 AAA 及其相关特殊 Token 通常使用类型 0，序列 BBB 使用类型 1，对应的标签只标记文本片段归属，不表达 Token 的具体语义

单序列输入通常全部使用类型 0

Position Embedding

自注意力本身不包含顺序信息，因此 BERT 为第 iii 个位置分配可学习位置向量：

eipos=WP[i]∈Rdhe_i^{\mathrm{pos}}=W_P[i]\in\mathbb{R}^{d_h} eipos​=WP​[i]∈Rdh​

其中：

WP∈RNmax⁡×dhW_P\in\mathbb{R}^{N_{\max}\times d_h} WP​∈RNmax​×dh​

原始 BERT 使用可学习绝对位置嵌入，它表示 Token 处于第几个序列位置，包括 [CLS][\mathrm{CLS}][CLS]、[SEP][\mathrm{SEP}][SEP] 和 [PAD][\mathrm{PAD}][PAD] 所占的位置

这里三个映射矩阵 WE,WS,WPW_E,W_S,W_PWE​,WS​,WP​ 可以分别认为每一行就是一个词向量，分别完成 Token ID，Segment ID 以及位置编号到对应词向量的映射

矩阵参数在训练初期随机初始化，随后通过梯度下降更新

输入叠加

三种向量均属于同一隐藏空间：

eitok,eiseg,eipos∈Rdhe_i^{\mathrm{tok}}, e_i^{\mathrm{seg}}, e_i^{\mathrm{pos}} \in\mathbb{R}^{d_h} eitok​,eiseg​,eipos​∈Rdh​

因此可以逐元素相加：

ei=eitok+eiseg+eipose_i = e_i^{\mathrm{tok}} + e_i^{\mathrm{seg}} + e_i^{\mathrm{pos}} ei​=eitok​+eiseg​+eipos​

相加不会增加隐藏维度，而是把三类信息共同编码进同一个位置表示，后续 Encoder 会学习如何使用这些叠加的信息

对全部位置堆叠后：

E=[e1;e2;…;eN]∈RN×dhE= [e_1;e_2;\ldots;e_N] \in\mathbb{R}^{N\times d_h} E=[e1​;e2​;…;eN​]∈RN×dh​

随后通常经过 LayerNorm 和 Dropout：

H(0)=Dropout⁡(LayerNorm⁡(E))H^{(0)} = \operatorname{Dropout} \left( \operatorname{LayerNorm}(E) \right) H(0)=Dropout(LayerNorm(E))

最终：

Token ID + Segment ID + 位置编号→三种嵌入查表→逐位置相加→H(0)\text{Token ID + Segment ID + 位置编号} \rightarrow \text{三种嵌入查表} \rightarrow \text{逐位置相加} \rightarrow H^{(0)} Token ID + Segment ID + 位置编号→三种嵌入查表→逐位置相加→H(0)

其中 H(0)H^{(0)}H(0) 是 BERT 输入层产生的初始表示，还不是经过上下文建模后的隐藏表示

BERT 的双向上下文建模

设输入序列的初始表示为：

H(0)=[h1(0),h2(0),…,hN(0)]H^{(0)} = [h_1^{(0)},h_2^{(0)},\dots,h_N^{(0)}] H(0)=[h1(0)​,h2(0)​,…,hN(0)​]

BERT 计算第 iii 个位置的隐藏表示时，允许该位置同时聚合左侧和右侧所有有效位置的信息：

ht(l)=F(l)(h1(l−1),…,hN(l−1))h_t^{(l)} = F^{(l)}\left(h_1^{(l-1)},\dots,h_N^{(l-1)}\right) ht(l)​=F(l)(h1(l−1)​,…,hN(l−1)​)

因此最终表示满足：

hi(L)=F(x1,…,xi−1,xi,xi+1,…,xN)h_i^{(L)} = F(x_1,\dots,x_{i-1},x_i,x_{i+1},\dots,x_N) hi(L)​=F(x1​,…,xi−1​,xi​,xi+1​,…,xN​)

这里的 “双向” 不是按两个方向依次计算，而是每一层都对完整的可见序列进行联合编码

非因果自注意力

在某一注意力头中：

Q=HWQ,K=HWK,V=HWVQ = HW^Q,\quad K = HW^K,\quad V = HW^V Q=HWQ,K=HWK,V=HWV

得到的注意力矩阵为：

A=softmax(QK⊤dk+M)A = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right) A=softmax(dk​​QK⊤​+M)

对于普通的有效 Token，BERT 不添加因果约束，因此第 iii 行注意力权重为：

Ai,:=[Ai1,Ai2,…,AiN]A_{i,:} = [A_{i1},A_{i2},\dots,A_{iN}] Ai,:​=[Ai1​,Ai2​,…,AiN​]

可以在 iii 左右两侧位置均取得非零值，位置 iii 的输出为：

zi=∑j=1NAijvjz_i = \sum_{j=1}^N A_{ij}v_j zi​=j=1∑N​Aij​vj​

所以 ziz_izi​ 可以同时融合 j<ij<ij<i 和 j>ij>ij>i 的信息，而上述注意力计算公式中的掩码 MMM 主要是用于屏蔽 [PAD]\text[PAD][PAD]：

Mij={0,j 为有效位置,−∞,j 为填充位置.M_{ij} = \begin{cases}0,&\text{j 为有效位置},\\-∞,&\text{j 为填充位置}.\end{cases} Mij​={0,−∞,​j 为有效位置,j 为填充位置.​

它并不等同于 Transformer Decoder 中用于屏蔽未来位置的因果掩码

多层编码深化双向表示

第一层编码器完成一次全序列信息的聚合：

H(0)→H(1)H^{(0)}\to H^{(1)} H(0)→H(1)

此时每个位置已经包含了其他位置的信息，随后：

H(1)→H(2)→⋯→H(L)H^{(1)}\to H^{(2)}\to\cdots\to H^{(L)} H(1)→H(2)→⋯→H(L)

高层继续对已经上下文化的表示进行重组，因此，BERT 的 “双向” 信息提取并不是只发生一次，而是在每个 Encoder 层中持续进行

MLM 的作用

如果训练目标是预测 xix_ixi​，在上述双向表示中，输入中原始的 Token xix_ixi​ 仍然被保存，模型可以直接读取答案：

xi→hi(L)→xix_i\to h_i^{(L)}\to x_i xi​→hi(L)​→xi​

这无法迫使模型根据上下文关系去推断 xix_ixi​ 的内容

因此，BERT 在预训练时把待预测位置替换成掩码，或进行扰动：

xi→[MASK]x_i\to\text{[MASK]} xi​→[MASK]

然后训练模型去预测：

下一句预测 NSP

NSP（Next Sentence Prediction）的目标是：给定两个文本片段 AAA 和 BBB，判断 BBB 是否在原始预料中真实紧接在 AAA 后面

它是原始的 BERT 句子级预训练任务，与 MLM 的 Token 级预测不同

训练样本构造

从语料中取文本片段 AAA，再构造 BBB

约一半样本为正样本：

yNSP=1y_{\text{NSP}} = 1 yNSP​=1

正样本表示 BBB 是语料中真实接在 AAA 后面的片段，标签被标记为 IsNext

另一半为负样本：

yNSP=0y_{\text{NSP}} = 0 yNSP​=0

负样本表示 BBB 是从语料库中随机抽取，比钱被标记为 NotNext

例如：

A=今天下了一场大雨A = \text{今天下了一场大雨} A=今天下了一场大雨

正样本可能是：

B=道路上因此有很多积水B = \text{道路上因此有很多积水} B=道路上因此有很多积水

负样本可能是：

B=阳光明媚天气晴朗B = \text{阳光明媚天气晴朗} B=阳光明媚天气晴朗

NSP 预测的是语料中的相邻关系，不严格等同于判断两句话在语义上是否连贯

输入组织

句子对按照以下形式组织为输入：

[CLS],A,[SEP],B,[SEP]\text{[CLS]},A,\text{[SEP]},B,\text{[SEP]} [CLS],A,[SEP],B,[SEP]

Segment ID 为：

[0,…,0,1,…,1][0,\dots,0,1,\dots,1] [0,…,0,1,…,1]

因此，BERT 既能够通过 [SEP]\text{[SEP]}[SEP] 知道片段边界，也能够通过 Segment Embedding 区分 AAA 和 BBB 两个片段

经过多层 Encoder：

H(L)=[hCLS(L),h1(L),…,hN−1(L)]H^{(L)} = [h_{\mathrm{CLS}}^{(L)},h_1^{(L)},\ldots,h_{N-1}^{(L)}] H(L)=[hCLS(L)​,h1(L)​,…,hN−1(L)​]

由于 [CLS][\mathrm{CLS}][CLS] 可以与两个片段中的所有有效 Token 进行信息交互，其最终隐藏表示包含句子对的联合上下文信息

原始 BERT 先对 [CLS]\text{[CLS]}[CLS] 表示进行 Pooler 变换：

NSP 任务可以理解成，将 AAA 和 BBB 两个序列拼接在一起，编码成输入向量后送入多级 Encoder 中，通过注意力机制，将两个序列的相关性全部融合到首个 Token 的隐藏表示 [CLS]\text{[CLS]}[CLS] 中

最终通过多次训练和反向传播，通过 [CLS]\text{[CLS]}[CLS] 对应的特征向量映射得到的二分类输出，进而判断序列的相关性

原始 BERT 同时执行 MLM 和 NSP：

换言之，MLM 预训练学习的是 Token 级上下文表示，NSP 训练学习的是句子级的监督信号

NSP 原本用于增强问答、文本蕴含等句子对任务所需的关系建模能力，不过随机负样本通常较容易，后续一些预训练模型移除了 NSP，说明它并不是 BERT 双向编码能力成立的必要条件

Ltask=−log⁡p(ytrue∣X)\mathcal L_{\mathrm{task}} = -\log p(y_{\mathrm{true}}\mid X) Ltask​=−logp(ytrue​∣X)

反向传播首先更新分类头：

ψ←ψ−η∇ψLtask\psi\leftarrow \psi-\eta\nabla_{\psi}\mathcal L_{\mathrm{task}} ψ←ψ−η∇ψ​Ltask​

随后梯度通过 hCLS(L)h_{\mathrm{CLS}}^{(L)}hCLS(L)​ 进入 BERT：

θ←θ−η∇θLtask\theta\leftarrow \theta-\eta\nabla_{\theta}\mathcal L_{\mathrm{task}} θ←θ−η∇θ​Ltask​

因此微调会让原本通用的隐藏表示逐渐偏向当前任务，例如文本情感分类会增强与情感极性相关的表示维度

三种参数更新方式

全参数微调：

∇θL≠0\nabla_{\theta}\mathcal L\neq0 ∇θ​L​=0

BERT 和任务头全部更新

冻结主干：

∇θL\nabla_{\theta}\mathcal L ∇θ​L

只训练任务头，这属于特征提取

部分微调则冻结底层，仅更新高层 Encoder 和任务头，底层通常保留较通用的词法表示，高层更容易适应任务语义

完整关系是：

预训练目标塑造通用表示→加载预训练参数→任务损失重新调整表示\text{预训练目标塑造通用表示} \rightarrow \text{加载预训练参数} \rightarrow \text{任务损失重新调整表示} 预训练目标塑造通用表示→加载预训练参数→任务损失重新调整表示

微调学习率通常较小，因为过大的参数更新可能破坏已有语言能力，即产生灾难性遗忘

下游任务与适配

BERT 下游任务适配的核心是：保留预训练的 BERT 主干，根据任务需要选择输出并连接任务头，再用有标签数据进行微调

我们设：

H(L)=BERTθ(X)=[h0(L),h1(L),…,hN−1(L)]H^{(L)} = \text{BERT}_\theta(X) = [h_0^{(L)},h_1^{(L)},\dots,h_{N-1}^{(L)}] H(L)=BERTθ​(X)=[h0(L)​,h1(L)​,…,hN−1(L)​]

其中，h0(L)h_0^{(L)}h0(L)​ 通常就对应 [CLS]\text{[CLS]}[CLS]

序列分类

适用于对一段文本进行情感分类、主题分类等 “一条输入对应一个标签” 的任务

我们使用序列级表示：

z=hCLS(L)z = h_{\text{CLS}}^{(L)} z=hCLS(L)​

连接分类头：

o=Wcz+bco = W_cz + b_c o=Wc​z+bc​

p(y=c∣X)=softmax(o)cp(y=c\mid X) = \text{softmax}(o)_c p(y=c∣X)=softmax(o)c​

计算交叉熵损失：

LCLS=−log⁡p(ytrue∣X)\mathcal{L}_{\text{CLS}} = -\log p(y_{\text{true}}\mid X) LCLS​=−logp(ytrue​∣X)

梯度通过分类头和 [CLS]\text{[CLS]}[CLS] 表示反向传播到整个 BERT

句子对分类

适用于文本蕴含、语义匹配等任务，输入组织为：

[CLS],A,[SEP],B,[SEP][\mathrm{CLS}],A,[\mathrm{SEP}],B,[\mathrm{SEP}] [CLS],A,[SEP],B,[SEP]

BERT 对两个片段联合编码，再使用：

hCLS(L)h_{\mathrm{CLS}}^{(L)} hCLS(L)​

进行分类

其计算形式与序列分类相同，区别主要在输入组织的形式，以及 [CLS][\mathrm{CLS}][CLS] 聚合的是两个文本片段的关系信息

Token 分类

适用于命名实体识别、词性标注等 “每个 Token 对应一个标签” 的任务

对每个位置分别计算：

oi=Wthi(L)+bto_i=W_th_i^{(L)}+b_t oi​=Wt​hi(L)​+bt​

p(yi=c∣X)=softmax⁡(oi)cp(y_i=c\mid X)=\operatorname{softmax}(o_i)_c p(yi​=c∣X)=softmax(oi​)c​

损失对有效 Token 求和：

Ltoken=−∑i∈Vlog⁡p(yi∣X)\mathcal L_{\mathrm{token}} = -\sum_{i\in\mathcal V} \log p(y_i\mid X) Ltoken​=−i∈V∑​logp(yi​∣X)

其中 V\mathcal VV 通常排除 [CLS][\mathrm{CLS}][CLS]、[SEP][\mathrm{SEP}][SEP] 和 [PAD][\mathrm{PAD}][PAD]

若一个单词被 WordPiece 拆成多个子词，需要规定使用首个子词表示，或为所有子词整体分配一个标签

抽取式问答

输入为：

[CLS],问题,[SEP],文章,[SEP][\mathrm{CLS}],\text{问题},[\mathrm{SEP}],\text{文章},[\mathrm{SEP}] [CLS],问题,[SEP],文章,[SEP]

我们希望模型能够从 “文章” 对应的 Token 序列中，预测 “问题” 对应答案的起点和终点，对每个位置：

si=ws⊤hi(L),ei=we⊤hi(L)s_i=w_s^\top h_i^{(L)},\quad e_i=w_e^\top h_i^{(L)} si​=ws⊤​hi(L)​,ei​=we⊤​hi(L)​

分别在序列维度做 Softmax：

pstart(i)=esi∑jesjp_{\mathrm{start}}(i) = \frac{e^{s_i}}{\sum_j e^{s_j}} pstart​(i)=∑j​esj​esi​​

pend(i)=eei∑jeejp_{\mathrm{end}}(i) = \frac{e^{e_i}}{\sum_j e^{e_j}} pend​(i)=∑j​eej​eei​​

若真实起止位置为 is,iei_s,i_eis​,ie​：

LQA=−log⁡pstart(is)−log⁡pend(ie)\mathcal L_{\mathrm{QA}} = -\log p_{\mathrm{start}}(i_s) -\log p_{\mathrm{end}}(i_e) LQA​=−logpstart​(is​)−logpend​(ie​)

也就是希望 isi_sis​ 被预测为起点位置的概率最大，同时 iei_eie​ 被预测为重点位置的概率最大，这样对应的交叉熵损失即尽可能小

在该任务中，BERT 只从输入文章中抽取答案，不会自由生成新文本

统一规律

不论下游要完成什么任务，其本质区别都在于要使用哪些输出：如果是序列级任务，则使用 hCLS(L)h_{\text{CLS}}^{(L)}hCLS(L)​；如果是 Token 级任务，则使用 h1(L),…,hN(L)h_1^{(L)},\dots,h_N^{(L)}h1(L)​,…,hN(L)​

任务头通常随机初始化，而 BERT 加载预训练参数，全参数微调时，任务损失同时更新任务头和 BERT，使通用上下文化表示逐渐适应具体任务
