交叉熵

交叉熵损失主要用于分类任务，它衡量的是模型预测的概率分布与真实标签分布之间的差异

模型越相信真实类别，对应的损失越小；模型越排斥真实诶别，对应的损失越大

从分类输出开始

假设一个样本有 KKK 个类别，模型最后一层输出 KKK 个 logit：

z=(z1,z2,…,zK)z = (z_1,z_2,\dots,z_K) z=(z1​,z2​,…,zK​)

Logits 是没有经过归一化的类别分数，不是概率，经过 Softmax：

pk=ezk∑j=1Kezjp_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}} pk​=∑j=1K​ezj​ezk​​

得到预测概率分布：

p=(p1,p2,…,pK),∑k=1Kpk=1p=(p_1,p_2,\dots,p_K),\quad \sum_{k=1}^K p_k = 1 p=(p1​,p2​,…,pK​),k=1∑K​pk​=1

真实类别标签通常用 One-hot 向量表示：

y=(y1,y2,…,yK)y = (y_1,y_2,\dots,y_K) y=(y1​,y2​,…,yK​)

若真实类别为第 ccc 类，则有：

yc=1,yk=0(k≠c)y_c = 1,\quad y_k = 0(k\ne c) yc​=1,yk​=0(k​=c)

理解真实标签以 One-hot 形式给出（如果不是 One-hot 编码，通常需要我们手动转换），是理解下面交叉熵计算公式化简的关键

多分类交叉熵

真实分布 yyy 与预测分布 ppp 之间的交叉熵为：

LCE=−∑k=1Kyklog⁡pk\mathcal{L}_{\text{CE}} = -\sum_{k=1}^K y_k\log p_k LCE​=−k=1∑K​yk​logpk​

由于 One-hot 标签中只有真实类别 ccc 对应的分量 yc=1y_c = 1yc​=1，因此：

LCE=−log⁡pc\mathcal{L}_{\text{CE}} = -\log p_c LCE​=−logpc​

所以交叉熵实际上只取决于模型为真实类别分配的概率

以一个三分类任务为例，假设真实类别为第二类：

y=[0,1,0]y = [0,1,0] y=[0,1,0]

若模型预测：

p=[0.1,0.8,0.1]p = [0.1,0.8,0.1] p=[0.1,0.8,0.1]

则交叉熵损失为：

L=−log⁡0.8=0.223\mathcal{L} = -\log 0.8 = 0.223 L=−log0.8=0.223

若模型预测：

p=[0.8,0.1,0.1]p = [0.8,0.1,0.1] p=[0.8,0.1,0.1]

则交叉熵损失为：

L=−log⁡0.1=2.303\mathcal{L} = -\log 0.1 = 2.303 L=−log0.1=2.303

模型把真实类别概率压得越低，受到的惩罚越大

使用负对数原因

函数 −log⁡pc-\log p_c−logpc​ 具有两个重要性质：

  1. 当 pc→1p_c\to 1pc​→1 时，损失趋近于 −log⁡1=0-\log 1 = 0−log1=0
  2. 当 pc→0p_c\to 0pc​→0 时，损失趋近于 −log⁡pc=+∞-\log p_c = +∞−logpc​=+∞

因此，如果模型如果给出比较离谱的分类结果（目标类别的概率很低），则会受到强烈的惩罚

同时，对数可以把多个样本概率的乘积转化为损失之和，若训练集为：

{(xi,yi)}i=1H\{(x_i,y_i)\}_{i=1}^H {(xi​,yi​)}i=1H​

模型产生真实标签的联合似然为：

∏i=1Bp(yi∣xi)\prod_{i=1}^B p(y_i\mid x_i) i=1∏B​p(yi​∣xi​)

最大化该似然，就等价于最小化负的对数似然：

−log⁡∏i=1Bp(yi∣xi)=−∑i=1Blog⁡p(yi∣xi)-\log\prod_{i=1}^B p(y_i\mid x_i) = -\sum_{i=1}^B \log p(y_i\mid x_i) −logi=1∏B​p(yi​∣xi​)=−i=1∑B​logp(yi​∣xi​)

这正是交叉熵损失，因此我们说，分类模型最小化交叉熵，本质上就是在执行最大似然估计

Softmax 与交叉熵的梯度

单个样本的损失为：

L=−∑k=1Kyklog⁡pk\mathcal L = -\sum_{k=1}^{K}y_k\log p_k L=−k=1∑K​yk​logpk​

其中：

pk=softmax⁡(z)kp_k=\operatorname{softmax}(z)_k pk​=softmax(z)k​

对第 kkk 个 Logit 求导，结果为：

∂L∂zk=pk−yk\frac{\partial\mathcal L}{\partial z_k} = p_k-y_k ∂zk​∂L​=pk​−yk​

对于真实类别 ccc：

∂L∂zc=pc−1<0\frac{\partial\mathcal L}{\partial z_c} = p_c-1<0 ∂zc​∂L​=pc​−1<0

梯度下降会提高真实类别的 Logit

对于错误类别 k≠ck\neq ck​=c：

∂L∂zk=pk>0\frac{\partial\mathcal L}{\partial z_k} = p_k>0 ∂zk​∂L​=pk​>0

梯度下降会降低错误类别的 Logit

因此，交叉熵训练的直接效果就在于：提高真实类别分数，降低错误类别分数

而且模型对某个错误类别给出的概率越高，抑制该类别的梯度就越大

二分类交叉熵

二分类中，模型通常输出一个 Logit zzz，经过 Sigmoid：

p=σ(z)=11+e−zp=\sigma(z)=\frac{1}{1+e^{-z}} p=σ(z)=1+e−z1​

其中 ppp 表示属于正类 y=1y=1y=1 的概率

二分类交叉熵为：

LBCE=−[ylog⁡p+(1−y)log⁡(1−p)]\mathcal L_{\mathrm{BCE}} = -\left[ y\log p+(1-y)\log(1-p) \right] LBCE​=−[ylogp+(1−y)log(1−p)]

当 y=1y=1y=1 时：

L=−log⁡p\mathcal L=-\log p L=−logp

当 y=0y=0y=0 时：

L=−log⁡(1−p)\mathcal L=-\log(1-p) L=−log(1−p)

因此，它同时鼓励正样本概率接近 1，负样本概率接近 0

需要区分：

  • 单标签多分类：Softmax + 多分类交叉熵
  • 多标签分类：每个类别独立使用 Sigmoid + BCE

一个 Batch 的损失

对 BBB 个样本，通常取所有批次的所有标签的交叉熵的平均值：

Lbatch=−1B∑i=1B∑k=1Kyiklog⁡pik\mathcal L_{\mathrm{batch}} = -\frac{1}{B} \sum_{i=1}^{B} \sum_{k=1}^{K} y_{ik}\log p_{ik} Lbatch​=−B1​i=1∑B​k=1∑K​yik​logpik​

然后反向传播：

Lbatch→Logit→分类头→主干网络\mathcal L_{\mathrm{batch}} \rightarrow \text{Logit} \rightarrow \text{分类头} \rightarrow \text{主干网络} Lbatch​→Logit→分类头→主干网络
