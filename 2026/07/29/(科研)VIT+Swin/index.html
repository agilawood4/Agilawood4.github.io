ViT and Swin

通过阅读本文，您可以了解计算机视觉领域的两个经典模型，ViT 和 Swin

图像 → Transformer 输入

Transformer 接收的是一维 Token 序列，而图像天然是二维空间数据：

X∈RH×W×CX\in\mathbb{R}^{H\times W\times C} X∈RH×W×C

其中，H,WH,WH,W 分别表示高和宽，CCC 表示通道数，文本 Token 本身是离散符号，而图像中的基本元素是连续像素，ViT 和 Swin 的共同做法是：把局部图像块 Patch 转换为视觉 Token

Patch 划分

设每个 Patch 的尺寸为 P×PP\times PP×P，并假设 H,WH,WH,W 均可以被 PPP 整除，则图像可沿空间维度被划分为：

Nh=HP,Nw=WPN_h = \frac{H}{P},\quad N_w = \frac{W}{P} Nh​=PH​,Nw​=PW​

由此得到的 Patch 总数为：

N=HP⋅WP=HWP2N = \frac{H}{P}\cdot\frac{W}{P} = \frac{HW}{P^2} N=PH​⋅PW​=P2HW​

第 (r,c)(r,c)(r,c) 个 Patch 为：

Xr,cP∈RP×P×CX_{r,c}^P\in\mathbb{R}^{P\times P\times C} Xr,cP​∈RP×P×C

当各个 Patch 不发生重叠时，每个像素只属于一个 Patch

Patch Flatten

每个 Patch 中都包含：

P×P×CP\times P\times C P×P×C

个数值，按照固定顺序可将其展开为一维向量：

xip=Flatten(Xr,cp)∈RP2Cx_i^p = \text{Flatten}(X_{r,c}^p)\in\mathbb{R}^{P^2C} xip​=Flatten(Xr,cp​)∈RP2C

这里的 xipx_i^pxip​ 只是展平后的像素向量，还不是 Transformer 使用的 Patch Token

Patch Token

设 Transformer 需要的隐藏表示维度为 DDD，使用可学习矩阵进行现行投影：

E∈RP2C×D,b∈RDE\in\mathbb{R}^{P^2C\times D},\quad b\in\mathbb{R}^D E∈RP2C×D,b∈RD

第 iii 个 Patch Token 被投影为：

zi=xipE+b∈RDz_i = x_i^pE + b\in\mathbb{R}^D zi​=xip​E+b∈RD

全部的 Patch 都使用同一个 EEE 矩阵进行投影，将投影结果按行堆叠则有：

Zpatch=[z1;z2;… ;zN]∈RN×DZ_{\text{patch}} = [z_1;z_2;\dots;z_N]\in\mathbb{R}^{N\times D} Zpatch​=[z1​;z2​;…;zN​]∈RN×D

因此，将图像转化为 Transformer 输入 Token 序列的过程为：

X∈RH×W×C→N=HWP2 个 Patch→Zpatch∈RN×DX\in\mathbb{R}^{H\times W\times C}\to N = \frac{HW}{P^2}\text{ 个 Patch}\to Z_{\text{patch}}\in\mathbb{R}^{N\times D} X∈RH×W×C→N=P2HW​ 个 Patch→Zpatch​∈RN×D

二维空间结构的保留

序列化并不等于完全丢失其二维结构，主要依靠：

  1. 每个 Patch 内都按固定行列顺序排列
  2. 为每个 Patch 加入位置编码，标明其在整张图像中的原始空间位置
  3. Swin 通常以 HP×WP×D\frac{H}{P}\times\frac{W}{P}\times DPH​×PW​×D 的二维特征网格组织 Token，并在局部窗口中计算

ViT

ViT 整体架构与信息流

经典 ViT（Vision Transformer）将图像分类转换为视觉 Token 序列分类的问题：

Image→Patch Embedding→[CLS]+Position Embedding→L层Encoder→分类头\text{Image}\to\text{Patch Embedding}\to\text{[CLS]+Position Embedding}\to\text{L层Encoder}\to\text{分类头} Image→Patch Embedding→[CLS]+Position Embedding→L层Encoder→分类头

Patch Token 序列

输入图像为：

X∈RH×W×CX\in\mathbb{R}^{H\times W\times C} X∈RH×W×C

以 P×PP\times PP×P 划分后，Patch 数量为：

N=HWP2N = \frac{HW}{P^2} N=P2HW​

每个 Patch 按固定顺序展平并线性投影到 DDD 维：

zi=xipE+bi,zi∈RDz_i = x_i^pE + b_i,\quad z_i\in\mathbb{R}^D zi​=xip​E+bi​,zi​∈RD

堆叠后得到：

Zpatch=[z1;z2;… ;zN]∈RN×DZ_{\text{patch}} = [z_1;z_2;\dots;z_N]\in\mathbb{R}^{N\times D} Zpatch​=[z1​;z2​;…;zN​]∈RN×D

这里的每个 ziz_izi​ 都是一个 DDD 维的 Patch Token

[CLS] Token

ViT 定义一个可学习的向量：

zcls∈RDz_{\text{cls}}\in\mathbb{R}^D zcls​∈RD

并将其放在整个 Patch Token 序列的首部：

Zseq=[zcls;z1;z2;… ;zN]∈R(N+1)×DZ_{\text{seq}} = [z_{\text{cls}};z_1;z_2;\dots;z_N]\in\mathbb{R}^{(N+1)\times D} Zseq​=[zcls​;z1​;z2​;…;zN​]∈R(N+1)×D

其中，[CLS]\text{[CLS]}[CLS] 不对应任何图像区域，它通过自注意力机制与所有的 Patch Token 交互，逐层聚合整幅图像的信息，最终用于图像分类

可学习位置嵌入

各个 Patch 序列化后，模型需要知道每个 Patch 在原始图像中的空间位置，ViT 使用可学习的绝对位置嵌入：

Epos∈R(N+1)×DE_{\text{pos}}\in\mathbb{R}^{(N+1)\times D} Epos​∈R(N+1)×D

初始 Encoder 输入为：

Z(0)=Zseq+EposZ^{(0)} = Z_{\text{seq}} + E_{\text{pos}} Z(0)=Zseq​+Epos​

其中，第 0 个位置嵌入对应 [CLS]\text{[CLS]}[CLS]，其余位置按 Patch 的行优先顺序依次对应二维图像上的每一个网格

多层 Encoder 架构

ViT 将构造好的输入序列 Z(0)Z^{(0)}Z(0) 依次输入 LLL 个串联的 Transformer Encoder：

Z(l)=Encoder(l)(Z(l−1)),l=1,…,LZ^{(l)} = \text{Encoder}^{(l)}(Z^{(l-1)}),\quad l=1,\dots,L Z(l)=Encoder(l)(Z(l−1)),l=1,…,L

每一层 Transformer Encoder 的结构为：

LayerNorm→MSA→残差连接→LayerNorm→FFN→残差连接\text{LayerNorm}\to\text{MSA}\to\text{残差连接}\to\text{LayerNorm}\to\text{FFN}\to\text{残差连接} LayerNorm→MSA→残差连接→LayerNorm→FFN→残差连接

其中，MSA 对应多头自注意力子层，FFN 对应逐位置前馈网络子层

原始 ViT 采用 Pre-LN 的顺序，层间直接传递完整的序列矩阵：

Z(0)→Z(1)→⋯→Z(L)Z^{(0)}\to Z^{(1)}\to\cdots\to Z^{(L)} Z(0)→Z(1)→⋯→Z(L)

各层参数独立，且始终保持隐层表示的形状为：

Z(l)∈R(N+1)×DZ^{(l)}\in\mathbb{R}^{(N+1)\times D} Z(l)∈R(N+1)×D

即信息融合过程中，序列长度和隐藏维度都不改变，只有每个 Token 的上下文表示不断深化

分类输出

最后一层 Encoder 的输出为：

Z(L)=[zcls(L);z1(L);… ;zN(L)]Z^{(L)} = [z_{\text{cls}}^{(L)};z_1^{(L)};\dots;z_N^{(L)}] Z(L)=[zcls(L)​;z1(L)​;…;zN(L)​]

取最终 [CLS][CLS][CLS] 对应的隐藏表示：

h=zcls(L)∈RDh = z_{\text{cls}}^{(L)}\in\mathbb{R}^D h=zcls(L)​∈RD

经过分类头输出：

o=Wch+bc∈RKp=softmax(o)o = W_ch + b_c\in\mathbb{R}^K\\ p = \text{softmax}(o) o=Wc​h+bc​∈RKp=softmax(o)

其中，KKK 为待分类的类别数

整个过程的类别变化过程为：

H×W×C,原始图像↓N×D,Patch Embedding↓(N+1)×D,[CLS] + Position Embedding↓(N+1)×D,Encoder 序列形状↓D,[CLS]隐层表示维度↓K,类别数H\times W\times C,\quad\text{原始图像}\\ \downarrow\\ N\times D,\quad\text{Patch Embedding}\\ \downarrow\\ (N+1)\times D,\quad\text{[CLS] + Position Embedding}\\ \downarrow\\ (N+1)\times D,\quad\text{Encoder 序列形状}\\ \downarrow\\ D,\quad\text{[CLS]隐层表示维度}\\ \downarrow\\ K,\quad\text{类别数} H×W×C,原始图像↓N×D,Patch Embedding↓(N+1)×D,[CLS] + Position Embedding↓(N+1)×D,Encoder 序列形状↓D,[CLS]隐层表示维度↓K,类别数

ViT 的核心在于：用 Patch Token 表示局部图像区域，[CLS] Token 通过多层全局自注意力汇总整张图像（即各个 Patch Token）的信息，最终完成分类

ViT 核心计算过程

进入第 lll 层 Encoder 的序列为：

Z(l−1)=[zcls(l−1),z1(l−1),…,zN(l−1)]∈R(N+1)×DZ^{(l-1)} = [z_{\text{cls}}^{(l-1)},z_1^{(l-1)},\dots,z_N^{(l-1)}]\in\mathbb{R}^{(N+1)\times D} Z(l−1)=[zcls(l−1)​,z1(l−1)​,…,zN(l−1)​]∈R(N+1)×D

其中，ziz_izi​ 表示第 iii 个 Patch Token 对应的隐藏表示

Patch Token 全局交互

ViT 不限制注意力范围，位置 iii 可以融合整个序列上 N+1N+1N+1 个位置 jjj 的信息：

qi=ziWQ,kj=zjWK,vj=zjWVq_i = z_iW^Q,\quad k_j = z_jW^K,\quad v_j = z_jW^V qi​=zi​WQ,kj​=zj​WK,vj​=zj​WV

αij=exp⁡(qikj⊤dk)∑m=0Nexp⁡(qikm⊤dk)\alpha_{ij} = \frac{\exp(\frac{q_i k_j^\top}{\sqrt d_k})}{\sum_{m=0}^N\exp(\frac{q_ik_m^\top}{\sqrt d_k})} αij​=∑m=0N​exp(d​k​qi​km⊤​​)exp(d​k​qi​kj⊤​​)​

因此，每个 Patch Token 不仅包含自身区域的信息，还能直接融合远距离 Patch 和 [CLS] 的信息，经过多层融合后，Patch 表示由局部像素描述逐渐变为全局上下文化的视觉表示

[CLS] 也会与每个 Patch Token 一起参与全局注意力，其输出为：

最后一层 Encoder 的输出经过 LayerNorm 之后：

H=[hcls,h1,…,hN]H = [h_{\text{cls}},h_1,\dots,h_N] H=[hcls​,h1​,…,hN​]

其中，hcls∈RDh_{\text{cls}}\in\mathbb{R}^Dhcls​∈RD 为面向整张图像的序列级表示；hi∈RDh_i\in\mathbb{R}^Dhi​∈RD 为第 iii 个空间区域的上下文化表示

二者具有不同的语义职责，如果是分类任务则使用 hclsh_{\text{cls}}hcls​ 即可代表整张图像，如果是目标检测、语义分割等密集任务则需要使用全部 Patch 对应的 hih_ihi​ 表示

分类头

对 KKK 类分类：

[CLS] 的作用也可以使用全局平均池化策略来代替，即对最后一层 Encoder 输出的所有 Patch Token 对应的隐藏表示求平均：

二者的融合机制并不相同，GAP 对所有 Patch 做等权重汇聚，[CLS][\mathrm{CLS}][CLS] 则通过多层注意力进行自适应聚合

ViT 位置编码插值

经典 ViT 架构使用可学习绝对位置嵌入，训练分辨率固定时，每个 Patch 位置都对应一个可学习的位置向量：

Epos=[ecls,e1,…,eN]∈R(N+1)×DE_{\text{pos}} = [e_{\text{cls}},e_1,\dots,e_N]\in\mathbb{R}^{(N+1)\times D} Epos​=[ecls​,e1​,…,eN​]∈R(N+1)×D

其中，eclse_{\text{cls}}ecls​ 对应 [CLS]，其余 NNN 个位置向量各自对应一个二维 Patch 网格

分辨率变化问题

假设训练时使用的图像满足：

H=W=224,P=16H=W=224,\quad P=16 H=W=224,P=16

则 Patch 网格为：

HP=WP=22416=14H_P = W_P = \frac{224}{16} = 14 HP​=WP​=16224​=14

Patch 数量为：

位置嵌入矩阵的形状为：

Epos∈R197×DE_{\text{pos}}\in\mathbb{R}^{197\times D} Epos​∈R197×D

某一时刻，输入图像的分辨率突然变成 384×384384\times 384384×384，而 Patch 大小仍然使用 16，则有：

Hp′=WP′=38416=24H_p^{'} = W_P^{'} = \frac{384}{16} = 24 Hp′​=WP′​=16384​=24

和原有的位置嵌入矩阵形状不符，二者无法再直接按行匹配相加

此时，我们不能通过简单的补零或数值复用策略来对齐两个序列，因为位置嵌入描述的是 Patch 在图像网格中的空间位置，直接补零会让新增位置没有有效位置信息；直接重复则会让多个不同位置使用相同的位置向量

因此，需要把原来的 14×1414\times1414×14 位置网格平滑扩展成 24×2424\times2424×24

具体插值过程

分离 [CLS]

其中，ecls∈R1×De_{\text{cls}}\in\mathbb{R}^{1\times D}ecls​∈R1×D，Epatch∈R196×DE_{\text{patch}}\in\mathbb{R}^{196\times D}Epatch​∈R196×D，由于 [CLS] 并不对应某个实际的二维图像的位置，因此不参与空间插值

其中位置 (r,c)(r,c)(r,c) 即对应原图中第 rrr 行，第 ccc 列的 Patch

对每个特征通道分别进行二维插值：

Epos′=[ecls;Epatch′]∈R577×DE_{\mathrm{pos}}' = [e_{\mathrm{cls}};E_{\mathrm{patch}}'] \in\mathbb R^{577\times D} Epos′​=[ecls​;Epatch′​]∈R577×D

此时可以与新输入序列相加：

Z(0)=Zseq+Epos′Z^{(0)} = Z_{\mathrm{seq}}+E_{\mathrm{pos}}' Z(0)=Zseq​+Epos′​

训练得到的位置嵌入通常在二维网格上呈现一定的平滑空间结构：邻近 Patch 的位置向量往往比远距离 Patch 更相似

因此，可以把位置嵌入看成一个离散二维位置场：

f(r,c)∈RDf(r,c)\in\mathbb R^D f(r,c)∈RD

插值相当于在原有位置之间估计新的位置表示，而不是从头随机初始化

Swin

第二部分：Swin Transformer

模块五：Swin Transformer 的设计动机

从 ViT 的两个主要问题出发：

  1. 全局注意力随图像分辨率呈平方复杂度增长；
  2. ViT 默认只生成单一尺度的序列表示，不具备 CNN 式层次特征。

由此引出 Swin 的三项核心设计：

局部窗口注意力+移位窗口+层次化特征结构\boxed{ \text{局部窗口注意力} + \text{移位窗口} + \text{层次化特征结构} }局部窗口注意力+移位窗口+层次化特征结构

这一模块只建立问题与改进方法的对应关系。

模块六：窗口多头自注意力 W-MSA

详细推导：

  • 特征图如何划分为互不重叠窗口；
  • 每个窗口内部如何独立执行自注意力；
  • 窗口尺寸与 Token 数量；
  • 为什么计算复杂度由全局平方级降低为近似线性；
  • 二维相对位置偏置；
  • 窗口之间暂时无法通信的问题。

重点比较：

ViT：全局注意力Swin：窗口内局部注意力\text{ViT：全局注意力} \qquad \text{Swin：窗口内局部注意力}ViT：全局注意力Swin：窗口内局部注意力

模块七：移位窗口注意力 SW-MSA

这是 Swin 最核心的模块，需要详细推导：

  • 为什么固定窗口会阻断跨窗口信息；
  • 窗口平移 M/2M/2M/2 后，Token 如何重新组合；
  • W-MSA 与 SW-MSA 为什么交替出现；
  • 循环移位；
  • Attention Mask 如何阻止错误区域相互注意；
  • 两个连续 Swin Block 如何完成跨窗口通信。

核心流程：

W-MSA Block→SW-MSA Block→跨窗口信息交换\text{W-MSA Block} \rightarrow \text{SW-MSA Block} \rightarrow \text{跨窗口信息交换}W-MSA Block→SW-MSA Block→跨窗口信息交换

模块八：Patch Merging 与层次化特征

详细讲解 Swin 如何逐阶段降低空间分辨率并增加通道维度：

H4×W4×C→H8×W8×2C→H16×W16×4C\frac{H}{4}\times\frac{W}{4}\times C \rightarrow \frac{H}{8}\times\frac{W}{8}\times2C \rightarrow \frac{H}{16}\times\frac{W}{16}\times4C4H×4W×C→8H×8W×2C→16H×16W×4C

重点包括：

  • 相邻 2×22\times22×2 Token 的拼接；
  • 为什么拼接后维度变成 4C4C4C；
  • 线性投影为什么输出 2C2C2C；
  • 空间分辨率和通道数如何变化；
  • 层次特征与 CNN 特征金字塔的联系。

  • 每个 Stage 内包含多少个 Swin Block；

  • Swin-T、Swin-S、Swin-B 的主要结构差异；
  • 最终分类表示如何形成。
