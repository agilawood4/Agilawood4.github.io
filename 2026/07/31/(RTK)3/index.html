GNSS 观测量

RTK 在完成定位解算时，主要使用接收机跟踪卫星信号后生成的原始观测数据：

伪距 P,载波相位 Φ,多普勒 D,C/N0\text{伪距 P},\quad \text{载波相位 }\Phi,\quad\text{多普勒 D},\quad\text{C/N0} 伪距 P,载波相位 Φ,多普勒 D,C/N0

此外，还需要配合观测时刻、卫星编号、信号和频点标识、周跳等信息，因此我们首先需要弄明白每种观测量都反映什么物理信息，以及它们在 RTK 解算中承担的作用

符号统一与说明

在后续的推导和说明中，我们统一使用以下符号：

  • rrr：接收机
  • sss：卫星
  • fff：载波所在频段
  • kkk：观测历元
  • tkt_ktk​：第 tkt_ktk​ 个观测时刻
  • ccc：光速
  • fff_fff​：频段 fff 的载波频率
  • λf\lambda_fλf​：频段 fff 的载波波长
  • ρrs\rho_r^sρrs​：卫星 sss 到接收机 rrr 的几何距离

四大类观测量统一记为：

  • Pr,fs(k)P_{r,f}^s(k)Pr,fs​(k)：伪距 - 米
  • Φr,fs(k)\Phi_{r,f}^s(k)Φr,fs​(k)：载波相位 - 周
  • Dr,fs(k)D_{r,f}^s(k)Dr,fs​(k)：多普勒 - Hz
  • C/N0r,fs(k)\text{C/N0}_{r,f}^s(k)C/N0r,fs​(k)：载噪比 - dB-Hz

观测历元

接收机通常按照固定采样频率输出观测数据，常见的频率比如：

  • 1Hz：每 1 秒输出一次
  • 5Hz：每 0.2 秒输出一次
  • 10Hz：每 0.1 秒输出一次

某一个采样时刻 tkt_ktk​ 就称为一个观测历元

在同一个历元内，接收机可能同时输出多颗卫星，每个卫星包含多个频段，每个频段有包含多条信号对应的观测值：

Or(k)={Pr,fs(k),  Φr,fs(k),  Dr,fs(k),  C/N0r,fs(k)}\mathcal{O}_r(k) = \{P_{r,f}^s(k),\;\Phi_{r,f}^s(k),\;D_{r,f}^s(k),\;\text{C/N0}_{r,f}^s(k)\} Or​(k)={Pr,fs​(k),Φr,fs​(k),Dr,fs​(k),C/N0r,fs​(k)}

换言之，一条完整的观测必须包含：

观测时刻 + 接收机 + 卫星 + 信号/频段 + 观测类型\text{观测时刻 + 接收机 + 卫星 + 信号/频段 + 观测类型} 观测时刻 + 接收机 + 卫星 + 信号/频段 + 观测类型

伪距

伪距是接收机根据测距码传播时间得到的 “卫星 - 接收机” 的距离观测值

卫星在发射时刻 tst^sts 发出测距码，接收机在接收时刻 trt_rtr​ 检测到该码，如果卫星钟和接收机钟完全同步，且不存在任何其他误差，则传播距离即为：

ρrs=c(tr−ts)\rho_r^s = c(t_r - t^s) ρrs​=c(tr​−ts)

但现实中，因为卫星钟和接收机钟之间存在偏差，信号经过电离层和对流层会引入噪声，再加上接收机和卫星硬件的延迟，以及码跟踪过程中的噪声和多路径

接收机实际获得的是：

Prs=c(t~r−t~s)P_r^s = c(\tilde{t}_r - \tilde{t}^s) Prs​=c(t~r​−t~s)

其中，t~r\tilde{t}_rt~r​ 和 t~s\tilde{t}^st~s 是接收机钟和卫星钟各自表示的时间，并不是完全一致的理想系统时间

所以则有：

Prs≠ρrsP_r^s \ne \rho_r^s Prs​​=ρrs​

这也是它被称为 “伪距” 的原因

RINEX 对伪距的定义也是：卫星天线到接收机天线距离的观测值，其中包含卫星钟差、接收机钟差、大气延迟等偏差，以米为单位进行存储

伪距观测方程

伪距的概念观测方程可以写成：

Pr,fs=ρrs+c(δtr−δts)+Ir,fs+Trs+bP,r,fs+εP,r,fsP_{r,f}^s = \rho_r^s + c(\delta t_r - \delta t^s) + I_{r,f}^s + T_r^s + b_{P,r,f}^s + \varepsilon_{P,r,f}^s Pr,fs​=ρrs​+c(δtr​−δts)+Ir,fs​+Trs​+bP,r,fs​+εP,r,fs​

其中，ρrs\rho_r^sρrs​ 为几何距离，δtr\delta t_rδtr​ 是接收机钟差，δts\delta t^sδts 是卫星钟差，Ir,fsI_{r,f}^sIr,fs​ 是电离层延迟，TrsT_r^sTrs​ 是对流层延迟，bP,r,fsb_{P,r,f}^sbP,r,fs​ 是硬件及其他系统偏差，εP,r,fs\varepsilon_{P,r,f}^sεP,r,fs​ 是其他噪声

换言之，伪距即为真实几何距离和各种误差与噪声加和的结果，它不是接收机根据已知坐标计算得到的理论值，而是接收机真实测量到的观测值

伪距的生成

接收机内部生成一份与卫星相同的本地 PRN 码，并调节本地码的位置，使它与接收到的卫星码对齐

假设估计出的码延迟为：

τ^r,f\hat{\tau}_{r,f} τ^r,f​

伪距即可表示为：

Pr,fs=cτ^r,fP_{r,f}^s = c\hat{\tau}_{r,f} Pr,fs​=cτ^r,f​

但这里的 τ^r,f\hat{\tau}_{r,f}τ^r,f​ 同样混入了时钟误差和传播误差，因此不能称为纯信号传播时间

伪距的优点和局限

伪距的优点在于：

  • 可以提供绝对测距信息
  • 不存在未知整周数问题
  • 信号重新捕获后可以较快重新生成
  • 可以直接用于单点定位和 RTK 初始化

伪距的局限性在于：

  • 码跟踪噪声较大
  • 多路径影响明显
  • 精度远低于载波相位
  • 单独使用难以稳定达到厘米级

因此，在 RTK 实际实现中，伪距通常仅负责提供粗位置、辅助初始化绝对尺度和模糊度，而真正的厘米级精度主要来自载波相位

载波相位

载波相位本身是周期性电磁波，接收机通过 PLL 跟踪接收载波与本地载波之间的相位差，接收机可以精确测得：

  • 当前载波的小数相位
  • 从上一历元到当前历元累计变化了多少周

但在刚开始锁定卫星时，接收机并不知道卫星和接收机之间已经存在多少个完整的载波周期

因此，载波相位观测仅能测得精确的小数相位和连续累计变化，但初始的整周期数未知，RINEX 把载波相位保存为以完整周期为单位的连续相位观测，历元之间需要通过累计整周期数保持连续

载波相位的单位

载波相位的观测值记为 Φr,fs\Phi_{r,f}^sΦr,fs​，单位是 cycle\text{cycle}cycle，例如：

Φr,fs=110000000.25cycle\Phi_{r,f}^s = 110000000.25\text{cycle} Φr,fs​=110000000.25cycle

表示接收机输出的累计载波相位是 1.1 亿个完整周，再加上四分之一周

将其转换成距离需要乘以载波波长：

Lr,fs=λΦr,fsL_{r,f}^s = \lambda\Phi_{r,f}^s Lr,fs​=λΦr,fs​

对应的单位为米

例如 GPS L1 频段的波长为 0.19m，则 0.01 周相位变化就对应：

0.01×0.19=0.0019m0.01\times0.19 = 0.0019m 0.01×0.19=0.0019m

这说明载波相位能够分辨非常细微的距离变化，但不代表其测得的绝对距离天然就是毫米级，因为其中还包含整周模糊度和其他误差

整周模糊度

假设接收机刚刚开始跟踪卫星，它能够看到当前相位处于一个周期中的某个位置，例如：

0.25 cycle0.25 \text{ cycle} 0.25 cycle

但它无法仅凭当前相位判断完整传播路径中是：

100 000 000.25 cycle100\,000\,000.25\ \text{cycle} 100000000.25 cycle

还是：

100 000 001.25 cycle100\,000\,001.25\ \text{cycle} 100000001.25 cycle

或其他整数周数

因此引入未知整数：

Nr,fs∈ZN_{r,f}^s\in\mathbb Z Nr,fs​∈Z

称为整周模糊度，它不是相位测量噪声，而是一个待估计的未知参数

载波相位观测方程

以距离为单位，载波相位观测方程可以写成：

λfΦr,fs=ρrs+c(δtr−δts)−Ir,fs+Trs+λfNr,fs+bΦ,r,fs+εΦ,r,fs\lambda_f\Phi_{r,f}^s = \rho_r^s + c(\delta t_r - \delta t^s) - I_{r,f}^s + T_r^s + \lambda_f N_{r,f}^s + b_{\Phi,r,f}^s + \varepsilon_{\Phi,r,f}^s λf​Φr,fs​=ρrs​+c(δtr​−δts)−Ir,fs​+Trs​+λf​Nr,fs​+bΦ,r,fs​+εΦ,r,fs​

其中，λrΦr,fs\lambda_r\Phi_{r,f}^sλr​Φr,fs​ 为载波相位距离，Nr,fsN_{r,f}^sNr,fs​ 为整周模糊度，bΦ,r,fsb_{\Phi,r,f}^sbΦ,r,fs​ 为载波硬件偏差和初始相位偏差，εΦ,r,fs\varepsilon_{\Phi,r,f}^sεΦ,r,fs​ 是载波相位噪声

其余参数和伪距观测方程中的物理含义完全相同

需要注意电离层项的符号，伪距中通常为 +I+I+I；载波相位中通常为 −I-I−I，这是因为电离层对码产生群延迟，而对载波相位产生相位超前

整周模糊度

对于固定的接收机 rrr，卫星 sss，频段 fff 以及连续跟踪弧段，如果载波始终保持锁定，没有发生周跳，那么则有：

Nr,fs(k)=Nr,fs(k+1)N_{r,f}^s(k) = N_{r,f}^s(k+1) Nr,fs​(k)=Nr,fs​(k+1)

即郑州模糊度在连续跟踪期间不发生改变

但是当遇到信号遮挡、接收机失锁、强多路径、强干扰、动态过大、接收机时钟跳变、重新捕获等情况时，累计相位可能发生不连续，导致原本的模糊度状态可能失效

载波相位 vs. 伪距

特性 伪距 (PPP) 载波相位 (Φ\PhiΦ)
信号来源 测距码跟踪 载波跟踪
常用单位 m cycle
转为距离 本身已经是米 乘以 (\lambda)
初始整数模糊度 无 有
测量噪声 较大 较小
多路径影响 通常更明显 通常较小但仍存在
连续性要求 相对较低 非常高
周跳影响 通常不产生整数跳变 会破坏相位连续性
RTK 中作用 粗定位、初始化、辅助约束 厘米级定位核心

当前定位解算的核心矛盾就在于：伪距测量值绝对但不够精确，载波相位精确但存在未知的整数模糊度

RTK 的核心工作，就是利用伪距和几何信息帮助估计载波模糊度，再充分利用载波相位的高精度，完成厘米级精度的定位

多普勒

当卫星和接收机之间存在相对运动时，接收机检测到的载波频率会偏离卫星信号的标称频率，这种现象就称为多普勒效应

例如，卫星与接收机相互靠近时，接收频率通常升高；而卫星与接收机相互远离时，接收频率通常降低

但接收机测得的频率变化还包含卫星钟漂、接收机钟漂等误差，因此多普勒并不能直接表示纯粹的几何相对速度

多普勒的单位

多普勒观测记为：

Dr,fsD_{r,f}^s Dr,fs​

单位是：

Hz=cycles\text{Hz} = \frac{\text{cycle}}{\text{s}} Hz=scycle​

它表示单位时间内，载波相位变化的周数

在 RINEX 符号约定中，规定当卫星靠近接收机时，多普勒为正

多普勒与载波相位变化的关系

按照 RINEX 和 RTKLIB 所采用的符号约定：

Dr,fs≈−dΦr,fsdtD_{r,f}^s\approx -\frac{d\Phi_{r,f}^s}{dt} Dr,fs​≈−dtdΦr,fs​​

在较短的时间间隔 Δt\Delta tΔt 内：

ΔΦr,fs≈−Dr,fsΔt\Delta \Phi_{r,f}^s\approx -D_{r,f}^s\Delta t ΔΦr,fs​≈−Dr,fs​Δt

其中：

ΔΦr,fs=Φr,fs(k)−Φr,fs(k−1)\Delta \Phi_{r,f}^s = \Phi_{r,f}^s(k) - \Phi_{r,f}^s(k-1) ΔΦr,fs​=Φr,fs​(k)−Φr,fs​(k−1)

换言之，我们可以用多普勒来预测或估计相邻历元之间，载波相位的变化

多普勒与距离变化的关系

当忽略钟漂、大气变化等误差影响时：

Φ≈ρλ+N\Phi\approx\frac{\rho}{\lambda} + N Φ≈λρ​+N

对时间求导得到：

Φ˙≈ρ˙λ\dot{\Phi} \approx \frac{\dot{\rho}}{\lambda} Φ˙≈λρ˙​​

代入上一小节的 D≈Φ˙D\approx\dot{\Phi}D≈Φ˙ 则有：

ρ˙≈−λD\dot{\rho}\approx-\lambda D ρ˙​≈−λD

其中，ρ˙\dot{\rho}ρ˙​ 表示 “卫星 - 接收机” 距离的变化率，也称为视线方向距离率，这不是接收机的三维速度，只是 “卫星 - 接收机” 之间的相对速度在视线方向上的投影

需要多颗卫星的多普勒联合解算，才能估计接收机三维速度和接收机钟漂

C/N0

C/N0 称为载噪比，是接收机对某颗卫星某个信号分量的跟踪质量指标，可以表示为：

CN0\frac{C}{N_0} N0​C​

其中，CCC 表示接收机跟踪到的某颗卫星、某个信号的载波功率，N0N_0N0​ 表示噪声功率谱密度

因此则有：

CN0=载波功率单位带宽噪声功率\frac{C}{N_0} = \frac{\text{载波功率}}{单位带宽噪声功率} N0​C​=单位带宽噪声功率载波功率​

其线性单位为 Hz，工程上通常使用：

(CN0)dB-Hz=10log⁡10(CN0)\left(\frac{C}{N_0}\right)_{\text{dB-Hz}} = 10\log_{10}\left(\frac{C}{N_0}\right) (N0​C​)dB-Hz​=10log10​(N0​C​)

对应的单位为 dB-Hz

C/N0 含义

一般而言，较高的 C/N0 通常表明：

  • 信号更强
  • 码跟踪更稳定
  • 载波跟踪噪声更小
  • 失锁概率更低
  • 观测值通常更可靠

而较低或剧烈波动的 C/N0 则可能和以下因素有关：

  • 卫星高度角过低
  • 建筑物或树木遮挡
  • 天线方向不佳
  • 射频干扰
  • 多路径干扰
  • 接收机前端饱和
  • 信号跟踪状态异常

但不能简单认为，C/N0 高就代表观测必然没有误差，某些强反射多路径的信号仍然可能具有较高的 C/N0，但观测偏差同样很大

S 与 SSI

RINEX 中存在两个容易混淆的概念

  • 信号观测强度值 S\text{S}S：例如 S1CS1CS1C，表示对应信号的的观测强度，一般会存储以 dB-Hz 为单位的载噪密度比
  • SSI\text{SSI}SSI：SSI\text{SSI}SSI 是附加在某个观测值后的单字符信号强度指示器，通常取值范围为 1∼91\sim91∼9，它是压缩后的等级，不是原始的 dB-Hz 数值

RINEX 将 S\text{S}S 定义为信号强度观测类型，SSI\text{SSI}SSI 定义为 1 到 9 的紧凑质量等级，二者不能混为一谈

锁定时间与锁定状态

当接收机的 DLL、FLL 或 PLL 能够持续跟踪某个卫星信号时，我们就称此时信号处于锁定状态

对于 RTK 而言，最关键的是载波锁定，如果载波连续锁定，接收机就可以保持载波相位历元之间的连续关系

锁定时间

锁定时间表示当前信号已连续保持多长跟踪时间，或者内部计数器表示连续锁定了多少个历元

锁定时间越长，一般就意味着：

  • 当前相位弧段持续更久，模糊度状态更稳定
  • 近期没有明显失锁，更适合参加模糊度固定

但锁定时间长也不保证观测一定正确，因为仍然可能存在未探测的周跳或多路径

LLI

LLI（Loss of Lock Indicator），即失锁指示标志，它通常附属于载波相位观测，用于告诉后处理软件：

  • 当前历元之前可能发生了失锁，相位连续性可能已经破坏
  • 可能存在周跳
  • 可能存在半周模糊度

RINEX 中将 LLI 定义为三比特标志位：

  • Bit 0：表示从上一历元道当前历元之间发生过失锁，因此可能存在周跳
  • Bit 1：表示当前相位可能存在半周模糊度或半周跳变
  • Bit 2：表示该观测使用了特定的 BOC 跟踪模式，可能具有较高噪声

LLI 主要与载波相位观测相关联，而不是伪距观测

半周模糊度

一个完整载波周期对应 2π2\pi2π 的相位，半个周期则对应 π\piπ 的相位，如果接收机只能确定相位到最小为 π\piπ 的周期，而不能准确区分相位相差 180°180^°180° 的两种状态，就可能产生 0.5cycle0.5\text{cycle}0.5cycle 的不确定性，这种情况就称为半周模糊度

经典整周模糊度固定要求：

N∈ZN\in\mathbb{Z} N∈Z

但如果观测存在未知半周偏差，则相位偏差可能属于：

N+12N+\frac{1}{2} N+21​

此时直接按整数进行固定会破坏整数模型

因此，当半周状态未知时，软件通常需要等待半周观测恢复，或排除该观测，RINEX 要求半波长相位观测以完整周期形式存储，但必须通过观测代码或 LLI 正确标记，模糊度处理中仍需考虑半波长性质

周跳

周跳是连续载波相位观测过程中的突发性不连续现象

假设正常情况下：

Φ(k)−Φ(k−1)\Phi(k) - \Phi(k-1) Φ(k)−Φ(k−1)

仅反映真实载波相位周期变化，钟差变化和小量噪声

但如果两个历元之间丢失了 mmm 个完整的载波周期，则有：

Φ(k)=Φ正常(k)+m\Phi(k) = \Phi_{\text{正常}}(k) + m Φ(k)=Φ正常​(k)+m

其中：

m∈Z,m≠0m\in\mathbb{Z},\quad m\ne 0 m∈Z,m​=0

这就是所谓的周跳现象

周跳对 RTK 的影响

发生周跳后，原有相位观测模型中的模糊度变为：

Nnew=Nold+mN_{\text{new}} = N_{\text{old}} + m Nnew​=Nold​+m

如果算法没有检测到周跳，而是仍然使用旧模糊度，就会导致浮点解偏移或模糊度固定失败，严重时可能会产生错误固定

因此，当检测到发生周跳时，通常需要标记该观测，重置相关模糊度状态，然后重新初始化并重新积累连续锁定历元

RINEX 观测代码

RINEX 使用三字符观测代码：

tnatna tna

其中，ttt 表示观测类型，nnn 表示频段编号，aaa 表示信号或跟踪属性

其中对于观测类型 ttt，有如下的几种候选类型：

取值 含义
C 码观测/伪距
L 载波相位
D 多普勒
S 信号强度

RINEX 明确使用 C/L/D/S 区分伪距、载波相位、多普勒和信号强度，并通过后两位继续描述频段和具体跟踪信号

以 GPS L1 C/A 为例：

C1C : L1 C/A 伪距L1C : L1 C/A 载波相位D1C : L1 C/A 多普勒S1C : L1 C/A 信号强度\text{C1C : L1 C/A 伪距}\\ \text{L1C : L1 C/A 载波相位}\\ \text{D1C : L1 C/A 多普勒}\\ \text{S1C : L1 C/A 信号强度} C1C : L1 C/A 伪距L1C : L1 C/A 载波相位D1C : L1 C/A 多普勒S1C : L1 C/A 信号强度

它们是来自同一个卫星信号的四种不同的观测量

RTKLIB 原始观测

RTKLIB 的核心观测结构 obsd_t 可以记为：

各指标单位为，L : cycle,P : m,D : Hz,SNR : 0.25dB-Hz\text{L : cycle},\quad \text{P : m},\quad\text{D : Hz},\quad \text{SNR : 0.25dB-Hz}L : cycle,P : m,D : Hz,SNR : 0.25dB-Hz

其中，载波相位的单位以周数进行保存，在实际定位模型中，还需要：

obs→L[i]×λi\text{obs}\to\text{L[i]}\times \lambda_i obs→L[i]×λi​

将其转换为米为单位

同理，SNR 和 C/N0 也有四倍关系：

SNR=4×C/N0dB-Hz\text{SNR} = 4\times \text{C/N0}_{\text{dB-Hz}} SNR=4×C/N0dB-Hz​

因此，真实的 C/N0 数值应当取记录中 SNR 数值的四分之一

四类核心观测量关系

RTK 解算定位用到的四类核心观测量：伪距，载波相位，多普勒，载噪比存在如下的关系

伪距 vs. 载波相位

二者本质都反映 “卫星 - 接收机” 之间的几何距离（含误差）：

P∼ρλΦ∼ρ+λNP\sim\rho\\ \lambda\Phi\sim\rho + \lambda N P∼ρλΦ∼ρ+λN

所以二者的变化趋势通常相近

区别在于，伪距没有整周模糊度，但噪声大；载波相位噪声小，但存在整周模糊度

载波相位 vs. 多普勒

多普勒可以近似看成载波相位对时间的负导数：

D≈−Φ˙D\approx-\dot{\Phi} D≈−Φ˙

因此可以利用多普勒预测短时间内的相位变化：

Φ(k)≈Φ(k−1)−D(k)Δt\Phi(k) \approx \Phi(k-1)-D(k)\Delta t Φ(k)≈Φ(k−1)−D(k)Δt

如果实际相位变化与预测严重不一致，则可能存在周跳、钟跳或其他异常
