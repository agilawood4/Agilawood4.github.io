序列建模与 RNN

序列建模问题

序列数据由按顺序排列的元素组成：

X=(x1,x2,…,xT)X = (x_1,x_2,\dots,x_T) X=(x1​,x2​,…,xT​)

其中，TTT 是序列长度，xt∈Rdxx_t\in\mathbb{R}^{d_x}xt​∈Rdx​ 是第 ttt 个时间步的输入向量

序列建模的目标即让第 ttt 个时刻的计算不仅依赖于 xtx_txt​，还依赖于此前的信息：

yt=F(x1,x2,…,xt)y_t = F(x_1,x_2,\dots,x_t) yt​=F(x1​,x2​,…,xt​)

RNN 整体架构

传统的循环神经网络 RNN 主要包含三部分：

xt→输入映射ht→输出映射ytx_t\xrightarrow{\text{输入映射}}h_t\xrightarrow{\text{输出映射}}y_t xt​输入映射​ht​输出映射​yt​

其中，第 ttt 个时刻的中间状态 hth_tht​ 不仅接收输入 xtx_txt​，还会接收上一时刻的中间状态 ht−1h_{t-1}ht−1​，即满足：

(xt,ht−1)→ht(x_t,h_{t-1})\to h_t (xt​,ht−1​)→ht​

因此，完整递推关系为：

ht=ϕ(Wxhxt+Whhht−1+bh)h_t = \phi(W_{xh}x_t + W_{hh}h_{t-1} + b_h) ht​=ϕ(Wxh​xt​+Whh​ht−1​+bh​)

其中，ht∈Rdhh_t\in\mathbb{R}^{d_h}ht​∈Rdh​ 表示当前隐藏状态，Wxh∈Rdh×dxW_{xh}\in\mathbb{R}^{d_h\times d_x}Wxh​∈Rdh​×dx​ 为输入到隐藏层之间的映射矩阵，Whh∈Rdh×dhW_{hh}\in\mathbb{R}^{d_h\times d_h}Whh​∈Rdh​×dh​ 为隐藏状态之间的循环映射矩阵，ϕ\phiϕ 为激活函数（通常选取 tanh）

隐状态和历史信息保存

用上一小节的递推关系，将前一时刻状态展开：

ht−1=ϕ(Wxhxt−1+Whhht−2+bh)h_{t-1} = \phi(W_{xh}x_{t-1} + W_{hh}h_{t-2} + b_h) ht−1​=ϕ(Wxh​xt−1​+Whh​ht−2​+bh​)

同理，对 ht−2,ht−1,…h1h_{t-2},h_{t-1},\dots h_1ht−2​,ht−1​,…h1​ 分别展开，则可得到：

ht=F(xt,xt−1,…,x1,h0)h_t = F(x_t,x_{t-1},\dots,x_1,h_0) ht​=F(xt​,xt−1​,…,x1​,h0​)

因此，hth_tht​ 是截至时刻 ttt 的序列信息经过递归压缩后形成的隐藏表示，它不是某一个输入元素，也不是原始历史数据的简单拼接

其中，初始隐藏状态 h0h_0h0​ 通常设置为零向量或一组可学习参数

输出层

RNN 的输出通常由隐层状态经过线性映射得到：

at=Whyht+bta_t = W_{hy}h_t + b_t at​=Why​ht​+bt​

其中，ata_tat​ 通常是输出层的未归一化得分，对于分类任务，则可进一步计算：

yt=softmax(at)y_t = \text{softmax}(a_t) yt​=softmax(at​)

隐藏状态 hth_tht​ 负责表示序列上下文，输出层则用于把该表示映射到具体的任务空间

时间展开与参数共享

RNN 在时间维度上可以展开为：

x1→h1→h2⋯→hTx_1\to h_1\to h_2\cdots\to h_T x1​→h1​→h2​⋯→hT​

每个时间步都会使用相同的参数：

Wxh,Whh,bhW_{xh},\quad W_{hh},\quad b_h Wxh​,Whh​,bh​

参数共享使得同一套状态更新规则能够处理不同长度的序列（改变的只是 dxd_xdx​，而 dhd_hdh​ 始终不变），时间步之间传递的是隐藏状态 hth_tht​，而不是重新建立一套网络参数

RNN 的常见输出结构包括以下三种

  1. 多对一：仅使用最后一个时刻的输出 hTh_ThT​ 进行序列分类
  2. 一对多：每个时刻的 hth_tht​ 都产生对应的输出 yty_tyt​
  3. 多对多：由一个输入 h0h_0h0​ 逐步生成整个序列，每次循环都使用 h0,h1,…,hth_0,h_1,\dots,h_th0​,h1​,…,ht​ 的共同信息，生成新的 ht+1h_{t+1}ht+1​

长期依赖问题

普通 RNN 的隐藏状态更新为：

ht=ϕ(Wxhxt+Whhht−1+bh)h_t = \phi(W_{xh}x_t + W_{hh}h_{t-1} + b_h) ht​=ϕ(Wxh​xt​+Whh​ht−1​+bh​)

其中，hth_tht​ 是截至时刻 ttt 的序列信息所形成的隐藏状态

如果时刻 ttt 的输出依赖很早的输入 xt−kx_{t-k}xt−k​，我们就称此时存在长期依赖，模型必须通过状态链 xt−k→ht−k→⋯→htx_{t-k}\to h_{t-k}\to\cdots\to h_txt−k​→ht−k​→⋯→ht​ 才能把早期信息传递到较晚的时刻

而在训练 RNN 时，损失函数可能由多个时间步共同组成：

L=∑t=1TLt\mathcal{L} = \sum_{t=1}^T \mathcal{L}_t L=t=1∑T​Lt​

由于同一组参数 WhhW_{hh}Whh​ 在所有时间步共享，计算梯度时需要沿着按时间展开后的网络进行反向传播，这一过程称为 BPTT

若损失 Lt\mathcal{L}_tLt​ 需要更新较早时刻的隐藏状态 ht−kh_{t-k}ht−k​，则根据链式法则：

∂Lt∂ht−k=∂Lt∂ht∂ht∂ht−k\frac{\partial \mathcal{L}_t}{\partial h_{t-k}} = \frac{\partial \mathcal{L}_t}{\partial h_t}\frac{\partial h_t}{\partial h_{t-k}} ∂ht−k​∂Lt​​=∂ht​∂Lt​​∂ht−k​∂ht​​

而最后一项分时可以展开为：

∂ht∂ht−k=∏j=t−k+1t∂hj∂hj−1\frac{\partial h_t}{\partial h_{t-k}} = \prod_{j = t - k + 1}^t\frac{\partial h_j}{\partial h_{j-1}} ∂ht−k​∂ht​​=j=t−k+1∏t​∂hj−1​∂hj​​

由此可以看出，长距离梯度的本质其实是多个梯度的连续乘积

我们记：

aj=Wxhxj+Whhhj−1+bhhj=ϕ(aj)a_j = W_{xh}x_j + W_{hh}h_{j-1} + b_h\\ h_j = \phi(a_j) aj​=Wxh​xj​+Whh​hj−1​+bh​hj​=ϕ(aj​)

则原梯度可以写成：

∂hj∂hj−1=DjWhh\frac{\partial h_j}{\partial h_{j-1}} = D_j W_{hh} ∂hj−1​∂hj​​=Dj​Whh​

其中：

Dj=diag(ϕ′(aj))D_j = \text{diag}(\phi^{'}(a_j)) Dj​=diag(ϕ′(aj​))

这里 diag(⋅)\text{diag}(\cdot)diag(⋅) 表示把向量变成对角矩阵的运算，比如 x∈Rd\mathbf{x}\in\mathbb{R}^{d}x∈Rd，则 diag(x)∈Rd×d\text{diag}(\mathbb{x})\in\mathbb{R}^{d\times d}diag(x)∈Rd×d

这说明梯度大小同时受两部分控制：循环权重矩阵 WhhW_{hh}Whh​ 和激活函数导数 DjD_jDj​

如果每一步梯度对应的 ∥DjWhh∥\|D_jW_{hh}\|∥Dj​Whh​∥ 都小于 1，则多步累乘结果会趋于 0：

∥∂ht∂ht−k∥≤∏j=t−k+1t∥DjWhh∥→0\left\|\frac{\partial h_t}{\partial h_{t-k}}\right\|\le\prod_{j = t-k+1}^t\|D_jW_{hh}\|\to0 ∥∥∥∥∥​∂ht−k​∂ht​​∥∥∥∥∥​≤j=t−k+1∏t​∥Dj​Whh​∥→0

随着依赖距离 kkk 的增大，梯度会呈现近似指数衰减

以 tanh 为例：

tanh′(a)=1−tanh2(a)≤1\text{tanh}^{'}(a) = 1 - \text{tanh}^2(a) \le 1 tanh′(a)=1−tanh2(a)≤1

当输入落入饱和区时：

∣tanh(a)∣=1⇒tanh′(a)≈0|\text{tanh}(a)| = 1\Rightarrow\text{tanh}^{'}(a)\approx0 ∣tanh(a)∣=1⇒tanh′(a)≈0

此时梯度会被进一步压缩，导致早期的时间步几乎得不到有效的训练信号，模型难以学习早期输入如何影响后期输出

总体来讲，RNN 将历史信息和当前输入反复经过同一个非线性状态进行更新：

ht−1→Whhht−1→ϕ(⋅)→hth_{t-1}\to W_{hh}h_{t-1}\to\phi(\cdot)\to h_t ht−1​→Whh​ht−1​→ϕ(⋅)→ht​

信息前向传递和梯度反向传播都必须经过这条连续的乘法链，时间距离越长，早期信息越容易被后续状态覆盖，梯度也越容易消失，由此可知，RNN 的核心限制在于：

LSTM 设计思想

LSTM（Long Short-Term Memory）称为长短期记忆网络，是对 RNN 的一种改进循环单元，它仍按时间步递归处理序列，但把普通 RNN 的单一隐藏状态更新改造成：

(xt,ht−1,ct−1)→(ht,ct)(x_t,h_{t-1},c_{t-1})\to (h_t,c_t) (xt​,ht−1​,ct−1​)→(ht​,ct​)

其中，xt∈Rdxx_t\in\mathbb{R}^{d_x}xt​∈Rdx​ 为当前时间步的输入向量，ht−1∈Rdhh_{t-1}\in\mathbb{R}^{d_h}ht−1​∈Rdh​ 为上一时间步的隐藏状态，ct−1∈Rdhc_{t-1}\in\mathbb{R}^{d_h}ct−1​∈Rdh​ 为上一时间步的细胞状态，ht,cth_t,c_tht​,ct​ 为当前时间步得到的新状态

LSTM 的核心不是简单增加网络深度，而是重新设计了时间维度上的信息传递方式

引入细胞状态

普通 RNN 只有一条状态通路：

ht−1→tanh(Wxxt+Whht−1+b)→hth_{t-1}\to\text{tanh}(W_xx_t + W_hh_{t-1} + b)\to h_t ht−1​→tanh(Wx​xt​+Wh​ht−1​+b)→ht​

历史信息在每个时间步都要经过线性变换和非线性激活，容易被不断压缩或覆盖

LSTM 额外引入细胞状态 ctc_tct​，形成一条相对稳定的长期信息通路：

ct−1→ctc_{t-1}\to c_t ct−1​→ct​

细胞状态不直接等价于输出，而是承担了跨时间步保存和传递内部记忆的作用

细胞状态 vs. 隐藏状态

细胞状态 ctc_tct​ 表示 LSTM 内部保存的长期信息，它主要沿时间维度传递，并通过受控的保留和写入进行更新

隐藏状态 hth_tht​ 表示当前时间步对外提供的隐藏表示，它会传递给下一个时间步，参与下一时间步各控制量的计算，同时也可以参与当前时间步的任务输出

因此可以理解为：ctc_tct​ 侧重内部长期记忆，而 hth_tht​ 侧重当前输出表示，二者通常维度相同

门控机制

LSTM 使用门控机制控制信息流，门不是独立存储信息的网络层，而是根据 xtx_txt​ 和 ht−1h_{t-1}ht−1​ 计算出的控制向量：

gt=σ(W[xt;ht−1]+b)g_t = \sigma(W[x_t;h_{t-1}] + b) gt​=σ(W[xt​;ht−1​]+b)

由于 Sigmoid 输出范围为 0<gi,j<10\lt g_{i,j}\lt 10<gi,j​<1，所以门向量的每一个分享都可以控制对应维度的信息通过程度：

  • 接近 0：抑制该维度的信息
  • 接近 1：保留或允许该维度的信息
  • 介于 0~1 之间：允许该维度的信息部分保留并通过

这种控制是逐元素进行的，不是对于整个状态的统一开关

核心控制

LSTM 的状态更新可以拆分为三个逻辑过程：

  1. 遗忘：决定 ct−1c_{t-1}ct−1​ 中哪些历史信息继续保留
  2. 写入：根据当前输入 xtx_txt​ 和历史表示 ht−1h_{t-1}ht−1​，生成新候选信息，并决定其中哪些内容细胞状态
  3. 输出：从更新后的细胞状态 ctc_tct​ 中选择出当前需要暴露的信息，形成隐藏状态 hth_tht​

整体逻辑可以总结为：

旧记忆选择性保留 + 新信息选择性写入→新细胞状态→选择性输出\text{旧记忆选择性保留 + 新信息选择性写入}\to\text{新细胞状态}\to\text{选择性输出} 旧记忆选择性保留 + 新信息选择性写入→新细胞状态→选择性输出

LSTM 的核心设计思想，就是将普通 RNN 中不可控的整体状态覆盖，改为对长期信息进行显式、逐维、可学习的管理

门控机制与候选记忆

在时刻 ttt，LSTM 根据当前输入向量 xtx_txt​ 和上一时刻隐藏状态 ht−1h_{t-1}ht−1​，计算三个门向量与一个候选记忆向量

先对 xtx_txt​ 和 ht−1h_{t-1}ht−1​ 进行信息拼接：

ut=[ht−1;xt]∈Rdh+dxu_t = [h_{t-1};x_t]\in\mathbb{R}^{d_h + d_x} ut​=[ht−1​;xt​]∈Rdh​+dx​

其中，[⋅;⋅][\cdot;\cdot][⋅;⋅] 表示沿特征维拼接，三个门均属于：

ft,it,ot∈(0,1)dhf_t,i_t,o_t\in(0,1)^{d_h} ft​,it​,ot​∈(0,1)dh​

它们仅作为逐维控制系数，不是被存储的记忆内容

遗忘门

遗忘门计算公式为：

ft=σ(Wfut+bf)f_t = \sigma(W_f u_t + b_f) ft​=σ(Wf​ut​+bf​)

其中：

Wf∈Rdh×(dh+dx)W_f\in\mathbb{R}^{d_h\times (d_h+d_x)} Wf​∈Rdh​×(dh​+dx​)

遗忘门用于判断上一时刻的细胞状态 ct−1c_{t-1}ct−1​ 的每个维度应该保留多少，若 ft,j≈1f_{t,j}\approx1ft,j​≈1，则需要基本保留第 jjj 维的历史信息；若 ft,j≈0f_{t,j}\approx0ft,j​≈0，则需要基本删除第 jjj 维的历史信息

由此可知，遗忘门控制的是旧记忆的保留比例

输入门

输入门计算公式为：

it=σ(Wiut+bi)i_t = \sigma(W_iu_t + b_i) it​=σ(Wi​ut​+bi​)

其中：

Wi∈Rdh×(dh+dx)W_i\in\mathbb{R}^{d_h\times (d_h+d_x)} Wi​∈Rdh​×(dh​+dx​)

输入门用于决定新生成的信息 utu_tut​ 中，哪些维度允许写入当前时刻的细胞状态 ctc_tct​，若 it,j≈1i_{t,j}\approx1it,j​≈1，则表示允许 utu_tut​ 第 jjj 维的历史信息写入 ctc_tct​；若 it,j≈0i_{t,j}\approx0it,j​≈0，则表示抑制 utu_tut​ 第 jjj 维的历史信息写入 ctc_tct​

由此可知，输入门本身不产生新内容，它只用于控制新内容的写入强度

候选记忆

候选记忆的计算公式为：

c~t=tanh(Wcut+bc)\tilde{c}_t = \text{tanh}(W_cu_t + b_c) c~t​=tanh(Wc​ut​+bc​)

其中：

c~t∈(−1,1)dh\tilde{c}_t\in(-1,1)^{d_h} c~t​∈(−1,1)dh​

候选记忆是根据当前输入 xtx_txt​ 和历史隐藏表示 ht−1h_{t-1}ht−1​ 生成的新信息的具体内容，它需要与输入门进行区分：

  • c~t\tilde{c}_tc~t​：决定的具体信息内容
  • iti_tit​：表示写入信息的强度 / 权重

这里之所以采用 tanh 作为激活函数，是为了产生有正负方向且数值受限的候选信息

输出门

输出门的计算公式为：

ot=σ(Wout+bo)o_t = \sigma(W_ou_t + b_o) ot​=σ(Wo​ut​+bo​)

其中：

Wo∈Rdh×(dh+dx)W_o\in\mathbb{R}^{d_h\times (d_h+d_x)} Wo​∈Rdh​×(dh​+dx​)

输出门决定更新后的内部记忆中，哪些维度可以形成当前的隐藏状态 hth_tht​

因此，输出门控制的不是细胞状态是否保存，而是内部信息在当前时刻的暴露程度

三个门和候选记忆都接收相同输入：

(ht−1,xt)(h_{t-1},x_t) (ht−1​,xt​)

但使用独立参数：

(Wf,bf), (Wi,bi), (Wc,bc), (Wo,bo)(W_f,b_f),\ (W_i,b_i),\ (W_c,b_c),\ (W_o,b_o) (Wf​,bf​), (Wi​,bi​), (Wc​,bc​), (Wo​,bo​)

因此它们学习不同功能：

ft:保留旧信息,it:控制写入,c~t:生成新内容,ot:控制输出f_t:\text{保留旧信息},\quad i_t:\text{控制写入},\quad \tilde c_t:\text{生成新内容},\quad o_t:\text{控制输出} ft​:保留旧信息,it​:控制写入,c~t​:生成新内容,ot​:控制输出

这些参数在不同时间步之间共享，但在四个计算分支之间不共享

LSTM 状态更新

在上一节中，我们根据当前时刻的输入 xtx_{t}xt​ 和上一时刻的隐藏输出 ht−1h_{t-1}ht−1​，得到了 ttt 时刻三个门的输出和候选记忆：

ft,it,ot,c~tf_t,\quad i_t,\quad o_t,\quad \tilde{c}_t ft​,it​,ot​,c~t​

其中，ftf_tft​ 对应遗忘门，iti_tit​ 表示输入门，oto_tot​ 表示输出门，c~t\tilde{c}_tc~t​ 表示候选记忆

LSTM 记下来会依次更新细胞状态 ctc_tct​ 和隐藏状态 hth_tht​

细胞状态更新

细胞状态更新公式为：

ct=ft⊙ct−1+it⊙c~tc_t = f_t\odot c_{t-1} + i_t\odot\tilde{c}_t ct​=ft​⊙ct−1​+it​⊙c~t​

其中，⊙\odot⊙ 表示矩阵哈达玛积（逐元素乘法），所有向量维度都满足：

该公式由两条信息分支组成

历史记忆保留

历史记忆保留对应公式前半部分：

ft⊙ct−1f_t\odot c_{t-1} ft​⊙ct−1​

遗忘门会对 ftf_tft​ 对旧细胞状态做逐维缩放：

(ft⊙ct−1)j=ft,jct−1,j(f_t\odot c_{t-1})_j = f_{t,j}c_{t-1,j} (ft​⊙ct−1​)j​=ft,j​ct−1,j​

因此，每个记忆维度都可以独立保留、削弱或近似清除

候选记忆 c~t\tilde{c}_tc~t​ 提供待写入的新内容，输入门 iti_tit​ 控制各维度的写入权重：

最终通过把保留的历史记忆和新写入的记忆相加，完成旧信息和选中的信息系的合并

传统 RNN 整体采用替换式的更新：

ht=tanh(Wxxt+Whht−1+b)h_t = \text{tanh}(W_xx_t + W_hh_{t-1} + b) ht​=tanh(Wx​xt​+Wh​ht−1​+b)

旧状态必须重新经过线性变换和非线性激活，才能生成新状态

而 LSTM 则把状态变化拆分成：

新状态 = 保留的旧状态 + 写入的新信息\text{新状态 = 保留的旧状态 + 写入的新信息} 新状态 = 保留的旧状态 + 写入的新信息

的形式，这种结构使得历史信息不必在每个时间步都被完全重新编码，而是可以沿着细胞状态通路直接被保留

隐藏状态更新

得到新的细胞状态 ctc_tct​ 后，LSTM 计算当前的隐藏状态：

因此，ctc_tct​ 是更新后的内部记忆，而 hth_tht​ 是从内部记忆中筛选出的当前时刻 ttt 对应的隐藏表示

前向传播

当前时间步计算完成后，ctc_tct​ 和 hth_tht​ 都会传递到 t+1t+1t+1 时刻，但二者作用不同

(ft,it,c~t)→ct→ot⊙tanh(ct)→ht(f_t,i_t,\tilde{c}_t)\to c_t\to o_t\odot\text{tanh}(c_t)\to h_t (ft​,it​,c~t​)→ct​→ot​⊙tanh(ct​)→ht​

可以用一句话总结为：ctc_tct​ 表示旧记忆的保留叠加新记忆的写入，hth_tht​ 表示当前记忆的选择性输出

梯度传递原理

LSTM 能够缓解梯度消失，关键在于其细胞状态的更新采用了加法结构：

ct=ft⊙ct−1+it⊙c~tc_t = f_t\odot c_{t-1} + i_t\odot \tilde{c}_t ct​=ft​⊙ct−1​+it​⊙c~t​

其中，第一项形成跨时间步传递历史信息的主要通路

单个时间步的梯度

我们先只考虑相邻时刻细胞状态之间的直接通路，把门控量视作当前时间步已经计算出的确定系数：

∂ct∂ct−1=diag(ft)\frac{\partial c_t}{\partial c_{t-1}} = \text{diag}(f_t) ∂ct−1​∂ct​​=diag(ft​)

从每个维度来看，则有：

∂ct,j∂ct−1,j=ft,j\frac{\partial c_{t,j}}{\partial c_{t-1,j}} = f_{t,j} ∂ct−1,j​∂ct,j​​=ft,j​

因此我们发现，遗忘门步进控制历史信息的保留程度，也会直接控制梯度沿细胞状态通路的传递比例

跨多个时间步传播

假设我们要把梯度从 ctc_tct​ 反向传播到较早的 ct−kc_{t-k}ct−k​：

∂ct∂ct−k≈∏r=t−k+1tdiag(fr)\frac{\partial c_t}{\partial c_{t-k}} \approx\prod_{r = t-k+1}^t \text{diag}(f_r) ∂ct−k​∂ct​​≈r=t−k+1∏t​diag(fr​)

对于第 jjj 个维度：

∂ct,j∂ct−k≈∏r=t−k+1tfr,j\frac{\partial c_{t,j}}{\partial c_{t-k}}\approx\prod_{r=t-k+1}^t f_{r,j} ∂ct−k​∂ct,j​​≈r=t−k+1∏t​fr,j​

当模型需要长期保存第 jjj 维的信息时，可以通过学习使得遗忘门取值接近 1：

fr,j≈1f_{r,j}\approx 1 fr,j​≈1

此时则有：

∏r=t−k+1tfr,j≈1\prod_{r = t-k+1}^t f_{r,j}\approx 1 r=t−k+1∏t​fr,j​≈1

梯度就能够沿着细胞状态的 jjj 维度较为稳定地传播到早期的时间步

对比 RNN

传统 RNN 的长距离梯度公式中包含连续的矩阵乘法和激活函数导数：

∂ht∂ht−k=∏rDrWhh\frac{\partial h_t}{\partial h_{t - k}} = \prod_{r} D_rW_{hh} ∂ht−k​∂ht​​=r∏​Dr​Whh​

梯度会反复受到 WhhW_{hh}Whh​ 和非线性激活函数导数的缩放，其中 WrrW_{rr}Wrr​ 是可学习的，而 DrD_rDr​ 是相对固定的，很有可能多个小 DrD_rDr​ 相乘导致梯度消失

而 LSTM 的细胞状态主通路则主要是：

ct−1→⊙ftctc_{t-1}\xrightarrow{\odot f_t} c_t ct−1​⊙ft​​ct​

它采用逐元素缩放和加法更新，不要求历史状态在每一步都进行完整的非线性变换，因此梯度传递更稳定

架构扩展

下面我们介绍传统 LSTM 框架的两种经典扩展：堆叠 LSTM 和双向 LSTM

堆叠 LSTM

单层 LSTM 只在时间维度上递归：

xt→htx_t\to h_t xt​→ht​

它需要在一次状态更新中，同时完成原始输入特征提取、时间依赖建模和任务相关表示生成，对于较为复杂的序列模式，单层结构的表示能力可能不足

堆叠 LSTM 在网络层维度上增加深度，使得序列经过多级变换：

xt→ht(1)→ht(2)→⋯→ht(L)x_t\to h_t^{(1)}\to h_t^{(2)}\to\cdots\to h_t^{(L)} xt​→ht(1)​→ht(2)​→⋯→ht(L)​

其核心动机在于：在时间建模之外，增加隐藏表示的层级变换深度

底层网络直接处理原始输入，而上层网络继续处理下层产生的隐藏表示

输入组织

设输入序列为：

X=(x1,x2,…,xT)X=(x_1,x_2,\dots,x_T) X=(x1​,x2​,…,xT​)

其中，xt∈Rdxx_t\in\mathbb{R}^{d_x}xt​∈Rdx​，如果考虑批次维度，则输入张量通常表示为：

其中，BBB 表示批次大小，TTT 表示序列长度。dxd_xdx​ 表示每个时间步输入向量的维度

第一层 LSTM 层直接接收原始输入：

xt(1)=xtx_t^{(1)} = x_t xt(1)​=xt​

从第二层开始，第 lll 层接收上一层在同一时间产生的隐层状态：

xt(l)=ht(l−1),l≥2x_t^{(l)} = h_t^{(l-1)},\quad l\ge 2 xt(l)​=ht(l−1)​,l≥2

因此，上一层的完整隐藏状态序列：

H(l−1)=(h1(l−1),h2(l−1),…,hT(l−1))H^{(l-1)} = (h_1^{(l-1)},h_2^{(l-1)},\dots,h_T^{(l-1)}) H(l−1)=(h1(l−1)​,h2(l−1)​,…,hT(l−1)​)

就是下一层的输入序列

核心架构

第 lll 层在时刻 ttt 的计算为：

(ht(l),ct(l))=LSTM(l)(xt(l),ht−1(l),ct−1(l))(h_t^{(l)},c_t^{(l)}) = \text{LSTM}^{(l)}\left(x_t^{(l)},h_{t-1}^{(l)},c_{t-1}^{(l)}\right) (ht(l)​,ct(l)​)=LSTM(l)(xt(l)​,ht−1(l)​,ct−1(l)​)

堆叠 LSTM 同时存在两种信息流

其一是时间方向的信息流：

(ht−1(l),ct−1(l))→(ht(l),ct(l))(h_{t-1}^{(l)},c_{t-1}^{(l)})\to(h_t^{(l)},c_t^{(l)}) (ht−1(l)​,ct−1(l)​)→(ht(l)​,ct(l)​)

它发生在同一层的内部，传递不同时刻的信息，负责建模该层的时间依赖

其二是层间方向的信息流：

ht(l−1)→xt(l)h_t^{(l-1)}\to x_t^{(l)} ht(l−1)​→xt(l)​

它发生在同一时间步，传递不同 LSTM 层之间的信息，负责将低层隐藏表示传递给高层

需要区分隐层状态和细胞状态，ht(l)h_t^{(l)}ht(l)​ 会同时传递给本层下一时间步和上层网络层，而 ct(l)c_t^{(l)}ct(l)​ 通常只沿本层时间方向传递，不会直接传递给上层网络层

完整数据流

以三层 LSTM 为例，在时刻 ttt

第一层 LSTM：

(ht(1),ct(1))=LSTM(1)(xt,ht−1(1),ct−1(1))(h_t^{(1)},c_t^{(1)}) = \text{LSTM}^{(1)}\left(x_t,h_{t-1}^{(1)},c_{t-1}^{(1)}\right) (ht(1)​,ct(1)​)=LSTM(1)(xt​,ht−1(1)​,ct−1(1)​)

第二层 LSTM：

(ht(2),ct(2))=LSTM(2)(ht(1),ht−1(2),ct−1(2))(h_t^{(2)},c_t^{(2)}) = \text{LSTM}^{(2)}\left(h_t^{(1)},h_{t-1}^{(2)},c_{t-1}^{(2)}\right) (ht(2)​,ct(2)​)=LSTM(2)(ht(1)​,ht−1(2)​,ct−1(2)​)

第三层 LSTM：

(ht(3),ct(3))=LSTM(3)(ht(2),ht−1(3),ct−1(3))(h_t^{(3)},c_t^{(3)}) = \text{LSTM}^{(3)}\left(h_t^{(2)},h_{t-1}^{(3)},c_{t-1}^{(3)}\right) (ht(3)​,ct(3)​)=LSTM(3)(ht(2)​,ht−1(3)​,ct−1(3)​)

因此，单个时间步内部的数据自下层网络向上层网络流动：

xt→ht(1)→ht(2)→ht(3)x_t\to h_t^{(1)}\to h_t^{(2)} \to h_t^{(3)} xt​→ht(1)​→ht(2)​→ht(3)​

与此同时，每一层都会把自己当前时刻的状态传向下一时间步：

(ht(l),ct(l))→(ht+1(l),ct+1(l))(h_t^{(l)},c_t^{(l)})\to (h_{t+1}^{(l)},c_{t+1}^{(l)}) (ht(l)​,ct(l)​)→(ht+1(l)​,ct+1(l)​)

所以堆叠 LSTM 实际上形成了一个 “时间 × 层数” 的二维计算结构

层级功能分析

各层的功能不是预先固定的，但通常表现为层级化表示，或者说我们希望各层经过训练能够分别学习到如下的特征表示：

  • 第一层直接处理原始输入，学习较基础的局部变化模式
  • 中间层重新组合底层隐藏表示，学习更复杂的时间模式
  • 最后一层形成与最终任务更相关的高层序列表示

不同层之间参数不共享：

Θ(1)≠Θ(2)\Theta^{(1)}\neq\Theta^{(2)} Θ(1)​=Θ(2)

但同一层在所有时间步共享参数：

Θt(l)=Θ(l)\Theta_t^{(l)}=\Theta^{(l)} Θt(l)​=Θ(l)

堆叠 LSTM 通常使用最后一层输出（注意通常选用一个网络层，但不一定是最后一个时间步），但具体使用方式取决于任务

如果是整体序列分类任务，通常使用最后一层最后时间步：

z=hT(L)z=h_T^{(L)} z=hT(L)​

然后：

y^=g(Wyz+by)\hat y=g(W_yz+b_y) y^​=g(Wy​z+by​)

也可以对最后一层全部时间步进行池化或注意力聚合：

z=Pool⁡(h1(L),…,hT(L))z=\operatorname{Pool} (h_1^{(L)},\ldots,h_T^{(L)}) z=Pool(h1(L)​,…,hT(L)​)

如果是序列标注或逐时刻预测任务，通常使用最后一层完整隐藏状态序列：

H(L)=(h1(L),…,hT(L))H^{(L)} = (h_1^{(L)},\ldots,h_T^{(L)}) H(L)=(h1(L)​,…,hT(L)​)

每个时间步分别输出：

y^t=g(Wyht+by)\hat y_t=g(W_yh_t+b_y) y^​t​=g(Wy​ht​+by​)

下层隐藏状态主要作为中间表示传给上层，在标准的堆叠 LSTM 结构中，下层网络层通常不会直接连接任务输出层

双向 LSTM

普通的单向 LSTM 在时刻 ttt 只能利用当前时刻以及之前的输入：

x1,x2,…,xtx_1,x_2,\dots,x_t x1​,x2​,…,xt​

但在许多离线的序列任务中，判断当前位置还需要后续上下文

例如，判断序列中第 ttt 个元素的含义，可能同时依赖 x1,…,xt−1x_1,\dots,x_{t-1}x1​,…,xt−1​ 和 xt+1,…,xTx_{t+1},\dots,x_Txt+1​,…,xT​

双向 LSTM 设计的动机为：为每个时间步同时提供前向上下文和后向上下文

输入组织

输入仍然是完整序列：

X=(x1,x2,…,xT)X=(x_1,x_2,\dots,x_T) X=(x1​,x2​,…,xT​)

双向 LSTM 将同一输入序列分别交给两个参数独立的 LSTM

正向分支按原始顺序读取：

x1→x2→⋯→xTx_1\to x_2\to\cdots\to x_T x1​→x2​→⋯→xT​

反向分支按相反顺序读取：

xT→xT−1→⋯x1x_T\to x_{T-1}\to\cdots x_1 xT​→xT−1​→⋯x1​

反向 LSTM 并不是预测未来数据，而是在训练和推理时已获得完整序列，然后从序列末端向前处理

核心架构

正向 LSTM 设计为：

(h→t,c→t)=LSTM⁡→(xt,h→t−1,c→t−1)(\overrightarrow h_t,\overrightarrow c_t) = \operatorname{LSTM}_{\rightarrow} \left( x_t, \overrightarrow h_{t-1}, \overrightarrow c_{t-1} \right) (ht​,ct​)=LSTM→​(xt​,ht−1​,ct−1​)

其中：

h→t=F→(x1,…,xt)\overrightarrow h_t = F_{\rightarrow}(x_1,\ldots,x_t) ht​=F→​(x1​,…,xt​)

它包含当前位置之前的上下文

反向 LSTM 设计为：

(h←t,c←t)=LSTM⁡←(xt,h←t+1,c←t+1)(\overleftarrow h_t,\overleftarrow c_t) = \operatorname{LSTM}_{\leftarrow} \left( x_t, \overleftarrow h_{t+1}, \overleftarrow c_{t+1} \right) (ht​,ct​)=LSTM←​(xt​,ht+1​,ct+1​)

其中：

h←t=F←(xT,…,xt)\overleftarrow h_t = F_{\leftarrow}(x_T,\ldots,x_t) ht​=F←​(xT​,…,xt​)

它包含当前位置之后的上下文

两个方向拥有独立参数：

Θ→≠Θ←\Theta_{\rightarrow}\neq\Theta_{\leftarrow} Θ→​​=Θ←​

它们之间不会直接传递细胞状态或隐藏状态

两个方向的融合

在同一时间步 ttt，通常将两个方向的隐藏状态拼接：

htbi=[ht→;ht←]h_t^{\text{bi}} = [\overrightarrow{h_t};\overleftarrow{h_t}] htbi​=[ht​​;ht​​]

如果每个方向隐藏特征的维度都是 dhd_hdh​，即：

ht→,ht←∈Rdh\overrightarrow{h_t},\overleftarrow{h_t}\in\mathbb{R}^{d_h} ht​​,ht​​∈Rdh​

则拼接后：

htbi∈R2dhh_t^{\text{bi}}\in\mathbb{R}^{2d_h} htbi​∈R2dh​

两个方向信息的融合也可以使用加权求和或者线性映射，但拼接的方式最常见，因为它能够完整保留两个方向的信息

每个方向的 LSTM 的细胞状态通常不会进行同样的逐时间步拼接以供任务层使用，任务层主要使用的是融合后的隐藏表示

完整数据流

以位置 ttt 为例，正向分支生成：

x1→⋯→xt→ht→x_1\to\cdots \to x_t\to\overrightarrow{h_t} x1​→⋯→xt​→ht​​

反向分支生成：

xt→⋯→xt→ht←x_t\to\cdots\to x_t\to\overleftarrow{h_t} xt​→⋯→xt​→ht​​

二者融合则有：

(ht→,ht←)→htbi\left(\overrightarrow{h_t},\overleftarrow{h_t}\right)\to h_t^{\text{bi}} (ht​​,ht​​)→htbi​

此时，htbih_t^{\text{bi}}htbi​ 即同时表示 xtx_txt​ 在前向上下文和后向上下文中的序列语义

完整的输出序列为：

Hbi=(h1bi,…,hTbi)H^{\text{bi}} = (h_1^{\text{bi}},\dots,h_T^{\text{bi}}) Hbi=(h1bi​,…,hTbi​)

对于序列标注任务，这是双向 LSTM 最典型的使用方式

每个时间步使用：

htbi=[h→t;h←t]h_t^{\mathrm{bi}} = [\overrightarrow h_t;\overleftarrow h_t] htbi​=[ht​;ht​]

生成对应输出：

y^t=g(Wyht+by)\hat y_t = g(W_yh_t + b_y) y^​t​=g(Wy​ht​+by​)

因此，每个位置的预测都利用完整序列上下文

对于整体序列分类任务，可以使用两个方向的最终状态：

z=[h→T;h←1]z= [\overrightarrow h_T;\overleftarrow h_1] z=[hT​;h1​]

其中：

  • h→T\overrightarrow h_ThT​：正向分支处理完整序列后的状态
  • h←1\overleftarrow h_1h1​：反向分支处理完整序列后的状态

也可以对全部双向隐藏状态进行池化：

z=Pool⁡(h1bi,…,hTbi)z= \operatorname{Pool} (h_1^{\mathrm{bi}},\ldots,h_T^{\mathrm{bi}}) z=Pool(h1bi​,…,hTbi​)

这样能够更好地融合全局的双向序列信息，之后再进行分类

需要注意的是，双向 LSTM 不能用于严格实时预测任务，因为其在计算 h←t\overleftarrow h_tht​ 时，需要访问：

xt+1,…,xTx_{t+1},\ldots,x_T xt+1​,…,xT​

因此，若时刻 ttt 必须立刻产生结果，而未来输入尚未到达，就无法完成标准双向计算

所以：

  • 离线文本标注、完整语音分析：适合 BiLSTM（双向 LSTM）
  • 实时轨迹预测、在线传感器预测：通常使用单向 LSTM

双向 + 堆叠

二者解决的问题不同：堆叠 LSTM 用于对同一序列表示进行逐层深化，而双向 LSTM 用于从两个时间方向理解同一序列位置

因此二者可以组合为多层双向 LSTM

第 lll 层先产生：

ht(l)=[h→t(l);h←t(l)]h_t^{(l)} = [\overrightarrow h_t^{(l)}; \overleftarrow h_t^{(l)}] ht(l)​=[ht(l)​;ht(l)​]

再将该拼接表示作为第 $ l+1$ 层的输入：

xt(l+1)=ht(l)x_t^{(l+1)}=h_t^{(l)} xt(l+1)​=ht(l)​

由此形成如下的架构：

X→第一层双向表示→第二层双向表示→⋯→任务输出X \rightarrow \text{第一层双向表示} \rightarrow \text{第二层双向表示} \rightarrow \cdots \rightarrow \text{任务输出} X→第一层双向表示→第二层双向表示→⋯→任务输出

应用场景

LSTM 主要适用于具有明确顺序关系、且当前输出依赖历史上下文的序列任务

序列分类

输入完整序列，输出一个类别：

(x1,…,xT)→y^(x_1,\ldots,x_T)\rightarrow \hat y (x1​,…,xT​)→y^​

例如文本情感分类，人体行为识别，设备运行状态分类，干扰类型识别等

此时，我们通常使用最后一个时刻的隐藏状态进行预测，或对全部时刻的隐藏状态聚合后再用于分类

序列标注

每个时间步都需要输出结果：

xt→y^tx_t\rightarrow \hat y_t xt​→y^​t​

例如命名实体识别，语音帧标注，故障时刻检测，时序数据逐点分类等

当完整序列可用时，BiLSTM（双向 LSTM）通常更合适

时间序列预测

根据历史序列预测未来值：

(x1,…,xt)→x^t+1(x_1,\ldots,x_t) \rightarrow \hat x_{t+1} (x1​,…,xt​)→x^t+1​

例如传感器数据预测，轨迹预测，流量或负载预测，设备状态趋势预测等

此类任务通常使用单向 LSTM，以保证预测只依赖过去信息，不会造成未来信息的泄露

序列到序列任务

输入一个序列，输出另一个序列：

X→YX\rightarrow Y X→Y

例如早期的机器翻译，语音识别，文本生成，多步时间序列预测等任务

经典结构通常由 LSTM 编码器和 LSTM 解码器组成

总体上，LSTM 更适合：中等长度序列 + 明显时间依赖 + 数据规模有限或需要递推处理的任务

对于极长序列、大规模并行训练或全局依赖建模，Transformer 往往更有优势；但在实时递推、小中型数据集和连续传感器任务中，LSTM 仍然具有较强实用性
