第六部分：瓶颈层为什么存在

瓶颈层不只是“U 的最下面”。

需要解释：

  • 它位于最大压缩尺度；
  • 具有最大的感受野；
  • 负责整合上下文；
  • 不直接拥有精确边界；
  • 是编码器和解码器之间的语义桥梁。

例如目标局部纹理可能相似，但利用更大范围上下文才能判断：

  • 这是器官内部区域；
  • 这是道路而不是屋顶；
  • 这是肿瘤而不是普通组织。

同时讨论瓶颈层过深可能导致：

  • 信息压缩过度；
  • 小目标丢失；
  • 参数量快速上升；
  • 训练困难。

第八部分：跳跃连接是 U-Net 的核心

这一部分会作为重点章节。

8.1 跳跃连接解决什么问题

深层特征回答：

这里大概是什么对象？

浅层特征回答：

边缘和位置具体在哪里？

解码器需要同时获得：

  • 高层语义；
  • 低层空间细节。

因此：

Dl=Conv⁡(Concat⁡(Up⁡(Dl+1),El))D_l = \operatorname{Conv} \left( \operatorname{Concat} \left( \operatorname{Up}(D_{l+1}), E_l \right) \right)Dl=Conv(Concat(Up(Dl+1),El))

其中：

  • ElE_lEl：编码器第 lll 层特征；
  • Dl+1D_{l+1}Dl+1：更深层解码器特征；
  • Up⁡\operatorname{Up}Up：上采样；
  • Concat⁡\operatorname{Concat}Concat：通道维拼接。

8.2 Concatenation 与 Addition 的区别

U-Net 使用拼接：

Cout=C1+C2C_{\text{out}}=C_1+C_2Cout=C1+C2

例如：

[B,256,64,64]和[B,256,64,64][B,256,64,64] \quad\text{和}\quad [B,256,64,64][B,256,64,64]和[B,256,64,64]

拼接得到：

[B,512,64,64][B,512,64,64][B,512,64,64]

而逐元素相加要求通道数相同，输出仍为：

[B,256,64,64][B,256,64,64][B,256,64,64]

需要比较：

  • 拼接保留两组特征；
  • 相加直接融合特征；
  • 拼接参数量更大；
  • ResNet 常用相加；
  • U-Net 常用拼接。

8.3 Skip connection 的局限

跳跃连接并非没有问题：

  • 浅层特征中包含大量无关背景；
  • 编码器和解码器存在语义差距；
  • 简单拼接可能引入噪声；
  • 高分辨率特征增加显存开销。

这些问题正是 Attention U-Net、UNet++ 等模型的出发点。

第十部分：输出层、激活函数和任务类型

10.1 为什么使用 1×11\times11×1 卷积

最终一层：

Conv⁡1×1:R64×H×W→RK×H×W\operatorname{Conv}_{1\times1}: \mathbb{R}^{64\times H\times W} \rightarrow \mathbb{R}^{K\times H\times W}Conv1×1:R64×H×W→RK×H×W

它在每个像素位置上对通道特征进行线性组合。

本质上相当于：

对每个像素位置的特征向量做一次分类。

10.2 二分类输出

常用：

Z∈RB×1×H×WZ\in\mathbb{R}^{B\times1\times H\times W}Z∈RB×1×H×W

概率：

P=σ(Z)P=\sigma(Z)P=σ(Z)

训练时通常用：

注意它已经内部包含 Sigmoid，因此模型前向输出不应先手动 Sigmoid。

10.3 多分类输出

输出：

Z∈RB×K×H×WZ\in\mathbb{R}^{B\times K\times H\times W}Z∈RB×K×H×W

标签形状：

Y∈RB×H×WY\in\mathbb{R}^{B\times H\times W}Y∈RB×H×W

使用：

它内部包含 LogSoftmax，因此模型也应直接输出 logits。

10.4 多标签分割

一个像素可以同时属于多个属性时：

  • 输出 KKK 个独立通道；
  • 每个通道使用 Sigmoid；
  • 使用 BCE 类型损失；
  • 不使用 Softmax 互斥约束。

第十一部分：损失函数的原理，而不是只背名称

11.1 Binary Cross-Entropy

LBCE=−1N∑i[yilog⁡pi+(1−yi)log⁡(1−pi)]\mathcal L_{\mathrm{BCE}} = -\frac{1}{N} \sum_i \left[ y_i\log p_i + (1-y_i)\log(1-p_i) \right]LBCE=−N1i∑[yilogpi+(1−yi)log(1−pi)]

讲清楚：

  • 为什么错误且自信的预测惩罚大；
  • 为什么 BCE 是逐像素损失；
  • 类别不平衡时的问题；
  • pos_weight 的作用。

11.2 Cross-Entropy

LCE=−1N∑ilog⁡pi,yi\mathcal L_{\mathrm{CE}} = -\frac{1}{N} \sum_i \log p_{i,y_i}LCE=−N1i∑logpi,yi

讲清楚 Softmax 与类别互斥。

11.3 Dice Loss

Dice 系数：

Dice=2∑ipiyi+ϵ∑ipi+∑iyi+ϵ\mathrm{Dice} = \frac{2\sum_i p_i y_i+\epsilon} {\sum_i p_i+\sum_i y_i+\epsilon}Dice=∑ipi+∑iyi+ϵ2∑ipiyi+ϵ

Dice Loss：

LDice=1−Dice\mathcal L_{\mathrm{Dice}} = 1-\mathrm{Dice}LDice=1−Dice

重点解释：

  • 为什么它适合小目标；
  • 为什么它关注区域重叠；
  • 为什么要加入 ϵ\epsilonϵ；
  • batch-wise 与 sample-wise 计算差异；
  • 二值 Dice 和多类别 Dice。

11.4 混合损失

例如：

L=λ1LCE+λ2LDice\mathcal L = \lambda_1\mathcal L_{\mathrm{CE}} + \lambda_2\mathcal L_{\mathrm{Dice}}L=λ1LCE+λ2LDice

解释：

  • CE 提供稳定的逐像素梯度；
  • Dice 直接优化区域重叠；
  • 二者互补。

11.5 其他常见损失

  • Focal Loss；
  • Tversky Loss；
  • Focal Tversky Loss；
  • Boundary Loss；
  • Lovász Loss。

第十二部分：训练流程与反向传播

这一部分会把 U-Net 放入完整深度学习训练系统中。

12.1 一个训练 step 中发生什么

逐行解释：

  • 梯度为什么需要清零；
  • 前向传播产生什么；
  • 损失函数如何连接预测和标签；
  • 自动微分如何计算梯度；
  • 优化器如何更新参数。

12.2 梯度如何经过跳跃连接

由于 skip feature 同时进入后续网络，它会收到来自解码器路径的梯度。

这意味着跳跃连接不仅传递前向特征，也改变反向传播路径，有助于：

  • 浅层特征直接服务于分割；
  • 梯度更容易传回编码器浅层；
  • 保持边缘与位置特征。

12.3 优化器与学习率

讲清楚：

  • SGD；
  • Momentum；
  • Adam；
  • AdamW；
  • weight decay；
  • 学习率；
  • scheduler；
  • warmup；
  • early stopping。

重点分析它们如何影响分割训练，而不是仅给推荐参数。

第十三部分：数据集、增强和工程细节

很多 U-Net 项目失败并不是模型错误，而是数据处理错误。

13.1 图像与 Mask 必须同步变换

几何增强必须同时作用于：

  • 输入图像；
  • 标签 Mask。

例如：

  • 随机裁剪；
  • 水平翻转；
  • 旋转；
  • 缩放。

颜色增强通常只作用于图像：

  • 亮度；
  • 对比度；
  • 饱和度；
  • 噪声。

13.2 Mask 插值方式

图像缩放可用双线性插值，但类别 Mask 必须使用最近邻插值。

否则类别值可能从：

0, 10,\ 10, 1

被插值成：

0.27, 0.640.27,\ 0.640.27, 0.64

这会破坏标签。

第十四部分：评价指标、错误分析和实验设计

14.1 Pixel Accuracy 为什么可能误导

如果背景占 99%，模型全部预测背景，也可获得 99% 准确率。

所以分割任务通常更关注：

  • IoU；
  • Dice；
  • Precision；
  • Recall；
  • Specificity；
  • Hausdorff Distance；
  • Boundary F-score。

14.2 IoU

IoU=∣P∩G∣∣P∪G∣\mathrm{IoU} = \frac{|P\cap G|} {|P\cup G|}IoU=∣P∪G∣∣P∩G∣

14.3 Dice 与 IoU 的关系

Dice=2IoU1+IoU\mathrm{Dice} = \frac{2\mathrm{IoU}} {1+\mathrm{IoU}}Dice=1+IoU2IoU

二者相关但数值不同，不能直接混用。

14.4 混淆矩阵

对于二分类分割，定义：

  • TP；
  • FP；
  • FN；
  • TN。

进而推导：

Precision=TPTP+FP\mathrm{Precision} = \frac{TP}{TP+FP}Precision=TP+FPTPRecall=TPTP+FN\mathrm{Recall} = \frac{TP}{TP+FN}Recall=TP+FNTPIoU=TPTP+FP+FN\mathrm{IoU} = \frac{TP}{TP+FP+FN}IoU=TP+FP+FNTP

14.5 可视化错误类型

不能只看一个平均指标，还要观察：

  • 漏分割；
  • 过分割；
  • 边界偏移；
  • 小目标消失；
  • 相邻目标粘连；
  • 背景误检；
  • 类别混淆。

第十八部分：U-Net 的局限与后续网络

在完全掌握标准 U-Net 后，再讲改进网络。顺序如下：

18.1 ResUNet

把普通卷积块替换为残差块，改善深层网络优化。

18.2 Attention U-Net

在 skip connection 上加入注意力门，抑制无关背景特征。

18.3 UNet++

通过嵌套和密集跳跃连接，缩小编码器与解码器之间的语义差距。

18.4 3D U-Net

将二维卷积扩展到三维，用于 CT、MRI 体数据。

18.5 nnU-Net

重点不在新网络模块，而在自动配置：

  • 预处理；
  • patch size；
  • 网络深度；
  • batch size；
  • 训练策略；
  • 后处理。

18.6 TransUNet

用 Transformer 建模长距离依赖，同时保留 U-Net 解码结构。

18.7 Swin-Unet

使用分层窗口 Transformer 替代传统卷积编码器。

通过这些模型反过来理解标准 U-Net 的不足：

  • 全局建模能力有限；
  • skip connection 过于直接；
  • 多尺度融合较简单；
  • 固定结构适应性有限；
  • 大图像计算成本较高。
