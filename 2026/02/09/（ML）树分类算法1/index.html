树分类算法

通过阅读本文，您可以大致了解决策树、随机森林、Extra Tress 等树分类算法的相关内容

决策树

随机森林（Random Forest）和极端随机树（Extra Trees）本质上都是决策树的集合（Decision Tree Ensemble），要了解后两个模型首先必须理解决策树

假设有训练集：

D={(xi,yi)}i=1N\mathcal D = \{(\mathbf x_i,y_i)\}_{i=1}^N D={(xi​,yi​)}i=1N​

其中：

xi=(xi1,xi2,…,xip)⊤\mathbf x_i = (x_{i1},x_{i2},\dots,x_{ip})^\top xi​=(xi1​,xi2​,…,xip​)⊤

表示 ppp 个输入特征

以二分类为例：

yi∈{0,1}y_i\in\{0,1\} yi​∈{0,1}

决策树的基本思想为：不断选择某个特征和一个阈值，把当前数据划分成两个 “标签纯度更高” 的子集合

例如，对于对于每一条样本去检查是否有 x3<5.2x_3\lt 5.2x3​<5.2，如果成立则划分到左子树，不成立则划分到右子树

因此一次划分可以抽象成：

DL={(xi,yi):xij<c}DR={(xi,yi):xij≥c}\mathcal D_L = \{(\mathbf x_i,y_i):x_{ij}\lt c\}\\ \mathcal D_R = \{(\mathbf x_i,y_i):x_{ij}\ge c\} DL​={(xi​,yi​):xij​<c}DR​={(xi​,yi​):xij​≥c}

其中，jjj 表示用于比较的特征，ccc 表示切分阈值

因此，决策树这种模型把原本的分类问题转换成了对于 jjj 和 ccc 的选取

对一次切分的评估

决策树判断一次切分好不好的核心标准叫做 Impurity\text{Impurity}Impurity，即不纯净度，分类树最常见的是 Gini Impurity\text{Gini Impurity}Gini Impurity 和 Entropy\text{Entropy}Entropy

Gini Impurity

假设某节点中有 KKK 个类别，第 kkk 类所占的比例为 pkp_kpk​

Gini 定义：

G=1−∑k=1Kpk2G = 1 - \sum_{k=1}^K p_k^2 G=1−k=1∑K​pk2​

对于二分类问题：

G=1−p02−p12G = 1 - p_0^2 - p_1^2 G=1−p02​−p12​

又因为有：

p0+p1=1p_0 + p_1 = 1 p0​+p1​=1

所以：

G=1−(1−p1)2−p12G = 1 - (1 - p_1)^2 - p_1^2 G=1−(1−p1​)2−p12​

展开则有：

G=2p1(1−p1)G = 2p_1(1 - p_1) G=2p1​(1−p1​)

完全纯净时，要么 p1=1,p0=0p_1=1,p_0=0p1​=1,p0​=0 或者 p0=1,p1=0p_0=1,p_1=0p0​=1,p1​=0，对应 G=0G=0G=0；而最混乱时，p0=p1=0.5p_0=p_1=0.5p0​=p1​=0.5，对应 G=0.5G=0.5G=0.5，因此可以认为 G 值越小，节点越纯净

最佳切分的选择

假设父节点有 NNN 个样本，原始不纯净度为 GparentG_{\text{parent}}Gparent​，经过 xj<cx_j<cxj​<c 划分之后，左子树有 NLN_LNL​ 个样本，右子树有 NRN_RNR​ 个样本，二者对应的不纯净度分别为 GLG_LGL​ 和 GRG_RGR​

则切分后节点的总不纯净度定义为：

Gsplit=NLNGL+NRNGRG_{\text{split}} = \frac{N_L}{N}G_L + \frac{N_R}{N}G_R Gsplit​=NNL​​GL​+NNR​​GR​

接着定义 impurity reduction：

ΔG=Gparent−Gsplit\Delta G = G_{\text{parent}} - G_{\text{split}} ΔG=Gparent​−Gsplit​

理想情况下，我们希望 ΔG\Delta GΔG 能够尽可能大，因此普通的 CART 决策树会寻找：

(j⋆,v⋆)=arg⁡max⁡j,cΔG(j,c)(j^\star,v^\star) = \arg\max_{j,c}\Delta G(j,c) (j⋆,v⋆)=argj,cmax​ΔG(j,c)

换言之，在大量的候选特征和阈值的组合中，寻找能够最好地区分类别的那一次切分，然后在左右子节点上重复上述过程

最终即可形成从根节点（Root）到中间节点（Internal Nodes）最终到叶子节点（Leaf Nodes）的整个过程

单棵决策树的缺点

决策树最大的优势在于其非线性，不需要做特征标准化，且可以自动处理特征交互，以及具有较强的可解释性

但其存在一个严重的缺点，即高方差（High Variance），如果训练数据稍微变化一点，原来的最佳切分可能是 x5<5.2x_5\lt 5.2x5​<5.2，新数据可能变成 x7<1.8x_7\lt1.8x7​<1.8

根节点一改变，整棵树下面的子节点都会随之改变，所以单棵决策树往往有 Bias 低，但 Variance 高的特点，这在机器学习中是典型的易过拟合表征

我们后续提到的 Random Forest 和 Extra Trees 本质上都是在想办法降低决策树的方差

“Bias 低，但 Variance 高” 是机器学习中非常经典的一个概念组合，用来描述模型在训练集上表现很好，但在测试集上表现很差的状态

  • Bias（偏差）是欠拟合的指标：Bias 代表模型的偏好或倾向，Bias 低意味着模型没有盲目猜测，它能很好地捕捉到训练数据中的规律
  • Variance（方差）是过拟合的指标：Variance 代表模型的波动或不稳定性，Variance 高意味着模型对训练数据的微小变化非常敏感，它会把训练数据里的偶然误差、噪声甚至异常点也当成了普遍规律强行记住

随机森林

随机森林（Random Forest）是 Bagging + Random Features Subspace + Decision Tress 的组合，即一种结合了 Bagging、随机特征子空间和决策树的集成学习方法

假设我们总共训练 MMM 课树 T1,T2,…,TMT_1,T_2,\dots,T_MT1​,T2​,…,TM​，Random Forest 故意让这些树彼此之间不完全相同，然后把它们集成起来

随机森林模型主要引入两种随机性：自助采样随机性（Bootstrap Sample Randomness）和特征随机性（Feature Randomness）

第一层随机性：Bootstrap

原始训练集：

D={z1,z2,…,zN}\mathcal D = \{z_1,z_2,\dots,z_N\} D={z1​,z2​,…,zN​}

对第 mmm 棵树进行有放回的采样：

Dm∼Bootstrap(D)\mathcal D_m\sim\text{Bootstrap}(\mathcal D) Dm​∼Bootstrap(D)

即每次从 NNN 个样本中随机抽取一个样本，抽完后放回，再重新抽取，总共抽取 NNN 次，因此一些样本会被重复抽取，一些样本不会被抽到，最终形如：

Dm={z3,z8,z3,z10,z1,z8,… }\mathcal D_m = \{z_3,z_8,z_3,z_{10},z_1,z_8,\dots\} Dm​={z3​,z8​,z3​,z10​,z1​,z8​,…}

对于不同树而言，使用的训练集不同（D1≠D2≠⋯\mathcal D_1\ne\mathcal D_2\ne\cdotsD1​​=D2​​=⋯），因此最终训练得到的各个树也会存在天然差异（T1≠T1≠⋯T_1\ne T_1\ne\cdotsT1​​=T1​​=⋯）

Bootstrap 中的 63.2%

对于某个样本而言，在一次抽样中没有抽到它的概率为 1−1N1-\frac{1}{N}1−N1​，连续抽取 NNN 次都没抽中它的概率为：

Pmiss=(1−1N)NP_{\text{miss}} = \left(1-\frac{1}{N}\right)^{N} Pmiss​=(1−N1​)N

当 N→∞N\to∞N→∞ 时，有：

(1−1N)N→e−1≈0.368\left(1-\frac{1}{N}\right)^N\to e^{-1} \approx 0.368 (1−N1​)N→e−1≈0.368

所以在一个 bootstrap 数据集中，大约会有 36.8% 的原始样本没有出现，出现过的独立样本占比则大约为;

1−0.368=63.2%1 - 0.368 = 63.2\% 1−0.368=63.2%

剩下的 36.8%36.8\%36.8% 则自动成为 OOB（Out-of-Bag samples），后面可以直接用做测试集，去评估模型的性能

第二层随机性：随机特征

如果只做 Bootstrap，还会存在另一个问题：假设某个特征 x1x_1x1​ 非常强，那么所有树的根节点可能都会选择 x1x_1x1​ 作为比较特征，这会导致各个树 T1,T2,…,TMT_1,T_2,\dots,T_MT1​,T2​,…,TM​ 仍然高度相似，这会降低随机森林集成的意义

所以 Random Forest 在每个节点都只随机考虑部分特征

假设特征总数为 ppp，每个节点随机选择 mtry<pm_{\text{try}}<pmtry​<p 个特征，分类任务重经典默认选择通常接近：

mtry=pm_{\text{try}} = \sqrt p mtry​=p​

然后仅在这些随机选中的特征中去寻找最佳的 (j⋆,c⋆)(j^\star,c^\star)(j⋆,c⋆)

需要说明的是，不是一棵树从头到尾都只在同一组选好的 p\sqrt pp​ 个特征中选取，而是每个节点都会重新抽取特征子集，然后再在这个特征子集中选取，所以整棵树最终仍然可能使用很多不同的特征

上层节点用过的特征，下层节点还可以使用，随机特征子空间”只限制当前节点在选最优分裂时的可选范围，不限制这个特征以后还能不能再出现

训练过程

对于第 mmm 棵树，其中 m=1,…,Mm=1,\dots,Mm=1,…,M，执行以下步骤：

  1. 从训练集 Bootstrap 得到 Dm\mathcal D_mDm​
  2. 从根节点开始，每个节点随机选择 mtrym_{\text{try}}mtry​ 个特征
  3. 在这些特征中优化切分阈值 (j⋆,c⋆)=arg⁡max⁡j∈Fm,cΔG(j,c)(j^\star,c^\star) = \arg\max_{j\in\mathcal F_m,c}\Delta G(j,c)(j⋆,c⋆)=argmaxj∈Fm​,c​ΔG(j,c)
  4. 不断递归直到满足停止条件（常见边界有：最大深度、最小叶节点样本数、叶节点纯度）

最终得到 TmT_mTm​，重复 MMM 次即得到整棵 Random Forest

预测过程

如果是分类任务，每棵树会给出 y^m(x)\hat y_m(\mathbf x)y^​m​(x)，最简单的方法是进行多数投票：

y^=mode{y^1,…,y^M}\hat y = \text{mode}\{\hat y_1,\dots,\hat y_M\} y^​=mode{y^​1​,…,y^​M​}

如果需要概率，则可以用叶节点类别比例然后在树间平均：

P(Y=k∣x)=1M∑m=1MPm(Y=k∣x)P(Y=k\mid \mathbf x) = \frac{1}{M}\sum_{m=1}^M P_m(Y=k\mid\mathbf x) P(Y=k∣x)=M1​m=1∑M​Pm​(Y=k∣x)

如果是回归任务，每棵树输出 y^m\hat y_my^​m​，森林间直接平均：

y^=1M∑m=1My^m\hat y = \frac{1}{M}\sum_{m=1}^M\hat y_m y^​=M1​m=1∑M​y^​m​

因此，随机森林模型可以同时用于分类（Classification）和回归（Regression）任务

随机森林稳定性分析

假设每棵树的预测方差为 σ2\sigma^2σ2，任意两棵树之间的相关系数为 ρ\rhoρ，森林平均为：

Tˉ=1M∑m=1MTM\bar T = \frac{1}{M}\sum_{m=1}^M T_M Tˉ=M1​m=1∑M​TM​

其方差为：

Var(Tˉ)=Var(1M∑mTm)\text{Var}(\bar T) = \text{Var}\left( \frac{1}{M}\sum_m T_m \right) Var(Tˉ)=Var(M1​m∑​Tm​)

将其展开则有：

Var(Tˉ)=1M2[∑mVar(Tm)+∑m≠nCov(Tm,Tn)]\text{Var}(\bar T) = \frac{1}{M^2}\left[ \sum_m\text{Var}(T_m) + \sum_{m\ne n}\text{Cov}(T_m,T_n) \right] Var(Tˉ)=M21​⎣⎢⎡​m∑​Var(Tm​)+m​=n∑​Cov(Tm​,Tn​)⎦⎥⎤​

由于 Var(Tm)=σ2\text{Var}(T_m) = \sigma^2Var(Tm​)=σ2，以及 Cov(Tm,Tn)=ρσ2\text{Cov}(T_m,T_n) = \rho\sigma^2Cov(Tm​,Tn​)=ρσ2，代入则有：

Var(Tˉ)=1M2[Mσ2+M(M−1)ρσ2]\text{Var}(\bar T) = \frac{1}{M^2}[M\sigma^2 + M(M-1)\rho\sigma^2] Var(Tˉ)=M21​[Mσ2+M(M−1)ρσ2]

整理：

Var(Tˉ)=ρσ2+1−ρMσ2\text{Var}(\bar T) = \rho\sigma^2 + \frac{1-\rho}{M}\sigma^2 Var(Tˉ)=ρσ2+M1−ρ​σ2

当森林规模 M→∞M\to∞M→∞ 时，第二项趋近于 0，但 ρσ2\rho\sigma^2ρσ2 还会保留，这说明不仅要增加森林中树的数量，还必须降低树之间的相关性

因此，Random Forest 同时采用 Bootstrap 和随机特征，用于使得 ρ↓\rho\downarrowρ↓

极端随机树

Extra Trees 全称为 Extremely Randomized Trees，中文一般称为极端随机树 / 极随机树，它同样是 Decision Tree Ensemble，和 Random Forest 非常接近，二者的核心区别在于：

  1. 随机森林：随机特征，但认真优化切分阈值
  2. Extra Trees：随机特征，并进一步随机切分阈值

因此 Extra Trees 的树之间通常更加多样

Extra Trees 切分规则

假设一个节点随机选中了 x2,x5,x8x_2,x_5,x_8x2​,x5​,x8​ 三个特征

如果是随机森林，对于 x2x_2x2​，它会寻找 c2⋆=arg⁡max⁡cΔG(x2,c)c_2^\star = \arg\max_c\Delta G(x_2,c)c2⋆​=argmaxc​ΔG(x2​,c)，对于 x5x_5x5​，它会寻找 c5⋆=arg⁡max⁡cΔG(x5,c)c_5^\star = \arg\max_c\Delta G(x_5,c)c5⋆​=argmaxc​ΔG(x5​,c)，对于 x8x_8x8​ 也同理

然后比较三个特征的切分，选出最优切分，换言之，随机森林对切分位置进行了优化

如果是 Extra Trees，对于 x2x_2x2​，在当前样本范围 [x2min⁡,x2max⁡][x_2^{\min},x_2^{\max}][x2min​,x2max​] 内随机生成一个 c2∼U(x2min⁡,x2max⁡)c_2\sim\text{U}(x_2^{\min},x_2^{\max})c2​∼U(x2min​,x2max​)，对于 x5,x8x_5,x_8x5​,x8​ 也同理生成：

c5∼U(x5min⁡,x5max⁡)c8∼U(x8min⁡,x8max⁡)c_5\sim\text{U}(x_5^{\min},x_5^{\max})\\ c_8\sim\text{U}(x_8^{\min},x_8^{\max}) c5​∼U(x5min​,x5max​)c8​∼U(x8min​,x8max​)

然后比较 (x2,c2),  (x5,c5),  (x8,c8)(x_2,c_2),\;(x_5,c_5),\;(x_8,c_8)(x2​,c2​),(x5​,c5​),(x8​,c8​) 这些随机候选，最终选取：

j⋆=arg⁡max⁡jΔG(xj,cj)j^\star = \arg\max_j\Delta G(x_j,c_j) j⋆=argjmax​ΔG(xj​,cj​)

换言之，Extra Trees 不再为每个特征穷举寻找最佳阈值，而是故意为之把阈值也随机化

随机阈值原因

这么设计看似很奇怪，既然已知最佳阈值是存在的，为什么不选这个最佳阈值？

这主要还是基于偏差 - 方差权衡（Bias-Variance Trade-off）的角度来考虑，普通决策树努力在训练集上寻找最佳切分，即使得 Bias 下降，但这也容易高度依赖训练数据，使得 Variance 上升

Extra Trees 故意增加随机性，单棵树的 Bias 可能略增，但树与树之间的相关性显著降低，即使得整个森林的方差进一步下降，所以 Extra Trees 通过牺牲一点单棵树的最优性，换取整个 Ensemble 更强的多样性

简单而言，RF 是随机数据 / 特征 + 优化切分，而 ET 是随机数据 / 特征 + 随机切分

常见超参数

两个模型的常见超参数高度类似

  1. 森林中包含树的数量 MMM：通常 M↑⇒Variance↓M\uparrow\Rightarrow\text{Variance}\downarrowM↑⇒Variance↓，同时随着树的数量增加，计算量和内存也会增加，但一般不会像加深网络层一样造成过拟合，更多体现在收益饱和上
  2. 树最大深度 DDD：通常 D↑⇒Bias↓,Variance↑D\uparrow\Rightarrow\text{Bias}\downarrow,\text{Variance}\uparrowD↑⇒Bias↓,Variance↑
  3. 一个叶节点最少包含的样本数：通常取值越大，决策边界越平滑，越不容易因为少数异常样本形成特殊规则
  4. 每个节点随机允许使用的特征数：作为 tree strength 和 tree diversity 之间的权衡

模型评估

这里需要区分模型本身的内部评估，与任务性能指标两个概念

OOB Score

在前面的推导中，我们得知 Bootstrap 会导致大约 36.8% 的样本不会进入某棵树，对于样本 xix_ixi​，我们只使用那些 xi∉Dmx_i\notin\mathcal D_mxi​∈/​Dm​ 的树去预测它，即可得到 y^iOOB\hat y_i^{\text{OOB}}y^​iOOB​

所有样本都这样进行预测，即可得到：

OOB Error=#{y^OOB≠yi}N\text{OOB Error} = \frac{\#\{\hat{y}^{\text{OOB}}\ne y_i\}}{N} OOB Error=N#{y^​OOB​=yi​}​

需要注意的是，#\## 运算可以理解成是判断每个样本是否被预测错过，只要错过，不管错了一次，统一记贡献为 1，然后把所有样本的贡献相加组成分子，这相当于在训练随机森林的过程中我们天然就得到了一个内部验证集

Feature Importance

树模型经常采用 Mean Decrease in Impurity 来量化每个特征的重要性

如果特征 xjx_jxj​ 在很多树中带来了大量的 Impurity reduction ΔG\Delta GΔG，我们就认为其重要性（Importance）较高，可以抽象成：

Ij=∑notes using xjwjΔGnI_j = \sum_{\text{notes using }x_j}w_j\Delta G_n Ij​=notes using xj​∑​wj​ΔGn​

再在所有树中做平均、归一化

但 MDI（Mean Decrease in Impurity）可能有局限性，例如其会偏向取值较为丰富的连续变量、高基数变量、与其他特征高度相关的变量等，因此更可靠的解释方式之一是使用 Permutation Importance，即随机打乱某个特征：

xj→shuffle(xj)x_j\to\text{shuffle}(x_j) xj​→shuffle(xj​)

然后观察模型性能下降了多少：

PIj=Metricoriginal−Metricshuffled(j)PI_j = \text{Metric}_{\text{original}} - \text{Metric}_{\text{shuffled(j)}} PIj​=Metricoriginal​−Metricshuffled(j)​

如果打乱以后性能下降很大，则说明 xjx_jxj​ 很重要

树模型适用场景

Random Forest 格外适合以下的场景：

  1. 表格数据：形如 X∈RN×p\mathbf X\in\mathbb R^{N\times p}X∈RN×p，这是 RF 最典型的应用场景
  2. 非线性关系：形如 y = \mathbf 1[(x_1\gt 3\and x_2\lt 5)\or x_3\gt 8]，线性 Logistic 很难直接表达，而树模型则天然适合这种阈值 + 特征交互的分类结构
  3. 特征尺度差异很大：形如 x1∈[0,1],  x2∈[0,106]x_1\in[0,1],\;x_2\in[0,10^6]x1​∈[0,1],x2​∈[0,106]，树模型分类几乎不受影响，因为它比较的是各自的 x∼cx\sim cx∼c，而不涉及特征间关系，因此不需要额外做 Standard Scaler
  4. 中小规模数据集：对于结构化的中小规模数据集，RF 可作为可靠的 baseline

Extra Trees 在以下场景下会很有竞争力：

  1. 特征较多
  2. 特征之间存在非线性交互
  3. 数据量中等
  4. 单棵树产生高方差
  5. 希望训练速度快
  6. 希望通过更强随机化提高泛化能力

尤其是当普通 RF 中的树仍然高度相关时，Extra Trees 的 random threshold 策略，有时可以进一步提高模型的稳定性
