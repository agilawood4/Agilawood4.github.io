LLM 微调理论

硬件基础

GPU 与显卡

GPU 定义

GPU 通常指 GPU 芯片，是真正完成图形渲染或各种计算任务的组件，最初特指用于图形渲染的处理器，随着 AI 的发展，研究人员或开发者利用 GPU 的并行能力加速模型训练或推理，GPU 厂商也随之变革，开发了专为高性能计算（High Performance Computing，HPC）场景而生的数据中心 GPU 或专用于 AI 计算的 NPU

现在的 GPU 泛指所有可用于并行计算的处理器，包括 GPU，TPU，NPU，由于 TPU 是谷歌专为自家的 AI 训练加速而使用的，这里我们只讨论 GPU 和 NPU

  • TPU：特指谷歌自研的 AI 芯片，针对自家的深度学习框架 TensorFlow 而设计，生态封闭且不出售
  • NPU：泛指各类厂商专为 AI 加速设计的芯片，需要专用的软件栈和编译器，生态相对较新且不成熟，广义上 TPU 也属于 NPU 的一种

GPU 分类

GPU 根据用途可以分为两类：

  1. PC GPU：用于个人电脑的 GPU，面向终端消费者，性能一般，显存较小，市场主要被国外厂商占据，国外的英伟达（NVIDIA），AMD，Intel 占据了几乎所有的市场份额（没有华为）
  2. 数据中心 GPU：用于搭建数据中心的 GPU，面向大企业，性能强大，显存大，能够处理图形渲染、科学计算、AI 计算等多种并行任务，用于搭建超级计算机或大型 AI 集群

目前在数据中心 GPU 市场，英伟达几乎是唯一的选择，其他厂商基本没有份额，英伟达作为数据中心 GPU 的龙头老大，CUDA 是生态标杆，有海量的库支持和优化工具，发展时间长，生态非常成熟

CPU vs. GPU

一个 CPU 内核包含若干 ALU，这些 ALU 擅长处理复杂任务，架构也相对比较复杂，因此单个 CPU 内核只能包含少量 ALU

一个 GPU 也可以包含多个运算单元，它们能力单一，通常只能支持简单的运算，比 CPU 的 ALU 能力弱很多，但 GPU 运算单元的数量要远多于 CPU 的 ALU，其核心特点是高并行计算能力，尤其是在数据并行的任务中，表现远超过传统 CPU

简单而言，GPU 擅长执行大量相互独立的并行运算，而 CPU 擅长少量的复杂任务

显卡定义

单独的 GPU 芯片无法工作，必须通过 PCB（印刷电路板）集成供电、散热等辅助模块，GPU 芯片和 PCB 以及其他所有辅助模块所构成的整体称为显卡

通常 GPU 芯片不会单独出售给消费者，个人或下游企业买到的都是可以直接使用的显卡，因此很多时候我们并不会特意区分 GPU 和显卡

公版显卡 vs. 非公版显卡

GPU 芯片制造商不会向终端消费者直接出售 GPU 芯片，而是封装为显卡，这类显卡在设计时以稳定性优先，其散热能力较为基础，被称为公版显卡，公版显卡是非公版显卡的设计规范，RTX 消费系列公版显卡通常只有单风扇

显卡厂商从 GPU 厂商处购买 GPU 芯片，参考公版显卡的设计规范重新设计 PCB、供电模块、散热系统以及外观结构，形成的差异化产品，被称为非公版显卡

显卡分类

根据用途不同，显卡大致可以分为四类：

  1. 游戏显卡（消费级显卡）：面向主流游戏玩家，注重图形渲染性能和实时体验，属于传统GPU，通常是独立显卡（discrete GPU，独立于主板存在，通过 PCIE插槽与PC主板相连，有独立的显存和散热系统），但也有特例，AMD 的部分集成显卡（Integrated Graphics，集显），集成在 CPU 内部，和 CPU 封装在一起，也称为核心显卡 / 核显）也属于游戏显卡

    代表：NVIDIA GeForce RTX 系列、AMD Radeon RX 系列、国产的摩尔线程 S80、S70

  2. 专业工作站显卡：针对 3D 建模、影视渲染、科学计算等专业领域，优化驱动和稳定性，也属于传统 GPU

    代表：NVIDIA Quadro（现为 RTX A 系列）、AMD Radeon Pro 系列、国产的摩尔线程 X300、S50

  3. 计算加速卡（专用于 AI 训练）：用于 AI 训练、高性能计算（HPC），侧重并行计算能力，包括英伟达的数据中心 GPU 和其他厂商的 NPU

    代表：NVIDIA H100、A100、AMD Instinct 系列，国产的华为昇腾（Ascend）系列、摩尔线程 S4000、S3000、S2000

  4. 入门级（办公显卡）：低功耗，适合日常办公、视频播放等轻度需求，属于传统 GPU，大部分是集成显卡，主要用于轻薄本，目标是以较低的功耗提供基本的图形渲染功能，平衡续航与性能

    代表：Intel 集显、NVIDIA GeForce GT 1030 和 GeForce MX570（独显），国产的摩尔线程 S30 和 S10（独显）

需要注意的是，大多数入门级显卡都是集成显卡，这部分大都是 Intel 和 AMD 的产品，此外，其他公司也有少量入门级独显
