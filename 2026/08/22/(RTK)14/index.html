Kalman Filter 约束下的 WLS

Kalman Filter 的观测更新，本质上就是带有先验约束的加权最小二乘，二者并不是独立的，在标准 RTK 实现中，二者的关系可以表述为：

上一历元状态及协方差+当前历元双差观测→WLS 思想当前历元后验状态\text{上一历元状态及协方差} + \text{当前历元双差观测}\xrightarrow{\text{WLS 思想}}\text{当前历元后验状态} 上一历元状态及协方差+当前历元双差观测WLS 思想​当前历元后验状态

其中，上一历元状态及协方差为先验信息，当前历元的双差观测为新观测信息，Kalman Filter 只是把带有历史先验的 WLS 以一套适合递推计算的形式展现出来

单纯 WLS

线性化后的 GNSS 观测模型：

l=Hδx+ε\mathbf l = H\delta \mathbf x + \varepsilon l=Hδx+ε

其中，l\mathbf ll 为验前残差，HHH 为设计矩阵，δx\delta\mathbf xδx 为状态改正量，ε\varepsilonε 为观测噪声，R=Cov(ε)R = \text{Cov}(\varepsilon)R=Cov(ε) 为观测噪声协方差

加权最小二乘目标函数为：

J(δx)=(l−Hδx)⊤R−1(l−Hδx)J(\delta\mathbf x) = (\mathbf l - H\delta\mathbf x)^\top R^{-1}(\mathbf l - H\delta\mathbf x) J(δx)=(l−Hδx)⊤R−1(l−Hδx)

其中，R−1R^{-1}R−1 即观测信息矩阵，对应每颗卫星参与解算的权重

对 J(δx)J(\delta\mathbf x)J(δx) 求导，令导数为零，即可得到最优解：

δx^WLS=(H⊤R−1H)−1H⊤R−1l\delta\hat{\mathbf x}_{\text{WLS}} = (H^\top R^{-1}H)^{-1}H^\top R^{-1}\mathbf l δx^WLS​=(H⊤R−1H)−1H⊤R−1l

这就是单纯 WLS 的解法，它只根据当前历元的观测，去求解状态改正量，并没有让上一历元的信息参与进来

Kalman Filter 的改进

假设现在是第 kkk 个历元，Kalman 预测阶段已经得到状态估计先验 x^k−\hat{\mathbf x}_k^-x^k−​ 和先验状态的协方差 Pk−P_k^-Pk−​

当前真实状态可以写成：

xk=x^k−+δxk\mathbf x_k = \hat{\mathbf x}_k^- + \delta\mathbf x_k xk​=x^k−​+δxk​

其中，xk\mathbf x_kxk​ 即上一节中的状态估计后验 x^k+\hat{\mathbf x}_k^+x^k+​，而 δxk\delta\mathbf x_kδxk​ 即上一节中 Kalman 增益和新息的乘积（δxk=Kkrk\delta\mathbf x_k = K_k\mathbf r_kδxk​=Kk​rk​）

同时，δxk\delta\mathbf x_kδxk​ 也表示当前状态相对于预测状态需要修正多少

由于 x^k−\hat{\mathbf x}_k^-x^k−​ 已经是当前最好的预测，在没有得到新观测之前，我们可以认为 δxk≈0\delta\mathbf x_k\approx 0δxk​≈0，也就是不需要再做修正

但这个 “0” 也不是绝对可信的，因为 x^k−\hat{\mathbf x}_k^-x^k−​ 存在不确定度 Pk−P_k^-Pk−​，因此可以把先验写成：

0=Iδxk+ηk\mathbf 0 = I\delta\mathbf x_k + \eta_k 0=Iδxk​+ηk​

其中，ηk∼N(0,Pk−)\eta_k\sim\mathcal N(0,P_k^-)ηk​∼N(0,Pk−​)

因此，先验可以看成是一组伪观测，即根据历史认为状态不应偏离预测值太多，但允许它按照 P−P^-P− 所描述的不确定度发生变化

GNSS 观测方程

Kalman Filter 当前的非线性观测为：

z=h(x)+ε\mathbf z = h(\mathbf x) + \varepsilon z=h(x)+ε

在先验状态 x^−\hat{\mathbf x}^-x^− 附近线性化：

h(x)≈h(x^−)+Hδxh(\mathbf x)\approx h(\mathbf{\hat x}^-) + H\delta\mathbf x h(x)≈h(x^−)+Hδx

由此：

z≈h(x^−)+Hδx+ε\mathbf z \approx h(\hat{\mathbf x}^-) + H\delta\mathbf x + \varepsilon z≈h(x^−)+Hδx+ε

把预测观测移到左边：

z−h(x^−)=Hδx+ε\mathbf z - h(\mathbf{\hat x}^-) = H\delta\mathbf x + \varepsilon z−h(x^−)=Hδx+ε

先前在线性 Kalman 中，我们有：

z^=Hx^−\hat{\mathbf z} = H\hat{\mathbf x}^- z^=Hx^−

在非线性 Kalman 模型中，h(x^−)h(\hat{\mathbf x}^-)h(x^−) 即对应线性 Kalman 模型中的 Hx^−H\mathbf{\hat x}^-Hx^−，因此同样可以定义新息：

ν=z−z^=z−h(x^−)\mathbf \nu = \mathbf z - \mathbf{\hat z} = \mathbf z - h(\hat{\mathbf x}^-) ν=z−z^=z−h(x^−)

而此时的 δx\delta \mathbf xδx 即对应线性 Kalman 模型中的 x~−=x−x^−\tilde{\mathbf x}^- = \mathbf x - \hat{\mathbf x}^-x~−=x−x^−，也就是状态和先验预测之间的误差

由此：

ν=Hδx+ε\nu = H\delta\mathbf x + \varepsilon ν=Hδx+ε

其中，ε\varepsilonε 为观测噪声，其协方差为：

Cov(ε)=R\text{Cov}(\varepsilon) = R Cov(ε)=R

这是非线性卡尔曼滤波（扩展卡尔曼 EKF）对应的观测方程

在之前的线性场景下，观测和状态是线性关系：

z=Hx+ε\mathbf z = H\mathbf x + \varepsilon z=Hx+ε

比如状态是 [x,y,vx,vy][x,y,v_x,v_y][x,y,vx​,vy​]，如果要测位置，观测就是直接从状态中取前两项，因此 HHH 矩阵可以设计为 [10000100]\begin{bmatrix} 1 & 0 & 0 & 0 \\ 0 & 1 & 0 & 0 \end{bmatrix}[10​01​00​00​]，观测和状态直接成比例

但实际绝大多数传感器的观测和状态是非线性关系，没法直接用矩阵 HHH 相乘表示，此时我们只能用一个通用的非线性函数 h(⋅)h(\cdot)h(⋅) 来描述状态到观测的转换：

z=h(x)+ε\mathbf z = h(\mathbf x) + \varepsilon z=h(x)+ε

以雷达观测 2D 目标为例，状态 x=[x,y]⊤x = [x,y]^\topx=[x,y]⊤（目标是要求解 2D 坐标），雷达在原点测量的是距离 rrr 和角度 θ\thetaθ：

x=[rθ]=h(x)+ε=[x2+y2arctan2(y,x)]+[εrεθ]\mathbf x = \begin{bmatrix} r\\\theta\\ \end{bmatrix} = h(\mathbf x) + \varepsilon = \begin{bmatrix} \sqrt{x^2+y^2} \\ \text{arctan2}(y,x)\\ \end{bmatrix} + \begin{bmatrix} \varepsilon_r\\\varepsilon_\theta\\ \end{bmatrix} x=[rθ​]=h(x)+ε=[x2+y2​arctan2(y,x)​]+[εr​εθ​​]

这种关系完全没法写成 HxH\mathbf xHx 的线性形式，因此只能用 h(x)h(\mathbf x)h(x) 表示

而扩展卡尔曼（EKF）处理非线性观测的思路还是在当前估计点附近做泰勒展开，取一阶线性近似，从而把 h(x)h(\mathbf x)h(x) 做线性化

对 h(x)h(\mathbf x)h(x) 在当前先验估计 x^−\hat{\mathbf x}^-x^− 处展开：

h(x)≈h(x^−)+∂h∂x∣x^−(x−x^−)h(\mathbf x)\approx h(\hat{\mathbf x}^-) + \left.\frac{\partial h}{\partial \mathbf x}\right|_{\hat{\mathbf x}^-}(\mathbf x - \hat{\mathbf x}^-) h(x)≈h(x^−)+∂x∂h​∣∣∣∣∣​x^−​(x−x^−)

其中偏导数矩阵 H=∂h∂xH=\frac{\partial h}{\partial x}H=∂x∂h​（也称为观测雅可比矩阵），就对应之前线性卡尔曼中的固定观测矩阵 HHH，后续即可完全套用之前的线性卡尔曼公式进行更新

衔接 WLS

单纯的 WLS 观测方程为：

l=Hδx+ε\mathbf l = H\delta\mathbf x + \varepsilon l=Hδx+ε

Kalman Filter 观测方程为：

ν=Hδx+ε\nu = H\delta\mathbf x + \varepsilon ν=Hδx+ε

换言之，以前最小二乘中的验前残差向量，放到 Kalman Filter 中，就是由当前先验状态产生的新息向量，因此最小二乘并没有消失，它仍然是 Kalman 观测更新的核心

现在我们同时有两组观测，第一组是历史先验：

0=Iδx+η\mathbf 0 = I\delta\mathbf x + \eta 0=Iδx+η

先验误差 η\etaη 对应的协方差为 P−P^-P−（过程噪声 w\mathbf ww 对应的协方差 QQQ 这里并未出现）

第二组是当前 GNSS 观测：

ν=Hδx+ε\nu = H\delta\mathbf x + \varepsilon ν=Hδx+ε

观测噪声 ε\varepsilonε 协方差为 RRR

把二者拼接起来则有：

[0ν]=[IH]δx+[ηε]\begin{bmatrix} \mathbf 0\\\nu\\ \end{bmatrix} = \begin{bmatrix} I\\H\\ \end{bmatrix}\delta\mathbf x + \begin{bmatrix} \eta\\\varepsilon\\ \end{bmatrix} [0ν​]=[IH​]δx+[ηε​]

通常我们认为先验误差 η\etaη 和观测噪声 ε\varepsilonε 之间相互独立，因此联合协方差：

\text{∑} = \begin{bmatrix} P^- & 0 \\ 0 & R \\ \end{bmatrix}

对应信息矩阵：

\text{∑}^{-1} = \begin{bmatrix} (P^-)^{-1} & 0 \\ 0 & R^{-1} \\ \end{bmatrix}

其中，P−P^-P− 是状态先验协方差，而 RRR 是观测噪声协方差

加权最小二乘目标函数

现在我们同时要求：

  1. 状态改正不要过度偏离先验
  2. 更新后的状态尽量符合 GNSS 观测

因此我们设计最小二乘目标函数为：

J(δx)=δx⊤(P−)−1δx+(ν−Hδx)⊤R−1(ν−Hδx)J(\delta\mathbf x) = \delta\mathbf x^\top(P^-)^{-1}\delta\mathbf x + (\nu - H\delta\mathbf x)^\top R^{-1}(\nu - H\delta\mathbf x) J(δx)=δx⊤(P−)−1δx+(ν−Hδx)⊤R−1(ν−Hδx)

第一项

第一项 δx⊤(P−)−1δx\delta\mathbf x^\top(P^-)^{-1}\delta \mathbf xδx⊤(P−)−1δx 中的 (P−)−1(P^-)^{-1}(P−)−1 是先验状态的信息矩阵：

  • 如果 P−P^-P− 很小，就意味着先验状态非常可信，对应 (P−)−1(P^-)^{-1}(P−)−1 会很大，此时如果 δx\delta\mathbf xδx 很大，对应 J(δx)J(\delta\mathbf x)J(δx) 就会很大，因此要求我们不要大幅度修改状态
  • 如果 P−P^-P− 很大，对应 (P−)−1(P^-)^{-1}(P−)−1 就会很小，说明历史预测不可靠，先验约束变弱，当前 GNSS 观测就可以把状态拉动很多

第二项

第二项 (ν−Hδx)⊤R−1(ν−Hδx)(\nu - H\delta\mathbf x)^\top R^{-1}(\nu - H\delta\mathbf x)(ν−Hδx)⊤R−1(ν−Hδx) 中 ν−Hδx\nu - H\delta\mathbf xν−Hδx 表示：如果把状态修正了 δx\delta\mathbf xδx 这么多，还剩下多少观测残差

如果某条 GNSS 观测的方差 σi2\sigma_i^2σi2​ 都很小，即说明这条 GNSS 观测比较可信，对应 R−1R^{-1}R−1 会很大，那么其对应的观测残差会受到更大的惩罚，因此需要我们尽可能取满足这条观测，以降低残差惩罚

由此我们知道，RRR 决定当前 GNSS 每一条观测的权重，P−P^-P− 决定历史先验的权重

目标函数求解

目标函数：

J(δx)=δx⊤(P−)−1δx+(ν−Hδx)R−1(ν−Hδx)J(\delta\mathbf x) = \delta\mathbf x^\top (P^-)^{-1}\delta\mathbf x + (\nu - H\delta\mathbf x)R^{-1}(\nu - H\delta\mathbf x) J(δx)=δx⊤(P−)−1δx+(ν−Hδx)R−1(ν−Hδx)

对 δx\delta\mathbf xδx 求导则有：

∂J∂δx=2(P−)−1δx−2H⊤R−1(ν−Hδx)\frac{\partial J}{\partial\delta\mathbf x} = 2(P^-)^{-1}\delta\mathbf x -2H^\top R^{-1}(\nu - H\delta\mathbf x) ∂δx∂J​=2(P−)−1δx−2H⊤R−1(ν−Hδx)

这里用到矩阵求导的链式法则，因为 δx⊤(P−)−1δx\delta\mathbf x^\top(P^-)^{-1}\delta\mathbf xδx⊤(P−)−1δx 和 (ν−Hδx)R−1(ν−Hδx)(\nu - H\delta\mathbf x)R^{-1}(\nu - H\delta\mathbf x)(ν−Hδx)R−1(ν−Hδx) 都是二次型，也就是标量，因此满足以下规则

假设 f:R→Rf:\mathbb R\to\mathbb Rf:R→R 为目标函数，y∈Rm\mathbf y\in\mathbb R^my∈Rm 为中间变量，x∈Rn\mathbf x\in\mathbb R^nx∈Rn 为自变量，三者关系满足 f=f(y),  y=y(x)f=f(\mathbf y),\;\mathbf y = \mathbf y(\mathbf x)f=f(y),y=y(x)，则链式法则为：

∂f∂x=(∂y∂x)⊤∂f∂y\frac{\partial f}{\partial\mathbf x} = \left( \frac{\partial \mathbf y}{\partial \mathbf x} \right)^\top\frac{\partial f}{\partial\mathbf y} ∂x∂f​=(∂x∂y​)⊤∂y∂f​

之所以要做转置并且调换顺序，主要是为了满足维度的对齐，求导的结果和 x\mathbf xx 相同

项 维度
∂f∂y\frac{\partial f}{\partial\mathbf y}∂y∂f​ m×1（列向量）
∂y∂x\frac{\partial \mathbf y}{\partial \mathbf x}∂x∂y​ m×n（雅可比矩阵，y 每行对 x 求导）
(∂y∂x)⊤\left( \frac{\partial \mathbf y}{\partial \mathbf x} \right)^\top(∂x∂y​)⊤ n×m（雅可比矩阵的转置）
∂f∂x\frac{\partial f}{\partial\mathbf x}∂x∂f​ n×1（列向量）

令导数为零则有：

[(P−)−1+H⊤R−1H]δx=H⊤R−1ν[(P^-)^{-1} + H^\top R^{-1}H]\delta\mathbf x = H^\top R^{-1}\nu [(P−)−1+H⊤R−1H]δx=H⊤R−1ν

解得：

δx^=[(P−)−1+H⊤R−1H]−1H⊤R−1ν\delta\hat{\mathbf x} = [(P^-)^{-1} + H^\top R^{-1}H]^{-1}H^\top R^{-1}\nu δx^=[(P−)−1+H⊤R−1H]−1H⊤R−1ν

这就是最小二乘形式的 Kalman 更新

对比普通 WLS

普通 WLS 的最优状态修正量估计：

δx^WLS=(H⊤R−1H)−1H⊤R−1l\delta\mathbf{\hat x}_{\text{WLS}} = (H^\top R^{-1} H)^{-1}H^\top R^{-1}\mathbf l δx^WLS​=(H⊤R−1H)−1H⊤R−1l

Kalman 最优状态修正量估计：

δx^KF=[(P−)−1+H⊤R−1H]−1H⊤R−1ν\delta\mathbf{\hat x}_{\text{KF}} = [(P^-)^{-1} + H^\top R^{-1} H]^{-1} H^\top R^{-1}\nu δx^KF​=[(P−)−1+H⊤R−1H]−1H⊤R−1ν

二者最大的区别就在于，Kalman 多了一项 (P−)−1(P^-)^{-1}(P−)−1，也就是历史先验信息

因此我们可以认为，Kalman Filter 即 WLS 结合先验状态约束的结果

Kalman Gain 等价性

δx^\delta\mathbf{\hat x}δx^ 等价性

在上一节中，我们熟悉的 Kalman 更新 δx^\delta\mathbf{\hat x}δx^ 的公式为：

δx^=Kν\delta\mathbf{\hat x} = K\nu δx^=Kν

其中，K=P−H⊤(HP−H⊤+R)−1K = P^-H^\top(HP^-H^\top + R)^{-1}K=P−H⊤(HP−H⊤+R)−1 为 Kalman 增益，ν\nuν 为新息

而刚才最小二乘推出来的结果为：

δx^=[(P−)−1+H⊤R−1H]−1H⊤R−1ν\delta\mathbf{\hat x} = [(P^-)^{-1} + H^\top R^{-1} H]^{-1} H^\top R^{-1}\nu δx^=[(P−)−1+H⊤R−1H]−1H⊤R−1ν

其中，Kalman Gain 又成为增益形式，而最小二乘又称为信息形式，可以证明二者更新结果完全相等，即：

P−H⊤(HP−H⊤+R)−1=[(P−)−1+H⊤R−1H]−1H⊤R−1P^-H^\top(HP^-H^\top + R)^{-1} = [(P^-)^{-1} + H^\top R^{-1} H]^{-1} H^\top R^{-1} P−H⊤(HP−H⊤+R)−1=[(P−)−1+H⊤R−1H]−1H⊤R−1

对于任意 ν\nuν 都成立

因此二者在数学上是同一个解

现在我们明白，增益矩阵 K=P−H⊤(HP−H⊤+R)−1K = P^-H^\top(HP^-H^\top + R)^{-1}K=P−H⊤(HP−H⊤+R)−1 只是把 “先验 + 当前观测的最小二乘解” 重新整理成一种适合递推计算的形式

P+P^+P+ 等价性

在上一节中，我们熟悉的 Kalman 更新后验协方差 P+P^+P+ 的公式为：

P+=(I−KH)P−P^+ = (I - KH)P^- P+=(I−KH)P−

这是其标准形式，写成信息形式即为：

P+=[(P−)−1+H⊤R−1H]−1P^+ = [(P^-)^{-1} + H^\top R^{-1} H]^{-1} P+=[(P−)−1+H⊤R−1H]−1

也可以证明，这两者是完全等价的

而在正规方程中，(P−)−1+H⊤R−1H(P^-)^{-1} + H^\top R^{-1} H(P−)−1+H⊤R−1H 就是中的信息矩阵，而后验状态的协方差又满足：

P+=[(P−)−1+H⊤R−1H]−1P^+ = [(P^-)^{-1} + H^\top R^{-1} H]^{-1} P+=[(P−)−1+H⊤R−1H]−1

取逆则有：

(P+)−1=(P−)−1+H⊤R−1H(P^+)^{-1} = (P^-)^{-1} + H^\top R^{-1} H (P+)−1=(P−)−1+H⊤R−1H

这是一个非常优雅的公式，它表示后验信息 = 先验信息 + 当前观测信息，其中，(P−)−1(P^-)^{-1}(P−)−1 是历史积累的信息，而 H⊤R−1HH^\top R^{-1}HH⊤R−1H 是当前 GNSS 观测提供的新信息

先验失效情况

如果我们不相信先验，即 P−→∞P^-\to∞P−→∞，对应 (P−)−1→0(P^-)^{-1}\to0(P−)−1→0，此时 Kalman 形式的最小二乘解变为：

δx^KF=(H⊤R−1H)−1H⊤R−1l\delta\mathbf{\hat x}_{\text{KF}} = (H^\top R^{-1} H)^{-1}H^\top R^{-1}\mathbf l δx^KF​=(H⊤R−1H)−1H⊤R−1l

这恰好就是普通的 WLS，因此我们认为，WLS 可以看成是 Kalman Filter 在没有有效先验情况下的特例
