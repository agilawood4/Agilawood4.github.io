时间与坐标系统

前面的模块我们了解了卫星发射的原始信号，以及接收机观测到的信号，现在需要有一套统一的时间和坐标基准，用以描述卫星和接收机之间的几何关系，后续所有伪距、载波相位和 RTK 双差方程，都建立在此基础上

GNSS 时间敏感性

GNSS 的基本测距关系为：

距离=光速×传播时间\text{距离} = \text{光速}\times\text{传播时间} 距离=光速×传播时间

即：

ρ=cτ\rho = c\tau ρ=cτ

如果时间测量误差为 1μs1\mu s1μs，则对应距离误差会变成：

10−6×3×108=300m10^{-6}\times 3\times10^8 =300m 10−6×3×108=300m

因此，即便卫星钟和接收机钟之间只存在很小的时间偏差，转换成距离后，这个误差也可能非常大

因此，在 GNSS 观测模型中必须明确区分

  • 系统时间
  • 卫星钟时间
  • 接收机钟时间
  • 信号发射时刻
  • 信号接收时刻

否则，微小的时间错位，也可能带来极大的测距偏差

理想时间与钟表时间

系统时间

假设当前存在一个理想、统一的 GNSS 系统时间，用 ttt 来表示

但实际卫星和接收机内部有自己的振荡器和时钟，它们不可能与理想系统时间完全一致

卫星钟时间

设真实系统时间为 ttt，卫星钟指示时间为 t~s\tilde{t}^st~s

定义卫星钟差：

δts=t~s−t\delta t^s = \tilde{t}^s - t δts=t~s−t

因此：

t~s=t+δts\tilde{t}^s = t + \delta t^s t~s=t+δts

其中，上标 sss 表示卫星

如果 δts>0\delta t^s>0δts>0，则表示卫星钟相对于系统时间走快了

接收机钟时间

同理，接收机钟指示时间为：

t~r\tilde{t}_r t~r​

定义接收机钟差：

δtr=t~r−t\delta t_r = \tilde{t}_r - t δtr​=t~r​−t

因此：

t~r=t+δtr\tilde{t}_r = t + \delta t_r t~r​=t+δtr​

下标 rrr 表示接收机

钟差对测距的影响

假设卫星在系统时刻 tst^sts 发射信号，接收机在系统时刻 trt_rtr​ 接收信号

理想传播时间为：

τrs=tr−ts\tau_r^s = t_r - t^s τrs​=tr​−ts

理想几何近似距离为：

ρrs=c(tr−ts)\rho_r^s = c(t_r - t^s) ρrs​=c(tr​−ts)

但接收机实际比较的是两套非理想时钟：

t~r=tr+δtrt~s=ts+δts\tilde{t}_r = t_r + \delta t_r\\ \tilde{t}^s = t^s + \delta t^s t~r​=tr​+δtr​t~s=ts+δts

所以接收机实际测得的时间差为：

t~r−t~s=(tr+δtr)−(ts+δts)=(tr−ts)+(δtr−δts)\tilde{t}_r - \tilde{t}^s = (t_r + \delta t_r) - (t^s + \delta t^s) = (t_r - t^s) + (\delta t_r - \delta t^s) t~r​−t~s=(tr​+δtr​)−(ts+δts)=(tr​−ts)+(δtr​−δts)

乘以光速得到距离：

c(t~r−t~s)=c(tr−ts)+c(δtr−δts)=ρrs+c(δtr−δts)c(\tilde{t}_r - \tilde{t}^s) = c(t_r - t^s) + c(\delta t_r - \delta t^s) = \rho_r^s + c(\delta t_r - \delta t^s) c(t~r​−t~s)=c(tr​−ts)+c(δtr​−δts)=ρrs​+c(δtr​−δts)

其中，ρrs\rho_r^sρrs​ 是理想的几何近似距离，c(δtr−δts)c(\delta t_r - \delta t^s)c(δtr​−δts) 就是伪距方程中钟差项的物理来源

接收时刻和发射时刻

对于同一条卫星信号，存在两个不同的时刻：

  • trt_rtr​：接收机收到该信号的时刻
  • tst^sts：卫星发出该信号的时刻

二者满足：

tr−ts=τrst_r - t^s = \tau_r^s tr​−ts=τrs​

其中 τrs\tau_r^sτrs​ 是传播时间

因此，在计算卫星和接收机的几何距离时，对于卫星而言，应当使用 rs(ts)\mathbf{r}^s(t^s)rs(ts) 计算卫星的位置；而对于接收机而言，应当使用 rr(tr)\mathbf{r}_r(t_r)rr​(tr​) 计算接收机的位置

观测历元对应的通常是接收机的接收时刻，卫星发射时刻需要据此回推：

ts≈tr−Pct^s\approx t_r - \frac{P}{c} ts≈tr​−cP​

t^r→t^s\hat t_r\to \hat t^st^r​→t^s

接收机收到信号的时刻 t^r\hat t_rt^r​ （接收机钟视角）通常是已知的，而传播时间一开始并不知道，因此真实几何距离也不知道

接收机此时已经可以算出粗略的伪距 PrsP_r^sPrs​，因此可以先用伪距估计传播时间：

τ^rs≈Prsc\hat{\tau}_r^s\approx \frac{P_r^s}{c} τ^rs​≈cPrs​​

从而得到卫星钟视角的信号发射时刻：

t^s≈t^r−Prsc\hat{t}^s\approx \hat t_r - \frac{P_r^s}{c} t^s≈t^r​−cPrs​​

将 t^r\hat t_rt^r​ 和 PrsP_r^sPrs​ 分别展开则有：

t^r=tr+δtrPrs=c(tr−ts)+c(δtr−δts),先不考虑其它噪声\hat t_r = t_r + \delta t_r\\ P_r^s = c(t_r - t^s) + c(\delta t_r - \delta t^s),\quad\text{先不考虑其它噪声} t^r​=tr​+δtr​Prs​=c(tr​−ts)+c(δtr​−δts),先不考虑其它噪声

代入上式则天然成立，这里比较巧妙的地方就在于 PrsP_r^sPrs​ 中天然带有接收机钟差，二者相减的时候，接收机钟差项会自然抵消

因此在已知 t^r\hat t_rt^r​ 和 PrsP_r^sPrs​ 即可反推 t^s\hat t^st^s，最后减去卫星钟差：

ts=t^s−δtst^s = \hat t^s - \delta t^s ts=t^s−δts

即可得到系统时间下的信号发射时间

RTKLIB 求解信号发射时刻就按照上述思路实现：先用伪距除以光速，从观测时刻回推发射时刻；随后计算卫星钟差并再次修正，最后在修正后的发射时刻计算卫星位置和卫星钟差

GNSS 时间系统

不同卫星系统使用不同的时间尺度，在进行多系统定位时，必须先把它们转换到一致的内部时间表示

UTC

UTC（Coordinated Universal Time），即协调世界时

UTC 用于民用时间表达，例如年月日、时分秒，它通过闰秒与地球自转时间保持接近，因此 UTC 并不是一个完全连续、永不跳变的时间尺度

当插入正闰秒时，UTC 会出现额外的一秒，且截至 2026 年 7 月，IERS 最新 Bulletin C 仍规定：

UTC−TAI=−37 s\text{UTC}-\text{TAI}=-37\ \text{s} UTC−TAI=−37 s

并确认到 2026 年 12 月末之前不增加闰秒

GPST

GPST 即 GPS Time（GPS 时间）

RTKLIB 中的 GPS 时间起点定义为：

1980-01-06  00:00:001980\text{-}01\text-06\;00:00:00 1980-01-0600:00:00

GPS 时间采用连续秒计数，不插入 UTC 润秒，RTKLIB 使用 GPS 周数 + 周内秒的形式表示 GPST：

tGPST=tGPS,0+604800W+TOWt_{\text{GPST}} = t_{\text{GPS,0}} + 604800 W + \text{TOW} tGPST​=tGPS,0​+604800W+TOW

其中，W\text WW 表示从 GPS 计时起始时刻开始截止到现在一共经过的整周数，TOW\text{TOW}TOW 表示除去整周以外，不足一周的秒数，即周内秒（Time of Week），604800 即 7×24×60×50，也就是一周内包含的秒数

每当经过完整的一周，则有：

W←W+1TOW←0W\gets W+1\\ \text{TOW}\gets 0 W←W+1TOW←0

按照当前 RTKLIB 的润秒表：

GPST=UTC+18s\text{GPST} = \text{UTC} + 18s GPST=UTC+18s

如果未来 UTC 时刻中插入新润秒，这一关系也会随之改变

GST

GST 即 Galileo System Time（Galileo 时间）

RTKLIB 中的 Galileo 时间起点定义为：

1999-08-22  00:00:001999\text-08\text-22\;00:00:00 1999-08-2200:00:00

同样使用 Galileo 周数和 Galileo 周内秒表示相应时刻

BDT

BDT 即 BeiDou Time（北斗时间）

RTKLIB 中的 BeiDuo 时间起点定义为：

2006-01-01  00:00:002006\text-01\text-01\;00:00:00 2006-01-0100:00:00

RTKLIB 采用：

BDT=GPST−14s\text{BDT} = \text{GPST} - 14s BDT=GPST−14s

来记录北斗时间

系统时间偏差

在进行多系统定位时，即使已经把 GPS、Galileo、北斗等观测转换到统一的时间表示，不同系统信号经过接收机内部不同的射频通道、信号相关器、硬件链路时，仍然可能产生系统相关延迟

因此，多系统定位中通常需要估计 ISB（Inter-System Bias），即系统时间偏差

RTKLIB 的单点定位模型除了 GPS 接收机钟差外，还为 GLONASS、Galileo 和北斗设置相对于 GPS 的时间偏差状态

其中，time 表示整数秒部分，sec 表示不足一秒的小数部分

观测结构中的 obsd_t.time 表示接收机采样时刻，并在 RTKLIB 内部通常以 GPST 组织，这样设计的好处在于：

  • 整数秒便于日期和长时间跨度处理
  • 小数秒单独保存，可以避免把全部秒数放入一个浮点数造成精度损失

GNSS 坐标系统

卫星位置和接收机位置必须统一到同一个坐标系下，才能完成后续距离等一系列计算

如果卫星位置写成：

rs=[xsyszs]⊤\mathbf{r}^s = [x^s\quad y^s\quad z^s]^\top rs=[xsyszs]⊤

接收机位置写成：

rr=[xryrzr]⊤\mathbf{r}_r = [x_r\quad y_r\quad z_r]^\top rr​=[xr​yr​zr​]⊤

只有当二者处于统一坐标系下，且统计时刻也对应时，才能计算二者之间的几何距离

本节重点讲解常见的三大坐标系：ECEF 坐标系，大地坐标系，局部ENU 坐标系

地球参考椭球

真实的地球其实并不是一个标准的球体，只是为了进行数学计算，GNSS 通常用一个旋转椭球来近似地球

椭球主要由两个参数定义：

  • 长半轴 aaa
  • 扁率 fff

RTKLIB 采用 WGS 84 椭球参数：

a=6378137.0mf=1298.257223563a = 6378137.0m\\ f = \frac{1}{298.257223563} a=6378137.0mf=298.2572235631​

并定义第一偏心率平方：

e2=f(2−f)e^2 = f(2 - f) e2=f(2−f)

ECEF 坐标系

ECEF（Earth-Centered, Earth-Fixed），即地心地固坐标系，它是一个随地球一起旋转的三维直角坐标系

  • 原点：地球质心
  • ZZZ 轴：沿地球自转轴指向北极
  • XXX 轴：指向赤道与本初子午线交点
  • YYY 轴：与 X,ZX,ZX,Z 轴组成右手坐标系

ECEF 坐标表示为：

r=[xyz]ECEF\mathbf r = \begin{bmatrix} x\\ y\\z \end{bmatrix}_{\text{ECEF}} r=⎣⎢⎡​xyz​⎦⎥⎤​ECEF​

单位为米

ECEF 坐标系的优点为：

  • 卫星和接收机可以统一表示
  • 三维距离可以直接用向量计算
  • 适合构造定位观测方程
  • 不存在经度跨越 180° 时的表达问题

WGS 84 是用于导航和定位的三维地球参考框架，RTKLIB的卫星位置、接收机位置和基线向量主要都以 ECEF 坐标处理

大地坐标系

大地坐标通常写成：

p=[φλh]\mathbf p = \begin{bmatrix} \varphi\\ \lambda\\ h\\ \end{bmatrix} p=⎣⎢⎡​φλh​⎦⎥⎤​

其中，φ\varphiφ 表示大地纬度，λ\lambdaλ 表示大地经度，hhh 表示椭球高

大地纬度

大地纬度 φ\varphiφ 指的是该点处的参考椭球法线与赤道平面之间的夹角，并不是地心道该点连线与赤道平面的夹角，后者称为地心纬度

因为地球是椭球而不是球，因此除了赤道和极点位置外，其余位置大地纬度和地心纬度都不相等，GNSS 定位结果中的纬度通常是指大地纬度

大地经度

大地经度 λ\lambdaλ 表示该点所在子午面相对于本初子午面的夹角，一般约定东经为正，西经为负

椭球高

椭球高 hhh 是沿参考椭球法线，从椭球表面到目标点的距离，并不是海拔高度 HHH

大地坐标→ECEF

首先定义：

N(φ)=a1−e2sin⁡2φ\mathcal{N}(\varphi) = \frac{a}{\sqrt{1 - e^2\sin^2\varphi}} N(φ)=1−e2sin2φ​a​

其中，aaa 为参考椭球的长半轴，φ\varphiφ 为大地纬度，eee 为第一偏心率平方，N(φ)\mathcal{N}(\varphi)N(φ) 称为卯酉圈曲率半径，它随维度变化，反映椭球沿东西方向的曲率

给定大地坐标：

(φ,λ,h)(\varphi,\lambda,h) (φ,λ,h)

其对应的 ECEF 坐标为：

x=[N(φ)+h]cos⁡φcos⁡λy=[N(φ)+h]cos⁡φsin⁡λz=[N(φ)(1−e2)+h]sin⁡φx = [\mathcal{N}(\varphi) + h]\cos\varphi\cos\lambda\\ y = [\mathcal{N}(\varphi) + h]\cos\varphi\sin\lambda\\ z = [\mathcal{N}(\varphi)(1-e^2) + h]\sin\varphi x=[N(φ)+h]cosφcosλy=[N(φ)+h]cosφsinλz=[N(φ)(1−e2)+h]sinφ

写成向量形式则有：

rECEF=[(N(φ)+h)cos⁡φcos⁡λ(N(φ)+h)cos⁡φsin⁡λ(N(φ)(1−e2)+h)sin⁡φ]\mathbf r_{\text{ECEF}} = \begin{bmatrix} \left(\mathcal{N}(\varphi) + h\right)\cos\varphi\cos\lambda\\ \left(\mathcal{N}(\varphi) + h\right)\cos\varphi\sin\lambda\\ \left(\mathcal{N}(\varphi)(1-e^2) + h\right)\sin\varphi \end{bmatrix} rECEF​=⎣⎢⎡​(N(φ)+h)cosφcosλ(N(φ)+h)cosφsinλ(N(φ)(1−e2)+h)sinφ​⎦⎥⎤​

ECEF → 大地坐标

给定 ECEF 坐标：

(x,y,z)(x,y,z) (x,y,z)

经度可以直接得到：

λ=atan2(y,x)\lambda = \text{atan2}(y,x) λ=atan2(y,x)

纬度和椭球高相互耦合，因为 N(φ)\mathcal{N}(\varphi)N(φ) 本身依赖纬度：

N=a1−e2sin⁡2φ\mathcal{N} = \frac{a}{\sqrt{1-e^2\sin^2\varphi}} N=1−e2sin2φ​a​

因此，从 ECEF 坐标到大地坐标通常需要迭代求解，其基本思想为：

  1. 根据 x,y,zx,y,zx,y,z 得到纬度初值
  2. 用当前纬度计算 N(φ)\mathcal{N}(\varphi)N(φ)
  3. 更新纬度
  4. 重复上述计算直到变化足够小
  5. 最后计算椭球高 hhh

最终得到的经度和纬度单位为弧度，高度单位为米

局部 ENU 坐标系

ENU 是以某个参考点为原点的局部直角坐标系

  • EEE：East，东向
  • NNN：North，北向
  • UUU：Up，天向

与 ECEF 坐标系不同，ENU 坐标系并不是全球唯一的，它必须指定一个参考点 (φ0,λ0,h0)(\varphi_0,\lambda_0,h_0)(φ0​,λ0​,h0​)，不同参考点会对应不同的 ENU 坐标系

ENU 坐标系通常用于表示：

  • 基线向量
  • 定位误差
  • 速度与相对位移
  • 方位角和高度角
  • 水平误差和垂直误差

例如，定位误差写成：

ΔrECEF=r^−rref\Delta \mathbf{r}_{\text{ECEF}} = \hat{\mathbf{r}} - \mathbf{r}_{\text{ref}} ΔrECEF​=r^−rref​

转换到 ENU 坐标系下，即得到：

ΔrENU=[ΔEΔNΔU]\Delta \mathbf{r}_{\text{ENU}} = \begin{bmatrix} \Delta E\\ \Delta N\\ \Delta U\\ \end{bmatrix} ΔrENU​=⎣⎢⎡​ΔEΔNΔU​⎦⎥⎤​

就可以直观解释为：

  • 东向误差
  • 北向误差
  • 高程方向误差

ECEF → ENU

设局部原点的大地纬度和经度为：

(φ0,λ0)(\varphi_0,\lambda_0) (φ0​,λ0​)

ECEF 到 ENU 的旋转矩阵为：

Ren=[−sin⁡λ0cos⁡λ00−sin⁡φ0cos⁡λ0−sin⁡φ0sin⁡λ0cos⁡φ0cos⁡φ0cos⁡λ0cos⁡φ0sin⁡λ0sin⁡φ0]\mathbf{R}_{e}^n = \begin{bmatrix} -\sin\lambda_0 & \cos\lambda_0 & 0\\ -\sin\varphi_0\cos\lambda_0 & -\sin\varphi_0\sin\lambda_0 & \cos\varphi_0\\ \cos\varphi_0\cos\lambda_0 & \cos\varphi_0\sin\lambda_0 & \sin\varphi_0 \end{bmatrix} Ren​=⎣⎢⎡​−sinλ0​−sinφ0​cosλ0​cosφ0​cosλ0​​cosλ0​−sinφ0​sinλ0​cosφ0​sinλ0​​0cosφ0​sinφ0​​⎦⎥⎤​

其中，nnn 表示局部导航坐标系（ENU），eee 表示 ECEF 坐标系，Ren\mathbf{R}_e^nRen​ 表示将 ECEF 向量转换到 ENU

假设目标点和局部原点的 ECEF 坐标分别为：

rte,r0e\mathbf{r}_t^e,\quad \mathbf{r}_0^e rte​,r0e​

需要先构造 ECEF 差分向量：

Δre=rte−r0e\Delta \mathbf{r}^e = \mathbf{r}_t^e - \mathbf{r}_0^e Δre=rte​−r0e​

这里的局部原点即转换后的 ENU 坐标系的参考点，因为 ENU 是局部相对坐标，必须先用目标点减去局部原点，不能直接把目标点的 ECEF 绝对坐标，直接乘以旋转矩阵

对于 ECEF 差分向量：

Δre=[ΔxΔyΔz]\Delta \mathbf{r}^e = \begin{bmatrix} \Delta x\\ \Delta y\\ \Delta z\\ \end{bmatrix} Δre=⎣⎢⎡​ΔxΔyΔz​⎦⎥⎤​

有：

Δrn=RenΔre\Delta\mathbf{r}^n = \mathbf{R}_e^n\Delta\mathbf{r}^e Δrn=Ren​Δre

即：

[ΔEΔNΔU]=Ren[ΔxΔyΔz]\begin{bmatrix} \Delta E\\ \Delta N\\ \Delta U\\ \end{bmatrix} = \mathbf{R}_e^n\begin{bmatrix} \Delta x\\ \Delta y\\ \Delta z\\ \end{bmatrix} ⎣⎢⎡​ΔEΔNΔU​⎦⎥⎤​=Ren​⎣⎢⎡​ΔxΔyΔz​⎦⎥⎤​

其中，ΔE,ΔN,ΔU\Delta E,\Delta N,\Delta UΔE,ΔN,ΔU 即表示目标点相对于 ENU 参考原点的东向、北向、天向偏移量

卫星 - 接收机几何向量

设卫星在发射时刻的 ECEF 坐标为：

rs(ts)=[xsyszs]\mathbf{r}^s(t^s) = \begin{bmatrix} x^s\\y^s\\z^s\\ \end{bmatrix} rs(ts)=⎣⎢⎡​xsyszs​⎦⎥⎤​

接收机在接收时刻的 ECEF 坐标为：

rt(tr)=[xryrzr]\mathbf{r}_t(t_r) = \begin{bmatrix} x_r\\y_r\\z_r\\ \end{bmatrix} rt​(tr​)=⎣⎢⎡​xr​yr​zr​​⎦⎥⎤​

由此定义卫星 - 接收机几何向量为：

drs=rs(ts)−rr(tr)\mathbf{d}_r^s = \mathbf{r}^s(t^s) - \mathbf{r}_r(t_r) drs​=rs(ts)−rr​(tr​)

展开为：

drs=[xs−xrys−yrzs−zr]\mathbf{d}_r^s = \begin{bmatrix} x^s - x_r\\ y^s - y_r\\ z^s - z_r\\ \end{bmatrix} drs​=⎣⎢⎡​xs−xr​ys−yr​zs−zr​​⎦⎥⎤​

它从接收机指向卫星

卫星 - 接收机几何距离

卫星 - 接收机几何距离为几何向量的欧式范数：

ρrs=∥drs∥=∥rs−rr∥\rho_r^s = \|\mathbf{d}_r^s\| = \|\mathbf{r}^s - \mathbf{r}_r\| ρrs​=∥drs​∥=∥rs−rr​∥

将其展开得到：

ρrs=(xs−xr)2+(ys−yr)2+(zs−zr)2\rho_r^s = \sqrt{(x^s - x_r)^2 + (y^s - y_r)^2 + (z^s - z_r)^2} ρrs​=(xs−xr​)2+(ys−yr​)2+(zs−zr​)2​

结合前面的章节，我们需要严格区分三个距离相关的概念：

  • ρrs\rho_r^sρrs​：根据坐标计算得到的理论几何距离
  • PrsP_r^sPrs​：接收机测得的伪距
  • λΦrs\lambda\Phi_r^sλΦrs​：由载波相位得到的距离观测值

一般情况下，Prs≠ρrsP_r^s\ne \rho_r^sPrs​​=ρrs​，因为伪距中还包含钟差、大气延迟、硬件偏差和测量噪声等因素

视线单位向量

将卫星 - 接收机之间的几何向量归一化：

urs=drsρrs\mathbf{u}_r^s = \frac{\mathbf{d}_r^s}{\rho_r^s} urs​=ρrs​drs​​

即用向量本身除以向量模数：

urs=rs−rr∥rs−rr∥\mathbf{u}_r^s = \frac{\mathbf{r}^s - \mathbf{r}_r}{\|\mathbf{r}^s - \mathbf{r}_r\|} urs​=∥rs−rr​∥rs−rr​​

展开即得到：

urs=[uxuyuz]=[xs−xrys−yrzs−zr]\mathbf{u}_r^s = \begin{bmatrix} u_x\\u_y\\u_z\\ \end{bmatrix} = \begin{bmatrix} x^s - x_r\\y^s - y_r\\z^s - z_r\\ \end{bmatrix} urs​=⎣⎢⎡​ux​uy​uz​​⎦⎥⎤​=⎣⎢⎡​xs−xr​ys−yr​zs−zr​​⎦⎥⎤​

它满足：

∥urs∥=1\|\mathbf{u}_r^s\| = 1 ∥urs​∥=1

视线单位向量表示从接收机指向卫星的方向，不包含距离大小，它后续会用于：

  • 构造定位设计矩阵
  • 计算方位角和高度角
  • 将速度投影到视线方向
  • 构造多普勒观测模型
  • 线性化几何距离

方位角与高度角

视线向量→ENU

视线单位向量当前位于 ECEF 坐标系：

ue=[uxuyuz]\mathbf{u}^e = \begin{bmatrix} u_x\\u_y\\u_z\\ \end{bmatrix} ue=⎣⎢⎡​ux​uy​uz​​⎦⎥⎤​

使用接收机所在位置的经纬度构造 ENU 旋转矩阵，将 ECEF 坐标投影为 ENU 坐标：

un=Renue\mathbf{u}^n = \mathbf{R}_e^n\mathbf{u}^e un=Ren​ue

得到 ENU 坐标系下的视线单位向量：

un=[uEuNuU]\mathbf{u}^n = \begin{bmatrix} u_E\\u_N\\u_U\\ \end{bmatrix} un=⎣⎢⎡​uE​uN​uU​​⎦⎥⎤​

因为旋转不会改变向量长度，所以仍然有：

ux2+uy2+uz2=1→uE2+uN2+u+U2=1u_x^2 + u_y^2 + u_z^2 = 1\quad \to \quad u_E^2 + u_N^2 + u+U^2 = 1 ux2​+uy2​+uz2​=1→uE2​+uN2​+u+U2=1

方位角

记方位角为：

AA A

GNSS 中通常规定：正北为 0∘0^\circ0∘，正东为 90∘90^\circ90∘，正南为 180∘180^\circ180∘，正西为 270∘270^\circ270∘

ENU 坐标转成方位角的公式为：

A=atan2(uE,uN)A = \text{atan2}(u_E,u_N) A=atan2(uE​,uN​)

如果结果为负，则加上 2π2\pi2π，确保 A∈[0,2π)A\in[0,2\pi)A∈[0,2π)，对应传入的两个参数分别为东向偏移和北向偏移

高度角

记高度角为：

ElE_l El​

表示卫星视线与当地水平面的夹角

对于单位视线向量：

El=arcsin(uU)E_l = \text{arcsin}(u_U) El​=arcsin(uU​)

其范围为：

−π2≤El≤π2-\frac{\pi}{2}\le E_l \le \frac{\pi}{2} −2π​≤El​≤2π​

其中，El=90∘E_l=90^\circEl​=90∘ 表示卫星位于天顶，El=0∘E_l = 0^\circEl​=0∘ 表示卫星位于地平线，El<0∘E_l<0^\circEl​<0∘ 表示卫星位于当地地平线以下

因此，我们常用的处理思想是，先把 ECEF 坐标系下的单位视线向量转换到 ENU 坐标系中，再使用：

A=atan2(uE,uN)El=arcsin(uU)A = \text{atan2}(u_E,u_N)\\ E_l = \text{arcsin}(u_U) A=atan2(uE​,uN​)El​=arcsin(uU​)

计算高度角和方位角

高度角的重要性

高度角不仅能表示卫星的位置方向，还与观测质量密切相关

低高度角的卫星通常具有（注意只是通常的性质）：

  • 更长的大气传播路径
  • 更强的对流层和电离层映射效应
  • 更高的建筑物遮挡概率
  • 更严重的地面和建筑物多路径
  • 更低或不稳定的 C/N0

因此，RTK 中通常设置截止高度角：

El≥EminE_l\ge E_{\text{min}} El​≥Emin​

只有满足一定高度角大小的卫星才参与定位

然而，高度角门限过高也会减少可用卫星的数量，削弱卫星几何结构，因此它是观测质量与卫星数量之间的一个折中门控

Sagnac 效应

卫星发射信号时刻为 tst^sts，接收机信号接收时刻为 trt_rtr​，信号传播时间，地球仍在自转

ECEF 坐标系会与地球一起自转，因此卫星发射时刻的 ECEF 坐标轴，与接收机接收时刻的 ECEF 坐标轴，方向并不完全相同

如果直接计算：

∥rs(ts)−rr(tr)∥\|\mathbf{r}^s(t^s) - \mathbf{r}_r(t_r)\| ∥rs(ts)−rr​(tr​)∥

就相当于把两个不同时刻的地固坐标放在同一坐标轴下比较，则会产生地球自转误差

一阶地球自转改正推导

记地球自转角速度为 ωe\omega_eωe​，信号传播时间为 τ\tauτ，则信号传播期间地球转过的角度为：

θ=ωeτ\theta = \omega_e\tau θ=ωe​τ

设发射时刻卫星坐标为：

rs=[xsyszs]\mathbf{r}^s = \begin{bmatrix} x^s\\y^s\\z^s\\ \end{bmatrix} rs=⎣⎢⎡​xsyszs​⎦⎥⎤​

考虑传播期间绕 ZZZ 轴的小角度旋转：

θ=ωeτ\theta = \omega_e\tau θ=ωe​τ

在一阶近似下，卫星坐标变化量为：

δrs≈[θys−θxs0]\delta \mathbf{r}^s\approx\begin{bmatrix} \theta y^s\\ -\theta x^s\\ 0\\ \end{bmatrix} δrs≈⎣⎢⎡​θys−θxs0​⎦⎥⎤​

几何距离的一阶变化为：

δρ=(urs)⊤δrs\delta \rho = (\mathbf{u}_r^s)^\top\delta \mathbf{r}^s δρ=(urs​)⊤δrs

代入视线单位向量公式：

urs=rs−rrρ\mathbf{u}_r^s = \frac{\mathbf{r}^s - \mathbf{r}_r}{\rho} urs​=ρrs−rr​​

得到：

δρ=1ρ[(xs−xr)θys−(ys−yr)θxs]=θρ(xsyr−ysxr)\delta\rho = \frac{1}{\rho}\left[ (x^s - x_r)\theta y^s - (y^s - y_r)\theta x^s \right] = \frac{\theta}{\rho}(x^sy_r - y^sx_r) δρ=ρ1​[(xs−xr​)θys−(ys−yr​)θxs]=ρθ​(xsyr​−ysxr​)

又因为：

θ=ωeτ≈ωeρc\theta = \omega_e\tau\approx \omega_e\frac{\rho}{c} θ=ωe​τ≈ωe​cρ​

最终则有：

δρSag=ωec(xsyr−ysxr)\delta \rho_{\text{Sag}} = \frac{\omega_e}{c}(x^sy_r - y^sx_r) δρSag​=cωe​​(xsyr​−ysxr​)

因此，考虑地球自转后的距离为：

ρcorr=∥rs−rr∥+δρSag=∥rs−rr∥+ωec(xsyr−ysxr)\rho_{\text{corr}} = \|\mathbf{r}^s - \mathbf{r}_r\| + \delta\rho_{\text{Sag}} = \|\mathbf{r}^s - \mathbf{}r_r\| + \frac{\omega_e}{c}(x^sy_r - y^sx_r) ρcorr​=∥rs−rr​∥+δρSag​=∥rs−rr​∥+cωe​​(xsyr​−ysxr​)

这就是常见的一阶 Sagnac 改正形式
