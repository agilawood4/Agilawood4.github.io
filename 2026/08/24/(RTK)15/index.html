Kalman Filter in RTK

我们先只考虑一个基本的短基线、单频 RTK 模型，约定符号如下：

  • 流动站（rover）：uuu
  • 基准站（base）：bbb
  • 参考卫星：jjj
  • 普通卫星：iii

双差伪距：

∇ΔPubij=∇Δρubij+εPij\nabla\Delta P_{ub}^{ij} = \nabla\Delta \rho_{ub}^{ij} + \varepsilon_P^{ij} ∇ΔPubij​=∇Δρubij​+εPij​

双差载波相位：

∇ΔLubij=∇Δρubij+λNubij+εLij\nabla\Delta L_{ub}^{ij} = \nabla\Delta\rho_{ub}^{ij} + \lambda N_{ub}^{ij} + \varepsilon_L^{ij} ∇ΔLubij​=∇Δρubij​+λNubij​+εLij​

RTK 中的 Kalman 状态

最简单的理论状态为：

x=[ruN]\mathbf x = \begin{bmatrix} \mathbf r_u\\\mathbf N\\ \end{bmatrix} x=[ru​N​]

其中，ru=[xuyuzu]\mathbf r_u = \begin{bmatrix} x_u\\y_u\\z_u\\ \end{bmatrix}ru​=⎣⎢⎡​xu​yu​zu​​⎦⎥⎤​ 为流动站位置，假设共有 nnn 个双差，N=[N1N2⋮Nn]\mathbf N = \begin{bmatrix} N_1\\N_2\\\vdots\\N_n\\ \end{bmatrix}N=⎣⎢⎢⎢⎢⎡​N1​N2​⋮Nn​​⎦⎥⎥⎥⎥⎤​ 为双差载波模糊度

预测阶段已经得到：

x^−=[r^u−N^−]\hat{\mathbf x}^- = \begin{bmatrix} \mathbf{\hat r}_u^-\\\mathbf{\hat N}^-\\ \end{bmatrix} x^−=[r^u−​N^−​]

以及先验误差的协方差：

P−P^- P−

Step1 - 先验状态计算理论双差观测

根据先验预测得到的伪距双差估计值为：

P^DDij=∇Δρij(r^u−)\hat{P}_{DD}^{ij} = \nabla\Delta\rho^{ij}(\mathbf{\hat r}_u^-) P^DDij​=∇Δρij(r^u−​)

实际的双差伪距为：

PDD,obsijP_{DD,\text{obs}}^{ij} PDD,obsij​

因此可以计算伪距新息：

νPij=∇ΔPobsij−∇Δρij(r^u−)\nu_P^{ij} = \nabla\Delta P_{\text{obs}}^{ij} - \nabla\Delta \rho^{ij}(\hat{\mathbf r}_u^-) νPij​=∇ΔPobsij​−∇Δρij(r^u−​)

根据先验预测得到的载波双差估计值为：

L^DDij=∇Δρij(r^u−)+λN^ij,−\hat{L}_{DD}^{ij} = \nabla\Delta \rho^{ij}(\mathbf{\hat r}_u^-) + \lambda\hat{N}^{ij,-} L^DDij​=∇Δρij(r^u−​)+λN^ij,−

实际的双差载波为：

LDD,obsijL_{DD,\text{obs}}^{ij} LDD,obsij​

因此可以计算载波新息：

νLij=∇ΔLobsij−[∇Δρij(r^u−)+λN^ij,−]\nu_L^{ij} = \nabla\Delta L_{\text{obs}}^{ij} - [\nabla\Delta\rho^{ij}(\mathbf{\hat r}_u^-) + \lambda\hat{N}^{ij,-}] νLij​=∇ΔLobsij​−[∇Δρij(r^u−​)+λN^ij,−]

这就是所谓的 O-C\text{O-C}O-C，即 Observed - Computed

Step2 - 双差几何距离线性化

伪距新息线性化

我们已经知道 ∇Δρij(r)\nabla\Delta\rho^{ij}(\mathbf r)∇Δρij(r) 关于 rover 位置是非线性的，因此在 r^u−\mathbf{\hat r}_u^-r^u−​ 附近对其做一阶泰勒展开：

∇Δρij(ru)≈∇Δρij(r^u−)+gij⊤δr\nabla\Delta\rho^{ij}(\mathbf r_u) \approx \nabla\Delta\rho^{ij}(\mathbf{\hat r}_u^-) + \mathbf g_{ij}^\top\delta\mathbf r ∇Δρij(ru​)≈∇Δρij(r^u−​)+gij⊤​δr

其中，gij=ej−ei\mathbf g_{ij} = \mathbf e^j - \mathbf e^igij​=ej−ei，即表示接收机指向两颗卫星 i,ji,ji,j 的 LOS 向量之差

将其代入原始的双差伪距公式中：

∇ΔPobsij≈∇Δρij(r^u−)+gij⊤δr+εPij\nabla\Delta P_{\text{obs}}^{ij}\approx\nabla\Delta\rho^{ij}(\mathbf{\hat r}_u^-) + \mathbf g_{ij}^\top\delta\mathbf r + \varepsilon_P^{ij} ∇ΔPobsij​≈∇Δρij(r^u−​)+gij⊤​δr+εPij​

移项，根据伪距新息的定义：

νPij=∇ΔPobsij−∇Δρij(r^u−)\nu_P^{ij} = \nabla\Delta P_{\text{obs}}^{ij} - \nabla\Delta\rho^{ij}(\mathbf{\hat r}_u^-) νPij​=∇ΔPobsij​−∇Δρij(r^u−​)

因此：

νPij≈gij⊤r+εPij\nu_P^{ij} \approx \mathbf g_{ij}^\top\mathbf r + \varepsilon_P^{ij} νPij​≈gij⊤​r+εPij​

载波新息线性化

我们已经知道 ∇Δρij(r)\nabla\Delta\rho^{ij}(\mathbf r)∇Δρij(r) 关于 rover 位置是非线性的，因此在 r^u−\mathbf{\hat r}_u^-r^u−​ 附近对其做一阶泰勒展开：

∇Δρij(ru)≈∇Δρij(r^u−)+gij⊤δr\nabla\Delta\rho^{ij}(\mathbf r_u) \approx \nabla\Delta\rho^{ij}(\mathbf{\hat r}_u^-) + \mathbf g_{ij}^\top\delta\mathbf r ∇Δρij(ru​)≈∇Δρij(r^u−​)+gij⊤​δr

其中，gij=ej−ei\mathbf g_{ij} = \mathbf e^j - \mathbf e^igij​=ej−ei，即表示接收机指向两颗卫星 i,ji,ji,j 的 LOS 向量之差

同时，真实模糊度满足：

Nij=N^ij,−+δNijN^{ij} = \hat{N}^{ij,-} + \delta N^{ij} Nij=N^ij,−+δNij

将其代入原始的双差载波相位公式中：

∇ΔLobsij≈∇Δρij(r^u−)+gij⊤δr+λN^ij,−+λδNij+εPij\nabla\Delta L_{\text{obs}}^{ij}\approx\nabla\Delta\rho^{ij}(\mathbf{\hat r}_u^-) + \mathbf g_{ij}^\top\delta\mathbf r + \lambda\hat{N}^{ij,-} + \lambda\delta N^{ij} + \varepsilon_P^{ij} ∇ΔLobsij​≈∇Δρij(r^u−​)+gij⊤​δr+λN^ij,−+λδNij+εPij​

移项，根据载波相位新息的定义：

νLij=∇ΔLobsij−[∇Δρij(r^u−)+λN^ij,−]\nu_{L}^{ij} = \nabla\Delta L_{\text{obs}}^{ij} - [\nabla\Delta\rho^{ij}(\mathbf{\hat r}_u^-) + \lambda\hat{N}^{ij,-}] νLij​=∇ΔLobsij​−[∇Δρij(r^u−​)+λN^ij,−]

因此：

νLij≈gij⊤δr+λδNij+εLij\nu_L^{ij}\approx \mathbf g_{ij}^\top\delta\mathbf r + \lambda\delta N^{ij} + \varepsilon_L^{ij} νLij​≈gij⊤​δr+λδNij+εLij​

至此，我们把伪距和载波相位的双差建模统一为：

ν=Hδx+ε\nu = H\delta\mathbf x + \varepsilon ν=Hδx+ε

RTK 的设计矩阵 H

假设有 4 个双差模糊度，整体状态修正量估计为：

δx=[δxδyδzδN1δN2δN3δN4]\delta\mathbf x = \begin{bmatrix} \delta x\\\delta y\\\delta z\\\delta N_1\\\delta N_2\\\delta N_3\\\delta N_4\\ \end{bmatrix} δx=⎣⎢⎢⎢⎢⎢⎢⎢⎢⎢⎡​δxδyδzδN1​δN2​δN3​δN4​​⎦⎥⎥⎥⎥⎥⎥⎥⎥⎥⎤​

把 4 条伪距和 4 条载波的双差放在一起：

ν=[νPνL]\nu = \begin{bmatrix} \nu_P\\\nu_L\\ \end{bmatrix} ν=[νP​νL​​]

设计矩阵可以构造为：

H=[G0GλI]H = \begin{bmatrix} G & 0\\G & \lambda I\\ \end{bmatrix} H=[GG​0λI​]

其中，G=[g1⊤g2⊤g3⊤g4⊤]G = \begin{bmatrix} \mathbf g_1^\top\\\mathbf g_2^\top\\\mathbf g_3^\top\\\mathbf g_4^\top\\ \end{bmatrix}G=⎣⎢⎢⎢⎡​g1⊤​g2⊤​g3⊤​g4⊤​​⎦⎥⎥⎥⎤​

设计矩阵 HHH 的结构可以分成上下两部分来看：

  • 伪距部分 [G0][G\quad0][G0] 表示双查伪距只直接约束位置，不包含整周模糊度
  • 载波部分 [GλI][G\quad\lambda I][GλI] 表示双差载波既约束位置，又约束模糊度

所以伪距和载波一起进入滤波以后，伪距帮助确定绝对几何位置，高精度载波不断约束位置和模糊度

Step3 - 构造 RTK 的 RRR

现在需要告诉滤波器：每一条双差观测有多可信

这就是 R=Cov(ε)R = \text{Cov}(\varepsilon)R=Cov(ε)，例如 σP2\sigma_P^2σP2​ 表示伪距方差，σL2\sigma_L^2σL2​ 表示载波相位方差，通常满足：

σL2≪σP2\sigma_L^2\ll\sigma_P^2 σL2​≪σP2​

对应信息矩阵：

RL−1≫RP−1R_L^{-1}\gg R_P^{-1} RL−1​≫RP−1​

也就是说，载波在滤波更新中的权重通常要远大于伪距

双差之后的 RRR 不再是简单的对角矩阵，例如：

∇ΔL21=ΔL2−ΔL1∇ΔL31=ΔL3−ΔL1\nabla\Delta L^{21} = \Delta L^2 - \Delta L^1\\ \nabla\Delta L^{31} = \Delta L^3 - \Delta L^1\\ ∇ΔL21=ΔL2−ΔL1∇ΔL31=ΔL3−ΔL1

两条双差中都包含参考量 ΔL1\Delta L^1ΔL1，所以它们的误差相关：

Cov(∇ΔL21,∇ΔL31)≠0\text{Cov}(\nabla\Delta L^{21},\nabla\Delta L^{31})\ne 0 Cov(∇ΔL21,∇ΔL31)​=0

因此完整的 RRR 矩阵通常存在非对角元素

Step4 - WLS 求解

现在我们已经有了 RTK 中的两组观测，即先验和当前双差观测

先验：

δx≈0,Cov=P−\delta\mathbf x\approx 0,\quad\text{Cov} = P^- δx≈0,Cov=P−

当前双差观测：

ν=Hδx+ε,Cov=R\nu = H\delta\mathbf x + \varepsilon,\quad\text{Cov} = R ν=Hδx+ε,Cov=R

于是当前 RTK 历元的目标函数写为：

J(δx)=δx⊤(P−)−1δx+(ν−δx)⊤R−1(ν−Hδx)J(\delta\mathbf x) = \delta\mathbf x^\top (P^-)^{-1}\delta\mathbf x + (\nu - \delta\mathbf x)^\top R^{-1}(\nu - H\delta\mathbf x) J(δx)=δx⊤(P−)−1δx+(ν−δx)⊤R−1(ν−Hδx)

我们要求的：

δx^=arg⁡min⁡δxJ(δx)\delta{\hat{\mathbf x}} = \arg\min_{\delta\mathbf x} J(\delta\mathbf x) δx^=argδxmin​J(δx)

求导，令导数为零，得到：

δx^=[(P−)−1+H⊤R−1H]−1H⊤R−1ν\delta\mathbf{\hat x} = \left[ (P^-)^{-1} + H^\top R^{-1}H \right]^{-1}H^\top R^{-1}\nu δx^=[(P−)−1+H⊤R−1H]−1H⊤R−1ν

写成 Kalman 增益形式，也等价于：

δx^=Kν\delta\hat{\mathbf x} = K\nu δx^=Kν

Step5 - 更新 RTK 状态

先验状态 x^−\hat{\mathbf x}^-x^− 经过 δx^\delta{\mathbf {\hat x}}δx^ 修正以后，得到：

x^+=x^−+δx^\hat{\mathbf x}^+ = \mathbf{\hat x}^- + \delta\mathbf{\hat x} x^+=x^−+δx^

在上一节的 Kalman 更新中

δx^=Kν\delta{\hat{\mathbf x}} = K\nu δx^=Kν

其中，ν\nuν 为当前双差观测的新息向量，KKK 为 Kalman 增益，δx^\delta\hat{\mathbf x}δx^ 为状态改正量

把状态拆分为 x=[rN]\mathbf x = \begin{bmatrix} \mathbf r\\\mathbf N\\ \end{bmatrix}x=[rN​]，因此 Kalman 增益也可以按照状态进行分块：

K=[KrKN]K = \begin{bmatrix} K_r\\K_N\\ \end{bmatrix} K=[Kr​KN​​]

因此则有：

[δr^δN^]=[KrKN]ν\begin{bmatrix} \delta\mathbf{\hat r}\\\delta\mathbf{\hat N} \end{bmatrix} = \begin{bmatrix} K_r\\K_N\\\end{bmatrix}\nu [δr^δN^​]=[Kr​KN​​]ν

因此状态更新实际上也可以分为两部分：

r^u+=r^u−+δx^N^+=N^−+δN^\hat{\mathbf r}_u^+ = \hat{\mathbf r}_u^- + \delta\hat{\mathbf x}\\ \hat{\mathbf N}^+ = \hat{\mathbf N}^- + \delta\hat{\mathbf N} r^u+​=r^u−​+δx^N^+=N^−+δN^

需要注意的是，这里的 N^+\hat{\mathbf N}^+N^+ 仍然是普通的实数估计，即这里得到的仍然是 Float RTK 状态，但是 Kalman Filter + WLS 在 RTK 中的作用至此已经完成

Kalman Filter 作用

如果每个历元都单独做 WLS，则上一历元的 N^\hat{N}N^ 和 PNNP_{NN}PNN​ 都没有被传递下来，模糊度会很难积累信息

而在 Kalman Filter 中，(N^k−1+,PNN,k−1+)(\hat{N}_{k-1}^+,P_{NN,k-1}^+)(N^k−1+​,PNN,k−1+​) 会成为下一历元的先验，即历史载波信息可以不断积累，这对 RTK 十分重要

逐历元积累 WLS

下面我们证明，如果状态不发生变化，Kalman 其实就是逐历元积累的 WLS

假设一个静止状态：

xk=xk−1\mathbf x_k = \mathbf x_{k-1} xk​=xk−1​

即状态转移矩阵：

F=IF = I F=I

而过程噪声协方差为 0：

Q=0Q = 0 Q=0

那么根据先验误差不确定性的递推公式：

Pk−=F⊤Pk−1+F+QP_{k}^- = F^\top P_{k-1}^+ F + Q Pk−​=F⊤Pk−1+​F+Q

可知：

Pk−=Pk−1+P_k^- = P_{k-1}^+ Pk−​=Pk−1+​

而在上一节中，我们给出了信息形式的后验误差不确定度更新：

(Pk+)−1=(Pk−)−1+Hk⊤Rk−1Hk(P_k^+)^{-1} = (P_{k}^-)^{-1} + H_k^\top R_k^{-1} H_k (Pk+​)−1=(Pk−​)−1+Hk⊤​Rk−1​Hk​

代入则有：

(Pk+)−1=(Pk−1+)−1+Hk⊤Rk−1Hk(P_k^+)^{-1} = (P_{k-1}^+)^{-1} + H_k^\top R_k^{-1} H_k (Pk+​)−1=(Pk−1+​)−1+Hk⊤​Rk−1​Hk​

如果对于每个时刻，都有 Pk−=Pk−1+P_k^- = P_{k-1}^+Pk−​=Pk−1+​ 成立，我们可以把 (Pk−1+)−1(P_{k-1}^+)^{-1}(Pk−1+​)−1 做同理展开：

(Pk−1+)−1=(Pk−2+)−1+Hk−1⊤Rk−1−1Hk−1(P_{k-1}^+)^{-1} = (P_{k-2}^+)^{-1} + H_{k-1}^\top R_{k-1}^{-1} H_{k-1} (Pk−1+​)−1=(Pk−2+​)−1+Hk−1⊤​Rk−1−1​Hk−1​

由此形成递推：

(Pk+)−1=(P0)−1+∑t=1kHt⊤Rt−1Ht(P_k^+)^{-1} = (P_0)^{-1} + \sum_{t=1}^k H_t^\top R_t^{-1}H_t (Pk+​)−1=(P0​)−1+t=1∑k​Ht⊤​Rt−1​Ht​

也就是说，每观测到一个历元，就把这个历元所提供的信息矩阵加到以前的信息上

这本质上就是在把从 t1t_1t1​ 到 tkt_ktk​ 的所有观测一起拿来做 WLS，但 Kalman 不需要把过去所有观测存下来重新求解，它只需要保存：

x^k−1+,Pk−1+\hat{\mathbf x}_{k-1}^+,\quad P_{k-1}^+ x^k−1+​,Pk−1+​

更靠前时刻的历史信息都已经压入其中，这就是递推最小二乘的本质

RTK 中 QQQ 的作用

现实状态并不是严格不变的，例如动态场景下，位置 rk\mathbf r_krk​ 会发生变化

所以预测：

Pk−=FPk−1+F⊤+QP_k^- = F P_{k-1}^+ F^\top + Q Pk−​=FPk−1+​F⊤+Q

其中，QQQ 的含义为：虽然历史信息很有价值，但是随着时间推移，我们不能无限相信旧状态

如果 QQQ 增加，那么 P−P^-P− 也随之增加，对应 (P−)−1(P^-)^{-1}(P−)−1 会减小，历史先验的权重随之减小，当前 GNSS 观测的作用相对增强

换言之，我们可以认为 QQQ 是在控制 “遗忘历史” 的速度

RTK 中两类权重

整个 RTK 滤波中的权重分为两类：

  • P−1P^{-1}P−1 表示历史预测状态有多可信
  • R−1R^{-1}R−1 表示当前卫星观测有多可信

对于 R−1R^{-1}R−1 而言，低高度角、低 C/N0、NLOS 观测都会导致 σ2\sigma^2σ2 增加，由此 RRR 增加，对应 R−1R^{-1}R−1 减小，则当前观测对 δx\delta\mathbf xδx 的影响随之降低

后续各种 RTK 自适应加权方法最终都是作用在 R−1R^{-1}R−1 矩阵上：

观测质量→R→R−1→K→δx\text{观测质量}\to R\to R^{-1}\to K\to\delta\mathbf x 观测质量→R→R−1→K→δx

总结

LS，WLS，KF 三者对比如下：

方法 使用当前观测 使用观测权重 R−1R^{-1}R−1 使用历史先验 P−1P^{-1}P−1
LS ✓ × ×
WLS ✓ ✓ ×
Kalman Filter ✓ ✓ ✓

其中：

  • LS 只考虑让观测残差的平方和最小
  • WLS 进一步考虑不同观测的可靠性
  • KF 进一步考虑怎么把以前历元已经获得的信息也作为约束加入当前求解

完整 RTK 过程

首先利用载波相位和伪距观测，进行站间单差和星间双差：

∇ΔPobsij=∇Δρij+εPij∇ΔLobsij=∇Δρij+λNij+εPij\nabla\Delta P_{\text{obs}}^{ij} = \nabla\Delta\rho^{ij} + \varepsilon_P^{ij}\\ \nabla\Delta L_{\text{obs}}^{ij} = \nabla\Delta \rho^{ij} + \lambda N^{ij} + \varepsilon_P^{ij} ∇ΔPobsij​=∇Δρij+εPij​∇ΔLobsij​=∇Δρij+λNij+εPij​

根据预测状态 x^−\hat{\mathbf x}^-x^−，计算双差观测的估计值：

P^DDij=∇Δρij(r^u−)L^DDij=∇Δρij(r^u−)+λN^ij,−\hat{P}_{DD}^{ij} = \nabla\Delta\rho^{ij}(\mathbf{ \hat r}_u^-)\\ \hat{L}_{DD}^{ij} = \nabla\Delta\rho^{ij}(\mathbf{\hat r}_u^-) + \lambda\hat{N}^{ij,-} P^DDij​=∇Δρij(r^u−​)L^DDij​=∇Δρij(r^u−​)+λN^ij,−

对双差几何距离进行线性化，在 r^u−\mathbf{\hat r}_u^-r^u−​ 处做一阶泰勒展开：

∇Δρij(ru)≈∇Δρij(r^u−)+g⊤δr\nabla\Delta\rho^{ij}(\mathbf r_u) \approx \nabla\Delta\rho^{ij}(\mathbf{\hat r}_u^-) + \mathbf g^\top\delta\mathbf r ∇Δρij(ru​)≈∇Δρij(r^u−​)+g⊤δr

同时模糊度满足：

Nij=N^ij,−+δNijN^{ij} = \hat{N}^{ij,-} + \delta N^{ij} Nij=N^ij,−+δNij

载波相位和伪距新息定义为：

νPij=∇ΔPobsij−P^DDijνLij=∇ΔLobsij−L^DDij\nu_P^{ij} = \nabla\Delta P_{\text{obs}}^{ij} - \hat{P}_{DD}^{ij}\\ \nu_L^{ij} = \nabla\Delta L_{\text{obs}}^{ij} - \hat{L}_{DD}^{ij} νPij​=∇ΔPobsij​−P^DDij​νLij​=∇ΔLobsij​−L^DDij​

将线性化结果代入信息定义则有：

νPij=g⊤δr+εPijνLij=g⊤δr+λδNij+εLij\nu_P^{ij} = \mathbf g^\top\delta \mathbf r + \varepsilon_P^{ij}\\ \nu_L^{ij} = \mathbf g^\top\delta\mathbf r + \lambda\delta N^{ij} + \varepsilon_L^{ij} νPij​=g⊤δr+εPij​νLij​=g⊤δr+λδNij+εLij​

即得到最小二乘的标准形式：

ν=Hδx+ε\nu = H\delta\mathbf x + \varepsilon ν=Hδx+ε

其中，待求解的状态估计量 δx=[rN]\delta\mathbf x = \begin{bmatrix} \mathbf r\\\mathbf N\\ \end{bmatrix}δx=[rN​]，设计矩阵 H=[G0GλI]H = \begin{bmatrix} G & 0\\ G & \lambda I\\ \end{bmatrix}H=[GG​0λI​]

最小二乘目标函数为：

J(δx)=δx⊤(P−)−1δx+(ν−δx)⊤R−1(ν−Hδx)J(\delta\mathbf x) = \delta\mathbf x^\top (P^-)^{-1}\delta\mathbf x + (\nu - \delta\mathbf x)^\top R^{-1}(\nu - H\delta\mathbf x) J(δx)=δx⊤(P−)−1δx+(ν−δx)⊤R−1(ν−Hδx)

解得最优 δx^\hat{\delta\mathbf x}δx^ 为：

δx^=[(P−)−1+H⊤R−1H]−1H⊤R−1ν\delta\mathbf{\hat x} = \left[ (P^-)^{-1} + H^\top R^{-1}H \right]^{-1}H^\top R^{-1}\nu δx^=[(P−)−1+H⊤R−1H]−1H⊤R−1ν

其中，H⊤R−1HH^\top R^{-1}HH⊤R−1H 信息由当前观测提供，(P−)−1(P^-)^{-1}(P−)−1 信息由历史观测提供

接着更新 P+P^+P+ 和 x^+\hat{\mathbf x}^+x^+ 后验：

(P+)−1=(P−)−1+H⊤R−1Hx^+=x^−+δx(P^+)^{-1} = (P^-)^{-1} + H^\top R^{-1} H\\ \hat{\mathbf x}^+ = \hat{\mathbf x}^- + \delta\mathbf x (P+)−1=(P−)−1+H⊤R−1Hx^+=x^−+δx

其中，对于 x^+\hat{\mathbf x}^+x^+ 的更新同时包含对位置和浮点模糊度的更新

以上就是完整 Kalman Filter + WLS 的求解过程
