RTK 观测质量控制与数据预处理

本讲我们主要解决：在伪距、载波相位进入 RTK 状态估计之前，怎样判断哪些观测能用、哪些可疑、哪些必须剔除

问题背景

标准 RTK 默认输入的伪距和载波相位已经具有基本可靠性，但实际接收机（尤其是手机）GNSS 中，经常出现：

  • 低高度角卫星
  • 低 C/N0
  • NLOS / Multipath
  • 相位失锁
  • 周跳
  • 频点消失
  • 异常伪距
  • 异常载波相位
  • 星历或卫星健康异常

如果这些观测直接进入 RTK，则很有可能污染整个解算过程，最终造成 False Fix，因此 RTK 前端需要先对卫星质量做一个基本的检查，确保 “坏星” 不会污染解算过程

原始 RTK 模型

以已经线性化的观测模型为例：

z=h(x)+εz = h(x) + \varepsilon z=h(x)+ε

在先验状态 x−x^-x− 附近：

z≈h(x−)+Hδx+εz\approx h(x^-) + H\delta x + \varepsilon z≈h(x−)+Hδx+ε

定义新息：

ν=z−h(x−)\nu = z - h(x^-) ν=z−h(x−)

因此则有：

ν=Hδx+ε\nu = H\delta x + \varepsilon ν=Hδx+ε

对于 RTK 双差观测，伪距新息可以写成：

νPij=gij⊤δr+εPij\nu_P^{ij} = g_{ij}^\top\delta r + \varepsilon_P^{ij} νPij​=gij⊤​δr+εPij​

载波信息可以写成：

νLij=gij⊤δr+λδNij+εLij\nu_L^{ij} = g_{ij}^\top\delta r + \lambda \delta N^{ij} + \varepsilon_L^{ij} νLij​=gij⊤​δr+λδNij+εLij​

二者组合起来则有：

ν=Hδx+ε\nu = H\delta x + \varepsilon ν=Hδx+ε

在 Kalman Filter 中：

S=HP−H⊤+RK=P−H⊤S−1δx^=KνS = HP^-H^\top + R\\ K = P^-H^\top S^{-1}\\ \delta\hat{x} = K\nu S=HP−H⊤+RK=P−H⊤S−1δx^=Kν

如果某个观测存在粗差，则会导致 ∣νi∣|\nu_i|∣νi​∣ 变大，而如果这个时候系统又没有识别出来，就可能导致 ∣δx^∣|\delta\hat{x}|∣δx^∣ 也变大

这就是我们观测质量控制的入口

方法原理

RTK 质量控制大致可以分成两层

  • 第一层：不依赖解算结果的前端检查，例如卫星高度角、载噪比等，这些检查甚至可以在构造双差之前就完成，通常是设置一个阈值，比如 ele≤emin⁡\text{ele}\le e_{\min}ele≤emin​ 或者 C/N0≤Cmin⁡\text{C/N0}\le C_{\min}C/N0≤Cmin​ 时就拒绝使用此观测（Reject）
  • 第二层：基于模型一致性的检查，即检查某个观测虽然表面上存在，但它和当前 RTK 状态模型是否一致，此时就需要新息、眼前残差、验后残差、标准化残差等

核心概念与公式

新息 Innovation

Kalman Filter 中定义：

ν=z−h(x−)\nu = z - h(x^-) ν=z−h(x−)

其中，zzz 为实际观测，x−x^-x− 为先验状态，h(x−)h(x^-)h(x−) 为由先验状态预测得到的观测，ν\nuν 为实际观测与预测观测的差

所以新息本质上反映当前观测和历史状态预测得到观测的差值

其理论协方差为：

S=HP−H⊤+RS = HP^-H^\top + R S=HP−H⊤+R

需要注意的是，Cov(ν)≠R\text{Cov}(\nu)\ne RCov(ν)​=R，因为信息不仅包含观测噪声，还包含先验状态的预测误差

验前残差 Pre-fit residual

在当前语境下，我们通常定义：

r−=z−h(x−)r^- = z - h(x^-) r−=z−h(x−)

也就是说，此时我们认为验前残差在数值上就等于新息

但这两个概念的侧重点不同，新息更强调在 Kalman Filter 中的 z−h(x−)z - h(x^-)z−h(x−)；而验前残差更强调当前观测在状态更新之前，与模型预测之间的偏差

验后残差 Post-fit residual

状态更新以后：

x+=x−+δx^x^+ = x^- + \delta \hat{x} x+=x−+δx^

重新计算观测预测：

h(x+)h(x^+) h(x+)

定义：

r+=z−h(x+)r^+ = z - h(x^+) r+=z−h(x+)

在线性模型下：

h(x+)≈h(x−)+Hδx^h(x^+)\approx h(x^-) + H\delta \hat{x} h(x+)≈h(x−)+Hδx^

代入则有：

r+=z−h(x−)−Hδx^r^+ = z - h(x^-) - H\delta\hat{x} r+=z−h(x−)−Hδx^

又因为有：

ν=z−h(x−)\nu = z - h(x^-) ν=z−h(x−)

因此：

r+=ν−Hδx^=r−−Hδx^r^+ = \nu - H\delta\hat{x} = r^- - H\delta\hat{x} r+=ν−Hδx^=r−−Hδx^

又因为有：

δx^=Kν\delta\hat{x} = K\nu δx^=Kν

代入则有：

r+=(I−HK)νr^+ = (I - HK)\nu r+=(I−HK)ν

从表达式中也可以看出，r+≤ν=r−r^+\le\nu = r^-r+≤ν=r−，因为此时一部分的新息（验前残差）已经在状态更新过程中被吸收了

标准化残差

假设两个观测分别出现 ν1=1m\nu_1 = 1mν1​=1m 和 ν2=1m\nu_2 = 1mν2​=1m，它们代表的异常程度未必相同

因为如果第一个观测本来就很差，理论标准差 σ1=2m\sigma_1 = 2mσ1​=2m，那么 ν1=1m\nu_1 = 1mν1​=1m 相对于这个观测比较正常；而如果第二个观测的理论标准差只有 σ2=0.1m\sigma_2 = 0.1mσ2​=0.1m，那么 ν2=1m\nu_2 = 1mν2​=1m 就很不正常

因此我们不能直接比较 ∣νi∣|\nu_i|∣νi​∣，而是要先除以各自的不确定度

对于信息：

S=HP−H⊤+RS = H P^- H^\top + R S=HP−H⊤+R

第 iii 条观测的新息对应的方差为 SiiS_{ii}Sii​，因此定义标准化残差：

γi=νiSii\gamma_i = \frac{\nu_i}{\sqrt{S_{ii}}} γi​=Sii​​νi​​

通常检测绝对值：

∣γi∣=∣νi∣Sii|\gamma_i| = \frac{|\nu_i|}{\sqrt{S_{ii}}} ∣γi​∣=Sii​​∣νi​∣​

这是一个无量纲的量

Observation Gating

有了标准化新息以后，可以按阈值进行筛选：

∣γi∣>τ|\gamma_i|\gt\tau ∣γi​∣>τ

就表示该观测异常，比如对于 τ=3\tau = 3τ=3，如果 ∣νi∣>3Sii|\nu_i|\gt 3\sqrt{S_{ii}}∣νi​∣>3Sii​​，则进入异常处理（对应观测被降权或直接拒绝使用）

卫星观测质量指标

卫星高度角 Elevation

低高度角的信号通常传播路径很长，且更容易受到建筑物遮挡、地面反射、多路径、对流层误差等的影响，因此通常设置：

ei<emin⇒Rejecte_i\lt e_{\text{min}}\Rightarrow\text{Reject} ei​<emin​⇒Reject

其中，emine_{\text{min}}emin​ 通常设置为 10° 或 15°

这种直接根据高度角阈值做卫星选择的策略称为 Elevation Mask，它直接在卫星层面做了保留 / 剔除的筛选，而没有修改解算权重 RRR

需要和下一讲中的高度角加权方法 ei↓→σi2↑→Ri↑e_i\downarrow\to\sigma_i^2\uparrow\to R_i\uparrowei​↓→σi2​↑→Ri​↑ 做区分

C/N0 和 SNR Mask

C/N0（载噪比）表示载波功率和噪声功率谱密度之比，单位为 dB-Hz，通常 C/N0 降低意味着信号质量可能变差

可以设置：

C/N0<Cmin⁡⇒Reject\text{C/N0}\lt C_{\min}\Rightarrow \text{Reject} C/N0<Cmin​⇒Reject

称为 SNR Mask

需要注意的是，低载噪比大概率对应低质量观测，但高载噪比对应的观测质量未必高，很多强反射信号可能也有不错的 C/N0，因此其不能单独作为判据使用

Lock Time、失锁与相位有效性

载波相位依赖连续跟踪

理论上：

Φk=ρk+λN+⋯\Phi_k = \rho_k + \lambda N + \cdots Φk​=ρk​+λN+⋯

只要能保持连续锁定，则有：

Nk=Nk−1N_k = N_{k-1} Nk​=Nk−1​

但如果发生周跳，则有：

Nk=Nk−1+ΔNN_k = N_{k-1} + \Delta N Nk​=Nk−1​+ΔN

此时的模糊度状态（ambiguity state）已经不再适用于新的载波相位

而 Lock time 则可以帮助判断当前载波连续跟踪了多久，如果 Lock time 突然变小，比如：

Tlock  :  30s→0sT_{\text{lock}}\;:\;30s\to0s Tlock​:30s→0s

则通常意味着发生了失锁、重新捕获（reacquisition）或者周跳风险

Satellite Health

广播星历中通常带有卫星健康状态，如果卫星被标记为 unhealthy，我们可以直接将其从可用卫星集合中剔除
