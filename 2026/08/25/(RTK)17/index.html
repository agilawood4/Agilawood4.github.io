Ratio Text 与 Fix 解生成

本讲主要解决以下两个问题：

  • LAMBDA 找到整数候选以后，怎样判断这个候选是否能被相信
  • 整数模糊度一旦被接收，Float 位置怎样变成 Fix 位置

之前我们已经有浮点位置 r^f\mathbf{\hat r}_fr^f​ 和浮点模糊度 N^f\hat{\mathbf N}_fN^f​，以及浮点状态协方差 Pf=[QrrQrNQNrQNN]P_f = \begin{bmatrix} Q_{rr} & Q_{rN}\\Q_{Nr} & Q_{NN}\\ \end{bmatrix}Pf​=[Qrr​QNr​​QrN​QNN​​]

LAMBDA 已经根据 N^f\hat{\mathbf N}_fN^f​ 和 QNNQ_{NN}QNN​，搜出了若干候选的整数模糊度

LAMBDA 第一候选解不一定为正确整数

LAMBDA 求解的是：

Nˇ1=arg⁡min⁡N∈Zn(N−N^f)⊤QNN−1(N−N^f)\check{\mathbf N}_1 = \arg\min_{\mathbf N\in\mathbb Z^n}(\mathbf N - \hat{\mathbf N}_f)^\top Q_{NN}^{-1}(\mathbf N - \hat{\mathbf N}_f) Nˇ1​=argN∈Znmin​(N−N^f​)⊤QNN−1​(N−N^f​)

定义目标函数：

S(N)=(N−N^f)⊤QNN−1(N−N^f)S(\mathbf N) = (\mathbf N - \hat{\mathbf N}_f)^\top Q_{NN}^{-1}(\mathbf N - \hat{\mathbf N}_f) S(N)=(N−N^f​)⊤QNN−1​(N−N^f​)

LAMBDA 找到最优候选 Nˇ1\check{\mathbf N}_1Nˇ1​，对应：

s1=s(Nˇ1)s_1 = s(\check{\mathbf N}_1) s1​=s(Nˇ1​)

以及次优候选 Nˇ2\check{\mathbf N}_2Nˇ2​，对应：

s2=s(Nˇ2)s_2 = s(\check{\mathbf N}_2) s2​=s(Nˇ2​)

满足：

s1≤s2s_1\le s_2 s1​≤s2​

因为第一候选只能保证：在所有整数向量中，它和当前浮点解模糊度向量（Float Ambiguity）的马氏距离最小，但并没有保证：

Nˇ1=Ntrue\check{\mathbf N}_1 = \mathbf N_{\text{true}} Nˇ1​=Ntrue​

换言之，由于多路径、观测噪声、较差的卫星几何条件等影响，LAMBDA 找到的最优整数解并不一定是物理正确的（一开始测出的浮点解可能就偏了），因此必须进行整数解可靠性验证

第二候选解的重要性

假设 LAMBDA 找到两组解 Nˇ1\check{\mathbf N}_1Nˇ1​ 和 Nˇ2\check{\mathbf N}_2Nˇ2​，分别对应代价为 s1s_1s1​ 和 s2s_2s2​

如果 s1s_1s1​ 和 s2s_2s2​ 非常相近，说明第一候选虽然排名第一，但第二候选几乎同样合理，此时整数搜索空间大致有 Nˇ1=Nˇ2\check{\mathbf N}_1 = \check{\mathbf N}_2Nˇ1​=Nˇ2​，难以区分

此时，我们认为整数解不可靠

而反之，如果 s1s_1s1​ 远小于 s2s_2s2​，即第一候选的马氏距离明显小于第二候选，即 Nˇ1\check{\mathbf N}_1Nˇ1​ 明显优于其它整数候选，此时第一候选更值得相信

Ratio Test

由此，我们定义：

Ratio=s2s1\text{Ratio} = \frac{s_2}{s_1} Ratio=s1​s2​​

因为 s1≥s1s_1\ge s_1s1​≥s1​，所以恒有 Ratio≥1\text{Ratio}\ge 1Ratio≥1 成立

通常采用：

s2s1>γ\frac{s_2}{s_1}\gt \gamma s1​s2​​>γ

作为是否可以把浮点解 Fix 为正数解的判决，其中 γ\gammaγ 是 Ratio Test 的判决阈值

如果满足 Ratio>γ\text{Ratio}\gt\gammaRatio>γ，则接受 Nˇ1\check{\mathbf N}_1Nˇ1​ 作为生猪模糊度候选，否则只能继续保持 Float

RTKLIB 中常见配置的 Ratio 阈值一般为：

γ=3\gamma = 3 γ=3

阈值越高（γ↑\gamma\uparrowγ↑），说明 Fix 条件越严格，False Fix 会减少，但 Fix 率也可能会降低

Ratio Test 判断依据

Ratio Test 不是直接计算：

P(Nˇ1=Ntrue)P(\check{\mathbf N}_1 = \mathbf N_{\text{true}}) P(Nˇ1​=Ntrue​)

而是在衡量第一整数候选相对于第二整数候选有多么突出

根据 sss 的定义：

si=∥Nˇi−N^f∥QNN−12s_i = \|\check{\mathbf N}_i - \hat{\mathbf N}_f\|^2_{Q_{NN}^{-1}} si​=∥Nˇi​−N^f​∥QNN−1​2​

Ratio Test 本质上是在比较最优整数距离和次优整数距离

Float、Fix 与 False Fix

Float 表示模糊度仍然是 N^∈Rn\hat{\mathbf N}\in\mathbb R^nN^∈Rn，此时没有接受任何整数约束

Fix 表示接受 N=Nˇ1∈Zn\mathbf N = \check{\mathbf N}_1\in\mathbb Z^nN=Nˇ1​∈Zn，并把整个整数条件重新作用到状态估计

False Fix 表示尽管当前 Nˇ1≠Ntrue\check{\mathbf N}_1\ne\mathbf N_{\text{true}}Nˇ1​​=Ntrue​，但系统仍然接受了它，这是 RTK 中非常危险的情况

由于整数模糊度误差可能带来极大的定位误差（ΔL=λN\Delta L = \lambda NΔL=λN），因此有时错误的 Fix 往往比 Float 更危险

Ratio Test 通过后对位置的修正

假设我们当前通过了 Ratio Test，此时可以把 N^f\hat{\mathbf N}_fN^f​ 固定为 Nˇ\check{\mathbf N}Nˇ，此时我们的 r^f\hat{\mathbf r}_fr^f​ 也要同步进行修正，因为 r\mathbf rr 和 N\mathbf NN 在 Float 解中是相关的

由于同一条载波双差观测：

νL=Gδr+λδN+εL\nu_L = G\delta\mathbf r + \lambda \delta\mathbf N + \varepsilon_L νL​=Gδr+λδN+εL​

会同时约束 r\mathbf rr 和 N\mathbf NN，所以在求解 Float 解的过程中，二者并不是独立变量，其联合协方差：

Pf=[QrrQrNQNrQNN]P_f = \begin{bmatrix} Q_{rr} & Q_{rN}\\ Q_{Nr} & Q_{NN} \end{bmatrix} Pf​=[Qrr​QNr​​QrN​QNN​​]

通常有 QrN≠0Q_{rN}\ne 0QrN​​=0

Fix 位置公式

当整数模糊度确定为 Nˇ\check{\mathbf N}Nˇ 以后，固定位置为：

r^fix=r^f+QrNQNN−1(Nˇ−N^f)\hat{\mathbf r}_{\text{fix}} = \hat{\mathbf r}_f + Q_{rN}Q_{NN}^{-1}\left(\check{\mathbf N} - \hat{\mathbf N}_f\right) r^fix​=r^f​+QrN​QNN−1​(Nˇ−N^f​)

通常也会等价写成：

r^fix=r^f−QrNQNN−1(N^f−Nˇ)\hat{\mathbf r}_{\text{fix}} = \hat{\mathbf r}_f - Q_{rN}Q_{NN}^{-1}\left( \hat{\mathbf N}_f - \check{\mathbf N} \right) r^fix​=r^f​−QrN​QNN−1​(N^f​−Nˇ)

下面我们给出这个公式的完整推导

Float 状态下误差定义为：

r~=r−r^fN~=N−N^f\tilde{\mathbf r} = \mathbf r - \hat{\mathbf r}_f\\ \tilde{\mathbf N} = \mathbf N - \hat{\mathbf N}_f r~=r−r^f​N~=N−N^f​

其联合分布满足：

[r~N~]∼N(0,[QrrQrNQNrQNN])\begin{bmatrix} \tilde{\mathbf r}\\\tilde{\mathbf N} \end{bmatrix}\sim\mathcal N\left( 0,\begin{bmatrix} Q_{rr} & Q_{rN} \\ Q_{Nr} & Q_{NN} \\ \end{bmatrix} \right) [r~N~​]∼N(0,[Qrr​QNr​​QrN​QNN​​])

在通过 Ratio Test 以后，模糊度固定为 Nˇ\check{\mathbf N}Nˇ，因此模糊度误差不再未知：

N~=Nˇ−N^f\tilde{\mathbf N} = \check{\mathbf N} - \hat{\mathbf N}_f N~=Nˇ−N^f​

那么现在问题变成：已经知道模糊度误差之后，位置误差的最合理估计为多少

由于 r~\tilde{\mathbf r}r~ 和 N~\tilde{\mathbf N}N~ 是相关的，线性最优估计满足：

E[r~∣N~]=QrNQNN−1N~E[\tilde{\mathbf r}\mid\tilde{\mathbf N}]= Q_{rN}Q_{NN}^{-1}\tilde{\mathbf N} E[r~∣N~]=QrN​QNN−1​N~

多源条件期望公式

对于联合高斯分布：

[x1x2]∼N([μ1μ2],[Q11Q12Q21Q22])\begin{bmatrix}x_1\\x_2\\\end{bmatrix} \sim \mathcal N\left( \begin{bmatrix}\mu_1\\\mu_2\\\end{bmatrix},\begin{bmatrix} Q_{11} & Q_{12}\\ Q_{21} & Q_{22}\\ \end{bmatrix} \right) [x1​x2​​]∼N([μ1​μ2​​],[Q11​Q21​​Q12​Q22​​])

条件期望为：

E[x1∣x2=a]=ν1+Q12Q22−1(a−ν2)\mathbb E[\mathbf x_1\mid \mathbf x_2 = \mathbf a] = \nu_1 + Q_{12}Q_{22}^{-1}(\mathbf a - \nu_2) E[x1​∣x2​=a]=ν1​+Q12​Q22−1​(a−ν2​)

条件协方差为：

Cov(x1∣x2=a)=Q11−Q12Q22−1Q21\text{Cov}(\mathbf x_1\mid \mathbf x_2 = \mathbf a) = Q_{11} - Q_{12}Q_{22}^{-1}Q_{21} Cov(x1​∣x2​=a)=Q11​−Q12​Q22−1​Q21​

代入：

N~=Nˇ−N^f\tilde{\mathbf N} = \check{\mathbf N} - \hat{\mathbf N}_f N~=Nˇ−N^f​

则有：

E[r~∣N=Nˇ]=QrNQNN−1(Nˇ−N^f)E[\tilde{\mathbf r}\mid\mathbf N = \check{\mathbf N}] = Q_{rN}Q_{NN}^{-1}(\check{\mathbf N} - \hat{\mathbf N}_f) E[r~∣N=Nˇ]=QrN​QNN−1​(Nˇ−N^f​)

代入：

r=r^f+r~\mathbf r = \hat{\mathbf r}_f + \tilde{\mathbf r} r=r^f​+r~

最终得到 Fix 位置更新公式：

r^fix=r^f+QrNQNN−1(Nˇ−N^f)\hat{\mathbf r}_{\text{fix}} = \hat{\mathbf r}_f + Q_{rN}Q_{NN}^{-1}(\check{\mathbf N} - \hat{\mathbf N}_f) r^fix​=r^f​+QrN​QNN−1​(Nˇ−N^f​)

从公式形式上理解，由于 QrN≠0Q_{rN}\ne0QrN​​=0，原本 Float 解中的模糊度维度的误差会对应一个与之相关的位置误差，我们通过 QrNQNN−1Q_{rN}Q_{NN}^{-1}QrN​QNN−1​ 将这个模糊度修正给映射成位置修正

模糊度固定后精度的提高

如果我们正确固定了模糊度，那么原本载波双差观测中的模糊度自由度就会被消除掉：

∇ΔL−λN=∇Δρ+εL\nabla\Delta L - \lambda N = \nabla\Delta\rho + \varepsilon_L ∇ΔL−λN=∇Δρ+εL​

此时，λN\lambda NλN 已经成为已知量，相当于厘米级高精度载波相位直接用于约束几何位置，因此位置精度会显著提高

Fix 后位置协方差的变化

Float 位置协方差 QrrQ_{rr}Qrr​ 在模糊度固定后，变为位置条件协方差：

Qrrfix=Qrr−QrN−QrNQNN−1QNrQ_{rr}^{\text{fix}} = Q_{rr} - Q_{rN} - Q_{rN}Q_{NN}^{-1}Q_{Nr} Qrrfix​=Qrr​−QrN​−QrN​QNN−1​QNr​

由于减掉一项非负项，所以 Fix 位置的不确定度不会比 Float 更大，在整数固定正确的前提下，位置方差会显著减小
