SADE-DID-2

SADE-DID: Static-Anchored Dynamic-Escalation Detection with Same-Satellite Dual-Frequency Difference-in-Differences Confirmation

基于静态锚定动态升级与同星双频差分确认的 GNSS 干扰检测方法

方法定位：在本文中，我们提出 SADE-DID，一种面向运动鲁棒 GNSS 干扰检测的静态锚定动态升级框架，通过非对称专家机制保留稳定攻击证据，并利用双星同频 Difference-in-Differences 实现物理确认

C. Same-Satellite Dual-Frequency Difference-in-Differences Confirmation

B 小节解决了由于运动状态造成的统计分布变化，但 Primary branch 本质上仍属于数据驱动检测器，即使加入 Kinematic Expert，快速运动、遮挡、多路径等突变仍可能产生疑似攻击的统计异常

因此我们换一个思路，引入一条新的证据链，不再继续增加模型复杂度，而是检查 GNSS 原始的双频观测是否出现物理上的频间和时间不一致

当前 Confirm 分支使用的是 Septentrio RINEX 3.04 中的 Code C∗C^*C∗ 和 Doppler D∗D^*D∗，通过同一卫星的 L1 / L5 配对形成 DID

同一颗卫星的 L1 / L5

假设卫星 kkk 在时刻 ttt 的两个频段观测分别为：

zk,tL1zk,tL5z_{k,t}^{L1}\quad z_{k,t}^{L5} zk,tL1​zk,tL5​

这里 zzz 可以代表：

  1. Doppler 转换得到的 range-rate（距离变化率）
  2. Code / Pseudorange（测距码 / 伪距）

如果直接比较：

mediank(zk,tL1)−medianj(zj,tL5)\text{median}_k(z_{k,t}^{L1}) - \text{median}_j(z_{j,t}^{L5}) mediank​(zk,tL1​)−medianj​(zj,tL5​)

那么两边很可能来自不同卫星集合，此时差值中会混入：

ρk,t−ρj,t\rho_{k,t} - \rho_{j,t} ρk,t​−ρj,t​

也就是不同卫星本身的几何距离差异

因此它无法单纯表示频段不一致，我们的算法首先要求：

kL1=kL5k_{L1} = k_{L5} kL1​=kL5​

即 L1 和 L5 必须来自同一颗卫星、同一 epoch，实际实现中的匹配键是：

(epoch, satellite, band)(\text{epoch, satellite, band}) (epoch, satellite, band)

其中 satellite\text{satellite}satellite 字段本身已经包含 constellation 和 PRN，同一频段存在多个 observation code 时取其中位数表示

因此，后续所有频间差都是同一卫星、同一 epoch 的不同频段（same satellite + same epoch + different frequency），这是本节的一个关键条件

Doppler 观测到 Range Rate

GNSS Doppler 本质上反映载波接收频率相对于理论频率的变化

设载波频率为：

FfF_f Ff​

波长为：

λf=cFf\lambda_f = \frac{c}{F_f} λf​=Ff​c​

RINNEX Doppler 观测为：

Dk,tfD_{k,t}^f Dk,tf​

我们使用：

vk,tf=−Dk,tfcFfv_{k,t}^f = -D_{k,t}^f\frac{c}{F_f} vk,tf​=−Dk,tf​Ff​c​

来进行单位统一

因为 Doppler 的单位为 cycle/s\text{cycle/s}cycle/s，λf\lambda_fλf​ 的单位为 m/cycle\text{m/cycle}m/cycle，因此 λfDf\lambda_f D_fλf​Df​ 的量纲为 m/s\text{m/s}m/s

所以 vk,tfv_{k,t}^fvk,tf​ 变成了一个 range-rate 型物理量（描述距离变化率）

由于 L1 和 L5 的原始 Doppler 以不同载波频率计量，不能简单做 DL1−DL5D^{L1} - D^{L5}DL1−DL5，必须先利用 λ=cf\lambda = \frac{c}{f}λ=fc​ 统一到相同的 m/s\text{m/s}m/s 量纲

Doppler 观测中的公共项

为了理解双频差的有效性，我们把某一频段的 range-rate 型量建模为：

vk,tf=ρ˙k,t+cδ˙tr,t−cδ˙tk,ts+bk,tf+ϵk,tfv_{k,t}^f = \dot{\rho}_{k,t} + c\dot{\delta}t_{r,t} - c\dot{\delta}t_{k,t}^s + b_{k,t}^f + \epsilon_{k,t}^f vk,tf​=ρ˙​k,t​+cδ˙tr,t​−cδ˙tk,ts​+bk,tf​+ϵk,tf​

其中，ρ˙k,t\dot{\rho}_{k,t}ρ˙​k,t​ 表示接收机与卫星 kkk 之间的几何距离变化率，δ˙tr,t\dot{\delta} t_{r,t}δ˙tr,t​ 表示接收机钟漂，δ˙tk,ts\dot{\delta} t_{k,t}^sδ˙tk,ts​ 表示卫星钟漂，bk,tfb_{k,t}^fbk,tf​ 表示频段相关偏差以及未建模项，ϵk,tf\epsilon_{k,t}^fϵk,tf​ 表示测量噪声

对于同一颗卫星、同一个 epoch：

vk,tL1=ρ˙k,t+cδ˙tr,t−cδ˙tk,ts+bk,tL1+ϵk,tL1vk,tL5=ρ˙k,t+cδ˙tr,t−cδ˙tk,ts+bk,tL5+ϵk,tL5v_{k,t}^{L1} = \dot{\rho}_{k,t} + c\dot{\delta}t_{r,t} - c\dot{\delta}t_{k,t}^s + b_{k,t}^{L1} + \epsilon_{k,t}^{L1}\\ v_{k,t}^{L5} = \dot{\rho}_{k,t} + c\dot{\delta}t_{r,t} - c\dot{\delta}t_{k,t}^s + b_{k,t}^{L5} + \epsilon_{k,t}^{L5} vk,tL1​=ρ˙​k,t​+cδ˙tr,t​−cδ˙tk,ts​+bk,tL1​+ϵk,tL1​vk,tL5​=ρ˙​k,t​+cδ˙tr,t​−cδ˙tk,ts​+bk,tL5​+ϵk,tL5​

注意前三项，ρ˙k,t,  cδ˙tr,t,  cδ˙tk,ts\dot{\rho}_{k,t},\;c\dot{\delta}t_{r,t},\;c\dot{\delta}t_{k,t}^sρ˙​k,t​,cδ˙tr,t​,cδ˙tk,ts​ 对于同星双频而言具有很强的公共性

第一层差分：Same-Satellite Inter-Frequency Difference

定义 Doppler 频间差：

Dk,tv=vk,tL1−vk,tL5D_{k,t}^v = v_{k,t}^{L1} - v_{k,t}^{L5} Dk,tv​=vk,tL1​−vk,tL5​

代入上一节 vk,tv_{k,t}vk,t​ 表达式展开则有：

Dk,tv=[ρ˙k,t+cδ˙tr,t−cδ˙tk,ts+bk,tL1+ϵk,tL1]−[ρ˙k,t+cδ˙tr,t−cδ˙tk,ts+bk,tL5+ϵk,tL5]D_{k,t}^v = \left[ \dot{\rho}_{k,t} + c\dot{\delta}t_{r,t} - c\dot{\delta}t_{k,t}^s + b_{k,t}^{L1} + \epsilon_{k,t}^{L1} \right] - \left[ \dot{\rho}_{k,t} + c\dot{\delta}t_{r,t} - c\dot{\delta}t_{k,t}^s + b_{k,t}^{L5} + \epsilon_{k,t}^{L5} \right] Dk,tv​=[ρ˙​k,t​+cδ˙tr,t​−cδ˙tk,ts​+bk,tL1​+ϵk,tL1​]−[ρ˙​k,t​+cδ˙tr,t​−cδ˙tk,ts​+bk,tL5​+ϵk,tL5​]

公共项抵消后：

Dk,tv=bk,tL1−bk,tL5+ϵk,tL1−ϵk,tL5D_{k,t}^v = b_{k,t}^{L1} - b_{k,t}^{L5} + \epsilon_{k,t}^{L1} - \epsilon_{k,t}^{L5} Dk,tv​=bk,tL1​−bk,tL5​+ϵk,tL1​−ϵk,tL5​

理想情况下，ρ˙k,t\dot{\rho}_{k,t}ρ˙​k,t​ 项消失，这是我们差分的第一个理论收益：接收机运动造成的主要几何 range-rate 项，在频间差中成为公共模态并被削弱 / 抵消

但是第一层差分还不够，因为此时 Dk,tvD_{k,t}^vDk,tv​ 的表达式中还存在：

Bk=bkL1−bkL5B_k = b_k^{L1} - b_k^{L5} Bk​=bkL1​−bkL5​

其中，BkB_kBk​ 可能来源于频段相关硬件偏置、观测码差异、频率相关传播项、接收机内部处理差异等，因此我们还需要第二层差分

第二层差分：Difference-in-Differences

对 Dk,tvD_{k,t}^vDk,tv​ 继续进行时间差分：

Dk,tv−Dk,t−1vD_{k,t}^v - D_{k,t-1}^v Dk,tv​−Dk,t−1v​

实际实现中我们会在外层取绝对值：

DIDk,tv=∣Dk,tv−Dk,t−1v∣DID_{k,t}^v = |D_{k,t}^v - D_{k,t-1}^v| DIDk,tv​=∣Dk,tv​−Dk,t−1v​∣

之所以取绝对值，是因为我们主要关心变化幅度，而不是变化方向，如果后续做窗口聚合，取绝对值可以防止窗口间正负相互抵消

展开则有：

DIDk,tv=∣(vk,tL1−vk,tL5)−(vk,t−1L1−vk,t−1L5)∣DID_{k,t}^v = |(v_{k,t}^{L1} - v_{k,t}^{L5}) - (v_{k,t-1}^{L1} - v_{k,t-1}^{L5})| DIDk,tv​=∣(vk,tL1​−vk,tL5​)−(vk,t−1L1​−vk,t−1L5​)∣

这就是所谓的 Difference-in-Differences，第一次差分我们用 L1 和 L5 频段作差，第二次差分我们在相邻时刻之间作差

我们假设：

Dk,t=Bk+ηk,tDk,t−1=Bk+ηk,t−1D_{k,t} = B_k + \eta_{k,t}\\ D_{k,t-1} = B_k + \eta_{k,t-1} Dk,t​=Bk​+ηk,t​Dk,t−1​=Bk​+ηk,t−1​

其中，BkB_kBk​ 在短时间内近似稳定

那么第二次作差：

Dk,tv−Dk,t−1v=(Bk+ηk,t)−(Bk+ηk,t−1)=ηk,t−ηk,t−1D_{k,t}^v - D_{k,t-1}^v = (B_k + \eta_{k,t}) - (B_k + \eta_{k,t-1}) = \eta_{k,t} - \eta_{k,t-1} Dk,tv​−Dk,t−1v​=(Bk​+ηk,t​)−(Bk​+ηk,t−1​)=ηk,t​−ηk,t−1​

因此，第二次作差会把 BkB_kBk​ 项消除

两级差分分别承担了不同的任务：

  1. 第一层：频率差分，主要消除同星公共项，例如几何运动和共同钟项
  2. 第二层：时间差分，进一步削弱短时间稳定的频间偏置

最终留下 inter-frequency temporal inconsistency，即 L1 和 L5 相对关系在连续两个时刻之间发生了多大的变化，这是 DID 真正检测的对象

Code / Pseudorange DID

第二条证据来自 Code，我们设：

Pk,tL1,Pk,tL5P_{k,t}^{L1},\quad P_{k,t}^{L5} Pk,tL1​,Pk,tL5​

为同一卫星两个频段的 code / pseudorange 观测（测距码本质也是为了求出伪距，因此这里可以理解成就是伪距观测）

首先做频间伪距差：

Dk,tP=Pk,tL1−Pk,tL5D_{k,t}^P = P_{k,t}^{L1} - P_{k,t}^{L5} Dk,tP​=Pk,tL1​−Pk,tL5​

随后除以 Δt\Delta tΔt：

DIDk,tP=∣Dk,tP−Dk,t−1P∣ΔtDID_{k,t}^P = \frac{|D_{k,t}^P - D_{k,t-1}^P|}{\Delta t} DIDk,tP​=Δt∣Dk,tP​−Dk,t−1P​∣​

这里与 Doppler DID 有一个关键差别在于：伪距相关的 Code DID 会除以 Δt\Delta tΔt，而多普勒的 DID 则没有

从伪距观测方程理解 Code DID

双频伪距观测可以统一建模成：

Pk,tf=ρk,t+c(δtr,t−δtk,ts)+Tk,t+Ik,tf+bkf+ϵk,tfP_{k,t}^f = \rho_{k,t} + c(\delta t_{r,t} - \delta t^s_{k,t}) + T_{k,t} + I^f_{k,t} + b_k^f + \epsilon_{k,t}^f Pk,tf​=ρk,t​+c(δtr,t​−δtk,ts​)+Tk,t​+Ik,tf​+bkf​+ϵk,tf​

其中，ρ\rhoρ 表示卫星 - 接收机几何距离，c(δtr−δts)c(\delta t_r - \delta t_s)c(δtr​−δts​) 表示钟差，TTT 表示对流层误差，IfI^fIf 表示电离层误差，bfb^fbf 表示码硬件等频率相关偏差，ϵf\epsilon^fϵf 表示测量噪声

做同星频间差：

Dk,tP=Pk,tL1−Pk,tL5D_{k,t}^P = P_{k,t}^{L1} - P_{k,t}^{L5} Dk,tP​=Pk,tL1​−Pk,tL5​

代入伪距公式展开则有：

Dk,tP=(ρ−ρ)+c(δtr−δts)−c(δtr−δts)+(T−T)+(IL1−IL5)+(bL1−bL5)+(ϵL1−ϵL5)D_{k,t}^P = (\rho - \rho) + c(\delta t_r - \delta t_s) - c(\delta t_r - \delta t_s) + (T - T) + (I^{L1} - I^{L5}) + (b^{L1} - b^{L5}) + (\epsilon^{L1} - \epsilon^{L5}) Dk,tP​=(ρ−ρ)+c(δtr​−δts​)−c(δtr​−δts​)+(T−T)+(IL1−IL5)+(bL1−bL5)+(ϵL1−ϵL5)

化简得到：

Dk,tP=Ik,tL1−Ik,tL5+bkL1−bkL5+ϵk,tL1−ϵk,tL5D_{k,t}^{P} = I_{k,t}^{L1} - I_{k,t}^{L5} + b_k^{L1} - b_k^{L5} + \epsilon_{k,t}^{L1} - \epsilon_{k,t}^{L5} Dk,tP​=Ik,tL1​−Ik,tL5​+bkL1​−bkL5​+ϵk,tL1​−ϵk,tL5​

即通过作差，ρ,  δt,  T\rho,\;\delta t,\;Tρ,δt,T 这些同星同 epoch 的公共项被理论上消去

因此，即便接收机发生运动导致 ρk,t\rho_{k,t}ρk,t​ 快速改变，它仍然同时存在于 L1 和 L5 频段中，这就是 Same-Satellite Difference 对动态检测有效的物理原因

进一步做时间差分

设：

Bk,tP=Ik,tL1−Ik,tL5+bkL1−bkL5B_{k,t}^P = I_{k,t}^{L1} - I_{k,t}^{L5} + b_k^{L1} - b_k^{L5} Bk,tP​=Ik,tL1​−Ik,tL5​+bkL1​−bkL5​

那么：

Dk,tP=Bk,tP+ϵk,tPD_{k,t}^P = B_{k,t}^P + \epsilon_{k,t}^P Dk,tP​=Bk,tP​+ϵk,tP​

如果在 1-2 秒的短时间尺度上：

Bk,tP≈Bk,t−1PB_{k,t}^P\approx B_{k,t-1}^P Bk,tP​≈Bk,t−1P​

则：

Dk,tP−Dk,t−1P≈ϵk,tP−ϵk,t−1P+ΔBk,tPD_{k,t}^P - D_{k,t-1}^P\approx \epsilon_{k,t}^P - \epsilon_{k,t-1}^P + \Delta B_{k,t}^P Dk,tP​−Dk,t−1P​≈ϵk,tP​−ϵk,t−1P​+ΔBk,tP​

稳定偏置 BBB 进一步被削弱，再除以 Δt\Delta tΔt 则得到：

DIDk,tP=∣ΔDk,tP∣ΔtDID_{k,t}^P = \frac{|\Delta D_{k,t}^P|}{\Delta t} DIDk,tP​=Δt∣ΔDk,tP​∣​

这里除以 Δt\Delta tΔt 的目的主要是为了统一量纲为 m/s\text{m/s}m/s，这样 Code DID 和 Doppler DID 最终才能都进入相近的 range-rate 型尺度

DID 核心抑制链

Code DID 和 Doppler DID 可以用以下的符号统一表示和推导

原始的双频观测都可以被抽象为：

zk,tf=Ck,t+Bk,tf+Ak,tf+ϵk,tfz_{k,t}^f = C_{k,t} + B_{k,t}^f + A_{k,t}^f + \epsilon_{k,t}^f zk,tf​=Ck,t​+Bk,tf​+Ak,tf​+ϵk,tf​

其中，Ck,tC_{k,t}Ck,t​ 为 L1 / L5 共同项，Bk,tfB_{k,t}^fBk,tf​ 为和频率相关但短时间内较稳定的项，Ak,tfA_{k,t}^fAk,tf​ 为我们关注的频间异常变化，ϵ\epsilonϵ 为噪声

先做同星频间差：

Dk,t=zk,tL1−zk,tL5D_{k,t} = z_{k,t}^{L1} - z_{k,t}^{L5} Dk,t​=zk,tL1​−zk,tL5​

得到：

Dk,t=(Bk,tL1−Bk,tL5)+(Ak,tL1−Ak,tL5)+ΔϵD_{k,t} = (B_{k,t}^{L1} - B_{k,t}^{L5}) + (A_{k,t}^{L1} - A_{k,t}^{L5}) + \Delta \epsilon Dk,t​=(Bk,tL1​−Bk,tL5​)+(Ak,tL1​−Ak,tL5​)+Δϵ

即第一层 common-mode suppression

接着做时间差：

Dk,t−Dk,t−1D_{k,t} - D_{k,t-1} Dk,t​−Dk,t−1​

如果：

Bk,tL1−Bk,tL5≈Bk,t−1L1−Bk,t−1L5B_{k,t}^{L1} - B_{k,t}^{L5}\approx B_{k,t-1}^{L1} - B_{k,t-1}^{L5} Bk,tL1​−Bk,tL5​≈Bk,t−1L1​−Bk,t−1L5​

则 quasi-static inter-frequency bias suppression

最终保留下来的仅有：

Δ(AL1−AL5)\Delta(A^{L1} - A^{L5}) Δ(AL1−AL5)

以及噪声 Δϵ\Delta\epsilonΔϵ

因此 DID 的核心思想可以概括为：检测 L1 / L5 的相对关系是否出现异常的时间变化

DID 对动态场景的意义

在运动状态下，接收机运动可能造成 ρk,t\rho_{k,t}ρk,t​ 快速变化，因此 Pk,t,  Dk,t,  C/N0,  satellite visibilityP_{k,t},\;D_{k,t},\;\text{C/N0},\;\text{satellite visibility}Pk,t​,Dk,t​,C/N0,satellite visibility 都可能出现显著变化

传统 detector 看到的可能某些特征随时间剧烈波动，但无法确定其来自于运动本身，还是因为受到攻击

Same-Satellite Dual-Frequency Difference 首先利用 L1−L5L1-L5L1−L5 把大量同时作用于 L1 / L5 的同星几何运动项变成公共模态，使得绝对运动（absolute motion）和频间不一致（inter-frequency inconsistency）部分解耦

因此，DID 不是简单添加几个额外的统计特征，而是直接针对动态检测中的核心混淆，单独增加了一条判断支线

多星 DID 聚合

先前我们推导的 DID，还仅是在单颗卫星上定义，即 DIDk,tDID_{k,t}DIDk,t​ 表示卫星 kkk 在时刻 ttt 的双差

单颗卫星容易受到多路径、观测噪声、低高度角等因素的影响，因此不能直接把某一颗卫星的 DID 当做最终证据

设时刻 ttt 的有效同星双频卫星集合为 Kt\mathcal K_tKt​，我们需要对每颗卫星都计算 DID，然后在同一 epoch 内跨卫星聚合

Epoch-Level Robust Aggregation

定义 Doppler DID median：

mtD,v=mediank∈KtDIDk,tvm_t^{D,v} = \text{median}_{k\in\mathcal K_t} DID_{k,t}^v mtD,v​=mediank∈Kt​​DIDk,tv​

以及 q75：
