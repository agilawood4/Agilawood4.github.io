SADE-DID-1

SADE-DID: Static-Anchored Dynamic-Escalation Detection with Same-Satellite Dual-Frequency Difference-in-Differences Confirmation

基于静态锚定动态升级与同星双频差分确认的 GNSS 干扰检测方法

方法定位：在本文中，我们提出 SADE-DID，一种面向运动鲁棒 GNSS 干扰检测的静态锚定动态升级框架，通过非对称专家机制保留稳定攻击证据，并利用双星同频 Difference-in-Differences 实现物理确认

A. Problem Formulation and Robust Window Representation

问题背景

我们首先不讨论具体的分类器，而是先把问题建模为一个严格的统计检测问题

设实验由若干个独立的 session 构成，用集合 sss 表示：

s∈{1,…,S}s\in\{1,\dots,\mathcal{S}\} s∈{1,…,S}

对于每个 session，都存在一个运动状态变量：

Ms∈{0,1}M_s\in\{0,1\} Ms​∈{0,1}

其中，我们规定：

Ms={0,static1,kinematicM_s = \begin{cases}0,\quad \text{static}\\1,\quad\text{kinematic}\end{cases} Ms​={0,static1,kinematic​

需要说明的是，当前实现中的 Static / Kinematic 是 Session 级别的标签，并不是根据某个窗口的瞬时速度重新定义的，换言之，及时一个动态 session 中的某一小段速度暂时接近 0，该窗口的运动状态标签仍然属于 kinematic

同时，我们定义攻击状态：

Ys,t∈{0,1}Y_{s,t}\in\{0,1\} Ys,t​∈{0,1}

其中，我们规定：

Ys,t={0,normal1,spoofedY_{s,t} = \begin{cases} 0,\quad\text{normal}\\1,\quad\text{spoofed} \end{cases} Ys,t​={0,normal1,spoofed​

在后续实验中，我们约定正类为 Spoofing

本算法设计的理论起点在于，静态和动态不能简单看做完全相同的分类分布

设一个时间窗口经过特征提取后表示为随机向量：

X∈Rp\mathbf X\in\mathbb{R}^p X∈Rp

如果动态和静态环境完全一致，则正常情况下应该有：

p(X∣Y=0,M=0)≈p(X∣Y=0,M=1)p(\mathbf X\mid Y=0,M=0)\approx p(\mathbf X\mid Y=0,M=1) p(X∣Y=0,M=0)≈p(X∣Y=0,M=1)

即静态和动态环境对于引起 X\mathbf XX 的先验概率应该近似相等

这样我们就可以完全忽略运动先验 MMM，训练一个统一的分类器：

P(Y=1∣X)P(Y=1\mid \mathbf X) P(Y=1∣X)

但 GNSS 动态场景显然不满足这一假设，即使 Y=0Y=0Y=0，即完全没有攻击时，接收机本身的运动仍会造成 C/N0 改变、卫星可见集合改变、Doppler 改变、Pseudorange-Rate 改变等因素，因此实际上有：

p(X∣Y=0,M=0)≠p(X∣Y=0,M=1)p(\mathbf X\mid Y=0,M=0)\ne p(\mathbf X\mid Y=0,M=1) p(X∣Y=0,M=0)​=p(X∣Y=0,M=1)

这是一个典型的由运动造成的分布偏移模型（motion-induced distribution shift），这一矛盾也是本文方法最核心的研究出发点

进一步看贝叶斯后验：

P(Y=1∣X)=∑m∈{0,1}P(Y=1∣X,M=m)P(M=m∣X)P(Y=1\mid \mathbf X) = \sum_{m\in\{0,1\}} P(Y=1\mid \mathbf X,M=m)P(M=m\mid\mathbf X) P(Y=1∣X)=m∈{0,1}∑​P(Y=1∣X,M=m)P(M=m∣X)

这说明如果我们做一个完全忽略运动状态的统一分类器，本质上是在同时逼近：

P(Y=1∣X,M=0)andP(Y=1∣X,M=1)P(Y=1\mid\mathbf X,M=0)\quad \text{and} \quad P(Y=1\mid \mathbf X,M=1) P(Y=1∣X,M=0)andP(Y=1∣X,M=1)

如果这两个条件分布差异很大，那么一个单独的决策边界必然需要在动态环境和静态环境之间取折中，最后的结果要么是一种拟合很好一种拟合很差，要么是两种拟合效果都很一般

因此我们不能简单去做：

f(X)→Yf(\mathbf X)\to Y f(X)→Y

这样一个分类，而是需要再保留统一检测能力的同时显示处理由于 MMM 运动标签造成的条件分布差异，这也是我们引入 Anchor 和 Kinematic Expert 的原因

B. Static-Anchored Dynamic-Escalation Expert Model

实际动态过程中，运动本身会改变 GNSS observables，因此通常存在：

P(Y=1∣X,M=0)≠P(Y=1∣X,M=1)P(Y=1\mid \mathbf X,M=0)\ne P(Y=1\mid\mathbf X,M=1) P(Y=1∣X,M=0)​=P(Y=1∣X,M=1)

如果使用一个统一的分类器 fUf_UfU​，则需要用同一个决策边界，同时处理两个条件域，即 fUf_UfU​ 必须在静态判别能力和动态判别能力之间进行折中

因此，更自然的建模方式是引入两个条件专家：

SA(t)=fA(Xt)SD(t)=fD(Xt)S_A(t) = f_A(\mathbf X_t)\\ S_D(t) = f_D(\mathbf X_t) SA​(t)=fA​(Xt​)SD​(t)=fD​(Xt​)

这两个专家之间该怎么路由和融合，正是本文最核心的创新点

Anchor Expert：稳定攻击证据锚点

我们定义 Anchor Expert：

SA(t)=fA(Xt)S_A(t) = f_A(\mathbf X_t) SA​(t)=fA​(Xt​)

其中，SA(t)∈[0,1]S_A(t)\in[0,1]SA​(t)∈[0,1] 表示当前窗口包含攻击的概率分数

需要说明的是，当前 Anchor 并不是一个只用静态数据训练的 static classifier，实际训练时，它使用：

DA=Dstatic∪Dkinematic\mathcal D_A = \mathcal D_{\text{static}} ∪ \mathcal D_{\text{kinematic}} DA​=Dstatic​∪Dkinematic​

也就是外层训练集合中全部静态和动态 session，但模型选择阶段主要通过其在静态数据上的表现，来评价其稳定性，即用较广的数据域学习普遍攻击规律，但把静态环境中的稳定判别能力作为重要选择标准（global attack detector with static-oriented model selection）

Anchor 需要覆盖动态数据

假设真正的攻击特征可以抽象为：

X=Xattack+Xenvironment\mathbf X = \mathbf X_{\text{attack}} + \mathbf {X}_{\text{environment}} X=Xattack​+Xenvironment​

静态情况下：

X(s)=Xattack+Xstatic\mathbf X^{(s)} = \mathbf X_{\text{attack}} + \mathbf {X}_{\text{static}} X(s)=Xattack​+Xstatic​

动态情况下：

X(k)=Xattack+Xmotion\mathbf X^{(k)} = \mathbf X_{\text{attack}} + \mathbf X_{\text{motion}} X(k)=Xattack​+Xmotion​

如果 Anchor 仅学习静态数据：

fA:Dstatic→Yf_A:\mathcal D_{\text{static}}\to Y fA​:Dstatic​→Y

那么它可能错误地把 Xstatic\mathbf X_{\text{static}}Xstatic​ 本身的一些偶然规律当成攻击判据

加入动态训练样本后，相当于迫使模型寻找 static 和 kinematic 样本中都相对稳定存在的攻击证据，而不是仅记住静态环境特征

因此 Anchor 的职责并不是追求某一个运动域的最优性能，而是构造一组鲁棒性的底层攻击证据（robust lower-level attack evidence），也就是整个系统最基本的的 “锚点”

Kinematic Expert：条件攻击专家

第二个专家定义为：

SK(t)=fK(Xt)S_K(t) = f_K(\mathbf X_t) SK​(t)=fK​(Xt​)

其目标大致为：

SK(t)≈P(Yt=1∣Xt,Mt=1)S_K(t)\approx P(Y_t=1\mid \mathbf X_t,M_t=1) SK​(t)≈P(Yt​=1∣Xt​,Mt​=1)

与 Anchor 不同，Kinematic Expert 的训练集严格限制在动态 session，这样做的意义在于，Kinematic Expert 不需要同时满足 P(Y∣X,M=0)P(Y\mid \mathbf X,M=0)P(Y∣X,M=0) 的判别需求

因此它可以把有限模型容量全部用于识别动态环境中的 attack-motion ambiguity，换言之，它的主要职责不是代替 Anchor，而是寻找 Anchor 在动态条件下遗漏的攻击证据

传统 Hard Routing 的缺陷

有了两个专家，最朴素的专家系统可以设计为：

SH(t)={SA(t),Rt=0SK(t),Rt=1S_H(t) = \begin{cases} S_A(t),\quad R_t = 0\\ S_K(t),\quad R_t = 1 \end{cases} SH​(t)={SA​(t),Rt​=0SK​(t),Rt​=1​

或者写成：

SH(t)=(1−Rt)SA(t)+RtSK(t)S_H(t) = (1 - R_t)S_A(t) + R_t S_K(t) SH​(t)=(1−Rt​)SA​(t)+Rt​SK​(t)

其中，Rt∈{0,1}R_t\in\{0,1\}Rt​∈{0,1} 是运动 Router

理想 Router 情况

如果 Rt=MtR_t = M_tRt​=Mt​ 始终成立，则：

Mt=0⇒SH=SAMt=1⇒SH=SKM_t = 0\Rightarrow S_H = S_A\\M_t = 1\Rightarrow S_H = S_K Mt​=0⇒SH​=SA​Mt​=1⇒SH​=SK​

就是标准的硬混合专家模型（hard mixture-of-experts），问题在于真实的 Router 不可能完全正确

Hard Routing 错误传播

设攻击判定阈值为：

τ\tau τ

假设有一个真实攻击窗口：

Yt=1Y_t = 1 Yt​=1

假设 Anchor 正确发现攻击：

SA(t)≥τS_A(t)\ge\tau SA​(t)≥τ

但 Kinematic Expert 没有发现：

SK(t)<τS_K(t)\lt \tau SK​(t)<τ

如果 Router 输出：

Rt=1R_t = 1 Rt​=1

Hard Routing 会得到：

SH(t)=SK(t)<τS_H(t) = S_K(t)\lt \tau SH​(t)=SK​(t)<τ

于是系统会给出标签：

Y^H(t)=0\hat{Y}_H(t) = 0 Y^H​(t)=0

也就是说，路由选择错误会导致覆盖原有正确的攻击证据（Router error can overwrite correct attack evidence），这并非分类器性能问题，而是融合结构本身的问题

Router Error 一般形式

定义二值专家决策：

At=1[SA(t)≥τA]Kt=1[SK(t)≥τK]A_t = \mathbf 1[S_A(t)\ge\tau_A]\\ K_t = \mathbf 1[S_K(t)\ge\tau_K] At​=1[SA​(t)≥τA​]Kt​=1[SK​(t)≥τK​]

Hard Routing 可以写为：

Ht=(1−Rt)At+RtKtH_t = (1 - R_t)A_t + R_t K_t Ht​=(1−Rt​)At​+Rt​Kt​

当 At−1,Kt=0A_t-1,K_t=0At​−1,Kt​=0 时，有：

Ht=1−RtH_t = 1 - R_t Ht​=1−Rt​

因此只要 Rt=1R_t=1Rt​=1，则会导致 Ht=0H_t=0Ht​=0，此时我们发现：

At=1⇏Ht=1A_t = 1\nRightarrow H_t=1 At​=1⇏Ht​=1

即 Anchor Expert 发现的攻击证据被 Hard Router 取消，换言之，此时的 Hard Router 具有否决权（veto power），我们的实现需要避免这一情况出现

因果运动 Router

我们定义 motion level，用于将设备当前的物理速度转换为一个标准化的运动强度指标：

mtraw=clip(vt5,0,1)m_t^{\text{raw}} = \text{clip}(\frac{v_t}{5}, 0, 1) mtraw​=clip(5vt​​,0,1)

其中，vtv_tvt​ 为安卓定位修复速度，即 Android Location Fix SpeedMps，截断函数 clip 用于将函数值限定在 [0,1][0,1][0,1] 区间内，因此 mtraw∈[0,1]m_t^{\text{raw}}\in[0,1]mtraw​∈[0,1]

Router 最终候选窗口特征来自于：

motion-levelmedianmotion-levelq90\text{motion-level}_{\text{median}}\\ \text{motion-level}_{\text{q90}} motion-levelmedian​motion-levelq90​

因此我们统一记 Router 使用的运动统计量为：

mtm_t mt​

瞬时运动证据

首先使用阈值：

τm\tau_m τm​

把连续运动特征转换成二值运动证据：

et=1[mt≥τm]e_t = \mathbf 1[m_t\ge \tau_m] et​=1[mt​≥τm​]

其中，et=0e_t = 0et​=0 表示当前窗口没有足够的动态证据，et=1e_t = 1et​=1 表示当前窗口出现动态特征

但我们还是不能直接令 Rt=etR_t = e_tRt​=et​，因为单个窗口中的速度可能因为 PVT 抖动、短暂停留、单次位置异常、运动速度暂时下降等因素发生跳变，这样 Router 会出现 0,1,0,1,0,…0,1,0,1,0,\dots0,1,0,1,0,… 这样的剧烈状态切换

因此我们还需要时间平滑

Casual EWMA Motion State Estimation

我们定义：

qt=αet+(1−α)qt−1q_t = \alpha e_t + (1-\alpha)q_{t-1} qt​=αet​+(1−α)qt−1​

其中，0<α<10\lt\alpha\lt10<α<1，初始的 q0=0.5q_0 = 0.5q0​=0.5

最终运动状态为：

Et=1[qt≥τR]E_t = \mathbf 1[q_t\ge\tau_R] Et​=1[qt​≥τR​]

实际实现中，α\alphaα 和 τR\tau_RτR​ 都从预定义网格中在训练 session 内选择

EWMA 完整展开

原递推形式为：

qt=αet+(1−α)qt−1q_t = \alpha e_t + (1-\alpha)q_{t-1} qt​=αet​+(1−α)qt−1​

再把 qt−1q_{t-1}qt−1​ 展开：

qt−1=αet−1+(1−α)qt−2q_{t-1} = \alpha e_{t-1} + (1-\alpha)q_{t-2} qt−1​=αet−1​+(1−α)qt−2​

代入 qtq_tqt​ 递推式有：

qt=αet+α(1−α)et−1+(1−α)2qt−2q_t = \alpha e_t + \alpha(1-\alpha)e_{t-1} + (1-\alpha)^2 q_{t-2} qt​=αet​+α(1−α)et−1​+(1−α)2qt−2​

继续递推，最终可得到：

qt=(1−α)tq0+α∑i=1t(1−α)t−ieiq_t = (1-\alpha)^t q_0 + \alpha\sum_{i=1}^t (1-\alpha)^{t-i}e_i qt​=(1−α)tq0​+αi=1∑t​(1−α)t−iei​

这个公式非常重要，它说明 qtq_tqt​ 实际上是过去运动证据的指数加权和，对于当前时刻 ttt，过去第 iii 个运动证据的权重为：

wt,i=α(1−α)t−iw_{t,i} = \alpha(1-\alpha)^{t-i} wt,i​=α(1−α)t−i

随着 iii 越靠前，t−it-it−i 逐渐增大，则 wt,iw_{t,i}wt,i​ 呈现指数衰减，因此最近邻的运动证据会得到最大的权重，而旧的运动状态会被逐渐遗忘

Router 的因果性

根据 qtq_tqt​ 最终的通项公式：

qt=(1−α)tq0+α∑i=1t(1−α)t−ieiq_t = (1-\alpha)^t q_0 + \alpha\sum_{i=1}^t (1-\alpha)^{t-i}e_i qt​=(1−α)tq0​+αi=1∑t​(1−α)t−iei​

可以看出，qtq_tqt​ 仅依赖 ttt 时刻及先前的运动证据 e1,e2,…,ete_1,e_2,\dots,e_te1​,e2​,…,et​，不会看到未来的运动证据 et+1,et+2,…e_{t+1},e_{t+2},\dotset+1​,et+2​,…，因此 qt=F(e1,…,et)q_t = F(e_1,\dots,e_t)qt​=F(e1​,…,et​) 满足因果系统定义

同理，Rt=1[qt≥τR]R_t = \mathbf 1[q_t\ge \tau_R]Rt​=1[qt​≥τR​] 同样也不会使用未来的运动信息，所以我们构建的 Router 是一个因果运动状态路由器（causal motion state router），而不是在做离线平滑（offline smoothing）

α 的物理意义

如果 α=1\alpha=1α=1，则 qt=etq_t = e_tqt​=et​，相当于完全没有时间平滑；如果 α≪1\alpha\ll 1α≪1，则 qt≈qt−1q_t \approx q_{t-1}qt​≈qt−1​，Router 比较稳定但状态变化响应很慢

因此，α\alphaα 用于控制稳定性与响应速度之间的平衡

可以据此定义旧信息的半衰期 hhh：

(1−α)h=12(1-\alpha)^h = \frac{1}{2} (1−α)h=21​

两边同时取对数：

hln⁡(1−α)=ln⁡12h\ln(1-\alpha) = \ln\frac{1}{2} hln(1−α)=ln21​

分离 hhh 则有：

h=−ln⁡2ln⁡(1−α)h = \frac{-\ln2}{\ln(1-\alpha)} h=ln(1−α)−ln2​

单位为 Router 更新步

专家概率的融合

现在我们考虑另一个关键的问题，不同专家概率为什么不能直接融合（比如简单取一个最大值）

假设 Anchor 的最优阈值为 τA=0.45\tau_A = 0.45τA​=0.45，而 Kinematic Expert 的最优阈值为 τD=0.7\tau_D = 0.7τD​=0.7，如果直接比较原始概率：

SA=0.55,SK=0.65S_A = 0.55,\quad S_K = 0.65 SA​=0.55,SK​=0.65

表面上有 SK>SAS_K\gt S_ASK​>SA​，但从各自决策边界来看，Anchor 认为已经进入攻击区域，而 Kinematic Expert 则认为仍然不是攻击

因此，原始概率的数值大小，不能直接在不同的专家（模型/模块）之间进行横向比较，因为不同模型的概率校准、类别分布、最优阈值等都不同，必须先把每个专家自己的判别边界映射到同一个参考位置

Threshold-Centered Score Normalization

以阈值为中心的分数归一化策略

对于一个专家，其原始分数：

S∈[0,1]S\in[0,1] S∈[0,1]

和决策阈值：

τ∈(0,1)\tau\in(0,1) τ∈(0,1)

我们定义：

g(S,τ)={0.5Sτ,S<τ0.5+0.5(S−τ)1−τ,S≥τg(S,\tau) = \begin{cases} \frac{0.5S}{\tau},\quad\quad\quad\quad\quad S\lt\tau\\ 0.5 + \frac{0.5(S-\tau)}{1-\tau},\quad S\ge \tau \end{cases} g(S,τ)={τ0.5S​,S<τ0.5+1−τ0.5(S−τ)​,S≥τ​

因此则有：

SA=g(SA,τA)SK=g(SK,τK)S_A = g(S_A,\tau_A)\\S_K = g(S_K,\tau_K) SA​=g(SA​,τA​)SK​=g(SK​,τK​)

归一化函数特点

归一化函数 g(S,τ)g(S,\tau)g(S,τ) 在设计时考虑了三个特点：

  1. 端点保持：g(0,τ)=0g(0,\tau)=0g(0,τ)=0，g(1,τ)=1g(1,\tau)=1g(1,τ)=1
  2. 决策边界统一映射到 0.5：无论左侧还是右侧逼近时，lim⁡S→τg(S,τ)=0.5\lim_{S\to\tau} g(S,\tau) = 0.5limS→τ​g(S,τ)=0.5
  3. 严格单调：∂g∂S>0\frac{\partial g}{\partial S}>0∂S∂g​>0 恒成立，归一化不会改变专家内部样本的排序关系

可以把 S~−0.5\tilde{S}-0.5S~−0.5 看做是相对于专家自身决策边界的归一化置信度（normalized confidence），当 S~<0.5\tilde S\lt0.5S~<0.5 时，认为是 normal side，当 S~>0.5\tilde S>0.5S~>0.5 时，认为是 attack side

因此经过归一化以后，S~A\tilde S_AS~A​ 和 S~K\tilde S_KS~K​ 至少在相对各自决策边界的位置意义上变得可比较

Static-Anchored Kinematic Escalation

静态锚定的动态升级策略（本文的核心算法之一）

我们定义：

SP(t)=max⁡[S~A(t),RtS~K(t)]S_P(t) = \max\left[ \tilde{S}_A(t),R_t\tilde S_K(t) \right] SP​(t)=max[S~A​(t),Rt​S~K​(t)]

其中，Rt∈{0,1}R_t\in\{0,1\}Rt​∈{0,1}

Primary branch 最终的判断依据为：

Y^P(t)=1[SP(t)≥0.5]\hat{Y}_P(t) = \mathbf 1[S_P(t)\ge 0.5] Y^P​(t)=1[SP​(t)≥0.5]

这就是静态锚定的动态升级策略（Static-Anchored Kinematic Escalation）的核心判别公式

Router → 静态

如果 Rt=0R_t = 0Rt​=0，则 RtS~D=0R_t\tilde{S}_D = 0Rt​S~D​=0，此时 SP=S~AS_P = \tilde S_ASP​=S~A​，在 static route 情况下，系统完全退化为 Anchor detector，Kinematic Expert 完全不参与判断

Router → 动态

如果 Rt=1R_t = 1Rt​=1，此时 SP=max⁡(S~A,S~K)S_P = \max(\tilde S_A,\tilde S_K)SP​=max(S~A​,S~K​)，两个专家竞争，但只允许保留更强的攻击证据，因此我们可以认为，动态专家只有把状态判别拉高的权利，但没有把状态判别压低的权利，即 Kinematic Expert can escalate but cannot suppress

这是我们所定义的 Kinematic Escalation 的严格数学含义

Anchor Preservation Property

根据 max 运算可知：

SP(t)≥S~A(t)S_P(t)\ge\tilde S_A(t) SP​(t)≥S~A​(t)

因此，如果 Anchor 已经检测到正类，即 S~A(t)≥0.5\tilde S_A(t)\ge 0.5S~A​(t)≥0.5，此时一定有：

SP(t)≥S~A(t)≥0.5S_P(t)\ge\tilde S_A(t)\ge 0.5 SP​(t)≥S~A​(t)≥0.5

则：

Y^A=1⇒Y^P=1\hat{Y}_A = 1\Rightarrow \hat{Y}_P = 1 Y^A​=1⇒Y^P​=1

永远成立

这是本方法最重要的理论性质之一，简单来讲就是锚点证据保留（Anchor evidence preservation）或者锚点证据的不可否决性（non-veto property），Router 和 Kinematic Expert 均没有权利取消 Anchor 已经建立的攻击判断

Primary Branch 完整数学表达

首先得到 Anchor：

SA(t)=fA(Xt)S_A(t) = f_A(\mathbf X_t) SA​(t)=fA​(Xt​)

以及 Kinematic Expert：

S~A=g(SA,τA)S~D=g(SD,τD)\tilde S_A = g(S_A,\tau_A)\\\tilde S_D = g(S_D,\tau_D) S~A​=g(SA​,τA​)S~D​=g(SD​,τD​)

运动证据：

qt=αet+(1−α)qt−1q_t = \alpha e_t + (1-\alpha)q_{t-1} qt​=αet​+(1−α)qt−1​

Rt=1[qt≥τR]R_t = \mathbf 1[q_t\ge\tau_R] Rt​=1[qt​≥τR​]
