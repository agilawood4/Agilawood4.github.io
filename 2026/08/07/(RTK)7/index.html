伪距观测方程

在前面的章节中，我们已经了解到，接收机通过测码距得到伪距 PrsP_r^sPrs​，通过广播星历得到卫星发射时刻的位置 rs\mathbf{r}^srs，可以计算卫星钟差 δts\delta t^sδts，已知电离层、对流层等误差项

现在我们要做的是把这些量组织成一个可以求解接收机位置的方程：

Prs=ρrs+c(δtr−δts)+Irs+Trs+brs+εrsP_r^s = \rho_r^s + c(\delta t_r - \delta t^s) + I_r^s + T_r^s + b_r^s + \varepsilon_r^s Prs​=ρrs​+c(δtr​−δts)+Irs​+Trs​+brs​+εrs​

这就是伪距观测方程

何为观测方程

所谓观测方程，就是要建立如下的等量关系：

接收机实际测得的量=未知状态的函数+误差\text{接收机实际测得的量} = \text{未知状态的函数} + \text{误差} 接收机实际测得的量=未知状态的函数+误差

对于 GNSS 而言，接收机实际测得的是 PrsP_r^sPrs​，即伪距；而我们实际想求的是 rr=[xryrzr]⊤\mathbf r_r = [x_r\quad y_r\quad z_r]^\toprr​=[xr​yr​zr​]⊤，以及接收机钟差 δtr\delta t_rδtr​

因此，我们要把伪距写成这些未知量的函数，这就是建立伪距观测方程的目的

从理想情况开始

我们先暂时假设：

  • 卫星钟和接收机钟完全准确
  • 没有电离层、对流层、多路径以及其他测量噪声

这样的理想环境，那么卫星 sss 在发射时刻的位置为：

rs=[xsyszs]\mathbf r^s = \begin{bmatrix} x^s\\y^s\\z^s\\ \end{bmatrix} rs=⎣⎢⎡​xsyszs​⎦⎥⎤​

接收机位置为：

rr=[xryrzr]\mathbf r_r = \begin{bmatrix} x_r\\y_r\\z_r\\ \end{bmatrix} rr​=⎣⎢⎡​xr​yr​zr​​⎦⎥⎤​

卫星到接收机的几何距离为：

ρrs=∥rs−rr∥\rho_r^s = \|\mathbf r^s - \mathbf r_r\| ρrs​=∥rs−rr​∥

展开即得到：

ρrs=(xs−sr)2+(ys−yr)2+(zs−zr)2\rho_r^s = \sqrt{(x^s - s_r)^2 + (y^s - y_r)^2 + (z^s - z_r)^2} ρrs​=(xs−sr​)2+(ys−yr​)2+(zs−zr​)2​

在完全理想的情况下：

Prs=ρrsP_r^s = \rho_r^s Prs​=ρrs​

展开即得到：

Prs=(xs−sr)2+(ys−yr)2+(zs−zr)2P_r^s = \sqrt{(x^s - s_r)^2 + (y^s - y_r)^2 + (z^s - z_r)^2} Prs​=(xs−sr​)2+(ys−yr​)2+(zs−zr​)2​

如果卫星坐标已知，那么未知量就只有：

xr,yr,zrx_r,\quad y_r,\quad z_r xr​,yr​,zr​

理论上三颗卫星似乎就能完成接收机三维坐标的求解，但现实中还有一个重要的未知量待求：接收机钟差

含接收机钟差的伪距方程

通过本节的推导，我们就能够说明为什么定位解算至少需要 4 颗可用卫星

我们设 tst^sts 是真实 GNSS 系统时间下信号发射时刻，trt_rtr​ 是真实 GNSS 系统时间下信号接收时刻，δts\delta t^sδts 是卫星钟差，δtr\delta t_rδtr​ 是接收机钟差

则卫星钟读出的信号发射时刻为：

t~s=ts+δts\tilde{t}^s = t^s + \delta t^s t~s=ts+δts

接收机钟读出的信号接收时刻为：

t~r=tr+δtr\tilde{t}_r = t_r + \delta t_r t~r​=tr​+δtr​

接收机通过测距码获得的时间差近似为：

t~r−t~s\tilde{t}_r - \tilde{t}^s t~r​−t~s

由此测得的伪距为：

Prs=c(t~r−t~s)P_r^s = c(\tilde{t}_r - \tilde{t}^s) Prs​=c(t~r​−t~s)

代入两套时钟，展开则有：

Prs=c[(tr−δtr)−(ts−δts)]P_r^s = c[(t_r - \delta t_r) - (t^s - \delta t^s)] Prs​=c[(tr​−δtr​)−(ts−δts)]

即：

Prs=c(tr−ts)+c(δtr−δts)P_r^s = c(t_r - t^s) + c(\delta t_r - \delta t^s) Prs​=c(tr​−ts)+c(δtr​−δts)

理想情况下：

c(tr−ts)≈ρrsc(t_r - t^s)\approx\rho_r^s c(tr​−ts)≈ρrs​

于是得到最基础的伪距观测模型：

Prs=ρrs+c(δtr−δts)P_r^s = \rho_r^s + c(\delta t_r - \delta t^s) Prs​=ρrs​+c(δtr​−δts)

其中，卫星钟差 δts\delta t^sδts 可以根据广播星历中的 af0,afa,af2a_{f_0},a_{f_a},a_{f_2}af0​​,afa​​,af2​​ 以及相对论项计算出来，因此在定位过程中，δts\delta t^sδts 可以近似认为是一个已知的改正量

而接收机钟差 δtr\delta t_rδtr​ 则没有外部数据告诉我们，只能靠伪距定位自己估计

其他误差加入

大气误差

现实中，信号传播嗨哟阿九经过电离层和对流层，其中电离层延迟为：

Ir,fsI_{r,f}^s Ir,fs​

与频率有关：

If∝1f2I_f∝\frac{1}{f^2} If​∝f21​

对于伪距，它使测量距离增大，因此符号为正

而电离层延迟为：

TrsT_r^s Trs​

在 GNSS 频率范围内近似于频率无关，也使得传播时间增加，因此符号也为正

硬件偏差和随机误差

更完整的伪距观测方程可以写为：

Pr,fs=ρrs+c(δtr−δts)+Ir,fs+Trs+bP,r,f+bP,fs+MP,r,fs+εP,r,fsP_{r,f}^s = \rho_r^s + c(\delta t_r - \delta t^s) + I_{r,f}^s + T_r^s + b_{P,r,f} + b_{P,f}^s + M_{P,r,f}^s + \varepsilon_{P,r,f}^s Pr,fs​=ρrs​+c(δtr​−δts)+Ir,fs​+Trs​+bP,r,f​+bP,fs​+MP,r,fs​+εP,r,fs​

其中：

  • bP,r,fb_{P,r,f}bP,r,f​：接收机码硬件偏差
  • bP,fsb_{P,f}^sbP,fs​：卫星码硬件偏差
  • MP,r,fsM_{P,r,f}^sMP,r,fs​：伪距多路径
  • εP,r,fsε_{P,r,f}^sεP,r,fs​：随机测量噪声

工程上，为避免方程过于庞杂，经常将硬件偏差、多路径以及剩余未建模误差统一写为：

br,fs+εr,fsb_{r,f}^s + \varepsilon_{r,f}^s br,fs​+εr,fs​

于是得到我们后续最常用的伪距模型：

Prs=ρrs+c(δtr−δts)+Ir,fs+Trs+br,fs+εr,fsP_{r}^s = \rho_r^s + c(\delta t_r - \delta t^s) + I_{r,f}^s + T_{r}^s + b_{r,f}^s + \varepsilon_{r,f}^s Prs​=ρrs​+c(δtr​−δts)+Ir,fs​+Trs​+br,fs​+εr,fs​

单点定位方程

要求解上面这个方程，首先要分清哪些量是已知量，哪些量是未知量

对于某颗卫星 sss，卫星位置 rs\mathbf{r}^srs，卫星钟差 δts\delta t^sδts，电离层改正 I^rs\hat{I}_r^sI^rs​，对流层改正量 T^rs\hat T_r^sT^rs​，部分码硬件偏差都是已知的

而主要的未知量则是以下四个：

xryrzrδtrx_r\quad y_r\quad z_r\quad \delta t_r xr​yr​zr​δtr​

因此，我们考虑把所有改正量移项，放到观测值一侧：

Prs+cδts−I^rs−T^rs−b^rsP_r^s + c\delta t^s - \hat I_r^s - \hat T_r^s - \hat b^s_r Prs​+cδts−I^rs​−T^rs​−b^rs​

定义改正后的伪距为：

Pr,corrsP_{r,\text{corr}}^s Pr,corrs​

则有：

Pr,corrs=ρrs+cδtr+εrsP_{r,\text{corr}}^s = \rho_r^s + c\delta t_r + \varepsilon_r^s Pr,corrs​=ρrs​+cδtr​+εrs​

再将几何距离展开则有：

Pr,corrs=(xs−xr)2+(ys−yr)2+(zs−zr)2+cδtr+εrsP_{r,\text{corr}}^s = \sqrt{(x^s - x_r)^2 + (y^s - y_r)^2 + (z^s - z_r)^2} + c\delta t_r + \varepsilon_{r}^s Pr,corrs​=(xs−xr​)2+(ys−yr​)2+(zs−zr​)2​+cδtr​+εrs​

这就是单点定位中最核心的数学模型

对于这样一个单系统三维定位，未知量为：

xryrzrδtrx_r\quad y_r\quad z_r\quad\delta t_r xr​yr​zr​δtr​

共 4 个未知参数

一颗卫星只能给出一个伪距方程：

P1=ρ1+cδtr+…P^1 = \rho^1 + c\delta t_r + \dots P1=ρ1+cδtr​+…

四颗卫星才能至少得到：

{P1=f1(xr,  yr,  zr,  δtr)P2=f2(xr,  yr,  zr,  δtr)P3=f3(xr,  yr,  zr,  δtr)P4=f4(xr,  yr,  zr,  δtr)\begin{cases} P^1 = f_1(x_r,\; y_r,\;z_r,\;\delta t_r)\\ P^2 = f_2(x_r,\; y_r,\;z_r,\;\delta t_r)\\ P^3 = f_3(x_r,\; y_r,\;z_r,\;\delta t_r)\\ P^4 = f_4(x_r,\; y_r,\;z_r,\;\delta t_r)\\ \end{cases} ⎩⎪⎪⎪⎪⎨⎪⎪⎪⎪⎧​P1=f1​(xr​,yr​,zr​,δtr​)P2=f2​(xr​,yr​,zr​,δtr​)P3=f3​(xr​,yr​,zr​,δtr​)P4=f4​(xr​,yr​,zr​,δtr​)​

即用 4 个观测方程去求解 4 个未知量，所以我们前面才说：三维 GNSS 单点定位至少需要 4 颗卫星

在实际求解过程中，四颗卫星只是数学上的最低要求，实际伪距中存在：

εrs≠0\varepsilon_r^s\ne 0 εrs​​=0

所以四个方程一般不可能被某个位置完美满足

而如果有 m>4m\gt 4m>4 颗卫星，则会得到：

{P1=f1(x)+ε1P2=f2(x)+ε2⋮Pm=fm(x)+εm\begin{cases} P^1 = f_1(\mathbf x) + \varepsilon^1\\ P^2 = f_2(\mathbf x) + \varepsilon^2\\ \vdots\\ P^m = f_m(\mathbf x) + \varepsilon^m\\ \end{cases} ⎩⎪⎪⎪⎪⎪⎨⎪⎪⎪⎪⎪⎧​P1=f1​(x)+ε1P2=f2​(x)+ε2⋮Pm=fm​(x)+εm​

其中：

x=[xryrzrcδtr]\mathbf x = \begin{bmatrix} x_r\\y_r\\z_r\\c\delta t_r\\ \end{bmatrix} x=⎣⎢⎢⎢⎡​xr​yr​zr​cδtr​​⎦⎥⎥⎥⎤​

此时，由于 m>4m>4m>4，方程数多余未知数的个数，形成超定方程组，不存在一个解能让所有方程严格成立，要寻找一个 “最合理” 的解，就需要用到最小二乘法

而在最小二乘之前，我们还需要解决一个问题：当前这个伪距方程是非线性的，我们还需要先将其线性化

所谓方程非线性，指的是该观测方程的几何距离项中出现了关于未知坐标 xr,  yr,  zrx_r,\;y_r,\;z_rxr​,yr​,zr​ 的平方、求和以及平方根项

因此观测模型并不是关于 xr,  yr,  zrx_r,\;y_r,\;z_rxr​,yr​,zr​ 的线性方程，也就不能写成简单的：

Ax=b\mathbf{Ax = b} Ax=b

的形式一次求解，必须要按照如下的范式去求解：

  1. 给定接收机位置初值
  2. 在初值附近对 ρ\rhoρ 做一阶泰勒展开
  3. 得到线性化方程
  4. 解出位置改正量
  5. 更新坐标并持续迭代

计算伪距 vs. 观测伪距

观测伪距即接收机实际测得的伪距 PrsP_r^sPrs​，它来自测距码

计算伪距则是根据当前估计的接收机位置 r^r\hat{\mathbf r}_rr^r​ 计算得到理论几何距离 ρ^rs=∥rs−r^r∥\hat\rho_r^s = \|\mathbf r^s - \hat{\mathbf{ r}}_r\|ρ^​rs​=∥rs−r^r​∥，接着加入当前接收机钟差估计、卫星钟差、电离层和对流层误差得到的理论伪距：

P^rs=ρ^rs+cδ^tr−cδts+I^rs+T^rs\hat{P}_r^s = \hat{\rho}_r^s + c\hat{\delta}t_r - c\delta t^s + \hat{I}_r^s + \hat{T}_r^s P^rs​=ρ^​rs​+cδ^tr​−cδts+I^rs​+T^rs​

二者作差：

crs=Prs−P^rsc_r^s = P_r^s - \hat{P}_r^s crs​=Prs​−P^rs​

即为当前观测状态下的伪距残差

需要注意的是，GNSS 单点定位本质上是一个迭代估计的过程，我们可能会对上面的内容有疑惑：

接收机位置和钟差不是待求的未知量吗，我们这一节怎么又根据接收机位置和钟差反过来取计算伪距了？

接收机真实位置确实是未知的，计算残差时用的并不是真实位置，而是一个当前位置估计值，这个估计值可以来自于：

  • 上一个历元的位置
  • 接收机已有的粗略单点解
  • 某个初始化位置
  • 第一次启动时甚至可以用较为粗糙的 ECEF 初值

算法先根据这个估计位置计算理论伪距，再与实际测得的伪距相减得到残差，然后利用多颗卫星的残差反推出位置和钟差需要修正多少，更新位置后再重新计算残差，如此迭代，直到改正量足够小、解收敛

因此本质上是：先猜位置 → 算残差 → 用残差修正位置 → 继续迭代，这一过程会在下一讲中给出详细推导过程
