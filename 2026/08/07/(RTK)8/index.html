非线性伪距观测方程的线性化

这一节是后续做最小二乘、加权最小二乘以及卡尔曼滤波的数学基础

上一节中我们已经得到单系统伪距模型：

Prs=ρrs+br−cδts+Irs+Trs+εrsP_r^s = \rho_r^s + b_r - c\delta t^s + I_r^s + T_r^s + \varepsilon_r^s Prs​=ρrs​+br​−cδts+Irs​+Trs​+εrs​

其中，br=cδtrb_r = c\delta t_rbr​=cδtr​，对应接收机钟差造成的距离误差，单位为米

当前待求的未知量为：

xryrzrbrx_r\quad y_r\quad z_r\quad b_r xr​yr​zr​br​

而待求解的观测方程中，几何距离项：

ρrs=(xs−xr)2+(ys−yr)2+(zs−zr)2\rho_r^s = \sqrt{(x^s - x_r)^2 + (y^s - y_r)^2 + (z^s -z_r)^2} ρrs​=(xs−xr​)2+(ys−yr​)2+(zs−zr​)2​

关于接收机坐标是非线性的，因此不能直接套用最小二乘公式

在本节中，我们给出把非线性伪距方程，在当前位置估计附近转换为线性方程的一种方法，其核心思路即：

不是直接求解真实位置，而是给出一个粗略的位置估计在这个估计附近求解还需要改进多少通过多轮迭代，使得估计位置最终逐渐逼近真实位置\text{不是直接求解真实位置，而是给出一个粗略的位置估计}\\\text{在这个估计附近求解还需要改进多少}\\\text{通过多轮迭代，使得估计位置最终逐渐逼近真实位置} 不是直接求解真实位置，而是给出一个粗略的位置估计在这个估计附近求解还需要改进多少通过多轮迭代，使得估计位置最终逐渐逼近真实位置

估计值与状态改正量

假设在第 kkk 次迭代时，当前状态估计为：

x^(k)=[x^r(k)y^r(k)z^r(k)b^r(k)]\hat{\mathbf x}^{(k)} = \begin{bmatrix} \hat{x}_r^{(k)}\\ \hat{y}_r^{(k)}\\ \hat{z}_r^{(k)}\\ \hat{b}_r^{(k)}\\ \end{bmatrix} x^(k)=⎣⎢⎢⎢⎢⎡​x^r(k)​y^​r(k)​z^r(k)​b^r(k)​​⎦⎥⎥⎥⎥⎤​

为了推导简洁，我们暂时省略上标 (k)^{(k)}(k)，简化写成：

x^=[x^ry^rz^rb^r]\hat{x} = \begin{bmatrix} \hat{x}_r\\ \hat{y}_r\\ \hat{z}_r\\ \hat{b}_r\\ \end{bmatrix} x^=⎣⎢⎢⎢⎡​x^r​y^​r​z^r​b^r​​⎦⎥⎥⎥⎤​

接收机真实状态和估计状态之间的关系可以表示为：

x=x^+Δx\mathbf x = \hat{\mathbf x} + \Delta \mathbf {x} x=x^+Δx

其中：

Δx=[ΔxΔyΔzΔb]\Delta \mathbf{x} = \begin{bmatrix} \Delta x\\ \Delta y\\ \Delta z\\ \Delta b\\ \end{bmatrix} Δx=⎣⎢⎢⎢⎡​ΔxΔyΔzΔb​⎦⎥⎥⎥⎤​

展开也就是：

xr=x^r+Δxyr=y^r+Δyzr=z^r+Δzbr=b^r+Δbx_r = \hat{x}_r + \Delta x\\ y_r = \hat{y}_r + \Delta y\\ z_r = \hat{z}_r + \Delta z\\ b_r = \hat{b}_r + \Delta b xr​=x^r​+Δxyr​=y^​r​+Δyzr​=z^r​+Δzbr​=b^r​+Δb

现在我们不是直接去求解 xr,yr,zr,brx_r,y_r,z_r,b_rxr​,yr​,zr​,br​，而是转而去求尽可能小的：

Δx,Δy,Δz,Δb\Delta x,\Delta y,\Delta z,\Delta b Δx,Δy,Δz,Δb

几何距离一阶展开

这是本节中最重要的一步

首先我们把几何距离定义为有关 xr,yr,zrx_r,y_r,z_rxr​,yr​,zr​ 的函数：

ρ(xr,yr,zr)=(xs−xr)2+(ys−yr)2+(zs−zr)2\rho(x_r,y_r,z_r) = \sqrt{(x^s - x_r)^2 + (y^s - y_r)^2 + (z^s - z_r)^2} ρ(xr​,yr​,zr​)=(xs−xr​)2+(ys−yr​)2+(zs−zr​)2​

在当前估计：

(x^r,y^r,z^r)(\hat{x}_r,\hat{y}_r,\hat{z}_r) (x^r​,y^​r​,z^r​)

附近做一阶泰勒展开：

ρ(xr,yr,zr)≈ρ(x^r,y^r,z^r)+∂ρ∂xrΔx+∂ρ∂yrΔy+∂ρ∂zrΔz\rho(x_r,y_r,z_r)\approx \rho(\hat{x}_r,\hat{y}_r,\hat{z}_r) + \frac{\partial \rho}{\partial x_r}\Delta x + \frac{\partial \rho}{\partial y_r}\Delta y + \frac{\partial \rho}{\partial z_r}\Delta z ρ(xr​,yr​,zr​)≈ρ(x^r​,y^​r​,z^r​)+∂xr​∂ρ​Δx+∂yr​∂ρ​Δy+∂zr​∂ρ​Δz

即：

ρrs=ρ^rs+∂ρ∂xrΔx+∂ρ∂yrΔy+∂ρ∂zrΔz\rho_r^s = \hat{\rho}_r^s + \frac{\partial\rho}{\partial x_r}\Delta x + \frac{\partial\rho}{\partial y_r}\Delta y + \frac{\partial\rho}{\partial z_r}\Delta z ρrs​=ρ^​rs​+∂xr​∂ρ​Δx+∂yr​∂ρ​Δy+∂zr​∂ρ​Δz

下面我们依次求解三个偏导数的值

∂ρ∂xr\frac{\partial\rho}{\partial x_r}∂xr​∂ρ​ 推导

我们令：

q=(xs−xr)2+(ys−yr)2+(zs−zr)2q = (x^s - x_r)^2 + (y^s - y_r)^2 + (z^s - z_r)^2 q=(xs−xr​)2+(ys−yr​)2+(zs−zr​)2

即：

ρ=q12\rho = q^{\frac{1}{2}} ρ=q21​

根据链式求导法则：

∂ρ∂xr=12q−12∂q∂xr\frac{\partial \rho}{\partial x_r} = \frac{1}{2}q^{-\frac{1}{2}}\frac{\partial q}{\partial x_r} ∂xr​∂ρ​=21​q−21​∂xr​∂q​

而：

∂∂xr(xs−xr)2=−2(xs−xr)\frac{\partial}{\partial x_r}(x^s - x_r)^2 = -2(x^s - x_r) ∂xr​∂​(xs−xr​)2=−2(xs−xr​)

其余两项和 xrx_rxr​ 无关，因此则有：

∂q∂xr=−2(xs−xr)\frac{\partial q}{\partial x_r} = -2(x^s - x_r) ∂xr​∂q​=−2(xs−xr​)

把 qqq 和 ∂q∂xr\frac{\partial q}{\partial x_r}∂xr​∂q​ 代回原公式则有：

∂ρ∂xr=−xs−xrρ\frac{\partial \rho}{\partial x_r} = -\frac{x^s - {x}_r}{\rho} ∂xr​∂ρ​=−ρxs−xr​​

在当前位置估计处：

∂ρ∂xr∣r^=−xs−x^rρ^rs\left.\frac{\partial \rho}{\partial x_r}\right|_{\hat {\mathbf r}} = -\frac{x^s - \hat{x}_r}{\hat\rho_r^s} ∂xr​∂ρ​∣∣∣∣∣​r^​=−ρ^​rs​xs−x^r​​

同理则有：

∂ρ∂yr=−ys−y^rρ^rs∂ρ∂zr=−zs−z^rρ^rs\frac{\partial\rho}{\partial y_r} = -\frac{y^s - \hat y_r}{\hat{\rho}_r^s}\\ \frac{\partial\rho}{\partial z_r} = -\frac{z^s - \hat z_r}{\hat{\rho}_r^s}\\ ∂yr​∂ρ​=−ρ^​rs​ys−y^​r​​∂zr​∂ρ​=−ρ^​rs​zs−z^r​​

这实际上就是视线单位向量

在上一讲中，我们已经定义过由接收机指向卫星的 LOS 单位向量：

ers=rs−rr^ρ^rs\mathbf{e}_r^s = \frac{\mathbf r^s - \hat{\mathbf{r}_r}}{\hat{\rho}_r^s} ers​=ρ^​rs​rs−rr​^​​

按三个位置分量展开则有：

exs=xs−x^rρ^rsexs=ys−y^rρ^rsexs=zs−z^rρ^rse_x^s = \frac{x^s - \hat x_r}{\hat\rho_r^s}\\ e_x^s = \frac{y^s - \hat y_r}{\hat\rho_r^s}\\ e_x^s = \frac{z^s - \hat z_r}{\hat\rho_r^s} exs​=ρ^​rs​xs−x^r​​exs​=ρ^​rs​ys−y^​r​​exs​=ρ^​rs​zs−z^r​​

即：

∂ρ∂xr=xs−x^rρ^rs∂ρ∂yr=ys−y^rρ^rs∂ρ∂zr=zs−z^rρ^rs\frac{\partial\rho}{\partial x_r} = \frac{x^s - \hat x_r}{\hat\rho_r^s}\\ \frac{\partial\rho}{\partial y_r} = \frac{y^s - \hat y_r}{\hat\rho_r^s}\\ \frac{\partial\rho}{\partial z_r} = \frac{z^s - \hat z_r}{\hat\rho_r^s} ∂xr​∂ρ​=ρ^​rs​xs−x^r​​∂yr​∂ρ​=ρ^​rs​ys−y^​r​​∂zr​∂ρ​=ρ^​rs​zs−z^r​​

因此，几何距离的一阶泰勒展开可以简写成：

ρrs=ρ^rs−exsΔx−eysΔy−ezsΔz\rho_r^s = \hat{\rho}_r^s - e_x^s\Delta x - e_y^s\Delta y - e_z^s\Delta z ρrs​=ρ^​rs​−exs​Δx−eys​Δy−ezs​Δz

由于我们定义的 ers\mathbf e_r^sers​ 是从接收机到卫星方向的向量，如果接收机沿着卫星方向移动，则接收机靠近卫星，对应的几何距离应该会减小

因此：

δρ=−(ers)⊤Δr\delta \rho = -(\mathbf e_r^s)^\top\Delta \mathbf r δρ=−(ers​)⊤Δr

接收机钟差改正量

上一节中最后得到的伪距模型是：

Pcorrs=ρrs+br+εrsP_{\text{corr}}^s = \rho_r^s + b_r + \varepsilon_r^s Pcorrs​=ρrs​+br​+εrs​

而：

br=b^r+Δbb_r = \hat{b}_r + \Delta b br​=b^r​+Δb

同时有：

ρrs≈ρ^rs−exsΔx−eysΔy−ezsΔz\rho_r^s\approx \hat \rho_r^s - e_x^s\Delta x - e_y^s\Delta y - e_z^s\Delta z ρrs​≈ρ^​rs​−exs​Δx−eys​Δy−ezs​Δz

代入则有：

Pcorrs≈ρ^rs−exsΔx−eysΔy−ezsΔz+b^r+Δb+εrsP_{\text{corr}}^s\approx\hat \rho_r^s - e_x^s\Delta x - e_y^s\Delta y - e_z^s\Delta z + \hat b_r + \Delta b + \varepsilon_r^s Pcorrs​≈ρ^​rs​−exs​Δx−eys​Δy−ezs​Δz+b^r​+Δb+εrs​

把已经估计出的理论值：

ρ^rs+b^r\hat \rho_r^s + \hat b_r ρ^​rs​+b^r​

移动到式子左边，则得到：

Pcorrs−(ρ^rs+b^r)=−exsΔx−eysΔy−ezsΔz+Δb+εrsP_{\text{corr}}^s - (\hat \rho_r^s + \hat b_r) = - e_x^s\Delta x - e_y^s\Delta y - e_z^s\Delta z + \Delta b + \varepsilon_r^s Pcorrs​−(ρ^​rs​+b^r​)=−exs​Δx−eys​Δy−ezs​Δz+Δb+εrs​

预拟合残差

定义：

vs=Pcorrs−(ρ^rs+b^r)v^s = P_{\text{corr}}^s - (\hat \rho_r^s + \hat b_r) vs=Pcorrs​−(ρ^​rs​+b^r​)

其中，vsv^svs 表示在当前状态估计下，实际观测与理论预测之间的不一致性

于是单颗卫星的线性化方程转化为：

vs=−exsΔx−eysΔy−ezsΔz+Δb+εrsv^s = -e_x^s\Delta x - e_y^s\Delta y - e_z^s\Delta z + \Delta b + \varepsilon_r^s vs=−exs​Δx−eys​Δy−ezs​Δz+Δb+εrs​

写成矩阵形式则有：

vs=[−exs−eys−ezs1][ΔxΔyΔzΔb]+εrsv^s = \begin{bmatrix}-e_x^s & -e_y^s& -e_z^s& 1\end{bmatrix}\begin{bmatrix} \Delta x\\ \Delta y\\ \Delta z\\ \Delta b\\ \end{bmatrix} + \varepsilon_r^s vs=[−exs​​−eys​​−ezs​​1​]⎣⎢⎢⎢⎡​ΔxΔyΔzΔb​⎦⎥⎥⎥⎤​+εrs​

这就是单颗卫星对应的一行线性化观测方程

接着，假设我们同时观测 mmm 颗卫星，每颗卫星都有：

vs=−exsΔx−eysΔy−ezsΔz+Δb+εrsv^s = -e_x^s\Delta x - e_y^s\Delta y - e_z^s\Delta z + \Delta b + \varepsilon_r^s vs=−exs​Δx−eys​Δy−ezs​Δz+Δb+εrs​

把所有卫星叠起来：

v=HΔx+ε\mathbf{v} = \mathbf{H}\Delta\mathbf{x} + \mathbf{\varepsilon} v=HΔx+ε

其中：

v=[v1v2⋮vm]\mathbf{v} = \begin{bmatrix} v^1\\v^2\\\vdots\\v^m\\ \end{bmatrix} v=⎣⎢⎢⎢⎢⎡​v1v2⋮vm​⎦⎥⎥⎥⎥⎤​

是 m×1m\times1m×1 的观测残差向量

Δx=[ΔxΔyΔzΔb]\Delta\mathbf x = \begin{bmatrix} \Delta x\\ \Delta y\\ \Delta z\\ \Delta b\\ \end{bmatrix} Δx=⎣⎢⎢⎢⎡​ΔxΔyΔzΔb​⎦⎥⎥⎥⎤​

是 4×14\times14×1 的状态改正量

H=[−ex1−ey1−ez11−ex2−ey2−ez21⋮⋮⋮⋮−exm−eym−ezm1]\mathbf H = \begin{bmatrix} -e_x^1 & -e_y^1 & -e_z^1 & 1\\ -e_x^2 & -e_y^2 & -e_z^2 & 1\\ \vdots & \vdots & \vdots & \vdots\\ -e_x^m & -e_y^m & -e_z^m & 1\\ \end{bmatrix} H=⎣⎢⎢⎢⎢⎡​−ex1​−ex2​⋮−exm​​−ey1​−ey2​⋮−eym​​−ez1​−ez2​⋮−ezm​​11⋮1​⎦⎥⎥⎥⎥⎤​

是 m×4m\times4m×4 的设计矩阵

整体形状关系满足：

(m×1)=(m×4)(4×1)(m\times1) = (m\times 4)(4\times1) (m×1)=(m×4)(4×1)

其中，设计矩阵也称为 Geometry Matrix、Observation Matrix、Jacobian Matrix 以及雅可比矩阵

它表示：状态发生微小变化时，观测预测值会变化多少

对于伪距：

Hs=[−exs−eys−ezs1]H^s = [-e_x^s \quad -e_y^s \quad -e_z^s \quad 1] Hs=[−exs​−eys​−ezs​1]

前三项来自于几何距离对接收机坐标的偏导：

∂ρ∂x,∂ρ∂y,∂ρ∂z\frac{\partial \rho}{\partial x},\quad\frac{\partial \rho}{\partial y},\quad\frac{\partial \rho}{\partial z} ∂x∂ρ​,∂y∂ρ​,∂z∂ρ​

最后一项来自于：

∂br∂br=1\frac{\partial b_r}{\partial b_r} = 1 ∂br​∂br​​=1

因此，本质上：

H=∂h(x)∂xH = \frac {\partial h (\mathbf{x})} {\partial \mathbf{x}} H=∂x∂h(x)​

也就是观测函数对于当前状态的雅可比矩阵

迭代线性化完整过程

假设初始状态为：

x^(0)\hat{\mathbf{x}}^{(0)} x^(0)

第 1 步：计算理论观测值

根据 x^(0)\hat{\mathbf{x}}^{(0)}x^(0)，计算 P^s,(0)\hat{P}^{s,(0)}P^s,(0)

第 2 步：计算预拟合残差

vs=Ps−P^s,(0)v^s = P^s - \hat{P}^{s,(0)} vs=Ps−P^s,(0)

第 3 步：计算 LOS

es,(0)=rs−r^(0)ρ^s,(0)\mathbf{e}^{s,(0)} = \frac{\mathbf{r}^s - \hat{\mathbf{r}}^{(0)}}{\hat{\rho}^{s,(0)}} es,(0)=ρ^​s,(0)rs−r^(0)​

从而构造：

H(0)\mathbf{H}^{(0)} H(0)

第 4 步：求状态改正量

通过后续的最小二乘：

v(0)=H(0)Δx(0)\mathbf{v}^{(0)} = \mathbf{H}^{(0)}\Delta\mathbf x^{(0)} v(0)=H(0)Δx(0)

求得：

Δx(0)\Delta \mathbf x^{(0)} Δx(0)

第 5 步：更新状态

x^(1)=x^(0)+Δx(0)\hat{\mathbf x}^{(1)} = \hat{\mathbf x}^{(0)} + \Delta\mathbf x^{(0)} x^(1)=x^(0)+Δx(0)

第 6 步：再次线性化

用新的：

x^(1)\hat{\mathbf x}^{(1)} x^(1)

重新计算：

ρ,e,H,v\rho,\quad \mathbf{e},\quad \mathbf H,\quad \mathbf v ρ,e,H,v

再次求：

Δx(1)\Delta x^{(1)} Δx(1)

继续：

x^(2)=x^(1)+Δx(1)\hat{\mathbf x}^{(2)} = \hat{\mathbf x}^{(1)} + \Delta\mathbf x^{(1)} x^(2)=x^(1)+Δx(1)

直到：

∥Δx∥<ϵ\|\Delta\mathbf x\|\lt\epsilon ∥Δx∥<ϵ

认为收敛

残差概念区分

在求状态改正量之前有一个残差：

vpre=P−h(x^)\mathbf v_{\text{pre}} = \mathbf P - h(\hat{\mathbf{x}}) vpre​=P−h(x^)

这称为预拟合残差，或者 innovation、observed-minus-computed，它用于告诉我们：当前状态和观测之间还差多少

当我们求出本轮的 Δx^\Delta\hat{\mathbf x}Δx^，并且完成状态更新：

x^+=x^+Δx^\hat{\mathbf x}^+ = \hat{\mathbf{x}} + \Delta\hat{\mathbf x} x^+=x^+Δx^

以后，重新计算：

vpost=P−h(x^+)\mathbf{v}_{\text{post}} = \mathbf{P} - h(\hat{\mathbf{x}}^+) vpost​=P−h(x^+)

这称为后验残差

二者是两个不同的概念，通常我们期望：

∥vpost∥<∥vpre∥\|\mathbf v_{\text{post}}\|\lt\|\mathbf{v}_{\text{pre}}\| ∥vpost​∥<∥vpre​∥

但残差不可能全部变成零，因为观测是存在噪声的
