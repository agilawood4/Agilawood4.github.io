IMU 误差与 INS 漂移机理

这一讲我们解决一个核心问题：为什么 INS 在对 IMU 积分时，最后会越算越偏

在上一讲中我们已经知道，INS 的基本过程分为两步：

  1. ω→∫姿态\omega \xrightarrow{\int}\text{姿态}ω∫​姿态
  2. f→Cbna→∫v→∫p\mathbf f \xrightarrow{\mathbf C_b^n} \mathbf a\xrightarrow{\int}\mathbf{v}\xrightarrow{\int}\mathbf pfCbn​​a∫​v∫​p

问题就在于，IMU 的测量并非完全准确的，一旦这些微小误差进入积分，就会随着时间积累，最终形成漂移（Drift）

漂移 - Drift

漂移（Drift）是指导航结果随时间逐渐偏离真实值，而这种误差具有明显的积累性

漂移不是一个简单的固定偏差，而是随时间不断积累

IMU 的理想测量和实际测量

我们先建立基本的误差模型

对于陀螺仪：

ω~=ω+bg+ng\tilde\omega = \omega + \mathbf b_g + \mathbf n_g ω~=ω+bg​+ng​

其中，ω~\tilde\omegaω~ 为陀螺仪实际输出（测量值），ω\omegaω 为真实角速度（真实值），bg\mathbf b_gbg​ 为陀螺零偏，ng\mathbf n_gng​ 为陀螺随机噪声

对于加速度计：

f~=f+ba+na\tilde{\mathbf f} = \mathbf f + \mathbf b_a + \mathbf n_a f~=f+ba​+na​

其中，f~\tilde{\mathbf f}f~ 为加速度计实际输出（测量值），f\mathbf ff 为真实比力（真实值），ba\mathbf b_aba​ 为加速度计零偏，na\mathbf n_ana​ 为加速度计随机噪声

这是我们后续理解 INS 误差传播的基础

零偏 - Bias

零偏（Bias）指的是传感器即使在真实输入为零时，输出仍然存在一个偏离零的量比如当设备完全静止时，理论上陀螺仪应该输出 ω=0\omega = 0ω=0，但实际测量结果为 ω~=0.02°/s\tilde{\omega} = 0.02^°/sω~=0.02°/s，这就是一种陀螺零偏

陀螺零偏会被 INS 误认为是真实运动，比如对于真实 ω=0\omega = 0ω=0，如果测量 ω~=bg\tilde{\omega} = b_gω~=bg​，那么积分以后：

δθ(t)=∫0tbgdτ\delta\theta(t) = \int_0^t b_gd\tau δθ(t)=∫0t​bg​dτ

如果 bgb_gbg​ 近似于常数，那么：

δθ=bgt\delta\theta = b_g t δθ=bg​t

也就是说，由于陀螺零偏的存在，姿态误差会线性增长，对于角速度而言，即便是很小的偏差，经过一段时间积分后，也会形成明显的姿态误差

陀螺仪误差 vs. 加速度计误差

加速度计误差主要直接影响速度和位置，其传播链为：

ba→δv→δpb_a\to\delta v \to \delta p ba​→δv→δp

陀螺仪误差则首先影响姿态，再通过姿态影响加速度转换：

bg→δθ→δa→δv→δpb_g\to\delta\theta\to\delta a\to\delta v\to\delta p bg​→δθ→δa→δv→δp

因此，陀螺仪误差通常具有更强的间接传播效应

随机噪声 - Noise

噪声（Noise）指的是传感器输出中的随机波动

比如，尽管设备完全静止，陀螺仪连续输出可能是 0.01−0.020.005−0.01⋯0.01\quad-0.02\quad0.005\quad-0.01\quad\cdots0.01−0.020.005−0.01⋯ 这样一个序列，它不是一个固定值，而是在零附近随机波动，这就是随机噪声

白噪声 - White Noise

白噪声（White Noise）是一种理想的随机噪声模型，其特点为：不同时刻的噪声近似彼此独立，没有明显的长期相关性

白噪声通常记作 ng\mathbf n_gng​ 或 na\mathbf n_ana​，通常假设：

E[n]=0E[\mathbf n] = 0 E[n]=0

也就是从平均来看，白噪声均值为 0

尽管如此，由于积分的对象并不是平均值，而是每一时刻的随机测量，比如：

n1,n2,n3,…n_1,n_2,n_3,\dots n1​,n2​,n3​,…

虽然长期平均可能接近零，但积分以后：

∑knkΔt\sum_k n_k\Delta t k∑​nk​Δt

仍然会随机偏离零，这种累积过程称为随机游走（Random Walk）

随机游走 - Random Walk

随机游走（Random Walk）指的是，一个量在随机扰动作用下，一步一步积累变化

白噪声积分的结果，通常就是随机游走型误差

角度随机游走 - Angle Random Walk

对于陀螺仪而言，角度白噪声积分后会形成角度随机游走（Angle Random Walk，ARW），即由于陀螺角速度噪声而产生的姿态随机漂移

它不像固定 Bias 那样确定地朝某个方向增长，而是随机地越来越不确定

速度随机游走 - Velocity Random Walk

对于加速度计而言，速度白噪声积分后会形成速度随机游走（Velocity Random Walk，VRW）

其表现为速度估计的不确定性逐渐增大

零偏不稳定性

在前面的分析中，我们为了方便，把 Bias 当成是常数，但实际 IMU 中，Bias 也不完全是恒定的，而是存在一个低频、缓慢的变化

这种 Bias 现象称为零偏不稳定性（Bias Instability），也就是说，b(t)\mathbf b(t)b(t) 本身也会随时间而变化

注意，Bias 是一个变量，而 Bias Instability 是一种现象

一种常见的简化模型是：

b˙g=nωgb˙a=nωa\dot{\mathbf b}_g = \mathbf n_{\omega g}\\ \dot{\mathbf b}_a = \mathbf n_{\omega a} b˙g​=nωg​b˙a​=nωa​

其中，nωg\mathbf n_{\omega g}nωg​ 为陀螺 Bias 驱动噪声，bωa\mathbf b_{\omega a}bωa​ 为加速度计 Bias 驱动噪声

也就是说，Bias 本身也会在随机扰动作用下慢慢变化，所以 Bias 通常被建模为随机游走过程（Random Walk Process）

比例因子误差 - Scale Factor Error

比例因子误差（Scale Factor Error）指的是传感器输出对真实输入的放大比例不完全准确

比如真实角速度为 ω=100°/s\omega=100^°/sω=100°/s，但传感器因为比例因子误差输出 ω~=101°/s\tilde{\omega}=101^°/sω~=101°/s，相当于多了 1%1\%1%，可以写成：

ω~=(1+sg)ω\tilde{\omega} = (1 + s_g)\omega ω~=(1+sg​)ω

其中，sgs_gsg​ 就是比例因子误差

Scale Factor 会随着真实输入大小按比例产生误差，和 Bias 相比，前者更像是缩放，而后者更像是平移

轴不对准误差 - Misalignment

轴不对准误差（Misalignment）指的是 IMU 内部的三根测量轴并不是理想地完全正交，或者传感器实际轴与定义的 Body Frame 并不完全一致

理想情况下，xb,yb,zbx_b,y_b,z_bxb​,yb​,zb​ 应该严格相互垂直，而实际加工中可能存在微小偏差，就会导致形如 “本来只沿 xxx 轴的运动，会泄露一部分到 y,zy,zy,z 轴” 这样的误差

交叉轴敏感 - Cross-Axis Sensitivity

与 Misalignment 相关的一个概念是交叉轴敏感（Cross-Axis Sensitivity），即一个轴的输入会影响另一个轴的输出

比如实际只沿 xxx 轴运动：

ωx≠0\omega_x \ne 0 ωx​​=0

但因为传感器轴不理想，yyy 轴也可能出现：

ω~y≠0\tilde{\omega}_y \ne 0 ω~y​​=0

这种误差在高精度 IMU 中需要标定

温度漂移 - Temperature Drift

温度漂移（Temperature Drift）指的是 IMU 的 Bias、Scale Factor 等参数会随温度变化，即不同温度下对应的参数值不同

很多高精度 IMU 内部都会做温度补偿（Temperature Compensation）

IMU 误差分类

上面提到的所有误差可以分成两类

确定性误差 Deterministic Error

确定性误差即理论上可以通过标定进行补偿的误差，包括：

  • Bias
  • Scale Factor
  • Misalignment

随机误差 Stochastic Error

随机误差即具有随机性的误差，包括：

  • White Noise
  • Random Walk
  • Bias Instability

完整 IMU 测量模型

陀螺仪测量：

ω~=(I+Sg+Mg)ω+bg+ng\tilde{\omega} = (\mathbf I + \mathbf S_g + \mathbf M_g)\omega + \mathbf b_g + \mathbf n_g ω~=(I+Sg​+Mg​)ω+bg​+ng​

加速度计测量：

f~=(I+Sa+Ma)f+ba+na\tilde{\mathbf f} = (\mathbf I + \mathbf S_a + \mathbf M_a)\mathbf f + \mathbf b_a + \mathbf n_a f~=(I+Sa​+Ma​)f+ba​+na​

其中：

  • Sg,Sa\mathbf S_g,\mathbf S_aSg​,Sa​：Scale Factor Error，比例因子误差
  • Mg,Ma\mathbf M_g,\mathbf M_aMg​,Ma​：Misalignment，轴不对准误差
  • bg,ba\mathbf b_g,\mathbf b_abg​,ba​：Bias，零偏
  • ng,na\mathbf n_g,\mathbf n_ang​,na​：随机噪声

低成本的 MEMS IMU 之所以漂移特别快，就是因为 Bias、Noise 等较大且温漂明显

手机、手表、消费级无人机中绝大部分 IMU 都属于 MEMS IMU（微电机系统）

IMU 一般从低到高的等级为消费级、工业级、战术级、导航级，其差别就在于 Bias 稳定性、噪声水平、比例因子稳定性、温度稳定性等精度指标

高等级的 IMU 即使进行积分，也相对更能保持较高的导航精度

Yaw 漂移

Roll 和 Patch 再很多静止或低动态情况下，可以借助重力方向得到一定的约束，因为重力可以告诉我们竖直方向，这有助于对横滚和俯仰动作的判断

但是重力无法告诉我们北在哪里，因此仅靠加速度计通常无法直接约束 Yaw / Heading，所以纯 IMU 中航向通常特别容易漂

因此，很多系统中会加入磁力计、GNSS 信号等对航向提供相关约束

阿伦方差 - Allan Variance

阿伦方差（Allan Variance）是一种分析传感器误差特性的常用方法，其特别适用于 IMU

假设采集一段很长时间的静态 IMU 数据：

ω1,ω2,…,ωN\omega_1,\omega_2,\dots,\omega_N ω1​,ω2​,…,ωN​

然后选择一个时间长度 τ\tauτ，把数据按照长度 τ\tauτ 分成很多段，对每一段求平均，再比较相邻时间段的平均值之间的变化程度

据此我们可以研究：当观察尺度从很短变到很长时，传感器误差如何变化，最终得到 Allan Deviation 随 Average Time τ\tauτ 的变化曲线
