INS 导航原理与机械编排

本节我们解决：给定连续的 IMU 测量，INS 怎么逐步算出姿态、速度和位置

整个 INS 可以分为两部分：

  1. Gyroscope\text{Gyroscope}Gyroscope：姿态更新
  2. Accelerometer\text{Accelerometer}Accelerometer：坐标转换（位置与速度更新）

INS Mechanization

INS Mechanization，惯导机械编排 / 捷联惯导递推，指的是：根据当前时刻的 IMU 测量和上一时刻的导航状态，递推出下一时刻的位置、速度和姿态

这里所谓的 “机械编排” 不是机械结构，而是一套固定的导航递推方程

假设上一时刻 kkk 已知：

pk,vk,Cb,kn\mathbf p_k,\quad \mathbf v_k,\quad \mathbf C_{b,k}^n pk​,vk​,Cb,kn​

其中，pk\mathbf p_kpk​ 表示位置，vk\mathbf v_kvk​ 表示速度，Cb,kn\mathbf C_{b,k}^nCb,kn​ 表示姿态矩阵，即从 Body Frame 到 Navigation Frame 的旋转

IMU 在这一小段时间 Δt\Delta tΔt 内给出 fkb\mathbf f_k^bfkb​ 和 ωib,kb\omega_{ib,k}^bωib,kb​，而 INS 要计算：

pk+1,vk+1,Cb,k+1n\mathbf p_{k+1},\quad \mathbf v_{k+1},\quad \mathbf C_{b,k+1}^n pk+1​,vk+1​,Cb,k+1n​

所以本质上就是：

(pk,vk,Ck)+(fk,ωk)→(pk+1,vk+1,Ck+1)(\mathbf p_k,\mathbf v_k,\mathbf C_k) + (\mathbf f_k,\mathbf \omega_k) \to (\mathbf p_{k+1},\mathbf v_{k+1},\mathbf C_{k+1}) (pk​,vk​,Ck​)+(fk​,ωk​)→(pk+1​,vk+1​,Ck+1​)

Strapdown INS

现代绝大多数 IMU 使用的是捷联惯导系统（Strapdown Inertial Navigation System，SINS），其中所谓 “捷联” 指的是 IMU 直接固定在载体上，因此 IMU 的坐标轴会跟随载体一起旋转

也就是说，加速度计一直测的是 fb\mathbf f^bfb，而我们真正需要的是 fn\mathbf f^nfn，所以需要不断计算姿态 Cbn\mathbf C_b^nCbn​，才能完成：

fb→fn\mathbf f^b\to\mathbf f^n fb→fn

所以我们说 INS 解算的第一步一定是姿态更新

INS 必须有初始值

INS 属于航位推算，所以不能凭空开始，必须知道初始的：

p0,v0,Cb,0n\mathbf p_0,\quad \mathbf v_0,\quad \mathbf C_{b,0}^n p0​,v0​,Cb,0n​

也就是初始位置、初始速度和初始姿态

换言之，如果一开始连初始朝向都不知道，那么即便加速度计测到运动状态，也不知道要将其叠加到什么方向，所以我们说：

INS=初始状态 + 连续 IMU 递推\text{INS} = \text{初始状态 } + \text{ 连续 IMU 递推} INS=初始状态 + 连续 IMU 递推

Step1：姿态更新

姿态更新使用的是陀螺仪，其测量：

ωinb=[ωxωyωz]\omega_{in}^b = \begin{bmatrix} \omega_x\\\omega_y\\\omega_z\\ \end{bmatrix} ωinb​=⎣⎢⎡​ωx​ωy​ωz​​⎦⎥⎤​

表示载体本身（bbb 系）相对于惯性空间（iii 系）的角速度，在 bbb 系中表达

角速度 → 角增量

假设在很短的一段时间 Δt\Delta tΔt 内，角速度近似不变，那么旋转角增量：

Δθ≈ωΔt\Delta\theta\approx\omega\Delta t Δθ≈ωΔt

也就是告诉 INS，在当前一小段时间内，载体本身转动了多少

二维姿态积分

假设当前航向为 ψk\psi_kψk​，角速度为 ωz\omega_zωz​，则：

ψk+1=ψk+ωzΔt\psi_{k+1} = \psi_k + \omega_z\Delta t ψk+1​=ψk​+ωz​Δt

如果写成连续形式就是：

ψ(t)=ψ(0)+∫0tωz(τ)dτ\psi(t) = \psi(0) + \int_0^t\omega_z(\tau)d\tau ψ(t)=ψ(0)+∫0t​ωz​(τ)dτ

三维姿态的情况思想完全相同，只不过 Roll，Pitch，Yaw 之间存在耦合，不能简单地对三个角各自积分，所以工程上通常使用旋转矩阵或四元数进行姿态递推

旋转矩阵更新姿态

对于三维向量：

a=[axayaz]\mathbf a = \begin{bmatrix} a_x\\a_y\\a_z\\ \end{bmatrix} a=⎣⎢⎡​ax​ay​az​​⎦⎥⎤​

定义它的反对称矩阵（Skew-Symmetric Matrix）为：

[a×]=[0−azayaz0−ax−ayax0][\mathbf a\times] = \begin{bmatrix} 0 & -a_z & a_y\\a_z & 0 & -a_x\\-a_y & a_x & 0\\ \end{bmatrix} [a×]=⎣⎢⎡​0az​−ay​​−az​0ax​​ay​−ax​0​⎦⎥⎤​

它满足：

[a×]b=a×b[\mathbf a\times]\mathbf b = a\times b [a×]b=a×b

也就是用反对称矩阵的点乘来表示原向量的叉乘

姿态微分方程

最常用的一种表达是：

Cbn˙=Cbn[ωibb×]−[ωinn×]Cbn\dot{\mathbf C_b^n} = \mathbf C_b^n[\omega_{ib}^b\times] - [\omega_{in}^n\times]\mathbf C_b^n Cbn​˙​=Cbn​[ωibb​×]−[ωinn​×]Cbn​

这里第一次出现了 ωinn\omega_{in}^nωinn​ 的概念，它表示导航坐标系 nnn 相对于惯性坐标系 iii 的旋转角速度在导航坐标系中的表示

因为地球在自转，而载体在地球表面移动，所以局部的 ENU / NED 坐标系也会跟着位置改变，所以姿态更新不仅要考虑载体本身转动多少，还要考虑导航参考系转动多少

ωinn\omega_{in}^nωinn​ 的组成

通常有：

ωinn=ωien+ωenn\omega_{in}^n = \omega_{ie}^n + \omega_{en}^n ωinn​=ωien​+ωenn​

其中，ωien\omega_{ie}^nωien​ 为地球自转角速度，即地球坐标系相对于惯性空间的旋转，而 ωenn\omega_{en}^nωenn​ 为运输角速度，即载体在地球曲面上移动时，局部导航坐标系相对于地球坐标系的旋转

离散姿态更新

在工程中，每个 IMU 周期做的是离散更新

如果忽略非常小的高阶项，可以理解为：

Cb,k+1n≈Cb,knExp([Δθ×])\mathbf C_{b,k+1}^n\approx\mathbf C_{b,k}^n\text{Exp}([\Delta\theta\times]) Cb,k+1n​≈Cb,kn​Exp([Δθ×])

其中：

Δθ≈ωΔt\Delta\theta\approx\omega\Delta t Δθ≈ωΔt

这里的 Exp(⋅)\text{Exp}(\cdot)Exp(⋅) 叫做指数映射（Exponential Map），它的作用可以简单理解成：把一个很小的旋转向量变成一个真正的三维旋转矩阵

四元数姿态更新

现实实现中，经常还使用四元数 qbn\mathbf q_b^nqbn​，假设一小段旋转 Δθ\Delta\thetaΔθ 对应的增量四元数为 δq\delta\mathbf qδq，则有;

qk+1=qk⊗δq\mathbf q_{k+1} = \mathbf q_k\otimes\delta\mathbf q qk+1​=qk​⊗δq

其中，⊗\otimes⊗ 表示四元数乘法，其表示把原来的姿态和这一小段新旋转组合起来，所以无论是旋转矩阵还是四元数，核心都是根据当前姿态，结合陀螺仪角增量，推断得到新姿态

姿态更新的作用

加速度计输出的是载体坐标系中的比力 fb\mathbf f^bfb，但导航需要的速度是导航坐标系中的 vn\mathbf v^nvn（比如 ENU 坐标系）

在得到转换矩阵后，首先要进行：

fn=Cbnfb\mathbf f^n = \mathbf C_b^n\mathbf f^b fn=Cbn​fb

这一步叫做比力坐标转换（Specific Force Transformation）

Step2 - 速度更新

上一章我们已经知道：

f=a−g\mathbf f = \mathbf a - \mathbf g f=a−g

所以：

a=f+g\mathbf a = \mathbf f + \mathbf g a=f+g

如果忽略地球旋转，那么最简单的形式就是：

an=Cbnfb+gn\mathbf a^n = \mathbf C_b^n\mathbf f^b + \mathbf g^n an=Cbn​fb+gn

其中，Cbn\mathbf C_b^nCbn​ 把 IMU 比力转到导航坐标系，gn\mathbf g^ngn 为重力

接着对加速度做积分：

v(t)=v(0)+∫0tan(τ)dτ\mathbf v(t) = \mathbf v(0) + \int_0^t \mathbf a^n(\tau)d\tau v(t)=v(0)+∫0t​an(τ)dτ

如果做离散速度更新，则为：

vk+1≈vk+aknΔt\mathbf v_{k+1}\approx\mathbf v_k + \mathbf a_k^n\Delta t vk+1​≈vk​+akn​Δt

实际 INS 完整速度方程

在地球上导航时，实际还要考虑地球的旋转

经典速度微分方程为：

v˙n=Cbnfb+gn−(2ωien+ωenn)×vn\mathbf {\dot v}^n = \mathbf C_b^n\mathbf f^b + \mathbf g^n - (2\omega_{ie}^n + \omega_{en}^n)\times \mathbf v^n v˙n=Cbn​fb+gn−(2ωien​+ωenn​)×vn

第一项 Cbnfb\mathbf C_b^n\mathbf f^bCbn​fb 表示把 IMU 测得的比力从载体坐标系（bbb 系）转换到导航坐标系（nnn 系）

第二项 gn\mathbf g^ngn 表示重力加速度，补偿重力

第三项 −2ωien×vn-2\omega_{ie}^n\times\mathbf v^n−2ωien​×vn 为科氏加速度，补偿地球自转

所谓科氏效应，即我们在使用随地球旋转的参考坐标系时，如果物体在旋转坐标系中运动，会表额外出现一个表观加速度

第四项 −ωenn×vn-\omega_{en}^n\times\mathbf v^n−ωenn​×vn 为运输角速度，补偿导航系旋转

局部导航坐标系随载体在地球表面移动，本身也在变化

Step3 - 位置更新

有了速度 v\mathbf vv 以后，位置自然满足：

p˙=v\mathbf{\dot p} =\mathbf v p˙​=v

最直观的笛卡尔坐标形式：

p(t)=p(0)+∫0tv(τ)dτ\mathbf p(t) = \mathbf p(0) + \int_0^t\mathbf v(\tau)d\tau p(t)=p(0)+∫0t​v(τ)dτ

写成离散形式为：

pk+1≈pk+vkΔt\mathbf p_{k+1}\approx\mathbf p_k + \mathbf v_k\Delta t pk+1​≈pk​+vk​Δt

位置转换公式

速度通常使用 NED 坐标系，即：

vn=[vNvEvD]\mathbf v^n = \begin{bmatrix} v_N\\v_E\\v_D\\ \end{bmatrix} vn=⎣⎢⎡​vN​vE​vD​​⎦⎥⎤​

而位置通常使用经纬高坐标系，即：

ϕ,λ,h\phi,\quad\lambda,\quad h ϕ,λ,h

依次表示纬度，经度，高度

从 NED 坐标系的速度得到经纬高坐标系的位置，有固定现成的公式，我们直接套用即可：

φ˙=vNRM+hλ˙=vE(RN+h)cos⁡φh˙=−vD\dot{\varphi} = \frac{v_N}{R_M + h}\\ \dot{\lambda} = \frac{v_E}{(R_N + h)\cos\varphi}\\ \dot{h} = -v_D φ˙​=RM​+hvN​​λ˙=(RN​+h)cosφvE​​h˙=−vD​

其中，hhh 即表示高度，RMR_MRM​ 为子午圆曲率半径，RNR_NRN​ 为卯酉圆曲率半径，其大致对应关系为：

  • 北向速度，主要影响纬度变化
  • 东向速度，主要影响经度变化
  • 地向速度，主要影响高度变化

三组核心方程

姿态更新方程

Cbn˙=Cbn[ωibb×]−[ωinn×]Cbn\dot{\mathbf C_b^n} = \mathbf C_b^n[\omega_{ib}^b\times] - [\omega_{in}^n\times]\mathbf C_b^n Cbn​˙​=Cbn​[ωibb​×]−[ωinn​×]Cbn​

速度更新方程

v˙n=Cbnfb+gn−(2ωien+ωenn)×vn\mathbf {\dot v}^n = \mathbf C_b^n\mathbf f^b + \mathbf g^n - (2\omega_{ie}^n + \omega_{en}^n)\times \mathbf v^n v˙n=Cbn​fb+gn−(2ωien​+ωenn​)×vn

位置转换方程

φ˙=vNRM+hλ˙=vE(RN+h)cos⁡φh˙=−vD\dot{\varphi} = \frac{v_N}{R_M + h}\\ \dot{\lambda} = \frac{v_E}{(R_N + h)\cos\varphi}\\ \dot{h} = -v_D φ˙​=RM​+hvN​​λ˙=(RN​+h)cosφvE​​h˙=−vD​
