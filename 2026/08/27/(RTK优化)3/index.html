载波相位平滑伪距 - Hatch Filter

本节主要讲解用载波相位提供历元间距离变化，用伪距提供绝对距离基准，最终得到噪声更小的平滑伪距：

Pk→PˉkP_k\to\bar{P}_k Pk​→Pˉk​

因此，Hatch Filter 本质上属于对观测值 zzz 的改善，而不是直接修改 Kalman Filter 中的 P,K,QP,K,QP,K,Q 或状态

问题背景

伪距 PPP 能够直接提供卫星到接收机的绝对距离，但噪声较大，载波相位 Φ\PhiΦ 精度非常高，但存在未知的整数模糊度 NNN，因此不能直接把 λΦ\lambda\PhiλΦ 当做绝对距离

Hatch Filter 的核心思想为：我们不需要知道载波相位的绝对距离，只利用它在相邻历元之间变化了多少

因为只要不存在周跳，则：

Nk=Nk−1N_k = N_{k-1} Nk​=Nk−1​

相邻历元之间作差时：

λNk−λNk−1=0\lambda N_k - \lambda N_{k-1} = 0 λNk​−λNk−1​=0

模糊度自然会消失

原始 GNSS 观测模型

先把载波相位换算成以米为单位：

Lk=λΦkL_k = \lambda\Phi_k Lk​=λΦk​

为了突出 Hatch Filter 的核心，我们仅保留主要项：

  • 伪距观测 Pk=ρk+bk+Tk+Ik+εP,kP_k = \rho_k + b_k + T_k + I_k + \varepsilon_{P,k}Pk​=ρk​+bk​+Tk​+Ik​+εP,k​
  • 载波相位观测：Lk=ρk+bk+Tk−Ik+λN+εL,kL_k = \rho_k + b_k + T_k - I_k + \lambda N + \varepsilon_{L,k}Lk​=ρk​+bk​+Tk​−Ik​+λN+εL,k​

其中：

  • PkP_kPk​：第 kkk 历元的伪距
  • LkL_kLk​：载波相位距离
  • ρk\rho_kρk​：几何距离
  • bkb_kbk​：卫星钟、接收机钟等公共项的合并表示
  • TkT_kTk​：对流层延迟
  • IkI_kIk​：电离层延迟
  • NNN：整数模糊度
  • εP\varepsilon_PεP​：伪距测量噪声
  • εL\varepsilon_LεL​：载波测量噪声

通常满足 σP2≫σL2\sigma_P^2\gg\sigma_L^2σP2​≫σL2​，所以载波能更精确的描述短时间运动

为什么载波历元差可用

相邻两个历元之间：

Lk=ρk+bk+Tk−Ik+λN+εL,kLk−1=ρk−1+bk−1+Tk−1−Ik−1+λN+εL,k−1L_k = \rho_k + b_k + T_k - I_k + \lambda N + \varepsilon_{L,k}\\ L_{k-1} = \rho_{k-1} + b_{k-1} + T_{k-1} - I_{k-1} + \lambda N + \varepsilon_{L,k-1} Lk​=ρk​+bk​+Tk​−Ik​+λN+εL,k​Lk−1​=ρk−1​+bk−1​+Tk−1​−Ik−1​+λN+εL,k−1​

二者相减：

ΔLk=Lk−Lk−1\Delta L_k = L_k - L_{k-1} ΔLk​=Lk​−Lk−1​

得到：

ΔLk=Δρk+Δbk+ΔTk−ΔIk+ΔεL\Delta L_{k} = \Delta \rho_k + \Delta b_k + \Delta T_k - \Delta I_k + \Delta \varepsilon_L ΔLk​=Δρk​+Δbk​+ΔTk​−ΔIk​+ΔεL​

关键在于，只要相邻两个历元之间不存在周跳，λN\lambda NλN 就会被消掉

而如果在很短时间内忽略电离层变化，则：

ΔIk≈0\Delta I_k\approx 0 ΔIk​≈0

那么即满足，ΔLk\Delta L_kΔLk​ 就表示真实距离以及公共误差在相邻历元间的变化

因此我们可以用：

Pˉk−1+ΔLk\bar{P}_{k-1} + \Delta L_k Pˉk−1​+ΔLk​

来预测第 kkk 历元的伪距

Hatch Filter 核心递推公式

先定义一个由载波预测得到的伪距：

Pk∣k−1pred=Pˉk−1+Lk−Lk−1P_{k\mid k-1}^{\text{pred}} = \bar{P}_{k-1} + L_k - L_{k-1} Pk∣k−1pred​=Pˉk−1​+Lk​−Lk−1​

该表示的含义为：上一历元已经得到一个平滑伪距 barPk−1bar{P}_{k-1}barPk−1​，载波告诉我们从 k−1k-1k−1 到 kkk 距离变化了 Lk−Lk−1L_k - L_{k-1}Lk​−Lk−1​，所以当前伪距应该大约变化到：

Pˉk−1+(Lk−Lk−1)\bar{P}_{k-1} + (L_k - L_{k-1}) Pˉk−1​+(Lk​−Lk−1​)

但这个预测不能无限相信，因为载波可能也会存在周跳、电离层变化、小量相位噪声等误差，因此还需要利用当前原始伪距 PkP_kPk​ 去修正

定义：

mk=min⁡(k,M)m_k = \min(k,M) mk​=min(k,M)

其中，MMM 为设定的平滑长度

Hatch Filter 最核心的伪距更新公式为：

Pˉk=1mkPk+mk−1mk[Pˉk−1+Lk−Lk−1]\bar{P}_k = \frac{1}{m_k}P_k + \frac{m_k - 1}{m_k}[\bar{P}_{k-1} + L_k - L_{k-1}] Pˉk​=mk​1​Pk​+mk​mk​−1​[Pˉk−1​+Lk​−Lk−1​]

公式推导

我们先看 Pk−LkP_k-L_kPk​−Lk​，由于载波中比较难确定的是 λN\lambda NλN，但是如果单看某个时刻的 P−LP-LP−L，此时这个模糊度 NNN 是一个基本固定不变的常数（只要确保连续跟踪），也就是退化成了一个静态偏置 Bias

定义：

Dk=Pk−LkD_k = P_k - L_k Dk​=Pk​−Lk​

对这个量做平均

如果目前已经积累到了 mkm_kmk​ 个历元，写成递推形式为：

Dˉk=1mkDk+mk−1mlDˉk−1\bar{D}_k = \frac{1}{m_k}D_k + \frac{m_k - 1}{m_l}\bar{D}_{k-1} Dˉk​=mk​1​Dk​+ml​mk​−1​Dˉk−1​

代入 Dk,Dˉk−1D_k,\bar D_{k-1}Dk​,Dˉk−1​ 即：

Dk=Pk−LkDˉk−1=Pˉk−1−Lk−1D_k = P_k - L_k\\\bar D_{k-1} = \bar P_{k-1} - L_{k-1} Dk​=Pk​−Lk​Dˉk−1​=Pˉk−1​−Lk−1​

因此则有：

Dˉk=1mk(Pk−Lk)+mk−1mk(Pˉk−1−Lk−1)\bar D_k = \frac{1}{m_k}(P_k - L_k) + \frac{m_k - 1}{m_k}(\bar P_{k-1} - L_{k-1}) Dˉk​=mk​1​(Pk​−Lk​)+mk​mk​−1​(Pˉk−1​−Lk−1​)

再代入 Pˉk=Dˉk+Lk\bar P_k = \bar D_k + L_kPˉk​=Dˉk​+Lk​：

Pˉk=Lk+1mk(Pk−Lk)+mk−1mk(Pˉk−1−Lk−1)\bar P_k = L_k + \frac{1}{m_k}(P_k - L_k) + \frac{m_k-1}{m_k}(\bar P_{k-1} - L_{k-1}) Pˉk​=Lk​+mk​1​(Pk​−Lk​)+mk​mk​−1​(Pˉk−1​−Lk−1​)

展开则有：

Pˉk=1mkPk+mk−1mk(Pˉk−1+Lk−Lk−1)\bar P_k = \frac{1}{m_k}P_k + \frac{m_k-1}{m_k}(\bar P_{k-1} + L_k - L_{k-1}) Pˉk​=mk​1​Pk​+mk​mk​−1​(Pˉk−1​+Lk​−Lk−1​)

这就是上面我们给出的 Hatch 递推公式

平滑窗口 MMM

初始化时，m1=1m_1 = 1m1​=1，即 Pˉ1=P1\bar P_1 = P_1Pˉ1​=P1​，并没有任何平滑

对于第二个历元，m2=2m_2 = 2m2​=2，于是有：

Pˉ2=12P2+12(Pˉ1+ΔL2)\bar P_2 = \frac{1}{2}P_2 + \frac{1}{2}(\bar P_1 + \Delta L_2) Pˉ2​=21​P2​+21​(Pˉ1​+ΔL2​)

随着历元数量的增加：

mk=1,2,3,…,Mm_k = 1,2,3,\dots,M mk​=1,2,3,…,M

当达到 mk=Mm_k = Mmk​=M 以后，历元数再增加，mkm_kmk​ 也都保持 MMM 不变了，于是之后恒有：

Pˉk=1MPk+M−1M(Pˉk−1+ΔLk)\bar P_k = \frac{1}{M}P_k + \frac{M-1}{M}(\bar P_{k-1} + \Delta L_k) Pˉk​=M1​Pk​+MM−1​(Pˉk−1​+ΔLk​)

这里，MMM 表示原始伪距的占比，MMM 越大，表示原始伪距占比越小，同时过去的平滑结果和载波的变化占比越大

换言之，MMM 的增加表示对伪距噪声的抑制更强，但代价是周跳、电离层变化等异常影响的持续更久

对噪声的降低

在启动阶段，m=km=km=k，可以把 Hatch Filter 写成：

Pˉk=Lk+1k∑i=1k(Pi−Li)\bar P_k = L_k + \frac{1}{k}\sum_{i=1}^k(P_i - L_i) Pˉk​=Lk​+k1​i=1∑k​(Pi​−Li​)

在启动阶段（前 kkk 个历元），最直观的做法是对 P−LP-LP−L 偏移量求算术平均，然后加到当前历元的载波相位 LkL_kLk​ 上，即用前 kkk 次观测的 P−LP-LP−L 平均值来估计当前的模糊度偏移，从而把 LkL_kLk​ 还原成伪距

只分析随机噪声部分：

εˉP,k=εL,k+1k∑i=1k(εP,i−εL,i)\bar \varepsilon_{P,k} = \varepsilon_{L,k} + \frac{1}{k}\sum_{i=1}^k(\varepsilon_{P,i} - \varepsilon_{L,i}) εˉP,k​=εL,k​+k1​i=1∑k​(εP,i​−εL,i​)

做如下假设：

  1. 不同历元的噪声独立
  2. 伪距（code）和载波相位（phase）的噪声独立
  3. 每历元的伪距方差均为 σP2\sigma_P^2σP2​，每历元的载波方差均为 σL2\sigma_L^2σL2​

代入上述噪声公式则有：

Var(εˉP,k)=Var(εL,k)+1k2∑i=1k(Var(εP,i)−Var(εL,i))\text{Var}(\bar \varepsilon_{P,k}) = \text{Var}(\varepsilon_{L,k}) + \frac{1}{k^2}\sum_{i=1}^k(\text{Var}(\varepsilon_{P,i}) - \text{Var}(\varepsilon_{L,i})) Var(εˉP,k​)=Var(εL,k​)+k21​i=1∑k​(Var(εP,i​)−Var(εL,i​))

因为假定不同历元之间，相同历元的载波和伪距噪声都独立，因此所有协方差项均为 0，进一步代入则有：

Var(εˉP,k)=σL2+1k2⋅k⋅(σP2−σL2=σP2k+k−1kσL2\text{Var}(\bar\varepsilon_{P,k}) = \sigma_L^2 + \frac{1}{k^2}\cdot k\cdot(\sigma_P^2 - \sigma_L^2 = \frac{\sigma_P^2}{k} + \frac{k-1}{k}\sigma_L^2 Var(εˉP,k​)=σL2​+k21​⋅k⋅(σP2​−σL2​=kσP2​​+kk−1​σL2​

而在 GNSS 观测中，有一个重要假设为：真实信号被视为非随机常数，总方差由随机噪声主导

因此则有：

Var(Pˉk)=Var(εˉP,k)\text{Var}(\bar P_k) = \text{Var}(\bar\varepsilon_{P,k}) Var(Pˉk​)=Var(εˉP,k​)

最终整理得到：

Var(Pˉk)=σP2k+k−1kσL2\text{Var}(\bar P_k) = \frac{\sigma_P^2}{k} + \frac{k-1}{k}\sigma_L^2 Var(Pˉk​)=kσP2​​+kk−1​σL2​

由于 σL2≪σP2\sigma_L^2\ll\sigma_P^2σL2​≪σP2​，前期近似有：

σPˉ≈σPk\sigma_{\bar P}\approx\frac{\sigma_P}{\sqrt k} σPˉ​≈k​σP​​

例如，原始的伪距标准差为 σP=2m\sigma_P = 2mσP​=2m，如果平滑 100100100 个历元，则有：

σPˉ≈2100=0.2m\sigma_{\bar P} \approx \frac{2}{\sqrt 100} = 0.2m σPˉ​≈1​002​=0.2m

理想情况下可以显著降低伪距白噪声，但随着窗口长度增加，最终不会无限趋近于 0，因为还有 σL\sigma_LσL​ 的存在，以及真实环境中的 Multipath、Ionosphere divergence（电离层发散效应）等误差

Hatch Filter 短板

周跳污染

假设第 kkk 历元发生周跳：

Nk=Nk−1+ΔNN_k = N_{k-1} + \Delta N Nk​=Nk−1​+ΔN

那么，Lk−Lk−1L_k - L_{k-1}Lk​−Lk−1​ 中就会出现 λΔN\lambda\Delta NλΔN，即：

ΔLk=ΔLktrue+λΔN\Delta L_k = \Delta L_k^{\text{true}} + \lambda \Delta N ΔLk​=ΔLktrue​+λΔN

Hatch 预测：

Pkpred=Pˉk−1+ΔLkP_k^{\text{pred}} = \bar{P}_{k-1} + \Delta L_k Pkpred​=Pˉk−1​+ΔLk​

中会直接多出 λΔN\lambda \Delta NλΔN 这一项，而且因为递归存在记忆，错误的 Pˉk\bar P_kPˉk​ 又会作为参与到下一历元的计算，因此周跳不仅污染一个历元，而是会污染后续所有的平滑状态

因此只要确认发生周跳（cycle slip）以后，通常必须：

Pˉk=Pk\bar P_k = P_k Pˉk​=Pk​

并且恢复：

mk=1m_k = 1 mk​=1

重新开始平滑

同理，当发生失锁、长时间数据中断、频点切换导致载波连续性破坏时，也应该做重置（reset）

Code-Carrier Divergence

伪距：

Pk=Gk+Ik+εPP_k = G_k + I_k + \varepsilon_P Pk​=Gk​+Ik​+εP​

载波：

Lk=Gk−Ik+λN+εLL_k = G_k - I_k + \lambda N + \varepsilon_L Lk​=Gk​−Ik​+λN+εL​

这里我们把几何、钟差、对流层等公共项统一写成 GkG_kGk​，因此则有：

Pk−Lk=2Ik−λN++εP−εLP_k - L_k = 2I_k - \lambda N + + \varepsilon_P - \varepsilon_L Pk​−Lk​=2Ik​−λN++εP​−εL​

由此可知，Pk−LkP_k - L_kPk​−Lk​ 其实并不严格为常数，因为电离层 IkI_kIk​ 会随时间变化，相邻历元真实伪距变化为：

ΔP=ΔG+ΔI\Delta P = \Delta G + \Delta I ΔP=ΔG+ΔI

而真实载波变化为：

ΔL=ΔG−ΔI\Delta L = \Delta G - \Delta I ΔL=ΔG−ΔI

二者作差则有：

ΔP−ΔL=2ΔI\Delta P - \Delta L = 2\Delta I ΔP−ΔL=2ΔI

也就是说，Hatch Filter 用 ΔL\Delta LΔL 去预测伪距变化，但真实伪距变化需要的是 ΔG+ΔI\Delta G + \Delta IΔG+ΔI，而载波给出的却是 ΔG−ΔI\Delta G - \Delta IΔG−ΔI，因此每一次更新，都会引入 2ΔI2\Delta I2ΔI 的误差

随着窗口变长，电离层变化积累越明显，就会产生码相发散（Code-Carrier Divergence），也就是所谓的平滑发散（smoothing divergence）

这也变相说明，平滑窗口长度 MMM 不能无限增加

Divergence-Free Hatch Filter

双频观测可以估计电离层变化，从而修正刚才的 2ΔH2\Delta H2ΔH

假设两个频率 f1,f2f_1,f_2f1​,f2​，电离层延迟满足：

If∝1f2I_f∝ \frac{1}{f^2} If​∝f21​

我们令：

γ=f12f22\gamma = \frac{f_1^2}{f_2^2} γ=f22​f12​​

则：

I2=γI1I_2 = \gamma I_1 I2​=γI1​

双频对应的载波分别为：

L1=G−I1+λ1N1L2=G−I2+λ2N2L_1 = G - I_1 + \lambda_1 N_1\\ L_2 = G - I_2 + \lambda_2 N_2 L1​=G−I1​+λ1​N1​L2​=G−I2​+λ2​N2​

做频间差分 geometry-free combination：

L1−L2=−I1+I2+λ1N1−λ2N2L_1 - L_2 = -I_1 + I_2 + \lambda_1 N_1 - \lambda_2 N_2 L1​−L2​=−I1​+I2​+λ1​N1​−λ2​N2​

即;

L1−L2=(γ−1)I1+constant ambiguityL_1 - L_2 = (\gamma - 1)I_1 + \text{constant ambiguity} L1​−L2​=(γ−1)I1​+constant ambiguity

相邻历元之间作差，模糊度常数被抵消：

Δ(L1−L2)=(γ−1)ΔI1\Delta (L_1 - L_2) = (\gamma - 1)\Delta I_1 Δ(L1​−L2​)=(γ−1)ΔI1​

于是：

ΔI1=Δ(L1−L2)γ−1\Delta I_1 = \frac{\Delta(L_1 - L_2)}{\gamma - 1} ΔI1​=γ−1Δ(L1​−L2​)​

前面已经知道，要想让 carrier increment 和 code increment 一致，需要补偿 2ΔI12\Delta I_12ΔI1​，所以构造：

ΔL1DF=ΔL1+2ΔI1\Delta L_1^{DF} = \Delta L_1 + 2 \Delta I_1 ΔL1DF​=ΔL1​+2ΔI1​

代入则有：

ΔL1DF=ΔL1+2γ−1Δ(L1−L2)\Delta L_1^{DF} = \Delta L_1 + \frac{2}{\gamma - 1}\Delta(L_1 - L_2) ΔL1DF​=ΔL1​+γ−12​Δ(L1​−L2​)

然后把原本 Hatch 中的 Lk−Lk−1L_k - L_{k-1}Lk​−Lk−1​ 换成 ΔLkDF\Delta L_k^{DF}ΔLkDF​，即：

Pˉk=1mkPk+mk−1mk(Pˉk−1+ΔL1+2γ−1Δ(L1−L2))\bar P_k = \frac{1}{m_k}P_k + \frac{m_k - 1}{m_k}(\bar P_{k-1} + \Delta L_1 + \frac{2}{\gamma - 1}\Delta (L_1 - L_2)) Pˉk​=mk​1​Pk​+mk​mk​−1​(Pˉk−1​+ΔL1​+γ−12​Δ(L1​−L2​))

这样可以明显削弱电离层所导致的平滑发散（smoothing divergence）

相应引入的代价也很明确，组合多个载波以后，会把第二频点的相位噪声一并引入，因此噪声会有一定的放大，而且此时必须同时保证，两个频点的载波都连续无周跳才可以
