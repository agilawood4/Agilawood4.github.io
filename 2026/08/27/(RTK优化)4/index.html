多普勒平滑伪距与 Doppler 辅助 RTK

这一讲主要解决三个问题：

  1. 如何用 Doppler 平滑伪距
  2. Doppler 如何辅助速度和状态预测
  3. Doppler 如何辅助检查载波连续性

问题背景

在上一讲中，Hatch Filter 用 Lk−Lk−1L_k - L_{k-1}Lk​−Lk−1​ 估计相邻历元之间的距离变化，它的优点是精度非常高，但要求 Nk=Nk−1N_k = N_{k-1}Nk​=Nk−1​

一旦历元间发生周跳，Lk−Lk−1L_k - L_{k-1}Lk​−Lk−1​ 就会多出 λΔN\lambda \Delta NλΔN，从而污染平滑伪距

Doppler 提供了另一种历元间的变化信息，即距离变化率，因此可以用 Doppler 得到距离变化率，进而对时间积分得到历元间距离变化，再去平滑伪距

需要说明的是，Doppler Smoothing 不是先根据 Doppler 算出接收机的三维位置移动了多少，再拿这个位置变化更新位距，它直接得到的就是接收机与某颗卫星之间的视线距离变化

每颗卫星都有自己的 Doppler 和自己的 range increment

原始 RTK 模型

载波相位模型

把载波相位以米为单位表示：

L=λΦL = \lambda\Phi L=λΦ

则：

L=ρ+c(δtr−δts)+T−I+λN+εLL = \rho +c(\delta t_r - \delta t_s) + T - I + \lambda N + \varepsilon_L L=ρ+c(δtr​−δts​)+T−I+λN+εL​

其中：

  • ρ\rhoρ：卫星 - 接收机几何距离
  • δtr,δts\delta t_r,\delta t_sδtr​,δts​：接收机、卫星钟差
  • TTT：对流层
  • III：电离层
  • NNN：整数模糊度
  • λ\lambdaλ：载波波长

载波相位对时间求导

在没有周跳的连续跟踪阶段，N=constantN = \text{constant}N=constant，即整数模糊度不会发生变化，因此：

d(λN)dt=0\frac{d(\lambda N)}{dt} = 0 dtd(λN)​=0

载波相位对时间求导得到：

L˙=ρ˙+c(δ˙tr−δ˙ts)+T˙−I˙+ε˙L\dot L = \dot\rho + c(\dot\delta t_r - \dot\delta t_s) + \dot T - \dot I + \dot\varepsilon_L L˙=ρ˙​+c(δ˙tr​−δ˙ts​)+T˙−I˙+ε˙L​

Doppler 本质上就是载波相位随时间变化的速率，很多 GNSS 接收机都定义：

D=−L˙λD = -\frac{\dot L}{\lambda} D=−λL˙​

因此则满足：

−λD≈ρ˙+c(δ˙tr−δ˙ts)+T˙−I˙-\lambda D \approx\dot\rho + c(\dot\delta t_r - \dot\delta t_s) + \dot T - \dot I −λD≈ρ˙​+c(δ˙tr​−δ˙ts​)+T˙−I˙

在简化情况下，常写为：

ρ˙≈−λD\dot\rho \approx -\lambda D ρ˙​≈−λD

核心原理：Doppler → 历元间距离变化

假设相邻历元分别对应时刻 tk−1,tkt_{k-1},t_ktk−1​,tk​，二者时间间隔为：

Δt=tk−tk−1\Delta t = t_k - t_{k-1} Δt=tk​−tk−1​

已知：

L˙(t)≈−λD(t)\dot L(t) \approx -\lambda D(t) L˙(t)≈−λD(t)

因此积分：

Lk−Lk−1=∫tk−1tkL˙(t)dtL_k - L_{k-1} = \int_{t_{k-1}}^{t_k}\dot L(t)dt Lk​−Lk−1​=∫tk−1​tk​​L˙(t)dt

于是：

ΔLD,K=−λ∫tk−1tkD(t)dt\Delta L_{D,K} = -\lambda\int_{t_{k-1}}^{t_k}D(t)dt ΔLD,K​=−λ∫tk−1​tk​​D(t)dt

这就是 Doppler 给出的历元间的距离变化

一阶积分

如果 Doppler 更新率较高，可以近似：

D(t)≈DkD(t) \approx D_k D(t)≈Dk​

于是：

ΔLD,K≈−λDkΔt\Delta L_{D,K}\approx-\lambda D_k\Delta t ΔLD,K​≈−λDk​Δt

梯形积分

更合理的是使用前后两个历元：

ΔLD,K≈−λDk−1+Dk2Δt\Delta L_{D,K}\approx-\lambda\frac{D_{k-1}+ D_k}{2}\Delta t ΔLD,K​≈−λ2Dk−1​+Dk​​Δt

这才是我们真正拿来更新伪距的量

注意 DDD 的单位是 Hz=cycles\text{Hz} = \frac{\text{cycle}}{s}Hz=scycle​，乘以波长 λ\lambdaλ 单位变成 ms\frac{m}{s}sm​，再乘以 Δt\Delta tΔt 单位变成 mmm，因此可以直接加在伪距上

Doppler 平滑伪距公式

假设上一历元已经有：

Pˉk−1\bar{P}_{k-1} Pˉk−1​

那么根据 Doppler 预测当前伪距：

Pk∣k−1D=Pˉk−1+ΔLD,kP_{k\mid k-1}^D = \bar P_{k-1} + \Delta L_{D,k} Pk∣k−1D​=Pˉk−1​+ΔLD,k​

即：

Pk∣k−1D=Pˉk−1−λDk−1+Dk2ΔtP_{k\mid k-1}^D = \bar P_{k-1} - \lambda \frac{D_{k-1} + D_k}{2}\Delta t Pk∣k−1D​=Pˉk−1​−λ2Dk−1​+Dk​​Δt

这个预测短时间内很平滑，但不能无限相信 Doppler 积分，所以还要利用当前的原始伪距 PkP_kPk​，把二者进行融合：

Pˉk=βPk+(1−β)Pk∣k−1D\bar P_k = \beta P_k + (1-\beta) P_{k\mid k-1}^D Pˉk​=βPk​+(1−β)Pk∣k−1D​

代入则有;

Pˉk=βPk+(1−β)[Pˉk−1+ΔLD,k]\bar P_k = \beta P_k + (1 - \beta)[\bar P_{k-1} + \Delta L_{D,k}] Pˉk​=βPk​+(1−β)[Pˉk−1​+ΔLD,k​]

进一步;

Pˉk=βPk+(1−β)[Pˉk−1−λDk−1+Dk2Δt]\bar P_k = \beta P_k + (1 - \beta)\left[ \bar P_{k-1} - \lambda\frac{D_{k-1} + D_k}{2}\Delta t \right] Pˉk​=βPk​+(1−β)[Pˉk−1​−λ2Dk−1​+Dk​​Δt]

这就是经典的 Doppler-smoothed pseudorange 递推

指数平滑系数 β\betaβ 的物理意义

对于刚刚的平滑公式：

Pˉk=βPk+(1−β)Pk∣k−1D\bar P_k = \beta P_k + (1 - \beta) P_{k\mid k-1}^D Pˉk​=βPk​+(1−β)Pk∣k−1D​

其中，0≤β≤10\le \beta\le 10≤β≤1

如果 β→1\beta\to 1β→1，那么 Pˉk≈Pk\bar P_k\approx P_kPˉk​≈Pk​，几乎完全相信原始伪距，平滑效果弱；如果 β→0\beta \to 0β→0，那么 Pˉk≈Pˉk−1+ΔLD\bar P_k \approx \bar P_{k-1} + \Delta L_DPˉk​≈Pˉk−1​+ΔLD​，几乎完全依赖 Doppler 积分，伪距在短时间内会非常平滑，但 Doppler 偏差和积分误差会积累，所以 β\betaβ 也不能无限小

如果取 β=1M\beta = \frac{1}{M}β=M1​，则形式和上一讲 Hatch Filter 极为相似：

Pˉk=1MPk+M−1M(Pˉk−1+ΔLD)\bar P_k = \frac{1}{M}P_k + \frac{M-1}{M}(\bar P_{k-1} + \Delta L_D) Pˉk​=M1​Pk​+MM−1​(Pˉk−1​+ΔLD​)

区别仅在于历元间的距离变化由谁来提供

Doppler Smoothing vs. Hatch Filter

Hatch：

ΔLcarrier=Lk−Lk−1\Delta L_{\text{carrier}} = L_k - L_{k-1} ΔLcarrier​=Lk​−Lk−1​

Doppler Smoothing：

ΔLD=−λ∫Ddt\Delta L_D = -\lambda \int Ddt ΔLD​=−λ∫Ddt

二者对于增量公式的数学结构几乎一样

Hatch：

Pˉk=βPk+(1−β)[Pˉk−1+(Lk−Lk−1)]\bar P_k = \beta P_k + (1-\beta)[\bar P_{k-1} + (L_k - L_{k-1})] Pˉk​=βPk​+(1−β)[Pˉk−1​+(Lk​−Lk−1​)]

Doppler：

Pˉk=βPk+(1−β)[Pˉk−1+ΔLD,k]\bar P_k = \beta P_k + (1 - \beta)[\bar P_{k-1} + \Delta L_{D,k}] Pˉk​=βPk​+(1−β)[Pˉk−1​+ΔLD,k​]

核心差异就在于增量的具体形式

Doppler 通常没有 Hatch 精确

载波相位本质上使用的是 LkL_kLk​ 观测，本身精度可以达到厘米级，因此 Lk−Lk−1L_k - L_{k-1}Lk​−Lk−1​ 本身也是非常精确的短时距离变化量

Doppler 本质上使用的是 L˙\dot LL˙ 观测，其存在 Doppler measurement noise：

Dk=Dktrue+εDD_k = D_k^{\text{true}} + \varepsilon_D Dk​=Dktrue​+εD​

于是积分误差：

ΔεD≈−λεDΔt\Delta \varepsilon_D\approx -\lambda\varepsilon_D\Delta t ΔεD​≈−λεD​Δt

如果 Doppler measurement noise 对应的标准差单位为 Hz，那么使用单点积分时：

σΔD≈λσDΔt\sigma_{\Delta D} \approx \lambda\sigma_{D}\Delta t σΔD​≈λσD​Δt

梯形积分下，假设前后 Doppler 独立：

σΔD2=λ2Δt24(σD,k−12+σD,k2)\sigma_{\Delta D}^2 = \frac{\lambda^2\Delta t^2}{4}(\sigma^2_{D,k-1} + \sigma^2_{D,k}) σΔD2​=4λ2Δt2​(σD,k−12​+σD,k2​)

所以，每积分一次，就把 Doppler 噪声变成了一次距离误差，所以通常 Carrier increment 精度会高于 Doppler integrated increment

Doppler 比 Hatch 更不怕周跳

假设载波发生周跳：

Nk=Nk−1+ΔNN_k = N_{k-1} + \Delta N Nk​=Nk−1​+ΔN

在 Hatch 中，Lk−Lk−1L_k - L_{k-1}Lk​−Lk−1​ 会变成 ΔLtrue+λΔN\Delta L^{\text{true}} + \lambda \Delta NΔLtrue+λΔN，所以立刻就会在后续平滑中都引入 λΔN\lambda \Delta NλΔN 的距离误差

而在 Doppler 方程中，DDD 没有整数模糊度，因为 Doppler描述的是相位变化率，理论上满足 d(λN)dt=0\frac{d(\lambda N)}{dt} = 0dtd(λN)​=0，因此 Doppler smoothing 不会直接依赖于整数模糊度的连续性

但不能理解为，发生周跳时，Doppler 也一定完全正常，发生失锁、reacquisition 时，Doppler 观测本身也可能产生瞬态异常，只是它不会像 Lk−Lk−1L_k - L_{k-1}Lk​−Lk−1​ 一样永久多出 λΔN\lambda \Delta NλΔN 这样的整数跳变

Doppler 积分的漂移

假设多普勒在平滑伪距时存在一个小的偏置 bias：

L˙D=L˙true+bD\dot L_D = \dot L_{\text{true}} + b_D L˙D​=L˙true​+bD​

经过一个历元以后：

ΔLD=ΔLtrue+bDΔt\Delta L_D = \Delta L_{\text{true}} + b_D\Delta t ΔLD​=ΔLtrue​+bD​Δt

如果完全积分：

Pk=Pk−1+ΔLDP_k = P_{k-1} + \Delta L_D Pk​=Pk−1​+ΔLD​

那么经过 nnn 个历元以后：

error=nbDΔt\text{error} = n b_D\Delta t error=nbD​Δt

误差会不断积累

之所以 Doppler smoothing 没有漂移乃至发散，主要是靠每个历元的 βPk\beta P_kβPk​ 把结果重新拉回绝对伪距，所以它本质上是 Doppler 提供短时平滑，结合 Code 提供长期绝对约束结合的结果

但是如果 β\betaβ 设置太小，Doppler bias 仍然可能造成明显的长期偏移

Doppler 其他作用

速度观测

Doppler 本身可以作为一个独立的 GNSS observation：速度观测

假设卫星 iii 到接收机的距离为：

ρi=∥rsi−rr∥\rho_i = \|\mathbf r_s^i - \mathbf r_r\| ρi​=∥rsi​−rr​∥

定义从接收机指向卫星的 LOS 向量：

ui=rsi−rrρi\mathbf u_i = \frac{\mathbf r_s^i - \mathbf r_r}{\rho_i} ui​=ρi​rsi​−rr​​

对几何距离求导：

ρ˙i=ui⊤(vsi−vr)\dot\rho_i = \mathbf u^\top_i(\mathbf v_s^i - \mathbf v_r) ρ˙​i​=ui⊤​(vsi​−vr​)

因此：

ρ˙i=ui⊤vsi−ui⊤vr\dot\rho_i = \mathbf u_i^\top\mathbf v_s^i - \mathbf u_i^\top\mathbf v_r ρ˙​i​=ui⊤​vsi​−ui⊤​vr​

其中，卫星速度 vsi\mathbf v_s^ivsi​ 可以由星历求得，未知的是接收机速度 vr\mathbf v_rvr​

再考虑接收机钟漂 cδ˙trc\dot\delta t_rcδ˙tr​，可以写成：

yi=−ui⊤vr+cδ˙tr+εiy_i = -\mathbf u_i^\top\mathbf v_r + c\dot\delta t_r + \varepsilon_i yi​=−ui⊤​vr​+cδ˙tr​+εi​

其中，已知的卫星运动和卫星钟漂已经改正到 yiy_iyi​ 中

因此，状态可以设为：

xv=[vxvyvzcδ˙tr]x_v = \begin{bmatrix} v_x\\v_y\\v_z\\c\dot\delta t_r\\ \end{bmatrix} xv​=⎣⎢⎢⎢⎡​vx​vy​vz​cδ˙tr​​⎦⎥⎥⎥⎤​

观测矩阵第 iii 行为：

Hi=[−uix−uiy−uiz1]H_i = [-u_{ix} \quad -u_{iy}\quad -u_{iz}\quad 1] Hi​=[−uix​−uiy​−uiz​1]

于是：

yD=HDxv+εDy_D = H_Dx_v + \varepsilon_D yD​=HD​xv​+εD​

可以用 WLS 或 KF 求速度
