RTK 单差与双差观测模型

符号约定

我们约定：

  • uuu：流动站 Rover
  • bbb：基准站 Base
  • sss：普通卫星
  • qqq：参考卫星
  • fff：频率
  • PrsP_r^sPrs​：伪距观测值
  • Lrs=λfΦrsL_r^s = \lambda_f\Phi_r^sLrs​=λf​Φrs​：由载波相位观测值得到的距离
  • ρrs\rho_r^sρrs​：卫星 sss 到接收机 rrr 的几何距离
  • δtr\delta t_rδtr​：接收机钟差
  • δts\delta t^sδts：卫星钟差
  • IrsI_r^sIrs​：电离层延迟
  • TrsT_r^sTrs​：对流层延迟
  • NrsN_r^sNrs​：整周模糊度

定义：

∇Oubs=Ous−Obs\nabla O_{ub}^{s} = O_u^s - O_b^s ∇Oubs​=Ous​−Obs​

表示接收机间单差

在此基础上，定义：

∇ΔOubsq=∇Oubs−∇Oubq\nabla \Delta O_{ub}^{sq} = \nabla O_{ub}^s - \nabla O_{ub}^q ∇ΔOubsq​=∇Oubs​−∇Oubq​

表示双差

原始非差观测方程

伪距观测模型：

Prs=ρrs+c(δtr−δts)+Irs+Trs+εP,rsP_r^s = \rho_r^s + c(\delta t_r - \delta t^s) + I_r^s + T_r^s + \varepsilon_{P,r}^s Prs​=ρrs​+c(δtr​−δts)+Irs​+Trs​+εP,rs​

载波相位观测模型：

Lrs=ρrs+c(δtr−δts)−Irs+Trs+λNrs+εL,rsL_r^s = \rho_r^s + c(\delta t_r - \delta t^s) - I_r^s + T_r^s + \lambda N_r^s + \varepsilon_{L,r}^s Lrs​=ρrs​+c(δtr​−δts)−Irs​+Trs​+λNrs​+εL,rs​

这里暂时把硬件延迟、多路径和未建模误差都统一包含在 ε\varepsilonε 中

伪距双差观测模型

伪距单差

对于同一颗卫星 sss，流动站观测为：

Pus=ρus+c(δtu−δts)+Ius+Tus+εP,usP_u^s = \rho_u^s + c(\delta t_u - \delta t^s) + I_u^s + T_u^s + \varepsilon_{P,u}^s Pus​=ρus​+c(δtu​−δts)+Ius​+Tus​+εP,us​

基准站观测为：

Pbs=ρbs+c(δtb−δts)+Ibs+Tbs+εP,bsP_b^s = \rho_b^s + c(\delta t_b - \delta t^s) + I_b^s + T_b^s + \varepsilon_{P,b}^s Pbs​=ρbs​+c(δtb​−δts)+Ibs​+Tbs​+εP,bs​

定义单差：

∇Pubs=Pus−Pbs\nabla P_{ub}^s = P_u^s - P_b^s ∇Pubs​=Pus​−Pbs​

各自展开后代入：

∇Pibs=ρus−ρbs+c(δtu−δtb)+(Ius−Ibs)+(Tus−Tbs)+(εP,us−εP,bs)\nabla P_{ib}^s = \rho_u^s - \rho_b^s + c(\delta t_u - \delta t_b) + (I_u^s - I_b^s) + (T_u^s - T_b^s) + (\varepsilon_{P,u}^s - \varepsilon_{P,b}^s) ∇Pibs​=ρus​−ρbs​+c(δtu​−δtb​)+(Ius​−Ibs​)+(Tus​−Tbs​)+(εP,us​−εP,bs​)

卫星钟差项 cδtsc\delta t^scδts 作差后消除，因此：

∇Pubs=∇ρubs+c(δtu−δtb)+∇Iubs+∇Tubs+∇εP,ubs\nabla P_{ub}^s = \nabla \rho_{ub}^s + c(\delta t_u - \delta t_b) + \nabla I_{ub}^s + \nabla T_{ub}^s + \nabla \varepsilon_{P,ub}^s ∇Pubs​=∇ρubs​+c(δtu​−δtb​)+∇Iubs​+∇Tubs​+∇εP,ubs​

因为每个接收机有各自的时钟，因此这里只能消除卫星钟差项，但 c(δtu−δtb)c(\delta t_u - \delta t_b)c(δtu​−δtb​) 仍然保留

对于对流层作差 ∇Tubs=Tus−Tbs\nabla T_{ub}^s = T_u^s - T_b^s∇Tubs​=Tus​−Tbs​ 和电离层作差 ∇Iubs=∇Ius−∇Ibs\nabla I_{ub}^s = \nabla I_u^s - \nabla I_b^s∇Iubs​=∇Ius​−∇Ibs​，如果基线较短，两台接收机看到的传播路径比较接近，则大约有：

∇Iubs≈0,∇Tubs≈0\nabla I_{ub}^s\approx 0,\quad\nabla T_{ub}^s\approx 0 ∇Iubs​≈0,∇Tubs​≈0

这里只是削弱，并不是数学意义上的严格消除

短基线指的是：基准站与流动站之间的距离足够近，使得电离层、对流层等空间相关误差能被双差基本消除，从而保证 RTK 能稳定获得厘米级固定解

伪距双差

接收机间做单差后还剩下：

c(δtu−δtb)c(\delta t_u - \delta t_b) c(δtu​−δtb​)

为了消除接收机钟差，我们再选一颗参考卫星 qqq

对于卫星 sss：

∇Pubs=∇ρubs+c(δtu−δtb)+∇Iubs+∇Tubs+∇εP,ubs\nabla P_{ub}^s = \nabla \rho_{ub}^s + c(\delta t_u - \delta t_b) + \nabla I_{ub}^s + \nabla T_{ub}^s + \nabla \varepsilon_{P,ub}^s ∇Pubs​=∇ρubs​+c(δtu​−δtb​)+∇Iubs​+∇Tubs​+∇εP,ubs​

对于卫星 qqq：

∇Pubq=∇ρubq+c(δtu−δtb)+∇Iubq+∇Tubq+∇εP,ubq\nabla P_{ub}^q = \nabla\rho_{ub}^q + c(\delta t_u - \delta t_b) + \nabla I_{ub}^q + \nabla T_{ub}^q + \nabla \varepsilon_{P,ub}^q ∇Pubq​=∇ρubq​+c(δtu​−δtb​)+∇Iubq​+∇Tubq​+∇εP,ubq​

定义双差：

∇ΔPubsq=∇Pubs−∇Pubq\nabla\Delta P_{ub}^{sq} = \nabla P_{ub}^s - \nabla P_{ub}^q ∇ΔPubsq​=∇Pubs​−∇Pubq​

代入：

∇ΔPubsq=∇ρubs−∇ubq+c(δtu−δtb)−(δtu−δtb)+∇Iubs−∇Iubq+∇Tubs−∇Tubq+∇εP,ubs+∇εP,ubq\nabla\Delta P_{ub}^{sq} = \nabla \rho_{ub}^s - \nabla_{ub}^{q} + c(\delta t_u - \delta t_b) - (\delta t_u - \delta t_b) + \nabla I_{ub}^s - \nabla I_{ub}^q + \nabla T_{ub}^s - \nabla T_{ub}^q + \nabla \varepsilon_{P,ub}^s + \nabla \varepsilon_{P,ub}^q ∇ΔPubsq​=∇ρubs​−∇ubq​+c(δtu​−δtb​)−(δtu​−δtb​)+∇Iubs​−∇Iubq​+∇Tubs​−∇Tubq​+∇εP,ubs​+∇εP,ubq​

接收机钟差 c(δtu−δtb)c(\delta t_u -\delta t_b)c(δtu​−δtb​) 在此作差后也被消除，因此：

∇ΔPubsq=∇Δρubsq+∇ΔIubsq+∇ΔTubsq+∇ΔεP,ubsq\nabla \Delta P_{ub}^{sq} = \nabla\Delta \rho_{ub}^{sq} + \nabla\Delta I_{ub}^{sq} + \nabla\Delta T_{ub}^{sq} + \nabla\Delta \varepsilon_{P,ub}^{sq} ∇ΔPubsq​=∇Δρubsq​+∇ΔIubsq​+∇ΔTubsq​+∇ΔεP,ubsq​

这就是经典的伪距双差模型

载波相位双差观测模型

载波相位单差

对于同一颗卫星 sss，流动站观测为：

Lus=ρus+c(δtu−δts)−Ius+Tus+λNus+εL,usL_{u}^s = \rho_u^s + c(\delta t_u - \delta t^s) - I_u^s + T_u^s + \lambda N_u^s + \varepsilon_{L,u}^s Lus​=ρus​+c(δtu​−δts)−Ius​+Tus​+λNus​+εL,us​

基准站观测为：

Lbs=ρbs+c(δtb−δts)−Ibs+Tbs+λNbs+εL,bsL_b^s = \rho_b^s + c(\delta t_b - \delta t^s) - I_b^s + T_b^s + \lambda N_b^s + \varepsilon_{L,b}^s Lbs​=ρbs​+c(δtb​−δts)−Ibs​+Tbs​+λNbs​+εL,bs​

各自展开后代入：

∇Lubs=ρus−ρbs+c(δtu−δts)−c(δtbδts)−(Ius−Ibs)+(Tus−Tbs)+λ(Nus−Nbs)+(εL,us−εL,bs)\nabla L_{ub}^s = \rho_u^s - \rho_b^s + c(\delta t_u - \delta t^s) - c(\delta t_b \delta t^s) - (I_u^s - I_b^s) + (T_u^s - T_b^s) + \lambda(N_u^s - N_b^s) + (\varepsilon_{L,u}^s - \varepsilon_{L,b}^s) ∇Lubs​=ρus​−ρbs​+c(δtu​−δts)−c(δtb​δts)−(Ius​−Ibs​)+(Tus​−Tbs​)+λ(Nus​−Nbs​)+(εL,us​−εL,bs​)

化简则有：

∇Lubs=∇ρubs+c(δtu−δtb)−∇Iubs+∇Tubs+λNubs+∇εL,ubs\nabla L_{ub}^s = \nabla \rho_{ub}^s + c(\delta t_u - \delta t_b) -\nabla I_{ub}^s + \nabla T^s_{ub} + \lambda N_{ub}^s + \nabla \varepsilon_{L,ub}^s ∇Lubs​=∇ρubs​+c(δtu​−δtb​)−∇Iubs​+∇Tubs​+λNubs​+∇εL,ubs​

其中，∇Nubs=Nus−Nbs\nabla N_{ub}^s = N_u^s - N_b^s∇Nubs​=Nus​−Nbs​，由于 NusN_u^sNus​ 和 NbsN_b^sNbs​ 都是整数，因此 ∇Nubs\nabla N_{ub}^s∇Nubs​ 也是整数，单差并没有破坏模糊度的整数性质

载波相位双差

同理，再选择参考卫星 qqq：

∇ΔLubsq=∇Lubs−∇Lubq\nabla\Delta L_{ub}^{sq} = \nabla L_{ub}^s - \nabla L_{ub}^q ∇ΔLubsq​=∇Lubs​−∇Lubq​

代入各自的载波相位单差方程，展开则有：

∇ΔLubsq=∇Δρubsq−∇ΔIubsq+∇ΔTubsq+λ∇ΔNubsq+∇ΔεL,ubsq\nabla\Delta L_{ub}^{sq} = \nabla\Delta \rho_{ub}^{sq} - \nabla\Delta I_{ub}^{sq} + \nabla\Delta T_{ub}^{sq} + \lambda\nabla\Delta N_{ub}^{sq} + \nabla\Delta\varepsilon_{L,ub}^{sq} ∇ΔLubsq​=∇Δρubsq​−∇ΔIubsq​+∇ΔTubsq​+λ∇ΔNubsq​+∇ΔεL,ubsq​

其中，双差模糊度项为：

∇ΔNubsq=∇ΔNubs−∇Nubq\nabla\Delta N_{ub}^{sq} = \nabla\Delta N_{ub}^s - \nabla N_{ub}^q ∇ΔNubsq​=∇ΔNubs​−∇Nubq​

进一步展开：

∇ΔNubsq=Nus−Nbs−Nuq+Nbq\nabla\Delta N_{ub}^{sq} = N_u^s - N_b^s - N_u^q + N_b^q ∇ΔNubsq​=Nus​−Nbs​−Nuq​+Nbq​

由于四项都是整数，所以最终 ∇ΔNubsq\nabla\Delta N_{ub}^{sq}∇ΔNubsq​ 也是整数

这是 RTK 的一个重要性质：双差之后，钟差项被消除，但整周模糊度仍然保持整数性质

整数模糊度

整数模糊度 NbsN_b^sNbs​ 和 NbqN_b^qNbq​ 分别属于 u↔su\leftrightarrow su↔s 和 b↔sb\leftrightarrow sb↔s 两条独立的载波跟踪链路，因此通常：

Nus≠NbsN_u^s \ne N_b^s Nus​​=Nbs​

它们只能组合成新的未知整数：

∇Nubs=Nus−Nbs\nabla N_{ub}^s = N_u^s - N_b^s ∇Nubs​=Nus​−Nbs​

再进行卫星间差分则有：

∇ΔNubsq=Nus−Nbs−Nuq+Nbq\nabla\Delta N_{ub}^{sq} = N_u^s - N_b^s - N_u^q + N_b^q ∇ΔNubsq​=Nus​−Nbs​−Nuq​+Nbq​

这仍然是一个未知量，所以 RTK 的双差操作并不会抵消模糊度，而是把四个模糊度重新整合成一个未知的双差整数模糊度

短基线经典模型

如果基准站（Base）和流动站（Rover）距离比较近，可以近似：

∇ΔIubsq≈0∇ΔTubsq≈0\nabla\Delta I_{ub}^{sq} \approx 0\\\nabla\Delta T_{ub}^{sq} \approx 0 ∇ΔIubsq​≈0∇ΔTubsq​≈0

于是伪距双差建模为：

∇ΔPubsq=∇Δρubsq+εPsq\nabla\Delta P_{ub}^{sq} = \nabla\Delta \rho_{ub}^{sq} + \varepsilon_P^{sq} ∇ΔPubsq​=∇Δρubsq​+εPsq​

载波相位双差建模为：

∇ΔLubsq=∇Δρubsq+λNDDsq+εLsq\nabla\Delta L_{ub}^{sq} = \nabla\Delta \rho_{ub}^{sq} + \lambda N_{DD}^{sq} + \varepsilon_L^{sq} ∇ΔLubsq​=∇Δρubsq​+λNDDsq​+εLsq​

其中，NDDsq≡∇ΔNubsqN_DD^{sq}\equiv\nabla\Delta N_{ub}^{sq}ND​Dsq≡∇ΔNubsq​ 是为了简化表述的等价形式

以上两个方程就是短基线 RTK 的核心观测模型

双差几何距离展开

双差几何距离：

∇Δρubsq=∇ρubs−∇ρubq\nabla\Delta \rho_{ub}^{sq} = \nabla \rho_{ub}^s -\nabla \rho_{ub}^q ∇Δρubsq​=∇ρubs​−∇ρubq​

接收机单差分别为 ρus−ρbs\rho_u^s - \rho_b^sρus​−ρbs​ 和 ρuq−ρbq\rho_u^q - \rho_b^qρuq​−ρbq​，代入则有：

∇Δρubsq=ρus−ρbs−ρuq+ρbq\nabla\Delta \rho_{ub}^{sq} = \rho_u^s - \rho_b^s - \rho_u^q + \rho_b^q ∇Δρubsq​=ρus​−ρbs​−ρuq​+ρbq​

其中：

ρus=∥rs−ru∥ρbs=∥rs−rb∥ρbs=∥rq−ru∥ρbq=∥rq−rb∥\rho_u^s = \|\mathbf r^s - \mathbf r_u\|\\ \rho_b^s = \|\mathbf r^s - \mathbf r_b\|\\ \rho_b^s = \|\mathbf r^q - \mathbf r_u\|\\ \rho_b^q = \|\mathbf r^q - \mathbf r_b\| ρus​=∥rs−ru​∥ρbs​=∥rs−rb​∥ρbs​=∥rq−ru​∥ρbq​=∥rq−rb​∥

基准站坐标 rb\mathbf r_brb​ 已知，卫星坐标 rs,rq\mathbf r^s,\mathbf r^qrs,rq 也已知，因此 ρbs,ρbq\rho_b^s,\rho_b^qρbs​,ρbq​ 可以直接计算

真正待求解的、包含 Rover 坐标的是 ρus\rho_u^sρus​ 和 ρuq\rho_u^qρuq​

双差几何距离线性化

假设我们当前有了一个对接收机的位置的粗略估计 r^u\mathbf{ \hat{r}_u}r^u​

则接收机的真实位置可以写成：

ru=r^u+δr\mathbf r_u = \mathbf{\hat{r}}_u + \delta\mathbf r ru​=r^u​+δr

其中，δr=[δxδyδz]\delta\mathbf r = \begin{bmatrix}\delta x\\\delta y\\\delta z\end{bmatrix}δr=⎣⎢⎡​δxδyδz​⎦⎥⎤​

对于卫星 sss：

ρus=∥rs−ru∥\rho_u^s = \|\mathbf r^s - \mathbf r_u\| ρus​=∥rs−ru​∥

在 r^u\mathbf{\hat r}_ur^u​ 附近做一阶泰勒展开：

ρus≈ρ^us+∂ρus∂ru∣ru=r^uδr\left.\rho_u^s\approx\hat{\rho}_u^s +\frac{\partial\rho_u^s}{\partial\mathbf{r}_u}\right|_{\mathbf r_u = \hat{\mathbf{r}}_u}\delta\mathbf{r} ρus​≈ρ^​us​+∂ru​∂ρus​​∣∣∣∣∣​ru​=r^u​​δr

其中，ρ^us=∥rs−r^u∥\hat{\rho}_u^s = \|\mathbf r^s - \hat{\mathbf r}_u\|ρ^​us​=∥rs−r^u​∥

现在的关键是求解 ∂ρus∂ru\frac{\partial \rho_u^s}{\partial \mathbf r_u}∂ru​∂ρus​​，将 ρus\rho_u^sρus​ 展开后代入：

ρus=(rs−ru)⊤(rs−ru)=(xu−xs)2+(yu−ys)2+(zu−zs)2\rho_u^s = \sqrt{(\mathbf r^s - \mathbf r_u)^\top(\mathbf r^s - \mathbf r_u)} = \sqrt{(x_u - x^s)^2 + (y_u - y^s)^2 + (z_u - z^s)^2} ρus​=(rs−ru​)⊤(rs−ru​)​=(xu​−xs)2+(yu​−ys)2+(zu​−zs)2​

因此：

∂ρus∂ru=12[(rs−ru)⊤(rs−ru)]−12×2×(rs−ru)×∂(rs−ru)∂ru\frac{\partial \rho_u^s}{\partial \mathbf r_u} = \frac{1}{2}\left[(\mathbf r^s - \mathbf r_u)^\top(\mathbf r^s - \mathbf r_u)\right]^{-\frac{1}{2}}\times2\times(\mathbf r^s - \mathbf r_u)\times\frac{\partial (\mathbf{r}^s - \mathbf r_u)}{\partial \mathbf r_u} ∂ru​∂ρus​​=21​[(rs−ru​)⊤(rs−ru​)]−21​×2×(rs−ru​)×∂ru​∂(rs−ru​)​

化简则有：

∂ρus∂ru=−rs−ruρus\frac{\partial\rho_u^s}{\partial\mathbf r_u} = -\frac{\mathbf r^s - \mathbf r_u}{\rho_u^s} ∂ru​∂ρus​​=−ρus​rs−ru​​

这恰好对应接收机 uuu 指向卫星 sss 的单位视线向量：

eus=rs−ruρus\mathbf e_u^s = \frac{\mathbf r^s - \mathbf r_u}{\rho_u^s} eus​=ρus​rs−ru​​

对于一阶展开，则代入 r^u\mathbf{\hat{r}_u}r^u​ 位置的取值即可，因此则有：

∂ρus∂ru=−(eus)⊤\frac{\partial\rho_u^s}{\partial\mathbf r_u} = -(\mathbf e_u^s)^\top ∂ru​∂ρus​​=−(eus​)⊤

最终：

ρus≈ρ^us−(eus)⊤∣r^uδr\rho_u^s\approx\hat{\rho}_u^s - \left.(\mathbf e_u^s)^\top\right|_{\mathbf{\hat{r}}_u}\delta\mathbf r ρus​≈ρ^​us​−(eus​)⊤∣∣∣​r^u​​δr

同理：

ρuq≈ρ^uq−(euq)⊤∣r^uδr\rho_u^q\approx\hat{\rho}_u^q - \left.(\mathbf e_u^q)^\top\right|_{\mathbf{\hat{r}}_u}\delta\mathbf r ρuq​≈ρ^​uq​−(euq​)⊤∣∣∣​r^u​​δr

通常简化表述为：

ρus≈ρ^us−(eus)⊤δrρuq≈ρ^uq−(euq)⊤δr\rho_u^s\approx\hat{\rho}_u^s - (\mathbf e_u^s)^\top\delta\mathbf r\\ \rho_u^q\approx\hat{\rho}_u^q - (\mathbf e_u^q)^\top\delta\mathbf r ρus​≈ρ^​us​−(eus​)⊤δrρuq​≈ρ^​uq​−(euq​)⊤δr

进而代入：

∇Δρubsq=ρus−ρbs−ρuq+ρbq\nabla\Delta\rho_{ub}^{sq} = \rho_u^s - \rho_b^s - \rho_u^q + \rho_b^q ∇Δρubsq​=ρus​−ρbs​−ρuq​+ρbq​

得到：

∇Δρubsq=ρ^us−(eus)⊤δr−ρbs−ρ^uq+(euq)⊤δr+ρbq\nabla\Delta\rho_{ub}^{sq} = \hat{\rho}_u^s - (\mathbf e_u^s)^\top\delta\mathbf r - \rho_b^s - \hat{\rho}_u^q + (\mathbf e_u^q)^\top\delta\mathbf r + \rho_b^q ∇Δρubsq​=ρ^​us​−(eus​)⊤δr−ρbs​−ρ^​uq​+(euq​)⊤δr+ρbq​

把已知的几何项放在一起：

ρ^rs−ρbs−ρ^us+ρbs\hat{\rho}_r^s - \rho_b^s -\hat{\rho}_u^s + \rho_b^s ρ^​rs​−ρbs​−ρ^​us​+ρbs​

记作 ∇Δρ^ubsq\nabla\Delta\hat{\rho}_{ub}^{sq}∇Δρ^​ubsq​

剩余的为状态改正量部分：

−(eus)⊤δr+(euq)⊤δr-(\mathbf e_u^s)^\top\delta \mathbf r + (\mathbf e_u^q)^\top\delta\mathbf r −(eus​)⊤δr+(euq​)⊤δr

可以合并为 (euq−eus)⊤δr(\mathbf e_u^q - \mathbf e_u^s)^\top\delta\mathbf r(euq​−eus​)⊤δr

因此最终得到：

∇Δρubsq=∇Δρ^ubsq+(euq−eus)⊤δr\nabla\Delta\rho_{ub}^{sq} = \nabla\Delta\hat{\rho}_{ub}^{sq} + (\mathbf e_u^q - \mathbf e_u^s)^\top\delta\mathbf r ∇Δρubsq​=∇Δρ^​ubsq​+(euq​−eus​)⊤δr

这是 RTK 双差几何模型最关键的线性化公式

双差模型设计矩阵

双差模型的设计矩阵为两个 LOS 向量的差，即 (euq−eus)⊤(\mathbf e_u^q - \mathbf e_u^s)^\top(euq​−eus​)⊤ 对应设计矩阵的一行：

hsq=[exq−exseyq−eysezq−ezs]\mathbf h^{sq} = [e_x^q - e_x^s\quad e_y^q - e_y^s\quad e_z^q - e_z^s] hsq=[exq​−exs​eyq​−eys​ezq​−ezs​]

这和 SPP 中的：

[−ex−ey−ez1][-e_x\quad -e_y\quad -e_z\quad 1] [−ex​−ey​−ez​1]

有明显区别，因为双差模型中的 cδtrc\delta t_rcδtr​ 通过双差已经被消除，所以其对应的 111 列也不复存在了

伪距双差线性模型

在短基线条件下：

∇ΔPsq=∇Δρsq+εPsq\nabla\Delta P^{sq} = \nabla\Delta\rho^{sq} + \varepsilon_P^{sq} ∇ΔPsq=∇Δρsq+εPsq​

代入几何距离线性化公式;

∇ΔPsq=∇Δρ^sq+(eq−es)⊤δr+εPsq\nabla\Delta P^{sq} = \nabla\Delta\hat{\rho}^{sq} + (\mathbf e^q - \mathbf e^s)^\top\delta\mathbf r + \varepsilon_P^{sq} ∇ΔPsq=∇Δρ^​sq+(eq−es)⊤δr+εPsq​

把当前估计的位置理论值移动到左边：

∇ΔPsq−∇Δρ^sq=(eq−es)⊤δr+εPsq\nabla\Delta P^{sq} - \nabla\Delta \hat{\rho}^{sq} = (\mathbf e^q - \mathbf e^s)^\top\delta\mathbf r + \varepsilon_P^{sq} ∇ΔPsq−∇Δρ^​sq=(eq−es)⊤δr+εPsq​

定义预拟合残差：

lPsq=∇ΔPsq−∇Δρ^sql_P^{sq} = \nabla\Delta P^{sq} - \nabla\Delta \hat{\rho}^{sq} lPsq​=∇ΔPsq−∇Δρ^​sq

于是则有：

lPsq=hsqδr+εPsql_P^{sq} = \mathbf h^{sq} \delta\mathbf r + \varepsilon_P^{sq} lPsq​=hsqδr+εPsq​

载波相位双差线性模型

在短基线条件下：

∇ΔLsq=∇Δρsq+λNDDsq+εLsq\nabla\Delta L^{sq} = \nabla\Delta \rho^{sq} + \lambda N_{DD}^{sq} + \varepsilon_L^{sq} ∇ΔLsq=∇Δρsq+λNDDsq​+εLsq​

代入几何距离线性化公式：

∇Δρsq=∇Δρ^sq+(eq−es)⊤δr+λNDDsq+εLsq\nabla\Delta\rho^{sq} = \nabla\Delta\hat{\rho}^{sq} + (\mathbf e^q - \mathbf e^s)^\top\delta\mathbf r + \lambda N_{DD}^{sq} + \varepsilon_L^{sq} ∇Δρsq=∇Δρ^​sq+(eq−es)⊤δr+λNDDsq​+εLsq​

把当前估计的位置理论值移动到左边：

∇ΔLsq−∇Δρ^sq=(eq−es)⊤δr+λNDDsq+εLsq\nabla\Delta L^{sq} - \nabla\Delta \hat{\rho}^{sq} = (\mathbf e^q - \mathbf e^s)^\top\delta\mathbf r + \lambda N_{DD}^{sq} + \varepsilon_L^{sq} ∇ΔLsq−∇Δρ^​sq=(eq−es)⊤δr+λNDDsq​+εLsq​

定义预拟合残差：

lLsq=∇ΔLsq−∇Δρ^sql_L^{sq} = \nabla\Delta L^{sq} - \nabla\Delta \hat{\rho}^{sq} lLsq​=∇ΔLsq−∇Δρ^​sq

于是则有：

lLsq=hsqδr+λNDDsq+εLsql_L^{sq} = \mathbf h^{sq} \delta\mathbf r + \lambda N_{DD}^{sq} + \varepsilon_L^{sq} lLsq​=hsqδr+λNDDsq​+εLsq​

多颗卫星组成矩阵

假设基准站和流动站共同观测 nnn 颗卫星，选择其中一颗作为参考卫星 qqq，剩下的 s1,s2,…,sn−1s_1,s_2,\dots,s_{n-1}s1​,s2​,…,sn−1​ 可以得到 n−1n-1n−1 组独立双差

构造设计矩阵：

H=[(eq−es1)⊤(eq−es2)⊤⋮(eq−esn−1)⊤]∈R(n−1)×3\mathbf H = \begin{bmatrix} (\mathbf e^q - \mathbf e^{s_1})^\top\\ (\mathbf e^q - \mathbf e^{s_2})^\top\\ \vdots\\ (\mathbf e^q - \mathbf e^{s_{n-1}})^\top \end{bmatrix}\in\mathbb{R}^{(n-1)\times3} H=⎣⎢⎢⎢⎢⎡​(eq−es1​)⊤(eq−es2​)⊤⋮(eq−esn−1​)⊤​⎦⎥⎥⎥⎥⎤​∈R(n−1)×3

伪距对应的预拟合残差向量为：

lP=[lPs1qlPs2q⋮lPsn−1q]\mathbf l_P = \begin{bmatrix} l_P^{s_1q}\\ l_P^{s_2q}\\ \vdots\\ l_P^{s_{n-1}q}\\ \end{bmatrix} lP​=⎣⎢⎢⎢⎢⎡​lPs1​q​lPs2​q​⋮lPsn−1​q​​⎦⎥⎥⎥⎥⎤​

因此有：

lP=Hδr+εP\mathbf l_P = \mathbf H\delta\mathbf r + \varepsilon_P lP​=Hδr+εP​

对于载波相位而言，定义模糊度向量：

N=[NDDs1qNDDs2q⋮NDDsn−1q]\mathbf N = \begin{bmatrix} N_{DD}^{s_1q}\\ N_{DD}^{s_2q}\\ \vdots\\ N_{DD}^{s_{n-1}q}\\ \end{bmatrix} N=⎣⎢⎢⎢⎢⎡​NDDs1​q​NDDs2​q​⋮NDDsn−1​q​​⎦⎥⎥⎥⎥⎤​

因此有：

lL=Hδr+λN+εL\mathbf l_L = \mathbf H\delta\mathbf r + \lambda\mathbf N + \varepsilon_L lL​=Hδr+λN+εL​

写成线性标准形式则有;

lL=[HλI][δrN]+εL\mathbf l_L = [\mathbf H\quad\lambda\mathbf I]\begin{bmatrix} \delta\mathbf r\\\mathbf N \end{bmatrix} + \varepsilon_L lL​=[HλI][δrN​]+εL​

其中，I\mathbf II 的形状和 N\mathbf NN 相同，为 R(n−1)×(n−1)\mathbb R^{(n-1)\times(n-1)}R(n−1)×(n−1)，因为每一条载波相位双差都对应一个双差模糊度

伪距和载波相位的联合观测

把两类观测堆叠：

[lPlL]\begin{bmatrix} \mathbf l_P\\ \mathbf l_L\\ \end{bmatrix} [lP​lL​​]

得到：

[lPlL]=[H0HλI][δrN]+[εPεL]\begin{bmatrix} \mathbf l_P \\ \mathbf l_L \end{bmatrix} = \begin{bmatrix} \mathbf H & \mathbf 0\\\mathbf H & \lambda\mathbf I \end{bmatrix}\begin{bmatrix} \delta\mathbf r\\\mathbf N \end{bmatrix} + \begin{bmatrix} \varepsilon_P\\\varepsilon_L \end{bmatrix} [lP​lL​​]=[HH​0λI​][δrN​]+[εP​εL​​]

其中，待求解的状态 δr=[δx,δy,δz]⊤\delta \mathbf r = [\delta x,\delta y,\delta z]^\topδr=[δx,δy,δz]⊤，以及 N=[N1,N2,…,Nn−1]\mathbf N = [N_1,N_2,\dots,N_{n-1}]N=[N1​,N2​,…,Nn−1​]

与 SPP 待求解的 [x,y,z,cδtr][x,y,z,c\delta t_r][x,y,z,cδtr​] 相比，变成了：

[x,y,z,N1,N2,…,Nn−1][x,y,z,N_1,N_2,\dots,N_{n-1}] [x,y,z,N1​,N2​,…,Nn−1​]

即接收机钟差从状态中消失，整周模糊度进入待求解状态
