GVINS 紧耦合实例

通过本章，我们介绍 GNSS、Camera、IMU 的数据怎样能变成一个统一优化问题

GVINS 优化目标

GVINS 使用滑动窗口优化（Sliding Window Optimization），所谓滑动窗口（Sliding Window），指的是不保存从程序启动到现在所有的历史状态，而是只保留最近的若干关键帧：

0,1,⋯ ,N0,1,\cdots,N 0,1,⋯,N

然后不断重复旧状态的移除和新状态的进入，这样才能完成实时运行

对于第 kkk 个时刻，我们维护的状态统一建模为：

xk={pkw,vkw,qkw,ba,k,bg,k,δtk,δtk˙}\mathbf x_k = \{\mathbf p_k^w,\mathbf v_k^w,\mathbf q_k^w,\mathbf b_{a,k},\mathbf b_{g,k},\delta\mathbf t_k,\dot{\delta\mathbf t_k}\} xk​={pkw​,vkw​,qkw​,ba,k​,bg,k​,δtk​,δtk​˙​}

其中，各个分量分别表示载体在局部世界坐标系 www 中的位置、速度、姿态、加速度计 Bias、陀螺仪 Bias、GNSS 接收机单差、GNSS 接收机钟漂

（接收机钟漂，即接收机钟差随时间变化速率）

此外，还有每一个视觉特征点的 ρl\rho_lρl​，即逆深度（Inverse Depth）：

ρl=1dl\rho_l = \frac{1}{d_l} ρl​=dl​1​

其中，dld_ldl​ 表示第 lll 个观测点相对于相机坐标系 pC=[X,Y,Z]⊤p^C = [X,Y,Z]^\toppC=[X,Y,Z]⊤ 在 zzz 轴上的分量

以及：

ψ\psi ψ

表示 VIO 局部坐标系 www 和 GNSS 使用的 ENU 坐标系之间的航向角偏差（Yaw Offset）

因此整个滑动窗口变量为：

X={x0,⋯ ,xN,ρ1,⋯ ,ρM,ψ}\mathcal X = \{\mathbf x_0,\cdots,\mathbf x_N,\rho_1,\cdots,\rho_M,\psi\} X={x0​,⋯,xN​,ρ1​,⋯,ρM​,ψ}

GVINS 就是按照这种思路，把位置、速度、姿态、IMU Bias、视觉逆深度、GNSS 钟差 /钟漂以及局部 - 全球航向对齐量放进同一个优化问题

紧耦合的数学基础：MAP

假设所有未知状态统称为：

X\mathcal X X

所有传感器观测统称为：

Z\mathcal Z Z

我们的目标是：

X⋆=arg⁡max⁡p(X∣Z)\mathcal X^\star = \arg\max p(\mathcal X\mid\mathcal Z) X⋆=argmaxp(X∣Z)

这就是最大后验估计（Maximum A Posteriori，MAP）

根据 Bayes：

p(X∣Z)∝p(X)p(Z∣X)p(\mathcal X\mid\mathcal Z)∝ p(\mathcal X)p(\mathcal Z\mid\mathcal X) p(X∣Z)∝p(X)p(Z∣X)

如果不同观测在给定状态后条件独立，则：

p(Z∣X)=∏ip(zi∣X)p(\mathcal Z\mid\mathcal X) = \prod_i p(\mathbf z_i\mid \mathcal X) p(Z∣X)=i∏​p(zi​∣X)

因此则有：

X⋆=arg⁡max⁡Xp(X)∏ip(zi∣X)\mathcal X^\star = \arg\max_{\mathcal X} p(\mathcal X)\prod_i p(\mathbf z_i\mid\mathcal X) X⋆=argXmax​p(X)i∏​p(zi​∣X)

现在我们再假设，如果每一种传感器噪声都是 Gauss 噪声，即每个观测都可以写成：

Zi=hi(X)+ni\mathbf Z_i = h_i(\mathcal X) + \mathbf n_i Zi​=hi​(X)+ni​

其中：

ni∼N(0,σi)\mathbf n_i\sim\mathcal N(0,\sigma_i) ni​∼N(0,σi​)

定义残差：

ri=zi−hi(X)\mathbf r_i = \mathbf z_i - h_i(\mathcal X) ri​=zi​−hi​(X)

高斯概率：

p(zi∣X)∝exp⁡(−12ri⊤σi−1ri)p(\mathbf z_i\mid\mathcal X)∝\exp\left(-\frac{1}{2}\mathbf r_i^\top\sigma_i^{-1}\mathbf r_i\right) p(zi​∣X)∝exp(−21​ri⊤​σi−1​ri​)

对 MAP 取负对数：

X⋆=arg⁡min⁡X∑iru⊤σi−1ri\mathcal X^\star = \arg\min_{\mathcal X}\sum_i\mathbf r_u^\top\sigma_i^{-1}\mathbf r_i X⋆=argXmin​i∑​ru⊤​σi−1​ri​

如果我们定义信息矩阵：

Ωi=σi−1\Omega_i = \sigma_i^{-1} Ωi​=σi−1​

则得到：

X⋆=arg⁡min⁡X∑iru⊤Ωiri\mathcal X^\star = \arg\min_{\mathcal X}\sum_i\mathbf r_u^\top\Omega_i\mathbf r_i X⋆=argXmin​i∑​ru⊤​Ωi​ri​

这就是最核心的加权非线性最小二乘（Weighted Nonlinear Least Squares）

GVINS 正是把各种传感器观测全部写成这样的 residual factor，再一起进行联合优化

GVINS 中的 Factor

GVINS 中的核心优化图可以概括为：

J(X)=Jprior+JIMU+Jvisual+Jpseudorange+JDoppler+JclockJ(\mathcal X) = J_{\text{prior}} + J_{\text{IMU}} + J_{\text{visual}} + J_{\text{pseudorange}} + J_{\text{Doppler}} + J_{\text{clock}} J(X)=Jprior​+JIMU​+Jvisual​+Jpseudorange​+JDoppler​+Jclock​

也就是：

X⋆=arg⁡min⁡{∥rprior∥2+∑∥rIMU∥ΩI2+∑∥rvision∥ΩC2+∑rP2σP2+∑rD2σD2+∑∥rT∥ΩT2+∑rW2σW2}\mathcal X^\star = \arg\min\{\|\mathbf r_{\text{prior}}\|^2 + \sum\|\mathbf r_{\text{IMU}}\|^2_{\Omega_I} + \sum\|\mathbf r_{\text{vision}}\|^2_{\Omega_C} + \sum\frac{r_P^2}{\sigma_P^2} + \sum\frac{r_D^2}{\sigma_D^2} + \sum\|\mathbf r_T\|^2_{\Omega_T} + \sum\frac{r_W^2}{\sigma_W^2}\} X⋆=argmin{∥rprior​∥2+∑∥rIMU​∥ΩI​2​+∑∥rvision​∥ΩC​2​+∑σP2​rP2​​+∑σD2​rD2​​+∑∥rT​∥ΩT​2​+∑σW2​rW2​​}

其中：

  • IMU Factor：约束相邻时刻的运动
  • Visual Factor：约束不同相机帧看到的同一个特征
  • Pseudorange Factor：提供全球位置方向上的约束
  • Doppler Factor：提供速度约束
  • Clock Factor：约束接收机钟差和钟漂
  • Prior Factor：保留历史信息

GVINS 的因子图正是由这些因子所构成

IMU Preintegration Factor

IMU 是高频观测，例如 200Hz200\text{Hz}200Hz，而相机等是低频观测，可能只有 20Hz20\text{Hz}20Hz，如果两张图之间有 10 帧 IMU，我们不能给每一帧 IMU 都加一个完整的状态

因此我们考虑使用 IMU 预积分（IMU Preintegration）

INS 方程

下面我们给出惯性导航系统（INS / IMU）在连续时间下的三个状态微分方程

首先由位置的变化率得到速度，平凡但必要：

p˙=v\dot{\mathbf p} = \mathbf v p˙​=v

接着由速度的变化率得到加速度：

v˙=Rbw(a~−ba−an)+gw\dot{\mathbf v} = \mathbf R_b^w(\mathbf{\tilde a} -\mathbf b_a -\mathbf a_n) + \mathbf g^w v˙=Rbw​(a~−ba​−an​)+gw

其中，a~\mathbf{\tilde a}a~ 为加速度计测量，ba\mathbf b_aba​ 为加速度计零偏误差，na\mathbf n_ana​ 为加速度计测量噪声，Rbw\mathbf R_b^wRbw​ 为旋转矩阵，表示从机体系旋转回世界系，gw\mathbf g^wgw 为重力加速度

最后由旋转矩阵的导数得到角速度：

R˙bw=Rbw[ω~−bg−ng]×\dot{\mathbf R}_b^w = \mathbf R_b^w[\tilde{\omega} - \mathbf b_g - \mathbf n_g]_{\times} R˙bw​=Rbw​[ω~−bg​−ng​]×​

其中，ω~\tilde{\omega}ω~ 为陀螺仪测量，bg\mathbf b_gbg​ 为陀螺仪零偏误差，ng\mathbf n_gng​ 为陀螺仪测量噪声，Rbw\mathbf R_b^wRbw​ 为旋转矩阵，表示从机体系旋转回世界系

我们考虑两个关键帧：

tk→tk+1t_k\to t_{k+1} tk​→tk+1​

速度积分

积分：

vk+1w=vkw+gwΔt+RbkwΔvk,k+1\mathbf v_{k+1}^w = \mathbf v_k^w + \mathbf g^w\Delta t + \mathbf R_{b_k}^w\Delta\mathbf v_{k,k+1} vk+1w​=vkw​+gwΔt+Rbk​w​Δvk,k+1​

其中：

Δvk,k+1=∫tktk+1Rbtbk(a~t−ba)dt\Delta \mathbf v_{k,k+1} = \int_{t_k}^{t_{k+1}}\mathbf R_{b_t}^{b_k}(\tilde{\mathbf a}_t - \mathbf b_a)dt Δvk,k+1​=∫tk​tk+1​​Rbt​bk​​(a~t​−ba​)dt

其中，Rbtbk\mathbf R_{b_t}^{b_k}Rbt​bk​​ 同样为旋转矩阵，表示把 ttt 时刻机体系的向量，旋转到关键帧 kkk 的机体系下

位置积分

继续积分：

pk+1w=pkw+vkwΔt+12gwΔt2+RbkwΔpk,k+1\mathbf p_{k+1}^w = \mathbf p_k^w + \mathbf v_k^w\Delta t + \frac{1}{2}\mathbf g^w\Delta t^2 + \mathbf R_{b_k}^w\Delta \mathbf p_{k,k+1} pk+1w​=pkw​+vkw​Δt+21​gwΔt2+Rbk​w​Δpk,k+1​

其中：

Δpk,k+1=∫tktk+1∫tktRbτbk(a~τ−ba)dτdt\Delta p_{k,k+1} = \int_{t_k}^{t_{k+1}}\int_{t_k}^t\mathbf R_{b_\tau}^{b_k}(\mathbf{\tilde{a}}_\tau - \mathbf b_a)d\tau dt Δpk,k+1​=∫tk​tk+1​​∫tk​t​Rbτ​bk​​(a~τ​−ba​)dτdt

其中，Rbτbk\mathbf R_{b_\tau}^{b_k}Rbτ​bk​​ 同样为旋转矩阵，表示把 τ\tauτ 时刻机体系的向量，旋转到关键帧 kkk 的机体系下，然后对时间积分两次，得到这段区间的位移增量

姿态预积分

陀螺仪：

ω~−bg\tilde{\omega} - \mathbf b_g ω~−bg​

不断累积：

ΔRk,k+1=∏jexp⁡[(ω~j−bg)Δtj]\Delta \mathbf R_{k,k+1} = \prod_j\exp[(\tilde\omega_j - \mathbf b_g)\Delta t_j] ΔRk,k+1​=j∏​exp[(ω~j​−bg​)Δtj​]

IMU Factor residual

对于位置，其真实观测方程为：

pk+1w=pkw+vkwΔt+12gwΔt2+RbkwΔp\mathbf p_{k+1}^w = \mathbf p_k^w + \mathbf v_k^w\Delta t + \frac{1}{2}\mathbf g^w\Delta t^2 + \mathbf R_{b_k}^w\Delta \mathbf p pk+1w​=pkw​+vkw​Δt+21​gwΔt2+Rbk​w​Δp

移项得到：

Δp=(Rbkw)⊤(pk+1w−pkw−vkwΔt−12gwΔt2)\Delta \mathbf p = (\mathbf R_{b_k}^w)^\top\left( \mathbf p_{k+1}^w - \mathbf p_k^w - \mathbf v_k^w\Delta t - \frac{1}{2}\mathbf g^w\Delta t^2 \right) Δp=(Rbk​w​)⊤(pk+1w​−pkw​−vkw​Δt−21​gwΔt2)

通过预积分，我们又得到一个估计值：

Δp^\widehat{\Delta\mathbf p} Δp​

因此位置的 residual 为：

rΔp=(Rbkw)⊤(pk+1w−pkw−vkwΔt−12gwΔt2)−Δp^\mathbf r_{\Delta p} = (\mathbf R_{b_k}^w)^\top\left( \mathbf p_{k+1}^w - \mathbf p_k^w - \mathbf v_k^w\Delta t - \frac{1}{2}\mathbf g^w\Delta t^2 \right) - \widehat{\Delta\mathbf p} rΔp​=(Rbk​w​)⊤(pk+1w​−pkw​−vkw​Δt−21​gwΔt2)−Δp​

同理，速度的 residual 为：

rΔv=(Rbkw)⊤(vk+1w−vkw−gwΔt)−Δv^\mathbf r_{\Delta v} = (\mathbf R_{b_k}^w)^\top \left( \mathbf v_{k+1}^w-\mathbf v_k^w -\mathbf g^w\Delta t \right) - \widehat{\Delta\mathbf v} rΔv​=(Rbk​w​)⊤(vk+1w​−vkw​−gwΔt)−Δv

姿态的 residual 为：

rΔR=Log⁡(ΔR^⊤(Rbkw)⊤Rbk+1w)\mathbf r_{\Delta R} = \operatorname{Log} \left( \widehat{\Delta\mathbf R}^{\top} (\mathbf R_{b_k}^w)^\top \mathbf R_{b_{k+1}}^w \right) rΔR​=Log(ΔR⊤(Rbk​w​)⊤Rbk+1​w​)

再加上 Bias 随机游走的 residual：

rba=ba,k+1−ba,krbg=bg,k+1−bg,k\mathbf r_{b_a} = \mathbf b_{a,k+1}-\mathbf b_{a,k} \\\mathbf r_{b_g} = \mathbf b_{g,k+1}-\mathbf b_{g,k} rba​​=ba,k+1​−ba,k​rbg​​=bg,k+1​−bg,k​

因此整个 IMU Factor 是：

rIMU=[rΔprΔvrΔRrbarbg]\mathbf r_{\text{IMU}} = \begin{bmatrix} \mathbf r_{\Delta p}\\ \mathbf r_{\Delta v}\\ \mathbf r_{\Delta R}\\ \mathbf r_{b_a}\\ \mathbf r_{b_g} \end{bmatrix} rIMU​=⎣⎢⎢⎢⎢⎢⎡​rΔp​rΔv​rΔR​rba​​rbg​​​⎦⎥⎥⎥⎥⎥⎤​

总共是 151515 维的连续向量，这就是 GVINS 中使用的 IMU residual

IMU Factor 约束目标

IMU Factor 用于连接 xk\mathbf x_kxk​ 和 xk+1\mathbf x_{k+1}xk+1​，用于告诉优化器：根据这段时间的 IMU，kkk 时刻和 k+1k+1k+1 时刻的速度、位置、姿态、Bias 不可以随便取，它们必须满足 IMU 运动关系

换言之，IMU Factor 主要负责的是短时间、高频运动的连续性
