Error Bar 的含义

误差条的一般建模可以统一写成：

mean±error\text{mean} ± \text{error} mean±error

即以每个时刻数据均值为中心，上下偏移 error 大小，具体而言 error 可以是：

  1. Standard Deviation
  2. Standard Error
  3. 95% Confidence Interval
  4. Min/Max
  5. IQR

不同的误差条，使用的 error 含义不同，因此需要在图中对 Error Bars 的含义进行清晰的解释

Standard Deviation：标准差

如果每个时刻我们都重复实验 NNN 次，得到 NNN 个结果（比如每个时刻都做 NNN 组相互对照的实验）：

x1,…,xNx_1,\dots,x_N x1​,…,xN​

每个时刻的标准差即：

SD=1N−1∑i=1N(xi−xˉ)2\text{SD} = \sqrt{\frac{1}{N-1}\sum_{i=1}^N(x_i - \bar{x})^2} SD=N−11​i=1∑N​(xi​−xˉ)2​

它可以反映样本本身的分散程度

如果误差条画成：

Mean±SD\text{Mean} ± \text{SD} Mean±SD

则可以表达数据波动

Standard Error：标准误

定义每个时刻的标准误为：

SE=SDN\text{SE} = \frac{\text{SD}}{\sqrt{N}} SE=N​SD​

它不描述样本有多分散，而是反映均值估计的不确定性

如果每个时刻我们重复实验的次数 NNN 增加，即便样本自身波动不变，SE\text{SE}SE 也会下降，因此 SE\text{SE}SE 和 SD\text{SD}SD 二者并不等价

95% confidence Interval

我们通常用 SE\text{SE}SE 来近似表示 95% Confidence Interval：

95%CI≈xˉ±1.96SE95\%\text{CI}\approx\bar{x} ± 1.96\text{SE} 95%CI≈xˉ±1.96SE

Error 选择

如果想反映数据本身波动有多大，则选择 SD\text{SD}SD

如果想反映对均值的估计有多稳定，则选择 SE\text{SE}SE

如果想表达均值的不确定范围，则选择 95%CI95\%\text{CI}95%CI

误差带 / 误差条的来源

如果每一轮 / 每个时刻，我们只有一个观测 / 一个结果，而没有做重复实验或统计分布，此时就不能凭空去画误差带和误差条

只有每一轮 / 每个时刻都进行了多组实验，进而对每一轮 / 每个时刻的结果求均值（Mean）和误差（Std），才能进而绘制出误差带或误差条
