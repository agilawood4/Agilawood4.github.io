GNSS 信号误差源

GNSS 信号从卫星发出，到穿过大气层，再到地面接收机接收，分别会经过：

  1. 卫星空间段
  2. 大气传播段
  3. 地面接收段

对应三大类误差：

  1. 卫星轨道 / 钟差
  2. 电离层 / 对流层
  3. 多路径 / 接收机 / 天线误差

GNSS 伪距观测方程

GNSS 伪距最基本的模型可以写成：

P=ρ+c(δtr−δts)+I+T+εP = \rho + c(\delta t_r - \delta t_s) + I + T + \varepsilon P=ρ+c(δtr​−δts​)+I+T+ε

其中：

  • PPP：接收机测得的伪距
  • ρ\rhoρ：接收机到卫星的几何距离
  • δtr\delta t_rδtr​：接收机钟差
  • δts\delta t_sδts​：卫星钟差
  • III：电离层延迟
  • TTT：对流层延迟
  • ε\varepsilonε：其他误差，包括多路径、接收机噪声等

我们后续要了解的三段误差，可以和这个方程进行对应：

区域 主要误差
空间段 卫星轨道误差、卫星钟差、卫星硬件误差
大气段 电离层延迟、对流层延迟
地面段 接收机钟差、多路径、NLOS、接收机噪声、天线误差

空间段误差

所谓空间段，就是指误差来自卫星本身，最重要的两个是：

  1. 卫星轨道误差
  2. 卫星钟差

卫星轨道误差

GNSS 定位时，我们需要知道卫星在发射信号的时刻所处的位置

卫星通过导航电文广播自己的轨道参数，即广播星历（Broadcast Ephemeris），接收机根据星历计算卫星坐标：

(xs,ys,zs)(x_s,y_s,z_s) (xs​,ys​,zs​)

然后计算几何距离：

ρ=(xs−xr)2+(ys−yr)2+(zs−zr)2\rho = \sqrt{(x_s - x_r)^2 + (y_s - y_r)^2 + (z_s - z_r)^2} ρ=(xs​−xr​)2+(ys​−yr​)2+(zs​−zr​)2​

问题在于，广播星历给出的卫星位置不可能绝对准确，例如卫星实际位置是 xs\mathbf x_sxs​，计算使用的是 x^s\hat{\mathbf x}_sx^s​，那么：

Δxs=xs−x^s\Delta\mathbf x_s = \mathbf x_s - \hat{\mathbf x}_s Δxs​=xs​−x^s​

就是轨道误差

轨道误差的产生原因包括：

  1. 地球非球形引力场
  2. 太阳、月球摄动
  3. 太阳辐射压
  4. 星历预测误差
  5. 卫星姿态变化

对于普通单点定位，使用广播星历即可，而对于高精度定位，则需要使用精密星历，或做 RTK 差分等方式来解决

卫星钟差

GNSS定位的本质是：

距离=c×传播时间\text{距离} = c \times\text{传播时间} 距离=c×传播时间

所以对时间的测量必须及其准确

卫星虽然安装有高精度原子钟，但仍然存在微小偏差：

δts\delta t_s δts​

对应距离误差：

δρ=cδts\delta\rho = c\delta t_s δρ=cδts​

由于光速 c=3×108m/sc=3\times 10^8m/sc=3×108m/s 本身很大，所以很小的卫星钟差也会造成很大的距离偏差

大约 1ns 的时间误差会造成 30cm 的距离误差

相对论效应

GNSS 卫星高速运行，而且卫星所在位置的引力势和地面不同，根据狭义相对论和广义相对论可知，卫星钟和地面钟走时速度存在差异，如果不修正，会产生巨大的累积定位误差，所以 GNSS 系统在卫星钟设计和导航电文中已经对相对论效应进行了修正

目前只需要知道：由于卫星高速运动和地球引力场差异，会产生卫星钟的相对论时间偏差，需要进行修正

卫星硬件延迟

卫星内部会经历：

原子钟→信号生成→射频电路→天线\text{原子钟}\to\text{信号生成}\to\text{射频电路}\to\text{天线} 原子钟→信号生成→射频电路→天线

这些电子器件也会产生传播延迟，例如：

  1. 码硬件延迟
  2. 载波硬件延迟
  3. 不同频率之间的群延迟

比如 TGD（Timig Group Delay），群延迟差，在多频 GNSS 定位中需要考虑

卫星天线相位中心误差

卫星坐标通常是指卫星的质心，但实际上 GNSS 信号是从卫星天线相位中心发射出来，二者并不是完全重合

因此高精度定位中还需要考虑

  1. PCO（Phase Center Offset）：相位中心偏移
  2. PCV（Phase Center Variation）：相位中心变化

普通 SPP 不用特别关注，但在 PPP、精密定位中很重要

大气段误差

信号从 20000+ 公里的高空卫星传到地面时，要先后穿过电离层和对流层，所以大气段最核心就是电离层延迟和对流层延迟

电离层延迟

电离层位于大约距离地面几十到上千公里的高度范围，其中存在大量的自由电子，GNSS 电磁波通过电离层后，传播速度发生变化，由此产生传播延迟

一阶电离层延迟近似：

I∝TECf2I ∝ \frac{\text{TEC}}{f^2} I∝f2TEC​

其中，fff 为信号频率，TEC\text{TEC}TEC 为总电子含量

这是电离层最重要的性质，即不同频段的信号（L1、L2、L5）的电离层虽然误差不同，但都和 f2f^2f2 成反比，因此双频接收机可以利用不同频率的观测量消除一阶电离层误差

例如构造无电离层组合：

PIF=f12P1−f22P2f12−f22P_{IF} = \frac{f_1^2 P_1 - f_2^2 P_2}{f_1^2 - f_2^2} PIF​=f12​−f22​f12​P1​−f22​P2​​

基本能够消掉一阶电离层误差

电离层对伪距和载波的影响

对于伪距：

P=ρ+⋯+IP = \rho + \cdots + I P=ρ+⋯+I

电离层的影响表现为码延迟，即测得的距离变长

对于载波相位：

Φ=ρ+⋯−I+λN\Phi = \rho + \cdots - I + \lambda N Φ=ρ+⋯−I+λN

电离层的影响表现为相位超前

因此在二者公式中，伪距对应 +I+I+I，而载波相位对应 −I-I−I

电离层误差来源

电离层误差主要受到以下因素影响：

  1. 太阳活动
  2. 昼夜变化
  3. 纬度
  4. 季节
  5. 地磁活动
  6. 卫星高度角

尤其是低高度角卫星，低高度角会导致信号在电离层中的传播路径更长，对应电离层误差更大

对流层延迟

经过电离层后，GNSS 信号进入地球低层大气，主要成分为氮气、氧气、水汽等，它们会改变电磁波的传播速度，产生对流层延迟（Tropospheic Delay），对应 TTT

电离层延迟对应 III，即 Ionospheric Delay

对流层 vs. 电离层

电离层 对流层
主要原因 自由电子 干燥气体 + 水汽
与频率关系 强相关 GNSS频段下基本无关
是否色散介质 是 基本不是
双频能否直接消除 可以 不可以
常用处理 双频组合/模型 对流层模型+参数估计

对流层误差组成

对流层误差可以分为两部分：

T=Td+TwT = T_d + T_w T=Td​+Tw​

其中：

  1. TdT_dTd​ 为干分量（Dry Delay），主要由气压、干燥空气等产生，大概占比 90%，比较稳定且易于建模
  2. TwT_wTw​ 为湿分量（Wet Delay），主要由水汽等产生，虽然比例较小，但变化非常快，难以准确建模

高精度 GNSS 往往需要估计 ZWD\text{ZWD}ZWD，即 Zenith Wet Delay（天顶湿延迟）

地面段误差

卫星信号到达地面段以后，最主要的集中误差为：

  1. 接收机钟差
  2. 多路径 / NLOS
  3. 接收机噪声
  4. 接收机硬件误差
  5. 天线误差

接收机钟差

普通 GNSS 接收机并没有卫星那种昂贵的原子钟，而是使用普通晶振，所以接收机时间存在钟差 δtr\delta t_rδtr​，对应距离误差为 cδtrc\delta t_rcδtr​

因此 SPP 定位通常需要解至少四个未知量：

xr,yr,zr,δtrx_r,y_r,z_r,\delta t_r xr​,yr​,zr​,δtr​

因为有四个未知数，所以 GNSS 观测方程中至少需要四颗独立卫星

多路径误差

多路径是城市 GNSS 中最重要的问题之一

正常情况下，卫星 → 接收机直接传播，但当周围有建筑物时，卫星 → 建筑物 → 接收机会出现反射信号，于是接收机会同时接收到直达信号和反射信号，两者叠加，会影响码和载波的测量

这就是多路径（Multipath）

NLOS

NLOS（Non-Line-of-Sight），即非视距传播，它比普通的多路径还要严重

多路径可能仅仅是 LOS + 反射，而 NLOS 则可能导致直达信号完全被挡住，只剩反射信号，因此传播路径明显变长：

ρNLOS>ρLOS\rho_{\text{NLOS}}\gt\rho_{\text{LOS}} ρNLOS​>ρLOS​

导致伪距出现明显正偏差，城市峡谷中几米乃至几十米的误差，通常就是 NLOS 导致的

接收机测量噪声

接收机在信号捕获、跟踪、码测量、相位测量等过程中都存在随机噪声，通常伪距噪声大约在 dm∼mdm\sim mdm∼m 级，载波相位噪声大约在 mm∼cmmm\sim cmmm∼cm 级

载波相位明显比伪距精确，因此 RTK 使用载波相位可以做到厘米级精度

接收机天线误差

和卫星天线类似，接收机天线也存在：

  1. 相位中心偏移 PCO
  2. 相位中心变化 PCV

在高精度测量型 GNSS 中需要标定

接收机硬件延迟

接收机不同通道、不同频率的电子器件可能产生不同延迟

例如码间偏差、频间偏差、接收机差分码偏差在多系统、多频、PPP、精密授时中比较重要

环境干扰

现在环境干扰通常也会被归入地面端误差来源，主要分为：

  1. Jamming（压制式干扰）：强干扰信号导致接收机背景底噪升高，进而淹没微弱目标信号
  2. Spoofing（欺骗式干扰）：攻击者发射伪造的 GNSS 信号，让接收机算出错误的位置 / 速度 / 时间

复试答题模版

问题：请介绍一下 GNSS 的主要误差来源

回答：

  1. GNSS 误差可以按照信号传播链路分为空间段、大气传播段和地面接收段三类
  2. 空间段主要包括卫星轨道误差和卫星钟差，此外高精度定位还需要考虑相对论效应、卫星硬件延迟以及天线相位中心误差
  3. 大气传播段主要包括电离层和对流层延迟，电离层属于色散介质，误差与频率平方成反比，因此可以利用双频组合消除一阶电离层误差；对流层在 GNSS 频段基本属于非色散介质，通常需要通过模型修正或参数估计处理
  4. 地面接收段主要包括接收机钟差、接收机噪声、硬件延迟、天线相位中心误差，以及城市环境中非常重要的多路径和 NLOS 误差
