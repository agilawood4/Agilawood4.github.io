RTK and Kalman Filter

RTK 的全称为 Real-Time Kinematic，即实时动态差分定位，它的核心思想是：利用基准站和流动站同时观测同一批卫星，通过差分消除公共误差，再利用高精度载波相位观测估计整数模糊度，从而实现厘米级定位

RTK 整个过程大致可以分为以下几步：

  1. 原始 GNSS 观测
  2. 单差 / 双差模型
  3. 线性化
  4. 浮点解求解
  5. 整数模糊度固定
  6. 固定解求解

伪距 vs. 载波相位观测

伪距观测方程：

P=ρ+c(δtr−δts)+T+I+εPP = \rho + c(\delta t_r - \delta t_s) + T + I + \varepsilon_P P=ρ+c(δtr​−δts​)+T+I+εP​

伪距噪声一般是分米级到米级，单纯用伪距很难达到厘米级定位

载波相位观测方程：

Φ=ρ+c(δtr−δts)+T−I+λN+εΦ\Phi = \rho + c(\delta t_r - \delta t_s) + T - I + \lambda N + \varepsilon_\Phi Φ=ρ+c(δtr​−δts​)+T−I+λN+εΦ​

其中，Φ\PhiΦ 是载波相位转换成距离后的测量，λ\lambdaλ 是载波波长，NNN 是整数模糊度，载波相位精度可以达到毫米到厘米级

RTK 厘米级定位精度的根本基础是载波相位，但它多出来一个未知数 NNN，所以 RTK 的核心问题之一就是把整数模糊度 NNN 给解出来

单差与双差过程

假设基准站 bbb，流动站 rrr，卫星 i,ji,ji,j

站间单差

两台接收机对同一颗卫星 iii 的伪距观测作差：

ΔΦi=Φri−Φbi\Delta\Phi^i = \Phi_r^i - \Phi_b^i ΔΦi=Φri​−Φbi​

因为两个站接收同一颗卫星，所以卫星钟差基本一样，作差后卫星钟差被消除

在短基线情况下（流动站 rrr 和基准站 bbb 距离较近），二者的电离层误差、对流层误差、轨道误差都高度相关，作差后都会被大幅削弱

但是接收机钟差还在，因此需要再做一次差分消除

星间双差

再选择一颗参考卫星 jjj，构造两台接收机对 jjj 的单差，然后两个单差再次作差：

∇ΔΦij=ΔΦi−ΔΦj\nabla\Delta \Phi^{ij} = \Delta\Phi^i - \Delta\Phi^j ∇ΔΦij=ΔΦi−ΔΦj

这样接收机钟差会被消除，换言之，单差消除的是卫星钟差，双差消除的是接收机钟差

双差载波相位模型最终可以化简为：

∇ΔΦij=∇Δρij+λ∇ΔNij+ε\nabla\Delta\Phi^{ij} = \nabla\Delta\rho^{ij} + \lambda \nabla\Delta N^{ij} + \varepsilon ∇ΔΦij=∇Δρij+λ∇ΔNij+ε

该公式可以展开为：

∇ΔΦij=(Φri−Φbi)−(Φrj−Φbj)∇Δρij=(ρri−ρbi)−(ρrj−ρbj)∇ΔNij=(Nri−Nbi)−(Nrj−Nbj)\nabla\Delta\Phi^{ij} = (\Phi_r^i - \Phi_b^i) - (\Phi_r^j - \Phi_b^j)\\ \nabla\Delta\rho^{ij} = (\rho_r^i - \rho_b^i) - (\rho_r^j - \rho_b^j)\\ \nabla\Delta N^{ij} = (N_r^i - N_b^i) - (N_r^j - N_b^j) ∇ΔΦij=(Φri​−Φbi​)−(Φrj​−Φbj​)∇Δρij=(ρri​−ρbi​)−(ρrj​−ρbj​)∇ΔNij=(Nri​−Nbi​)−(Nrj​−Nbj​)

在短基线情况下，I,TI,TI,T 等公共误差也被明显削弱，所以 RTK 特别适用于短基线定位

双差线性化

双差非线性

以几何距离 ρri\rho_r^iρri​ 为例，流动站位置是未知的，假设卫星 iii 坐标已知：

si=[xsiysizsi]\mathbf s^i = \begin{bmatrix}x_s^i\\y_s^i\\z_s^i\end{bmatrix} si=⎣⎢⎡​xsi​ysi​zsi​​⎦⎥⎤​

流动站真实位置：

p=[xyz]\mathbf p = \begin{bmatrix}x\\y\\z\\\end{bmatrix} p=⎣⎢⎡​xyz​⎦⎥⎤​

二者间的几何距离为：

ρri=∥si−p∥\rho_r^i = \|\mathbf s^i - \mathbf p\| ρri​=∥si−p∥

将其展开为：

ρri=(xsi−x)2+(ysi−y)2+(zsi−z)2\rho_r^i = \sqrt{(x_s^i - x)^2 + (y_s^i - y)^2 + (z_s^i - z)^2} ρri​=(xsi​−x)2+(ysi​−y)2+(zsi​−z)2​

这就是双差非线性的来源

我们没法直接把这样一个平方根放到最小二乘或 Kalman Filter 中求解，因此我们需要先有一个流动站位置的近似值：

p0=[x0y0z0]\mathbf p_0 = \begin{bmatrix}x_0\\y_0\\z_0\\\end{bmatrix} p0​=⎣⎢⎡​x0​y0​z0​​⎦⎥⎤​

把真实位置写成估计值 + 修正量的形式：

p=p0+δp\mathbf p = \mathbf p_0 + \delta\mathbf p p=p0​+δp

其中我们真正要估计的是未知修正量：

δp=[δxδyδz]\delta \mathbf p = \begin{bmatrix}\delta x\\\delta y\\\delta z\\\end{bmatrix} δp=⎣⎢⎡​δxδyδz​⎦⎥⎤​

对 ρ\rhoρ 泰勒展开

我们把 ρri(p)\rho_r^i(\mathbf p)ρri​(p) 在 p0\mathbf p_0p0​ 位置附近做泰勒展开：

ρri≈ρri(p0)+∂ρri∂xδx+∂ρri∂yδy+∂ρri∂zδz\rho_r^i\approx\rho_r^i(\mathbf p_0) + \frac{\partial \rho_r^i}{\partial x}\delta x + \frac{\partial \rho_r^i}{\partial y}\delta y + \frac{\partial \rho_r^i}{\partial z}\delta z ρri​≈ρri​(p0​)+∂x∂ρri​​δx+∂y∂ρri​​δy+∂z∂ρri​​δz

三个偏导分别可以算得：

∂ρri∂x=x−xsiρri∂ρri∂y=y−ysiρri∂ρri∂z=z−zsiρri\frac{\partial \rho_r^i}{\partial x} = \frac{x - x_s^i}{\rho_r^i}\\ \frac{\partial \rho_r^i}{\partial y} = \frac{y - y_s^i}{\rho_r^i}\\ \frac{\partial \rho_r^i}{\partial z} = \frac{z - z_s^i}{\rho_r^i} ∂x∂ρri​​=ρri​x−xsi​​∂y∂ρri​​=ρri​y−ysi​​∂z∂ρri​​=ρri​z−zsi​​

在近似位置 p0\mathbf p_0p0​ 处，我们令：

gi=[x0−xsiρr,0iy0−ysiρr,0iz0−zsiρr,0i]\mathbf g_i = \left[\frac{x_0 - x_s^i}{\rho_{r,0}^i}\quad\frac{y_0 - y_s^i}{\rho_{r,0}^i}\quad\frac{z_0 - z_s^i}{\rho_{r,0}^i}\right] gi​=[ρr,0i​x0​−xsi​​ρr,0i​y0​−ysi​​ρr,0i​z0​−zsi​​]

也就是导数值代入 p0=[x0y0z0]⊤\mathbf p_0 = [x_0\quad y_0\quad z_0]^\topp0​=[x0​y0​z0​]⊤，同时令：

δp=[δxδyδz]\delta \mathbf p = \begin{bmatrix}\delta x\\\delta y\\\delta z\\\end{bmatrix} δp=⎣⎢⎡​δxδyδz​⎦⎥⎤​

则有：

ρri≈ρr,0i+giδp\rho_r^i \approx \rho_{r,0}^i + \mathbf g_i\delta\mathbf p ρri​≈ρr,0i​+gi​δp

LOS 向量

上述公式中的 gi\mathbf g_igi​ 本质上就是卫星视线方向 LOS 向量的负方向

我们定义：

ei=si−p0∥si−p0∥\mathbf e_i = \frac{\mathbf s^i - \mathbf p_0}{\|\mathbf s^i - \mathbf p_0\|} ei​=∥si−p0​∥si−p0​​

表示从接收机指向卫星 iii 的单位向量

那么根据 gi\mathbf g_igi​ 的定义，则有：

gi=−ei⊤\mathbf g_i = -\mathbf e_i^\top gi​=−ei⊤​

所以上述线性化公式也可以等价写成：

ρri≈ρr,0i−e⊤δp\rho_r^i \approx \rho_{r,0}^i - \mathbf e^\top\delta\mathbf p ρri​≈ρr,0i​−e⊤δp

后续我们采用这种写法

单差线性化

上面我们求得流动站 rrr 到卫星 iii 几何距离的线性化估计：

ρri=ρr,0i−e⊤δp\rho_r^i = \rho_{r,0}^i - \mathbf e^\top\delta\mathbf p ρri​=ρr,0i​−e⊤δp

同理，对参考卫星 jjj 也可做线性化估计：

ρrj≈ρr,0j−e⊤δp\rho_r^j\approx\rho_{r,0}^j - \mathbf e^\top\delta\mathbf p ρrj​≈ρr,0j​−e⊤δp

流动站到两个卫星之间的几何距离差即可写为：

ρri−ρrj=(ρr,0i−ρr,0j)−(ei−ej)⊤δp\rho_r^i - \rho_r^j = (\rho_{r,0}^i - \rho_{r,0}^j) - (\mathbf e_i - \mathbf e_j)^\top\delta\mathbf p ρri​−ρrj​=(ρr,0i​−ρr,0j​)−(ei​−ej​)⊤δp

双差线性化

双差几何距离为：

∇Δρij=(ρri−ρbj)−(ρrj−ρbj)\nabla\Delta \rho^{ij} = (\rho_r^i - \rho_b^j) - (\rho_r^j - \rho_b^j) ∇Δρij=(ρri​−ρbj​)−(ρrj​−ρbj​)

重新整理得到：

∇Δρij=(ρri−ρrj)−(ρbi−ρbj)\nabla\Delta\rho^{ij} = (\rho_r^i - \rho_r^j) - (\rho_b^i - \rho_b^j) ∇Δρij=(ρri​−ρrj​)−(ρbi​−ρbj​)

因为基准站位置 pb\mathbf p_bpb​、参考卫星位置 sj\mathbf s^jsj 都已知，因此 ρbi,ρbj\rho_b^i,\rho_b^jρbi​,ρbj​ 都是已知量

我们把刚才流动站线性化的结果代入：

∇Δρij≈(ρr,0i−ρr,0j)−(ei−ej)⊤δp−(ρbi−ρbj)\nabla\Delta\rho^{ij}\approx (\rho_{r,0}^i - \rho_{r,0}^j) - (\mathbf e_i - \mathbf e_j)^\top\delta\mathbf p - (\rho_b^i - \rho_b^j) ∇Δρij≈(ρr,0i​−ρr,0j​)−(ei​−ej​)⊤δp−(ρbi​−ρbj​)

定义在当前近似位置计算得到的双差几何距离：

∇Δρ0ij=(ρr,0i−ρbi)−(ρr,0j−ρbj)\nabla\Delta\rho_0^{ij} = (\rho_{r,0}^i - \rho_b^i) - (\rho_{r,0}^j - \rho_b^j) ∇Δρ0ij​=(ρr,0i​−ρbi​)−(ρr,0j​−ρbj​)

于是最终得到：

∇Δρij≈∇Δρ0ij−(ei−ej)⊤δp\nabla\Delta\rho^{ij}\approx\nabla\Delta \rho_0^{ij} - (\mathbf e_i - \mathbf e_j)^\top\delta\mathbf p ∇Δρij≈∇Δρ0ij​−(ei​−ej​)⊤δp

线性距离回代

原本的双差载波相位观测为：

∇ΔΦij=∇Δρij+λNij+εij\nabla\Delta\Phi^{ij} = \nabla\Delta\rho^{ij} + \lambda N^{ij} + \varepsilon^{ij} ∇ΔΦij=∇Δρij+λNij+εij

代入线性化结果：

∇ΔΦij=∇Δρ0ij−(ei−ej)⊤δp+λNij+εij\nabla\Delta\Phi^{ij} = \nabla\Delta\rho_0^{ij} - (\mathbf e_i - \mathbf e_j)^\top\delta\mathbf p + \lambda N^{ij} + \varepsilon^{ij} ∇ΔΦij=∇Δρ0ij​−(ei​−ej​)⊤δp+λNij+εij

把所有已知项已到左侧：

∇ΔΦij−∇Δρ0ij=−(ei−ej)⊤δp+λNij+εij\nabla\Delta\Phi^{ij} - \nabla\Delta\rho_0^{ij} = -(\mathbf e_i - \mathbf e_j)^\top\delta\mathbf p + \lambda N^{ij} + \varepsilon^{ij} ∇ΔΦij−∇Δρ0ij​=−(ei​−ej​)⊤δp+λNij+εij

定义：

zij=∇ΔΦij−∇Δρ0ijz^{ij} = \nabla\Delta\Phi^{ij} - \nabla\Delta\rho_0^{ij} zij=∇ΔΦij−∇Δρ0ij​

于是最终得到：

zij=−(ei−ej)⊤δp+λNij+εijz^{ij} = -(\mathbf e_i - \mathbf e_j)^\top\delta\mathbf p + \lambda N^{ij} + \varepsilon^{ij} zij=−(ei​−ej​)⊤δp+λNij+εij

这就是一个标准的线性方程

变形：z=Hx+vz = Hx+vz=Hx+v

把状态向量定义成：

x=[δxδyδzNij]\mathbf x = \begin{bmatrix}\delta x\\\delta y\\\delta z\\ N^{ij}\\\end{bmatrix} x=⎣⎢⎢⎢⎡​δxδyδzNij​⎦⎥⎥⎥⎤​

接着定义矩阵 HHH 为：

H=[−(eix−ejx)−(eiy−ejy)−(eiz−ejz)λ]H = [-(e_{ix}-e_{jx})\quad-(e_{iy}-e_jy{})\quad-(e_{iz}-e_{jz})\quad\lambda] H=[−(eix​−ejx​)−(eiy​−ej​y)−(eiz​−ejz​)λ]

也是最终得到：

zij=Hx+εijz^{ij} = H\mathbf x + \varepsilon^{ij} zij=Hx+εij

这就是一条双差的最终观测方程

多星观测矩阵化

假设当前一共观测到 mmm 颗卫星，选择卫星 111 为参考卫星，则可以构造 m−1m-1m−1 条双差：

(2,1),(3,1),⋯ ,(m,1)(2,1),(3,1),\cdots,(m,1) (2,1),(3,1),⋯,(m,1)

每个双差都对应一个模糊度：

N21,N31,⋯ ,Nm1N^{21},N^{31},\cdots,N^{m1} N21,N31,⋯,Nm1

由此构建状态向量：

x=[δxδyδzN21N31⋮Nm1]\mathbf x = \begin{bmatrix}\delta x\\\delta y\\\delta z\\N^{21}\\N^{31}\\\vdots\\N^{m1}\\ \end{bmatrix} x=⎣⎢⎢⎢⎢⎢⎢⎢⎢⎢⎢⎡​δxδyδzN21N31⋮Nm1​⎦⎥⎥⎥⎥⎥⎥⎥⎥⎥⎥⎤​

观测向量：

z=[z21z31⋮zm1]\mathbf z = \begin{bmatrix} z^{21}\\z^{31}\\\vdots\\z^{m1}\\ \end{bmatrix} z=⎣⎢⎢⎢⎢⎡​z21z31⋮zm1​⎦⎥⎥⎥⎥⎤​

其中：

zi1=∇ΔΦi1−∇Δρ0i1z^{i1} = \nabla\Delta \Phi^{i1} - \nabla\Delta\rho_0^{i1} zi1=∇ΔΦi1−∇Δρ0i1​

观测矩阵 H\mathbf HH 为：

H=[−(e2−e1)⊤0λ00−(e3−e1)⊤00λ0⋮⋮⋮⋮⋮−(em−e1)⊤000λ]\mathbf H = \begin{bmatrix} -(\mathbf e_2 - \mathbf e_1)^\top & 0 & \lambda & 0 & 0\\ -(\mathbf e_3 - \mathbf e_1)^\top & 0 & 0 & \lambda & 0\\ \vdots & \vdots & \vdots & \vdots & \vdots\\ -(\mathbf e_m - \mathbf e_1)^\top & 0 & 0 & 0 & \lambda\\ \end{bmatrix} H=⎣⎢⎢⎢⎢⎡​−(e2​−e1​)⊤−(e3​−e1​)⊤⋮−(em​−e1​)⊤​00⋮0​λ0⋮0​0λ⋮0​00⋮λ​⎦⎥⎥⎥⎥⎤​

将第一列展开为：

H=[h2xh2yh2z0λ00h3xh3yh3z00λ0⋮⋮⋮⋮⋮⋮⋮hmxhmyhmz000λ]\mathbf H = \begin{bmatrix} h_{2x} & h_{2y} & h_{2z} & 0 & \lambda & 0 & 0\\ h_{3x} & h_{3y} & h_{3z} & 0 & 0 & \lambda & 0\\ \vdots & \vdots & \vdots & \vdots & \vdots & \vdots & \vdots\\ h_{mx} & h_{my} & h_{mz} & 0 & 0 & 0 & \lambda\\ \end{bmatrix} H=⎣⎢⎢⎢⎢⎡​h2x​h3x​⋮hmx​​h2y​h3y​⋮hmy​​h2z​h3z​⋮hmz​​00⋮0​λ0⋮0​0λ⋮0​00⋮λ​⎦⎥⎥⎥⎥⎤​

其中：

hi=−(ei−e1)⊤\mathbf h_i = -(e_i - e_1)^\top hi​=−(ei​−e1​)⊤

因此最终得到矩阵形式的线性观测：

z=Hx+v\mathbf z = \mathbf H\mathbf x + \mathbf v z=Hx+v

Kalman Filter

现在我们得到了单个历元的观测模型：

zk=Hkxk+vk\mathbf z_k = \mathbf H_k \mathbf x_k + \mathbf v_k zk​=Hk​xk​+vk​

假如 vk∼N(0,Rk)\mathbf v_k\sim\mathcal N(0,\mathbf R_k)vk​∼N(0,Rk​)，其中 Rk\mathbf R_kRk​ 为观测噪声协方差，则通过 WLS（加权最小二乘）可以解得：

x^k=(Hk⊤Rk−1Hk)−1Hk⊤Rk−1zk\hat{\mathbf x}_k = (\mathbf H_k^\top\mathbf R_k^{-1}\mathbf H_k)^{-1}\mathbf H_k^\top\mathbf R_k^{-1}\mathbf z_k x^k​=(Hk⊤​Rk−1​Hk​)−1Hk⊤​Rk−1​zk​

该解法的特点在于，只利用第 kkk 个历元当前的观测，前面 k−1k-1k−1 个历元的信息，并没有显式参与

但实时 RTK 是 1,2,3,⋯ ,k−1,k,k+1,⋯1,2,3,\cdots,k-1,k,k+1,\cdots1,2,3,⋯,k−1,k,k+1,⋯ 这样连续不断的历元，显然 xk\mathbf x_kxk​ 和 xk−1\mathbf x_{k-1}xk−1​ 也存在关系

所以我们希望利用上一历元估计结合当前 GNSS 观测同时来估计当前状态，这就是 Kalman Filter

Kalman Filter

WLS 相当于只有观测方程，Kalman Filter 相比之多了状态方程，即：

xk=Fkxk−1+wk\mathbf x_k = \mathbf F_k\mathbf x_{k-1} + \mathbf w_k xk​=Fk​xk−1​+wk​

其中，xk−1\mathbf x_{k-1}xk−1​ 为上一时刻状态，xk\mathbf x_kxk​ 为当前状态，Fk\mathbf F_kFk​ 为状态转移矩阵，wk\mathbf w_kwk​ 为过程噪声

假设 wk∈N(0,Qk)\mathbf w_k\in\mathcal N(0,\mathbf Q_k)wk​∈N(0,Qk​)，其中 Qk\mathbf Q_kQk​ 为过程噪声协方差，它描述我们对状态运动模型的不确定性，满足：

Qk=E[wkwk⊤]\mathbf Q_k = \mathbb E[\mathbf w_k\mathbf w_k^\top] Qk​=E[wk​wk⊤​]

Kalman Filter 估计的 RTK 状态

最简单的 RTK 状态包含：

  1. 位置修正量
  2. 双差浮点模糊度

实际系统中还可能加入速度、加速度、对流层参数、电离层参数、接收机钟差等信息

对于模糊度而言，在没有发生周跳、失锁和卫星切换时，整数模糊度几乎保持不变：

Nk=Nk−1N_k = N_{k-1} Nk​=Nk−1​

所以它天然具有很强的时间连续性，例如：

N1,k=N1,k−1+wNN_{1,k} = N_{1,k-1} + w_N N1,k​=N1,k−1​+wN​

其中 wNw_NwN​ 通常设置的很小，因此 KF 可以随着历元增加不断积累信息，让浮点模糊度越来越精确，这也是 KF 对 RTK 很重要的原因

KF 第一阶段：预测

假设第 k−1k-1k−1 个历元已经得到后验状态估计：

x^k−1+\hat{ x}_{k-1}^+ x^k−1+​

以及对应的后验估计误差协方差：

Pk−1+P_{k-1}^+ Pk−1+​

定义第 k−1k-1k−1 历元的后验状态估计误差为：

第二项，残差是 z−Hxz - Hxz−Hx，权矩阵是 R−1R^{-1}R−1，表示当前观测 zzz 对 xxx 的约束

KF WLS 最优解求解

我们把 J(x)J(x)J(x) 进行拆分：

J(x)=J1+J2J(x) = J_1 + J_2 J(x)=J1​+J2​

其中：

J1=(x−x^−)⊤(P−)−1(x−x^−)J_1 = (x - \hat x^-)^\top (P^-)^{-1} (x - \hat x^-) J1​=(x−x^−)⊤(P−)−1(x−x^−)

J2=(z−Hx)⊤R−1(z−Hx)J_2 = (z - Hx)^\top R^{-1} (z - Hx) J2​=(z−Hx)⊤R−1(z−Hx)

我们令 J(x)J(x)J(x) 对 xxx 求导，利用二次型求导公式：

∂∂x(x−a)⊤A(x−a)=(A+A⊤)(x−a)\frac{\partial}{\partial x}(x - a)^\top A(x - a) = (A+A^\top)(x - a) ∂x∂​(x−a)⊤A(x−a)=(A+A⊤)(x−a)

分别得到：

∂J1∂x=2(P−)−1(x−x^−)\frac{\partial J_1}{\partial x} = 2(P^-)^{-1}(x - \hat x^-) ∂x∂J1​​=2(P−)−1(x−x^−)

∂J2∂x=−2H⊤R−1(z−Hx)\frac{\partial J_2}{\partial x} = -2H^\top R^{-1}(z - Hx) ∂x∂J2​​=−2H⊤R−1(z−Hx)

因此最终则有：

∂J∂x=2(P−)−1(x−x^−)−2H⊤R−1(z−Hx)\frac{\partial J}{\partial x} = 2(P^-)^{-1}(x - \hat x^-) -2H^\top R^{-1}(z - Hx) ∂x∂J​=2(P−)−1(x−x^−)−2H⊤R−1(z−Hx)

令导数为零则有：

[(P−)−1+H⊤R−1H]x=(P−)−1x^−+H⊤R−1z[(P^-)^{-1} + H^\top R^{-1} H]x = (P^-)^{-1}\hat x^- + H^\top R^{-1}z [(P−)−1+H⊤R−1H]x=(P−)−1x^−+H⊤R−1z

最终则有：

x^+=[(P−)−1+H⊤R−1H]−1[(P−)−1x^−+H⊤R−1z]\hat x^+= [(P^-)^{-1} + H^\top R^{-1} H]^{-1}[(P^-)^{-1}\hat x^- + H^\top R^{-1}z] x^+=[(P−)−1+H⊤R−1H]−1[(P−)−1x^−+H⊤R−1z]

这就是 KF WLS 得到的后验估计

对应后验高斯分布的信息矩阵为：

(P+)−1=(P−)−1+H⊤R−1H(P^+)^{-1} = (P^-)^{-1} + H^\top R^{-1} H (P+)−1=(P−)−1+H⊤R−1H

则后验估计误差协方差更新公式为：

P+=[(P−)−1+H⊤R−1H]−1P^+ = [(P^-)^{-1} + H^\top R^{-1} H]^{-1} P+=[(P−)−1+H⊤R−1H]−1

浮点解和整周模糊度固定

浮点解

我们先把模糊度当做普通实数 N∈RN\in\mathbb RN∈R 而不是整数，通过最小二乘或者卡尔曼滤波估计，得到：

x^=[p^N^]\hat{\mathbf x} = \begin{bmatrix} \hat{\mathbf p}\\\hat{\mathbf N}\\ \end{bmatrix} x^=[p^​N^​]

虽然真正的 NNN 要求必须是整数，但这里我们暂时先得到一个实数估计，则就是浮点解（Float Solution）

假设我们当前得到一组模糊度浮点解为 N^=[12.27.7]\hat{\mathbf N} = \begin{bmatrix} 12.2\\7.7\\ \end{bmatrix}N^=[12.27.7​]，不能将其简单变成 [128]\begin{bmatrix}12\\8\\\end{bmatrix}[128​]，因为不同模糊度之间具有相关性，真正需要考虑的是 QN^\mathbf Q_{\hat{\mathbf N}}QN^​，也就是浮点模糊度的协方差矩阵

所以整数模糊度固定本质上是：

min⁡N∈Zn(N−N^)⊤QN^−1(N−N^)\min_{\mathbf N\in\mathbb Z^n}(\mathbf N - \hat{\mathbf N})^\top\mathbf Q_{\hat{\mathbf N}}^{-1}(\mathbf N - \hat{\mathbf N}) N∈Znmin​(N−N^)⊤QN^−1​(N−N^)

这是一个整数最小二乘问题

LAMBDA 算法

LAMBDA（Least-squares AMBiguity Decorrelation Adjustmet）只要用于解决整数模糊度搜索的问题

它并不是简单对 N^\hat{\mathbf N}N^ 做四舍五入，而是：

  1. 对高度相关的模糊度进行去相关
  2. 在整数空间寻找最优候选解
  3. 找到距离浮点解最近的整数向量

通过 LAMBDA 算法，我们找到最优候选的整数模糊度 N1\mathbf N_1N1​，以及次优候选的整数模糊度 N2\mathbf N_2N2​，二者残差平方应满足：

s1<s2s_1\lt s_2 s1​<s2​

通常还要做 Ratio Test\text{Ratio Test}Ratio Test 来判断第一候选是否足够可靠

Ratio Test

常见形式为：

Ratio=s2s1\text{Ratio} = \frac{s_2}{s_1} Ratio=s1​s2​​

其中，s1s_1s1​ 为最佳整数候选的残差平方，s2s_2s2​ 为次优整数候选的残差平方

如果：

s2s1>γ\frac{s_2}{s_1}\gt\gamma s1​s2​​>γ

说明最优候选明显优于次优候选，此时才接受固定，否则就继续保持浮点解

固定解

得到固定的整数模糊度 Nˇ\check{\mathbf N}Nˇ 以后，将模糊度作为已知整数约束，再重新估计位置 p^fix\hat{\mathbf p}_{\text{fix}}p^​fix​，这就是所谓的固定解（Fixed Solution），精度可以提升到厘米级

RTK 可以总结为：先通过双差消除公共误差，再利用载波相位求浮点模糊度，然后通过 LAMBDA 将模糊度固定为整数，最终得到厘米级的固定解
