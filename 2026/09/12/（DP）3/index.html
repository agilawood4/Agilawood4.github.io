数据清洗

数据清洗的目标，是把 Raw Data\text{Raw Data}Raw Data 变成 Clean Data\text{Clean Data}Clean Data，合格的数据清洗，不是发现异常就删除，而是先判断这个值为什么异常，再决定删除、修正、填补还是保留

NaN 的处理

对缺失值的处理是数据清洗中最重要的问题之一，我们不是简单的 dropna()，而是主要有三种处理策略：

  1. 删除
  2. 填补
  3. 保留

这具体取决于当前字段是什么，以及缺失为什么发生

统计异常值 Outlier

对这份数据中的 C/N0 做统计：

我们发现最大值为 88.8 dB-Hz，这一条非常可疑

但这里需要区分 Invalid Value 和 Outlier，C/N0 的最大值为 88.8 dB-Hz 只是高度可疑，但不能直接认为它是非法数值

换言之，异常值处理需要分为两类

  1. 数据错误：比如不符合范围的高度角，可以根据物理规矩认定为错误数据
  2. 极端但真实的数据，比如因为干扰发生而出现的较大 residual，这是研究对象，应该被保留

IQR 异常值检测

IQR（Interquartile Range），称为四分位距，定义为：

IQR=Q3−Q1\text{IQR} = Q_3 - Q_1 IQR=Q3​−Q1​

其中：

Q1=P25Q3=P75Q_1 = P_{25}\\ Q_3 = P_{75} Q1​=P25​Q3​=P75​

经典规则认为，如果：

x<Q1−1.5 IQRx\lt Q_1 - 1.5\,\text{IQR} x<Q1​−1.5IQR

或者：

x>Q3+1.5 IQRx\gt Q_3 + 1.5\, \text{IQR} x>Q3​+1.5IQR

则可以判定为统计意义上的异常点，也就是需要被当做 Invalid Value 处理

upper=μ+3σlower=μ−sσ\text{upper} = \mu + 3\sigma\\ \text{lower} = \mu - s\sigma upper=μ+3σlower=μ−sσ
