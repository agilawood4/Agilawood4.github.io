因子图

以 GNSS + PDR 组合导航为例，因子图的核心思想为：把导航状态作为变量节点，把 GNSS / PDR 等约束作为因子，通过联合优化得到最优轨迹

因子图

因子图（Factor Graph）是一种表示变量与约束之间关系的图模型，它包含两类节点：

  1. 变量节点（Variable Node）：要估计的未知状态
  2. 因子节点（Factor）：传感器观测或运动模型对状态施加的约束

例如我们想估计行人在各个时刻的位置：

X={x0,x1,x2,⋯ ,xN}\mathbf X = \{\mathbf x_0,\mathbf x_1,\mathbf x_2,\cdots,\mathbf x_N\} X={x0​,x1​,x2​,⋯,xN​}

其中，最简单地可以令：

xk=[xkyk]\mathbf x_k = \begin{bmatrix} x_k\\y_k\\ \end{bmatrix} xk​=[xk​yk​​]

表示 kkk 时刻的二维位置，那么 GNSS 告诉我们第 kkk 时刻的位置大概在哪里，PDR 告诉我们从第 kkk 时刻到第 k+1k+1k+1 时刻走了多远，往哪个方向走

于是就可以形成：

x0⟷PDRx1⟷PDRx2⟷PDRx3x_0 \overset{\text{PDR}}{\longleftrightarrow} x_1 \overset{\text{PDR}}{\longleftrightarrow} x_2 \overset{\text{PDR}}{\longleftrightarrow} x_3 x0​⟷PDR​x1​⟷PDR​x2​⟷PDR​x3​

同时每个时刻可能还有：

xk⟷GNSSx_k \longleftrightarrow \text{GNSS} xk​⟷GNSS

这就是一个最简单的 GNSS / PDR 因子图

因子图 → 最小二乘

首先我们有 Bayes 公式：

p(A∣B)=p(B∣A)p(A)p(B)p(A\mid B) = \frac{p(B\mid A)p(A)}{p(B)} p(A∣B)=p(B)p(B∣A)p(A)​

这四个概率分别是：

  • p(A)p(A)p(A)：先验概率 Prior，看到 BBB 之前对 AAA 的认识
  • p(B∣A)p(B\mid A)p(B∣A)：似然 Likelihood，假设 AAA 成立，出现 BBB 的可能性
  • p(A∣B)p(A\mid B)p(A∣B)：后验概率 Positerior，看到 BBB 以后对 AAA 的新认识
  • p(B)p(B)p(B)：证据项，用来归一化

用一句话概括就是：

后验∝似然×先验\text{后验}∝\text{似然}\times\text{先验} 后验∝似然×先验

因为如果我们只关心：

arg⁡max⁡Ap(A∣B)\arg\max_A p(A\mid B) argAmax​p(A∣B)

而 p(B)p(B)p(B) 和 AAA 无关，可以直接忽略，所以有：

p(A∣B)∝p(B∣A)p(A)p(A\mid B)∝p(B\mid A)p(A) p(A∣B)∝p(B∣A)p(A)

现在我们要估计整条轨迹：

X={x0,x1,⋯ ,xN}\mathbf X = \{\mathbf x_0,\mathbf x_1,\cdots,\mathbf x_N\} X={x0​,x1​,⋯,xN​}

所有观测记为：

Z={z1,z2,⋯ ,zM}\mathbf Z = \{\mathbf z_1,\mathbf z_2,\cdots,\mathbf z_M\} Z={z1​,z2​,⋯,zM​}

我们的目标是：

p(X∣Z)p(\mathbf X\mid\mathbf Z) p(X∣Z)

即已知所有 GNSS、PDR 等观测以后，某条轨迹 X\mathbf XX 出现的概率是多少

利用 Bayes：

p(X∣Z)=p(Z∣X)p(X)p(Z)p(\mathbf X\mid\mathbf Z) = \frac{p(\mathbf Z\mid\mathbf X)p(\mathbf X)}{p(\mathbf Z)} p(X∣Z)=p(Z)p(Z∣X)p(X)​

同理，p(Z)p(\mathbf Z)p(Z) 和待估计的 X\mathbf XX 无关，所以：

p(X∣Z)∝p(Z∣X)p(X)p(\mathbf X\mid \mathbf Z)∝ p(\mathbf Z\mid\mathbf X)p(\mathbf X) p(X∣Z)∝p(Z∣X)p(X)

假设有很多传感器观测：

z1,z2,⋯ ,zM\mathbf z_1,\mathbf z_2,\cdots,\mathbf z_M z1​,z2​,⋯,zM​

那么：

p(Z∣X)=p(z1,z2,⋯ ,zM∣X)p(\mathbf Z\mid\mathbf X) = p(\mathbf z_1,\mathbf z_2,\cdots,\mathbf z_M\mid\mathbf X) p(Z∣X)=p(z1​,z2​,⋯,zM​∣X)

如果假设在给定真实状态 X\mathbf XX 以后，各个观测噪声相互独立，那么联合概率就可以拆成：

p(Z∣X)=∏ip(zi∣z1,z2,⋯ ,X)p(\mathbf Z\mid\mathbf X) = \prod_i p(\mathbf z_i\mid z_1,z_2,\cdots,\mathbf X) p(Z∣X)=i∏​p(zi​∣z1​,z2​,⋯,X)

进一步化简即得到：

p(Z∣X)=∏ip(zi∣Xi)p(\mathbf Z\mid\mathbf X) = \prod_i p(\mathbf z_i\mid\mathbf X_i) p(Z∣X)=i∏​p(zi​∣Xi​)

其中，Xi\mathbf X_iXi​ 表示第 iii 个观测所依赖的状态

对于 GNSS 因子而言，GNSS 位置观测只依赖 xkx_kxk​，因此可以写成：

p(zkGNSS∣xk)p(z_k^{\text{GNSS}}\mid x_k) p(zkGNSS​∣xk​)

对于 PDR 因子而言，PDR 位移约束同时依赖 xk,xk+1x_k,x_{k+1}xk​,xk+1​，因此可以写成：

p(zkPDR∣xk,xk+1)p(z_k^{\text{PDR}}\mid x_k,x_{k+1}) p(zkPDR​∣xk​,xk+1​)

这样的每一个 p(zi∣Xi)p(\mathbf z_i\mid\mathbf X_i)p(zi​∣Xi​) 就对应因子图里面的一个因子

因此我们最终得到：

p(X∣Z)∝p(X)∏ip(zi∣Xi)p(\mathbf X\mid\mathbf Z) ∝ p(\mathbf X)\prod_i p(\mathbf z_i\mid\mathbf X_i) p(X∣Z)∝p(X)i∏​p(zi​∣Xi​)

如果我们建模中只有一个单独的初始先验 p(x0)p(\mathbf x_0)p(x0​)，而 PDR、GNSS 等约束全部作为因子放在乘积中，则可以进一步写成：

p(X∣X)∝p(x0)∏ip(zi∣Xi)p(\mathbf X\mid\mathbf X)∝p(\mathbf x_0)\prod_i p(\mathbf z_i\mid\mathbf X_i) p(X∣X)∝p(x0​)i∏​p(zi​∣Xi​)

对于第 iii 个因子，我们建立统一的观测模型：

zi=hi(Xi)+vi\mathbf z_i = h_i(\mathbf X_i) + \mathbf v_i zi​=hi​(Xi​)+vi​

其中，zi\mathbf z_izi​ 表示第 iii 个实际观测，Xi\mathbf X_iXi​ 表示第 iii 个因子所连接的状态变量，hi(⋅)h_i(\cdot)hi​(⋅) 表示根据状态预测观测的函数，vi\mathbf v_ivi​ 表示观测噪声

例如 GNSS 因子可能是：

zkGNSS=pk+vkGNSS\mathbf z_k^{\text{GNSS}} = \mathbf p_k + \mathbf v_k^{\text{GNSS}} zkGNSS​=pk​+vkGNSS​

而 PDR 因子可能是：

zkPDR=h(xk,xk+1)+vkPDR\mathbf z_k^{\text{PDR}} = h(\mathbf x_k,\mathbf x_{k+1}) + \mathbf v_k^{\text{PDR}} zkPDR​=h(xk​,xk+1​)+vkPDR​

根据每个因子的观测模型，移项有：

vi=zi−hi(Xi)\mathbf v_i = \mathbf z_i - h_i(\mathbf X_i) vi​=zi​−hi​(Xi​)

因此可以定义第 iii 个因子的残差：

ri(Xi)=zi−hi(Xi)\mathbf r_i(\mathbf X_i) = \mathbf z_i - h_i(\mathbf X_i) ri​(Xi​)=zi​−hi​(Xi​)

也就是说，残差就等于实际观测减去当前状态预测得到的观测

此时实际上就有 ri=vi\mathbf r_i = \mathbf v_iri​=vi​，如果当前状态完全正确，那么残差理论上就是每个因子的观测噪声

假设每个因子的噪声都服从高斯分布：

vi∼N(0,σi)\mathbf v_i\sim\mathcal N(0,\sigma_i) vi​∼N(0,σi​)

其中，σi\sigma_iσi​ 为第 iii 个因子观测噪声的协方差矩阵

因为 ri=vi\mathbf r_i= \mathbf v_iri​=vi​，因此有：

ri∼N(0,σi)\mathbf r_i \sim \mathcal N(0,\sigma_i) ri​∼N(0,σi​)

根据多维高斯分布的概率密度：

p(vi)=1(2π)mi2∣σi∣12exp⁡[−12vi⊤σi−1vi]p(\mathbf v_i) = \frac{1}{(2\pi)^{\frac{m_i}{2}}|\sigma_i|^{\frac{1}{2}}}\exp\left[ -\frac{1}{2}\mathbf v_i^\top\sigma_i^{-1}\mathbf v_i \right] p(vi​)=(2π)2mi​​∣σi​∣21​1​exp[−21​vi⊤​σi−1​vi​]

因此：

p(zi∣Xi)=1(2π)mi2∣σi∣12exp⁡[−12ri⊤σi−1ri]p(\mathbf z_i\mid\mathbf X_i) = \frac{1}{(2\pi)^{\frac{m_i}{2}}|\sigma_i|^{\frac{1}{2}}}\exp\left[ -\frac{1}{2}\mathbf r_i^\top\sigma_i^{-1}\mathbf r_i \right] p(zi​∣Xi​)=(2π)2mi​​∣σi​∣21​1​exp[−21​ri⊤​σi−1​ri​]

这是高斯分布的一个典型性质：高斯分布加上一个常量后仍为高斯分布，只是均值会发生偏移

p(zi∣Xi)p(\mathbf z_i\mid \mathbf X_i)p(zi​∣Xi​) 的含义为：假设状态 Xi\mathbf X_iXi​ 已经确定，观测 zi\mathbf z_izi​ 会服从什么分布

而一旦给定 Xi\mathbf X_iXi​，hi(Xi)h_i(\mathbf X_i)hi​(Xi​) 就相当于是常量，那么：

zi=vi+hi(Xi)\mathbf z_i = \mathbf v_i + h_i(\mathbf X_i) zi​=vi​+hi​(Xi​)

就相当于是服从高斯分布的变量 vi\mathbf v_ivi​，加上一个常量，因此可以认为 zi∣Xi\mathbf z_i\mid\mathbf X_izi​∣Xi​ 也服从高斯分布：

zi∣Xi∼N(hi(Xi),σi)\mathbf z_i\mid\mathbf X_i \sim \mathcal N(h_i(\mathbf X_i), \sigma_i) zi​∣Xi​∼N(hi​(Xi​),σi​)

即变成以 hi(Xi)h_i(\mathbf X_i)hi​(Xi​) 为中心，方差仍为 σi\sigma_iσi​ 的高斯分布

对于优化 X\mathbf XX 而言，前面的系数和 X\mathbf XX 无关，因此：

p(zi∣Xi)∝exp⁡[−12ri⊤σi−1ri]p(\mathbf z_i\mid\mathbf X_i)∝\exp\left[ -\frac{1}{2}\mathbf r_i^\top\sigma_i^{-1}\mathbf r_i \right] p(zi​∣Xi​)∝exp[−21​ri⊤​σi−1​ri​]

假设初始状态先验为：

x0∼N(xˉ0,σ0)\mathbf x_0 \sim\mathcal N(\bar{\mathbf x}_0,\sigma_0) x0​∼N(xˉ0​,σ0​)

其中，xˉ0\bar{\mathbf x}_0xˉ0​ 是给定的初始状态，σ0\sigma_0σ0​ 是初始状态的不确定性

定义先验残差：

r0=x0−xˉ0\mathbf r_0 = \mathbf x_0 - \bar{\mathbf x}_0 r0​=x0​−xˉ0​

于是：

p(x0)∝exp⁡[−12r0⊤σ0−1r0]p(\mathbf x_0)∝ \exp\left[ -\frac{1}{2}\mathbf r_0^\top\sigma_0^{-1}\mathbf r_0 \right] p(x0​)∝exp[−21​r0⊤​σ0−1​r0​]

所以先验本质上也只是一个特殊的因子

现在我们把所有因子带回到后验概率：

p(X∣Z)∝p(x0)∏ip(zi∣Xi)p(\mathbf X\mid\mathbf Z)∝ p(\mathbf x_0)\prod_i p(\mathbf z_i\mid\mathbf X_i) p(X∣Z)∝p(x0​)i∏​p(zi​∣Xi​)

得到高斯形式：

p(X∣Z)∝exp⁡[−12r0⊤σ0−1r0]∏iexp⁡[−12ri⊤σi−1ri]p(\mathbf X\mid\mathbf Z)∝ \exp\left[ -\frac{1}{2}\mathbf r_0^\top\sigma_0^{-1}\mathbf r_0 \right]\prod_i \exp\left[ -\frac{1}{2}\mathbf r_i^\top\sigma_i^{-1}\mathbf r_i \right] p(X∣Z)∝exp[−21​r0⊤​σ0−1​r0​]i∏​exp[−21​ri⊤​σi−1​ri​]

利用 ea⋅eb=ea+be^a\cdot e^b = e^{a+b}ea⋅eb=ea+b 把连乘变成指数连加，可以得到：

p(X∣Z)∝exp⁡[−12(r0⊤σ0−1r0+∑iri⊤σi−1ri)]p(\mathbf X\mid\mathbf Z)∝ \exp\left[-\frac{1}{2}\left( \mathbf r_0^\top\sigma_0^{-1}\mathbf r_0 + \sum_i \mathbf r_i^\top\sigma_i^{-1}\mathbf r_i \right)\right] p(X∣Z)∝exp[−21​(r0⊤​σ0−1​r0​+i∑​ri⊤​σi−1​ri​)]

我们的目标是寻找概率最大的轨迹：

X⋆=arg⁡max⁡Xp(X∣Z)\mathbf X^\star = \arg\max_{\mathbf X} p(\mathbf X\mid\mathbf Z) X⋆=argXmax​p(X∣Z)

因为指数函数单调递增，所以等价于最小化指数中的负二次型：

X⋆=arg⁡min⁡X[r0⊤σ0−1r0+∑iri⊤σi−1ri]\mathbf X^\star = \arg\min_{\mathbf X}\left[ \mathbf r_0^\top\sigma_0^{-1}\mathbf r_0 + \sum_i\mathbf r_i^\top\sigma_i^{-1}\mathbf r_i \right] X⋆=argXmin​[r0⊤​σ0−1​r0​+i∑​ri⊤​σi−1​ri​]

定义：

Ωi=σi−1\Omega_i = \sigma_i^{-1} Ωi​=σi−1​

其中，Ωi\Omega_iΩi​ 就称为信息矩阵（Information Matrix）

于是目标函数可以写成：

X⋆=arg⁡min⁡X[r0⊤Ω0r0+∑iri⊤Ωiri]\mathbf X^\star = \arg\min_{\mathbf X}\left[ \mathbf r_0^\top\Omega_0\mathbf r_0 + \sum_i \mathbf r_i^\top\Omega_i\mathbf r_i \right] X⋆=argXmin​[r0⊤​Ω0​r0​+i∑​ri⊤​Ωi​ri​]

通常定义加权平方范数：

∥r∥Ω2=r⊤Ωr\|\mathbf r\|_{\Omega}^2 = \mathbf r^\top\Omega\mathbf r ∥r∥Ω2​=r⊤Ωr

因此可以进一步简化为：

X⋆=arg⁡min⁡x[∥r0∥Ω02+∑i∥ri(Xi)∥Ωi2]\mathbf X^\star = \arg\min_{\mathbf x}\left[ \|\mathbf r_0\|_{\Omega_0}^2 + \sum_i\|\mathbf r_i(\mathbf X_i)\|_{\Omega_i}^2 \right] X⋆=argxmin​[∥r0​∥Ω0​2​+i∑​∥ri​(Xi​)∥Ωi​2​]

这就是因子图优化最标准的数学形式

因为引入了信息矩阵 Ωi=σi−1\Omega_i = \sigma_i^{-1}Ωi​=σi−1​，如果某个观测噪声较小，更加可靠，对应 σi\sigma_iσi​ 较小，也即 Ωi\Omega_iΩi​ 较大，在目标函数中的乘法就会变强；反之如果某个观测噪声较大且不可靠，对应 σi\sigma_iσi​ 较大，也即 Ωi\Omega_iΩi​ 较小，对最终结果的影响相应会降低

所以本质上，越可靠的观测，在目标函数中的权重就越大，这和 WLS 中的 W=R−1W = R^{-1}W=R−1 思想完全相同，因此我们说因子图本质上可以转换为 WLS 的问题

现在我们回到 GNSS + PDR 的场景，如果只有：

  1. 先验因子
  2. GNSS 因子
  3. PDR 因子

那么后验状态可以按 “运动模型” 和 “传感器观测” 分开来写：

p(X∣Z)∝p(x0)∏kp(xk∣xk−1)∏kp(zk∣xk)p(X\mid Z)∝ p(x_0)\prod_k p(x_k\mid x_{k-1})\prod_k p(z_k\mid x_k) p(X∣Z)∝p(x0​)k∏​p(xk​∣xk−1​)k∏​p(zk​∣xk​)

其中，p(x0)p(x_0)p(x0​) 为最初始的状态先验，p(xk∣xk−1)p(x_k\mid x_{k-1})p(xk​∣xk−1​) 是状态转移 / 运动模型，p(zk∣xk)p(z_k\mid x_k)p(zk​∣xk​) 是传感器观测模型

如果是 GNSS + PDR 则具体可以表示为：

p(X∣Z)∝p(x0)∏kp(zkPDR∣xk,xk+1)∏kp(zkGNSS∣xk)p(X\mid Z)∝ p(x_0)\prod_k p(z_k^{PDR}\mid x_k,x_{k+1})\prod_k p(z_k^{GNSS}\mid x_k) p(X∣Z)∝p(x0​)k∏​p(zkPDR​∣xk​,xk+1​)k∏​p(zkGNSS​∣xk​)

也即：

后验∝初始先验×所有 PDR 约束×所有 GNSS 约束\text{后验}∝\text{初始先验}\times\text{所有 PDR 约束}\times\text{所有 GNSS 约束} 后验∝初始先验×所有 PDR 约束×所有 GNSS 约束

目标函数可以写成：

X⋆=arg⁡min⁡X[∥rprior∥Ωprior2+∑k∥rkGNSS∥ΩkGNSS+∑k∥rkPDR∥ΩkPDR2]\mathbf X^\star = \arg\min_{\mathbf X}\left[ \| \mathbf r^{prior} \|_{\Omega_{prior}}^2 + \sum_k\|\mathbf r_k^{GNSS}\|_{\Omega_k^{GNSS}} + \sum_k\|\mathbf r_k^{PDR}\|_{\Omega_k^{PDR}}^2 \right] X⋆=argXmin​[∥rprior∥Ωprior​2​+k∑​∥rkGNSS​∥ΩkGNSS​​+k∑​∥rkPDR​∥ΩkPDR​2​]

其中，GNSS 残差可以写为：

rkGNSS=zkGNSS−pk\mathbf r_k^{GNSS} = \mathbf z_k^{GNSS} - \mathbf p_k rkGNSS​=zkGNSS​−pk​

即表示当前状态位置与 GNSS 绝对位置之间差多少

PDR 残差可以写为：

rkPDR=(pk+1−pk)−ΔpkPDR\mathbf r_k^{PDR} = (\mathbf p_{k+1} - \mathbf p_k) - \Delta \mathbf p_k^{PDR} rkPDR​=(pk+1​−pk​)−ΔpkPDR​

即表示状态节点之间真实产生的位移，与 PDR 测到的相对位移之间差多少

最终的目的就是找一条轨迹，让 GNSS 绝对位置误差 + PDR 相对运动误差 + 先验误差，在各自的权重下整体最小
