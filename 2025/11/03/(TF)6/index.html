Padding

假设 Dataset 中的样本长度不同，我们需要对其做 padding 对齐，而 padding 对齐可以在两个地方做：

  1. 在 map 方法的 tokenizer 中对齐，也称为静态对齐，所有样本都会被 padding 到同一个长度
  2. 在 DataLoader 按 Batch 加载数据的时候进行对齐，也称为动态对齐，每一个 Batch 内的数据长度相同

静态对齐（Static Padding）的特点为所有数据形状统一、逻辑简单，但会浪费存储和计算，往往需要大量 Padding

动态对齐（Dynamic Padding）的特点为每个 Batch 的数据会 Padding 到本 Batch 的最大长度，而不是全局最大长度，通常会更加高效
